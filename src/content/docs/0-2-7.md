# 更新日志

## 新功能、选项与改进

*   全新 FFB 后处理脚本，可完全取代 FFB；
*   新的优化（实验性，默认禁用）：
    *   推迟可选功能，防止卡死；
    *   超线程修复（尝试让物理远离渲染核心）；

*   MoTeC 记录器：新增空气动力学速度与 Cosmic 悬架受力；
*   Drift Challenge 更新到 1.1；
*   物理实验：
    *   面向单帧碰撞生命周期的新碰撞检测逻辑；

    *   为树木阴影使用各向异性过滤的选项；
    *   自动分割时为第一人称视角禁用锐利车内阴影的选项；
*   全新加载画面：
    *   可隐藏某些组件的选项；
    *   用 Lua 脚本彻底替换外观的选项，附带一个基础脚本作为示例；
*   全新 Behavior（行为选项）：
    *   修复 AI 升挡阈值的选项现在默认启用（适用于升挡阈值高于 `limiterThreshold - 100` 的车辆）；
    *   更改 AI 降挡阈值的新选项（若升挡阈值已被修改则默认激活），会考虑挡位比；
    *   非常实验性的 AI 调整，为 AI 增加一些差异与适应能力，尽量让它们在可能时稍快一些；
*   Nice Screenshots：

    *   变形宽银幕（anamorphic）DOF 选项（散景看起来像径向模糊）；
    *   DOF 的色差选项（仅限 DOF）；
    *   DOF 相关选项可在照片应用中调整，包括快速开启累积 DOF；
    *   截图为每辆车使用独立立方体贴图的选项，反射更准确；
    *   若效果足够好，按 `enter` 可停止累积截图并保存结果；
    *   无动态模糊的累积 DOF 会把偏移从小到大排序，DOF 随累积增强，但观感始终不错；
    *   累积阴影：单一滑块拆分为独立滑块，并根据迭代次数实时调整，默认设置与太阳的正常角直径一致；
    *   为反射立方体贴图添加累积 AA 的选项；
*   默认 WeatherFX 样式：修复了 LCS 下的太阳光束，看到流星的概率略有提高；
*   GUI：在暂停菜单中启用应用的选项（将使用第五个游戏内桌面作为专门的应用布局）；
*   若车辆没有专用闪光灯，原版 AC 的 `Flash Headlights` 绑定现在会闪烁常规大灯；
*   GrassFX 着色更新，增加了更多层次与强度；
*   通用：可为 AC 显式选择所用网络连接的选项（适用于联机、`web.` API 与 Mumble 客户端）；
*   Render Stats 应用：三大核心分组的测量（加起来与整帧 CPU 和 GPU 时间接近得多），测量层级已修复；
*   加载期间对主板固件未更新的 Intel 13/14 代 CPU 的警告（检查是靠 ChatGPT 做的，我自己的硬件没法测试，但应该能用）；
*   自定义 VR HUD：跟随头显的实验性选项；
*   WindscreenFX：为外部视角的风挡添加反射的选项（主要是为了车门打开时玻璃内侧的观感）；
*   CSP 版本更改时清除部分 CSP 缓存的选项（默认启用）；
*   Mumble 客户端：音量滑块上限从 100% 提高到 200%；
*   Android Auto：浏览器现在应该能拦截一些广告了；

    *   `[SHADER_REPLACEMENT_…]` 新标志 `LINK_KS_VALUES = 1`，将 ksAmbient 与 ksDiffuse 同步（对大型赛道表面应该很有帮助）；

*   定位辅助（那些用来移动物的箭头和圆圈）在鼠标悬停于 UI 或使用 F5 相机时不再激活；
