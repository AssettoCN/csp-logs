# 更新日志

## 新功能、选项与改进

*   修复罗技方向盘 FFB 的问题，非常抱歉；
*   VR：
    *   修复 HUD 未在右眼中显示的问题；
    *   鼠标指针在点击、按下手柄按钮或触碰 HUD 表面时变色；
    *   调整 VR 中触碰 HUD 的阈值，降低烦人程度；
    *   控制器可视化（将控制器渲染为点和一条蓝线）已更新；
    *   修复控制器在新主菜单中不断选择不同车辆的问题；
    *   用控制器拖动 AC 应用可正常工作，控制器未能充当鼠标的其他类似问题也已修复；
*   更新后的车身音频已修复，回放中应能正常工作；
*   修复带宇宙悬挂的车辆在维修区内的离地间隙计算；
*   内置浏览器引擎更新至 v148，封装层做了若干优化和修复，最大标签页数增至 2000；
*   OptiScaler 加载器现在会尝试从旧版本迁移设置（删除 `assettocorsa\cache\binaries\optiscaler-0.9.2.1` 可使其运行）；
*   新菜单：在单机离线练习赛中，按住 Shift 即可在设置无效时开始驾驶；
*   修复使用 DLSS（或 TAA）时 MX-5 仪表盘指针的渲染；
*   修复媒体控制的偶发崩溃；
*   截图元数据更新并修复，现在与各种平台和应用的兼容性大幅提升；
*   `Redirect media players audio through FMOD` 选项再次禁用（直到被妥善修复）；
*   Weather FX：慢速立方贴图更新速度翻倍，使用 `ac.setReflectedSkyTweaks()` 不再（完全）激活该选项；
*   在 `tyres.ini` 中将 `LATERAL_RAYS` 设为 0 可强制禁用侧向光线，即使扩展物理正在激活它们；
*   新增 `ac.accessCarPhysics().turboBoost` 字段；
*   面向 Lua 应用新增 `ac.overrideAppLazyFlag()` 函数（有了它，Web Browser 应用就不必在有固定应用之前随 Assetto Corsa 一起启动）；
*   新增 `os.tweakMainWindow()`；
*   新增 `shared/vr/vrmisc` 库，用于调试时上报原始设备位置；
