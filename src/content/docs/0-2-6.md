# 更新日志

## 新功能、选项与改进

*   修复了 CSP 音频，例如雨声或雨刮音频；
*   修复了手柄上的 FFB；
*   补上了 Mumble 客户端缺失的音频文件（用于新 PTT 模式），该模式使用的失真效果已调整；
*   AI 的行驶轨迹拉直选项已重做，不再标记为实验性；
*   倾斜的车手不再弄坏动态模糊；
*   以防万一，倾斜车手与新的头部晃动都是可选的，可在 Graphics Adjustments 中禁用；
*   更新了车手与安全带的渲染逻辑，应该能修复一些边缘情况下出现的各种问题；
*   草地风效在禁用 Single Pass Stereo 的 VR 下工作；
*   修复了启用 Single Pass Stereo 时 TyresFX 的观感；
*   修复了 LCS 下 VR 中的 HUD 亮度；
*   新 KN5 加载器不再弄坏联机中的 GT86；
*   修复了交通车不可见的问题；
*   Cosmic 悬架更新，带有一些修复；
*   MoTeC 记录器：风向会考虑赛道航向角，无效圈不再被跳过，新增通道（外倾角/前束角符号、涡轮增压、表面抓地力与碰撞体磨损）；
*   Cosmic 悬架：虚拟元件（例如绞牙避震）安装在轮毂上时现在会正确计入 FFB；
*   第二追逐相机的替代脚本现在可用；
*   实时切换 H 挡换挡器的新快捷键；
*   AC 启动后头几秒内游戏内日期大幅变化时，胎痕不再淡出，橡胶痕迹在任何游戏内日期变化时都完全不会淡出；
*   胎痕会记录冬季季节调整，若保存时的值与当前差异过大则不会加载（影响尘土与砂砾风格的痕迹）；
*   树木再次在第四级联投射阴影，这次阴影是半透明的；
*   半透明阴影（`SEMITRANSPARENT_SHADOWS=1`）重叠时会产生更暗的阴影；
*   材质名含 `groove` 或 `tyre` 且以 alpha 混合渲染的赛道网格不再跳过 G-buffer 导致 SSLR 出错；
*   胎痕现在也能正确遮挡 SSLR 反射；
*   修复了 Shuto 上灯罩（以及其他纹理被错误分配的场合）的问题；
*   赛道灯光序列现在会缓存，提升了 Shuto 的加载速度；
*   修复了车辆污渍导致重置失效的小问题；
*   修复了当前播放音乐的读取，特别是专辑封面错乱的问题；
*   烟花不再在展厅模式激活，烟花烟雾发射器上限提高；
*   音乐未播放时车载音响也会更新时间，专辑封面按原始宽高比绘制；
*   修复了在聊天中按 `Tab` 键导致 AC 崩溃的问题；
*   在 `suspensions.ini` 中设置的图形偏移不再被视为默认值（那是个错误）；
*   音量应用：修复了变速箱音量的联动；
*   联机的 `CUSTOM_MOTION` 选项现在默认应用于要求 CSP 3266 或更新版本的服务器；
*   修复了 `DISABLE_SURFACE_SNAPPING_ONLINE`（`car.ini` 与扩展服务器选项中均可）；
*   VR Variable Rate Shading：视线锁定、隐藏选项以及调整视线方向的 API 函数；
*   ReflectionsFX：分辨率高于 512×512 时停止立方体贴图预过滤，运动外推改进；
*   离地过远的车辆不再黏着假阴影；
*   修复了动画悬架下 TyresFX 效果与车轮转动不同步的问题；
*   禁用 WeatherFX 时烟花不再弄坏天空；
*   默认 WeatherFX 样式：蓝色夜晚重做并默认禁用，YEBIS 替代获得了正确的 bloom 实现与脏镜头选项（默认禁用），胶片颗粒强度可调，行星已修复，即使在光污染下也可见；
*   地球纹理使用双三次插值；
*   土星有光环了；
*   修复了轮胎磨损减少的问题；
*   几个物理实验（alternate multithreading 与 physics objects motion）转为完成态，已启用并处处可用；
*   为所有物体启用双面阴影的赛道修复，现在对保存不正确的赛道也有效；
*   若服务器（在有其他车辆连接时）停止发送 UDP 数据包超过几秒，CSP 会显示警告；
*   WeatherFX：修复了无 SPS 的 VR 中场景渲染回调失灵的问题；
*   带动画悬架的车辆的初始车轮转动也会随机化；
*   刚性碰撞（发生在特殊的碰撞深度下，现在计算方式不同）不再有弹性且配置更好，主车永远不会使用简化的接触计算，确保即使在最离谱的情况下碰撞也保持稳定；
*   远处大灯眩光重做并回归（在更远处激活，以掩盖很多车的灯光与自发光没对齐的事实，现在也适用于其他车灯，目前仍默认禁用）；
*   即使没有 `ksTyres` 网格，轮胎钉也会在地面留下痕迹（仍然非常不推荐这样做）；
*   修复了 F5 相机偶尔故障变成黑屏的问题；
*   一项安全检查，确保相机不会落入非有限坐标；
*   若玩家车辆被发现处于非有限坐标，会显示警告消息；
*   非常实验性的技巧，可为联机选择特定槽位（适用于有多辆不同涂装车辆的服务器），CM 支持即将推出；
*   冰面物理：FFB 已调整；
*   AC 关闭流程已更新，更快也更稳定；

## 配置

*   赛道灯光新增 `DISTANCE_CLIP`，在特定距离处截停光照，用于额外优化，并可在不使用阴影贴图的情况下模拟一些基础阴影；
*   车辆配置新增 `[EMISSIVE_...] NO_FALLBACK_WHILE_BLINKING=1`，阻止回退值在主输入闪烁的 `off` 阶段激活；
*   `[MESH_ADJUSTMENT]` 与 `[SHADER_REPLACEMENT]` 的 `IS_VISIBLE`；
*   用 `DEBUG_OVERRIDE` 调试侧网偏移，可更改最终偏移量（在限度内）；
*   `DistantEmissive` 材质现在支持法线贴图（例如 Shuto 的灯罩在使用）；
*   可磨损碰撞体新增 `PROHIBIT_AC_RESET`，彻底阻止 AC 在会话重置时重置碰撞体磨损；
*   `[SHADER_REPLACEMENT]` 新增 `DIM_EMISSIVE_IN_CUBEMAP`；
*   侧网（以及使用相同倾斜机制的例如 BMW E30 的天线）会取 G 力的高频部分产生一点点额外偏移，观感更自然；
*   文件名以 `./` 开头时，赛道配置会在配置文件所在目录查找文件（为了保持兼容）；

## Lua & Python

*   修复了 `ui.imageState()`；
*   为 UI 设置 MIP bias 的函数现在也可以强制双三次插值；
*   一些 Lua 函数（例如 `io.` 和 `os.`）已被重写，标准库缩小了 15%，一些功能改为按需加载；
*   把车手标记为好友现在应该能用了；
*   新的 `os.setCurrentFolder()` 会影响文件搜索（包括标准 Lua 函数），不影响 AC 本身或其他脚本；
*   修复了 `web.socket()`（此前收到的数据经常乱码）；
*   修复了 Lua 预处理器，不再在 `ENUM..somethingElse` 场合生成无效代码；
*   Lua 着色器：可提示编译器把某些值编译进去的选项（应该能解决 YEBIS 替代更改设置导致卡顿的所有问题，现在所有设置都不是编译期常量，而是在运行一段时间后以编译期方式应用）；
*   从不带 `loop` 参数的文件加载的音频事件，播完后现在会报告为无效，因为它们确实失效了；
*   `:resetSkin()` 不再影响车辆动态纹理；
*   Lua 应用新增 `ac.setHShifterActive()`；
*   Lua Debug 应用：日志消息带时间戳；
*   `ui.drawCarIcon()` 有了提示参数；
*   `physics.resetWearPlanks()` 已弃用（`ac.resetColliderWears()` 的副本）；
*   新增 `ac.getSim().timeSinceLastUDPPacket`，以防万一；
*   传递 C++ API 函数的新方式现在会在期望字符串时把 `nil` 处理为空字符串，与旧方式一致（0.2.5 中会错误地变成 `'nil'`，`ac.setMessage()` 等函数受影响）；
