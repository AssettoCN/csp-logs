# 更新日志

## 新功能、选项与改进

*   全新烟雾：
    *   观感、形状和行为已调整；
    *   阴影与环境阴影稍作重做；
    *   基于碰撞盒而非球体的额外烟雾与车辆碰撞检查；
    *   排气烟雾；
    *   火焰产生的烟雾；
    *   发动机受损时冒烟；
    *   刹车盘过热冒烟（以上这些可能还需要调整）；
*   赛道条件新输入：`SPECTATORS`（观众数量减少时为 1 或更小）；
*   额外赛道音频事件的新选项：`BOUND_TO_SPECTATORS`；
*   全新 `TRANSPARENT_AS_BLACK` 混合模式：不混合，但透明区域绘制为黑色（用于通过配置修复现有模型；比如 Ruf Yellowbird）；
*   PBR 着色器大更新，主要得益于 Google 的 Filament 文档：
    *   全新且更新过的 PBR 纹理；
    *   改进了 PBR 纹理的应用；
    *   金属度取自 txDetail 的 alpha 通道；
    *   改进了能量守恒；
    *   修复了反射过强的问题；
    *   独立的 PBR 布料着色器，带光泽（sheen）与次表面颜色；
    *   清漆更简化也更准确；
    *   改进了与动态光源的交互以及 vertex AO 的应用；
    *   修复了法线混合；
    *   修复了灰色纹理上的 DXT1/5 伪影；
    *   可将 txDetail 模糊到只取颜色、不取图案的选项（图案改用 PBR 纹理）；
*   修复了车内遮罩的映射与亮度；
*   Object Inspector 应用已更新：
    *   全新布局；
    *   材质属性支持滚动、排序和筛选；
    *   可复制的区域取代了复制按钮；
    *   纹理查看器，帮助设置自定义自发光区域；
*   轮胎扩展光线检测的推力现在使用更好的公式；
*   雨刮动画在非焦点车辆上也能工作；
*   Brake Disc FX 与 Tyres FX 的默认磨损速度放慢；
*   修复了时域抗锯齿让风挡从车内看发模糊的问题；
*   修复了 SSLR 过度贪婪的问题，现在湿滑赛道上的车内视角应该更合理了；
*   Grass FX：
    *   更懒散的更新方式，稍稍改善性能；
    *   修复了车辆产生的环境阴影；
*   折射大灯会将表面标记为不透明，并支持内部网格的强制反射；
*   线光源：漫反射集中度选项生效；
*   车辆动画现在在远处也能工作；
*   改进了 TAA 的模板，按物体而非按材质生效，应该能减少内饰中的 TAA 伪影；
*   改进了车牌灯的光源定位（新参数 `MESH_FILTER_DIRECTION` 和 `MESH_FILTER_OFFSET`）；
*   所有着色器的高光现在都会随掠射角衰减，以消除某些伪影；
*   车漆新增 `NormalizeAO` 参数，设为 1 可改善 txDiffuse 中 AO 的应用方式（主要针对 txDiffuse 中带 AO 的车辆）；
*   全新 `CustomEmissive_AreaMask` 模板，可将四个区域用作遮罩；
*   少量小型优化与修复；
