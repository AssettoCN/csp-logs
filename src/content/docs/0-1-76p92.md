# 更新日志

## 新功能、选项与改进

*   联机动态天气条件，可通过服务器插件（文档即将推出）或自定义 acServer 实现提供；
*   用于隐藏和显示额外车身几何体的扰流翼状态现在会在联机中同步；
*   FSR：
    *   整个功能基于正式发布的 SDK 重做：
        *   画质预设现在有所不同；
        *   现在使用推荐的锐化级别；
        *   选项，按推荐调整 MIP 偏置；
    *   选项，三屏模式下为左右两侧设置更低的画质档位；
    *   可选的调试模式：按住 Space 快速切换到简单的线性放大以作对比；
*   烟雾完全重做（不含轮胎加热与生成逻辑）：
    *   全新的改进着色；
    *   改进了烟雾与车辆的碰撞；
    *   更好地支持开放式车轮赛车；
    *   极限漂移角度下轮胎烟雾在车底生成；
    *   尘土与水花在车身周围生成，而不只是来自车轮；
    *   尘土从沾满尘土的车轮上飞出；
    *   部分带木质滑板的 F1 赛车在滑板触地时会出现少许尘土（可按碰撞体逐个配置，类似火花）；
    *   碰撞时生成尘土云；
    *   接触点会生成更小的泥土碎屑颗粒与更小的水花；
    *   长效的烟雾与尘土（可持续数分钟）；
    *   在草地上时，不再生成尘土云，而是使用更细腻的土壤颗粒（颜色在赛道配置中设置）；
    *   排气、过热刹车与受损发动机的烟雾新观感；
    *   烟雾不会出现在座舱内；
    *   彩色烟雾与尘土随扩散失去饱和度，新增配置参数可调整速率；
    *   烟雾剔除改进，进一步优化并使过渡更平滑；
    *   调整密度与屏幕尺寸的新选项，在观感与性能之间取得平衡；
    *   烟雾覆盖整个屏幕的额外效果，以更低的成本获得相机陷入烟雾的效果；
*   碎片粒子更新：
    *   调整了各类碎片的概率、尺寸与着色；
    *   碰撞检测现在使用车辆高度图而非深度缓冲，结果更精确；
*   修复了火花粒子的尺寸，正碰时不再生成火花；
*   TyresFX：
    *   轮胎上的草地与泥土重做，纹理与渲染均是；
    *   考虑土壤颜色；
*   GrassFX：
    *   Active ExtraFX pass 选项现在正确支持车辆虚假阴影重投影；
    *   草形变更新，现在考虑草的高度；
    *   如果你使用原版 AC 运动模糊，它现在也会影响草；
*   新渲染模式：360°、鱼眼、分屏（新 Content Manager 支持 AC 视频设置中的自定义模式）；
*   为手柄输入模式指定手柄索引；
*   支持 VAO 补丁 v5，为动态物体提供空间 AO 采样；
*   新的天空网格，三角形分布更均匀，反射与镜子效果更好；
*   隐藏控制台的选项；
*   为自由漫游服务器创建通往其他服务器传送门的选项；
*   新照片模式应用的场景调整在应用隐藏时于回放中保持激活；
*   若 VR 初始化失败，加载画面会显示警告（如果你不小心选错了渲染模式，尤其有用）；
*   若 ExtraFX 因 AC 运动模糊而初始化失败，也会显示类似警告；
*   聊天快捷方式重做：新 UI 系统，不再触发涡轮变化，替代消息集采用不同方式实现；
*   选项，解除数字键与涡轮档位的绑定；
*   三屏调整：选项，始终显示车手名牌（使用原版系统）；
*   来自烟雾、火焰、半透明物体等的半透明阴影通过 Bayer 抖动得到改进；
*   限速器手动控制按钮（在默认会话设置下维修区内仍会自动启用，但在某些情况下可以覆盖）；
*   下车模块：设置、改进的过渡、几处修复、选中的车即受控车辆，以及让摆放车辆更容易一点的工具；
*   自由相机：使用踏板平滑控制相机速度；

## 配置

*   通过在 `extension/data_override` 文件夹中创建新文件，覆盖与视觉相关的车辆数据文件，如 `lods.ini` 或 `lights.ini`；
*   彩色阴影：整体观感改进，新参数；
*   遮罩通道着色改进，深色纹理下不再显得凌乱，新参数；
*   自定义车辆物理：
    *   创建与某个 AC 物理控制器关联的隐藏调校项（例如创建随车速自适应车身高度的悬架）；
    *   将离合器损伤与过高的扭矩关联；
*   自定义赛道物理：
    *   修复软墙，新增 `MAX_DEPTH` 选项，限制过深碰撞的柔软度（文档即将推出）；
    *   车辆生成时与赛道表面对齐（可选，由赛道物理配置 surfaces.ini 控制，启用自定义赛道物理时默认开启）；
*   用于深度碰撞的可形变赛道护栏（带软碰撞体），适用于轮胎墙等；
*   TyresFX：
    *   新的 `DIRT_OFFSET_K` 参数，类似 `DAMAGE_OFFSET_K`；
    *   选项，为不同轮胎设置自定义网格；
*   `[MESH_SPLIT_...]`：
    *   直接设置分割名称或材质，或使用现有材质；
    *   新模式 `COPY_FLIPPED`，修复缺失的内侧车窗；
    *   新的 `INSERT_TO` 选项，为新网格指定新的父节点；
*   参数 `[BOUNCED_LIGHT] AMBIENT_MULT=0.2`，用于减弱环境光对反弹光的影响，因为新的赛道 VAO 补丁已带有光反弹；
*   参数 `[REFLECTIONS_FX] INTERIOR_NODES=…`，针对未正确设置 `COCKPIT_HR` 的车辆，现在工作得更好，影响更多 CSP 功能；
*   KERS 的新车辆仪表输入；
*   额外车辆开关（那些额外的 A/B/C/D 功能）：
    *   新增额外的 E 与 F 开关；
    *   开关现在可以在配置中设置名称，加载时显示在车辆描述中；
    *   可选地，开关可以按住模式工作（按住按钮期间激活）；
    *   可选地，开关可以要求车辆静止才能激活（例如布加迪威龙的速度钥匙），或空挡，或踩下刹车踏板；
*   CSP 配置可以在加载画面上添加关于车辆功能的额外注释；
*   可调扰流翼现在可以一次影响多个节点（更容易让 LOD 正常工作）；
*   车漆着色器的新参数 `ColoredBlackSpecular`，改善多色涂装的观感，第四版自动启用；
*   为赛道设置土壤颜色，连同泥土与草地颜色；
*   选项，为不同类型的表面设置土壤、泥土与草地颜色；
*   新的赛道输入：
    *   `CAR_DAMAGE_N`，第 N 辆车的损伤量；
    *   `CAR_DAMAGE`，所有车辆的最大损伤量（可以联动救护车的车顶灯？）；
    *   `ONLINE_RACE`，联机比赛时切换为 1；
    *   `TIME_SMOOTH`：以秒计的一天时间，无舍入；
*   在条件表达式中，引用其他条件时不再需要写 `condition:` 前缀；
*   此前赛道参数只能是数字或引用条件的地方，现在完整支持表达式；
*   赛道灯光与材质调整的 `CONDITION` 现在也可以使用表达式（不过暂时不支持颜色）；
*   修复了参数 `MOVE_MESH_BEHIND` 与 `MOVE_MESH_IN_FRONT_OF` 无法在同一父节点内重排元素的问题；
*   赛道配置现在可以设置火焰发射器；
*   新的 `common/particles_track.ini`，附带一些赛道粒子预设（篝火、火炉、照明弹）；
*   新的 `common/displays.ini`，帮助轻松为车辆数字显示屏创建新的四边形面片；
*   如果你使用扰流翼动画来显示和隐藏额外部件，现在可以配置让 `hidden` 几何体真正隐藏，节省绘制调用：
    *   车辆灯光现在可以绑定到扰流翼状态，引用扰流翼 ID 并使用 LUT 作为亮度倍率；
    *   对于隐藏部件要么缩小要么移远的简单双状态场景，CSP 应能自动猜测；
    *   CSP wiki 上有快速生成此类动画及相应配置的工具；
*   从 Objects Inspector 复制坐标时，按住 Shift 进入超高精度模式；
*   修复了车辆的刹车输入，现在使用 `[BASIC] BRAKES_THRESHOLD` 作为默认阈值；
*   修复了半透明阴影的更改无法实时应用的问题；
