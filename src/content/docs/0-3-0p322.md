# 更新日志

## 新功能、选项与改进

*   AI 与 New Behavior：
    *   修复一个存在已久、影响多方面的 AI 通用问题；
    *   妥善重做了 `Straighten AI's trajectory when starting`；
    *   `Prevent AIs from redlining before the start` 也得到改进；
    *   `Adjust shifting for slow sectors` 现在应该可以工作；
    *   `physics.setAISplineAbsoluteOffset()` 应该工作得更好一些；
    *   冷却圈不再导致车辆在结束时不断传送；
    *   修复无头模式下 AI 倒车的问题；
*   修复玻璃材质丢失法线贴图的问题；
*   修复在线机器人误显示在地图上的问题（近期引入的回归），隐藏车辆不再显示在悬浮排行榜或新菜单中；
*   修复 CSP 在 Linux 上无法启动的问题；
*   修复车辆传送时模拟偶发死锁的问题；
*   Smart Shadows：
    *   重写自适应首级分割，不再应用于可驾驶视角和座舱视角；
    *   自适应首级分割选项重新可见；
    *   远级联更新，重新尊重树木纹理；
*   修复路面噪声升级的问题，调整了缩放（之前的 Perlin 就有点过高，新加的 simplex 更是相当狂野）；
*   修复新 KN5 加载器跨车辆共享材质的问题（此前基础材质随后又被涂装覆盖的情况会出错）；
*   Shader 会将输出颜色钳制以确保永不为负，这样即使材质配置得离谱也不会过分破坏渲染；
*   `nePBR` Shader 能稍好地处理清漆 F0 超过 100% 的情况（F0 永远不应超过 100%）；
*   Shader 更好地处理超过 100% 的 `extColoredReflection`；
*   后备 LOD 的形状和着色有所改进；
*   默认 Weather FX：草地着色和雾色调的小调整，新 `Volumetric fog` 效果（实验性，默认禁用）；
*   CSP Debug：
    *   改进传送预览的定位；
    *   按住 Ctrl 传送车辆时，如果点击位置在车上，不再产生力；
    *   切换额外车辆动画；
    *   额外 `observe` 命令的快捷方式；
    *   快速切换车辆 LOD 的辅助工具；
*   `Increase conditions limits` 调整默认启用，允许将路面温度设为 36° C 以上；
*   加载时修正 KN5 中不正确的（归零）法线，修复一些视觉瑕疵（尤其是 Windscreen FX 反射相关）；
*   Neck FX：`Maximum offset` 现在支持按轴配置数值；
*   碎片粒子：
    *   更新运动参数以增加视觉多样性；
    *   粒子不再在平面上滑来滑去；
    *   减少了稀有幸运粒子过大的问题；
*   从车轮和轮拱飞出的雨滴略有改进；
*   拍照应用：镜头标签页的布局更整洁；
*   分屏：
    *   稳定控制及其他 AI 调整不再应用于第二辆车；
    *   更改 ABS、TC 等的系统快捷键同时作用于两辆车；
    *   第二辆车的输入平滑已禁用；
    *   Grass FX 在第二视图中正确显示；
    *   第二视图也有了自己的反射立方贴图；
    *   修复车头灯强度的差异；
*   OBS 视图：
    *   新 `Higher quality` 选项，带专属草地生成和阴影集；
*   `ac.GeometryShot:update()` 新增重载，接受实际视图和投影矩阵，也有专属草地生成和阴影贴图的选项；
*   几何拍摄：草地改为在粒子之前绘制；
*   如果 HDR 已启用但不可用，通过 `ac.INIConfig.cspModule(ac.CSPModuleID.DXGITweaks)` 加载的配置中该选项将被禁用；
*   崩溃命名格式更新，稍短一些，但同时包含 CSP 版本；
*   修复灰烬运动；
*   游戏内车牌生成器更新，更好地应对纹理需要时间加载的情况；
*   INIpp：
    *   在模板/混入/生成器或常规节中使用 `@DISCARD=1` 可将其完全丢弃（比 `ACTIVE=0` 更好的选择）；
    *   添加 `@PARENT=SECTION_NAME`，从 `SECTION_NAME` 复制本节中不存在的值，可列出多个以持续复制缺失的值；
    *   在 `@OUTPUT` 中使用 `discard()` 丢弃最终节（适用于只生成生成器、不做其他事的模板）；
    *   几项小修复和优化（解析器提速约 60%）；
*   `ac.getCarBlindSpot()` 和 `BLIND_SPOT` 输入的检测范围从 20 米增至 200 米；
*   `ac.getSetupValue()` 在值缺失时返回真正的 `nil`，跨调用缓存结果，文档新增关于处理 `GEAR_SET` 的提示；
*   Gameplay API 新增 `ac.forceDetailedCarLOD()`，部分默认 OBS 视图用它来强制详细 LOD；
*   修复 `ui.progressBar()`；
*   `ac.CarPhysicsValueID` 新增字段，用于实时更改自动换挡器的参数；
*   Weather FX 风格新增 `ac.getSceneShadow()`，在相机位置采样阴影贴图（使用第四级联）；
*   场景 Shader 新增 `getApproximateSceneShadow(position)`（同样使用第四级联）；
*   在车辆数据中使用 `[HEADER] PARSER=INIPP` 即可使用 INIpp 特性（包括 include），或用 `read('data/car.ini/SECTION/KEY', 0)` 访问其他文件；
*   车辆非物理脚本（不含可脚本化显示屏）在无头模式下加载（显然，有些很酷的 MOD 用它们做物理相关的事，这我完全没预料到）；
*   即使 `GUIDs.txt` 是只读文件，CSP 也会加载它；
*   Render stats 应用的几项小修复；
