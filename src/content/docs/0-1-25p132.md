# 更新日志

## 新功能、选项与改进

*   Extra FX 默认禁用（之前是个错误的配置）；
*   修复了新材质库；
*   赛道材质库：更好用的水面与数字屏幕；
*   Stereo 车漆着色器已集成并可用；
*   新车漆着色器的镜面高光逻辑有变（文档即将推出）；
*   用于车窗与车灯的新 PBR 玻璃着色器，附带可选的光弹性效应（好吧，算是一次重现它的尝试）；
*   新的视差与细分着色器，暂时还没有材质库（即将推出）；
*   Stereo 为这些车漆着色器新增了镜面环境光；
*   重写了 SSLR 的光线追踪，以减少空洞、改善整体观感，并尝试提速（如果帧数掉得厉害，可降低分辨率）；
*   对 Extra FX 的一些优化；
*   HBAO+ 不再模糊累积截图；
*   累积截图下，Extra FX 动态模糊与 SSAO 平滑了许多；
*   电缆的问题修好了，办法是默认禁用；
*   树木不再使用 SSAO/HBAO+；
*   修复了远处漂浮的阴影方块；
*   修复了带阴影的车轮；
*   修复了卡死问题；
*   调整车辆各类事件音量的选项；
*   仅使用车内声音的选项；
*   更改赛道网格剔除模式的选项；
*   修复了累积模糊下的火焰；
*   PP 滤镜支持 INIpp（包括 `INCLUDE` 等在内）；
*   INIpp 解析改进；
*   一些小修复；
