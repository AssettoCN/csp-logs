# 更新日志

## 新功能、选项与改进

*   灯光改用新的 BVH 排序，应能提升性能；
*   除非常远的光源外，不再合并灯光；
*   所有光源都有高光；
*   仪表盘灯光检测应更可靠；
*   额外的反弹光；
*   动态反弹光颜色；
*   可隐藏和替换赛道网格的选项，Brands Hatch 的灯光就是一例；
*   可用 UV 坐标过滤赛道灯光顶点的选项（同样可以参考 Brands Hatch 的配置）；
*   正在制作赛道或灯光补丁，想让灯光在朝向相机时变亮？使用 ksPerPixel 着色器并将 ksAlphaRef 设为 -193；
*   自定义赛道上树木很多？将 ksTree 的 ksEmissive 设为负值（比如 -0.001），树木就不会再获得额外光照；
*   修复了后处理下虚拟后视镜的亮度；
*   Smart mirror 现在只在第一人称视角下生效（之前的做法太蠢了）；
