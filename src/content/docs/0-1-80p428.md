# 更新日志

## 新功能、选项与改进

*   RainFX：改进了对轻量级赛车的处理；

*   将 UI 绘制在其他 HUD 元素（例如 AC 车手名称或距离指示）之上的选项；
*   实时调整 FOV 的快捷键；
*   雨刮与车辆 Lua 脚本的音量滑块；
*   曲面显示器滤镜现在可以调整渲染比例；
*   滤镜编辑器中可用全新的色调映射函数；
*   灯光设置中可在镜子里使用精细阴影与高质量着色的选项（开销非常大）；

## 配置

*   多个配置的处理方式已更改，后续配置拥有更高优先级（例如，涂装配置中的 `[SHADER_REPLACEMENT_…]` 会在车辆配置的 `[SHADER_REPLACEMENT_…]` 之后应用）；
*   `[MESH_SPLIT_…]` 可以基于 UV 工作（为了 NeckFX 头盔渲染，不得不拆分 70 年代的头盔）；
*   额外灯光的新参数：`AFFECTS_TRACK = INTERIOR_ONLY`，阻止灯光同时影响车辆外观（例如很适合 GT3 的车内灯）；
*   车辆脚本可以使用条件（例如 `INPUT = …`），只在特殊情况发生时激活；
*   新的车辆输入：`FPS`、`FRAME_TIME_MS`；
*   车辆导航仪得到了一些修复与改进，例如更好的相机移动、全新的比例控件（用于自定义老式布局）或字体缩放选项；
*   InteriorPBR 着色器与弯折效果兼容；
*   弯道中的机油压力估计略低；
*   自定义纹理也支持实时重载；
*   新树木：新增关于处理不当的已编译树木的警告，默认将 GrassFX 表面作为表面，以确保法线同步（缺乏同步会破坏假阴影），draw call 与三角形计数正确；
*   将闪烁条件引用为另一个条件的输入现在可以正常工作；
*   用着色器替换节的 `INCLUDE_IN_SECONDARY_VIEWS=0` 可在次要视图（例如镜子）中隐藏网格；
*   网格拆分与网格优化提示重新可用了；
*   对轮胎版本低于 3 却带 `RIM_RADIUS` 参数的车辆给出警告（可能意味着有人把版本设错了，甚至可能少写了一个零）；
*   新的过滤器：`insideNthWheel:N`、`insideNthSuspension:N`、`driverRoot:N`、`driverNeck:N`；
