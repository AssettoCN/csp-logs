# 更新日志

## 新功能、选项与改进

*   序列式换挡的新绑定（应该比 CM 的次要绑定可靠得多）；
*   基于碰撞体的 LOD 更新：着色与形状都更接近实际模型；
*   全新的分屏比赛模式（从 Custom Rendering Modes 模块迁移而来，还附带一堆修复）；
*   隐藏远处车手的新选项；
*   Traffic 模式新增最高车速倍率选项，以及一堆修复与性能改进；
*   全屏模式下也可以延迟系统绑定（需要即将发布的 CM 版本）；

## 修复

*   修复了 Lua 音频；
*   AI 车手不再一窝蜂地同时驶出维修区；
*   OpenVR 延迟交换缓冲不再影响 FFB；
*   基于碰撞体的 LOD 与无 LOD 车辆限制兼容；
*   新音频应用：变速箱音量可以关联到发动机音量；
*   修复了加载自定义变速箱音量设置的问题；
*   车辆开关 G/H/I/J 的绑定已加入列表；
*   再次修复了自定义物理车辆的调校标签页顺序；
*   New Modes 与 Custom Rendering Modes 模块始终激活（不启用时不占用任何资源）；
*   VAO 补丁现在正确应用于车手 LOD B；
*   阴影车轮与车手不再只作用于最近的几辆车；
*   保存车辆状态时会包含木板（plank）磨损；
*   自定义车手模式加载更快，修复了 LOD B 的问题；
*   KN5 变更时 AI 载荷缓存会刷新；
*   修复了额外回放流（如带温度的刹车）的罕见崩溃；
*   绑定 POV 时的按键冲突提示问题应该已修复；
*   修复了加载某些严重损坏的 DDS 纹理时的崩溃；
*   一些小修复与稳定性改进；

## 配置

*   完整重载现在能正确重载灯光；
*   大部分自定义物理不再实时重载，以保持更稳定；
*   将蒙皮着色器替换应用到非蒙皮网格（或反过来）将不再生效；
*   `race.ini` 中的 `ALLOWED_TYRES_OUT` 在离线比赛中受尊重（值为负时除外）；

## Lua & Python

*   新的 `ac.blockSystemMessages()`，可过滤掉部分消息；
*   新的 `ac.StateCar.isDriverSeatbeltOn` 标志；
*   新的 `ac.GeometryShot():setOpaqueAlphaFix()`，用于在透明背景下正确绘制物体；
*   `ac.applyLiveConfigEdit()` 支持 `custom_rendering_modes.ini`；
*   面向 Lua 应用的新 `ac.loadCarControlsConfiguration()`，用于一些非常特殊的场合；
*   新的 `physics.setAllowedTyresOut()`（即使 Physics API 其余部分不可用，新模式中也可用）；
*   面向车辆物理脚本的新 `ac.StateCphysCar.fuelConsumption` 和 `ac.setFuelConsumption()`；
*   物理与自定义物理脚本 API 中的有限性检查已更改，应更有参考价值、更少崩溃；
*   修复了释放命名 Lua 纹理的问题；
*   释放 Lua 纹理时也会将其清空，以防万一；
*   附加到 AI 驾驶车辆的脚本不再显示系统消息；
*   修复了 `ac.SceneReference:loadKN5LOD()` 的内存泄漏与性能问题；
*   几个新的 Python 函数；
