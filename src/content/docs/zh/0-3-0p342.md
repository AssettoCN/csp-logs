# 更新日志

## 新功能、选项与改进

*   Extra FX：若干针对单屏和三屏运动缓冲区的修复，TAA 从零重写以提升清晰度、减少残影并改进抗锯齿，与树木风动画的兼容性更好；
*   放大技术：
    *   FSR2/3 现在应该可以工作；
    *   高级放大技术可在三屏模式下工作（侧边可降低画质也可不降，不过侧边同画质的情况仍需改进）；
    *   三屏侧边使用不同放大画质与部分放大技术的兼容性更好；
    *   `Disable for screenshots` 选项可被正确读取；
    *   OptiScaler 可正常下载；
*   像素密度：新增用于测试的 `Point` 放大器，新增 `Catmull-Rom` 放大器（观感接近 Lanczos 但更快，同时作为基础放大器的一个变体加入）；
*   针对新放大技术的几项小调整；
*   Revenant 模式：一项针对回放的修复；
