# 更新日志

## 新功能、选项与改进

*   AC 与 CSP 物理：
    *   修复原版 AC 中后续撞击覆盖悬挂损伤的老问题；
    *   热模型 v4 兼容 AI；
    *   限速器（`electronics.ini` 中的 `[SPEED_LIMITER]`）重写，更准确并防止振荡；
    *   `[_EXTENSION_FLEX]` 新参数：`VERTICAL_BENDING`、`LATERAL_BENDING`、`LATERAL_SHEAR`、`VERTICAL_SHEAR`、`LONGITUDINAL`（现在所有参数都能准确生效）；
    *   为 `[FRONT]` / `[REAR]` 新增 `EXT_DAMAGE_GAIN=<amount>` 参数，当行程超过同节 `EXT_DAMAGE_THRESHOLD` 时对悬挂造成损伤；
    *   可在 `engine.ini` 中添加 `[_EXTENSION] WATER_THERMAL_MASS=20 WATER_COOL_SPEED_K=0.002` 来调整水温计算；
    *   路面噪声重做：大量修复，现在独立作用于所有接触点；
    *   已完成的物理实验不再允许在线禁用，确保所有人条件一致；
    *   编辑自定义物理设置滑块时也会触发离地间隙重新评估；
    *   离地间隙最小时，只要离地间隙仍在变化，宇宙悬挂就会持续被检测；
    *   物理引擎使用 GIMPACT 检测碰撞，替代 OPCODE；

*   新任务栏：
    *   更改任务栏所在屏幕边缘的选项；
    *   配置图标对齐方式的选项；
    *   若干小修复；

*   新菜单：
    *   若圈速分段为空，则显示上一圈的分段数据，与原版行为一致；
    *   分段计时的舍入方式与原版菜单一致；
    *   比赛信息：点击顶部的会话可快速切换（在线模式下无法后退）；
    *   时间表：支持之前会话的成绩、不同车辆的成绩，修复打印功能；

*   Rain FX：
    *   降雨开始时的卡顿应有所减少；
    *   挡风玻璃的小修复；
    *   修复雨刮器在错误位置显示一帧的问题；
    *   调整溅水粒子的阈值；
    *   雨天兼容精确后视镜投影；
    *   修复雨水遮挡未能复用缓存变体的错误；

*   CSP Debug 应用：
    *   新增复选框，显示赛道实际表面起伏（受赛道表面噪声等影响）；
    *   新增用于破坏和修复悬挂的按钮；
    *   新增按钮，查看自动生成轮胎组的车辆的 `tyres.ini`；
    *   显示已保存车辆状态的轮廓及其距离；
    *   LOD 选择器会显示所选车辆的 LOD 距离倍率；

*   车辆状态保存重写：
    *   修复支柱式悬挂的跳变；
    *   保存更多数据：涡轮、控制器、ERS/KERS、宇宙损伤、额外宇宙体、自定义设置项的状态；
    *   修复 CSP 车身形变、车手移动或配重相关的问题；
    *   多个状态之间的插值及状态精度得到改进；
    *   修复状态变换函数，即使车辆不存在也能正常工作；

*   视觉效果：
    *   修复车辆反光问题；
    *   动态阴影：修复车头灯边缘问题，其他小改进；
    *   调整树木接收阴影的效果；
    *   大型 Grass FX 草块在靠近边缘时观感更好；
    *   假车轮阴影与表面噪声的兼容性更好；
    *   修复基于深度的粒子碰撞，火花和碎片现在可以出现在桥下；
    *   后视镜使用钳制采样器，修复偶发的渲染瑕疵；
    *   刹车火花被完全禁用，直到我找到更好的调校方式；

*   新增及变更的选项：
    *   DXGI Tweaks 新选项 `VRR / uncapped FPS`：自动（默认）只在 Windows 或 GPU 设置中开启 G-Sync 或 FreeSync 时解除帧率限制；否则帧率仍锁定在显示器刷新率以避免撕裂；
    *   新的天气控制器，可在多个天气之间切换：Schedule；
    *   现在可以禁用自由相机时的滚轮缩放；
    *   新实验选项：使用 FFmpeg 替代 Microsoft Media Foundation；

*   默认 Weather FX 风格：
    *   水洼音效在雨量和湿度为零时也能工作；
    *   闪电对场景的照亮更强；

*   展厅与 CSP 预览：
    *   修复生成预览时的崩溃和渲染问题，车身形变会暂停；
    *   展厅支持高斯泼溅（Gaussian splats）；

*   Neck FX：
    *   `Fix cursor in place` 默认禁用（与某些应用存在冲突）；
    *   旧运动方法在 AI 样条线重叠时不再出错；
    *   为 `vrc_rhp_helmet_b_fa` 模型新增头盔定义；

*   DualSense 触觉反馈：
    *   在方向盘输入模式下可用；
    *   以立体声方式运作（针对方向盘）；
    *   随主音量自动调整（不过主音量为 0% 时仍然无效）；
    *   若干修复；

*   音乐监视：
    *   新实现，更高效、更灵敏、信息更丰富；
    *   直接仅从音乐进程捕获音频，可精确跟踪峰值和音频频谱；
    *   实验选项：从内置音乐播放器跟踪峰值和频谱，默认禁用；
    *   AIMP 集成已更新，默认禁用；

*   杂项：
    *   为在线远程车辆提供简单的涡轮增压估算；
    *   `Flash lights` 按钮现在使用与闪烁远光灯类似的逻辑（新选项 `[BASIC] FLASH_HIGH_BEAMS=1`，默认开启）；
    *   若干 Surfaces FX 物理的小修复，改进与 Rain FX 的兼容性；
    *   新实验性控制器调整：转向外推（默认禁用）；
    *   Car Debug 应用：新增 `Dynamic & aero controllers` 板块，显示详细的控制器状态；
    *   车辆包围球计算重写，尽可能使用最低 LOD（与 AABB 相同），修复问题 MOD 带来的问题；
    *   CSP 现在使用 WIC 保存普通 PNG 截图，不再包含 Alpha 通道（此前如果累积 AA 被禁用，可能会弄乱截图）；
    *   支持 Radiance（`.hdr`）和 TGA 纹理；
    *   Shader 缓存清理重做，或许能改善初始化耗时过长的问题；
    *   默认计时模式切换为高精度计时器，`Sleep` 模式经过调整以提升响应速度；
    *   冻结性能分析可在 Render Stats 应用中启用，无需开发者板块中的该设置，另有小修复；
    *   `Check Intel CPUs` 选项重新启用（根据我做的所有检查，现在应该能正确工作）；
    *   HBAO+ 在后台初始化；
    *   大量后台 Shader 加载改进，以减少卡顿；
    *   超线程修复已重做，更好地兼容 Windows 11 和那些新颖的 CPU；
    *   极端帧率限制值与鼠标键盘事件的配合更好（基本上，任何此类事件都会促使下一帧提前到来）；
    *   `assetto_corsa.ini` 中更多值支持实时更改：`LOW_SPEED_FF`、`FORCE_FEEDBACK`、`FF_EXPERIMENTAL`、`OVER_TIME_MULT`、截图格式、污垢倍率和玻璃破损阈值；
    *   如果累积截图因某种原因被禁用，拍照应用功能（手电筒、预览等）仍应可用；
    *   Smart Shadows 新增隐藏的 `OVERRIDE_SPLIT` 设置，用于特殊情况，允许完全覆盖阴影距离；
    *   CEF 更新至 v150.0.11.0；
    *   `meshoptimizer` 库从 0.25 更新到 1.1；

## 修复

*   SFP 应兼容 altonline（及 P2P 模式）；
*   修复已禁用的辅助系统显示为已启用的问题；
*   修复回放中的排行榜；
*   修复若干与自定义物理相关的崩溃；
*   修复 P2P 与自定义物理在其他用户连接时偶发的崩溃；
*   修复与禁用原版火焰相关的偶发崩溃；
*   小幅性能改进，CSP 物理不再使用 MMCCS；
*   从主菜单直接跳到比赛会话不再导致车辆轮胎状态混乱；
*   修复仅有单个 LOD 的车辆消失的问题；
*   Test Pad 赛道不再因 `Do not wait for walls to be ready` 实验而出问题；
*   `Account for ping online`：偶发崩溃现在应该已修复；
*   偶发的 GPU 崩溃应该已修复；
*   Extra FX 在分辨率变化时不再丢弃所有内容，修复累积截图与 DLSS 的问题（或单纯的分辨率比例不同）；
*   修复在线会话中的会话名称（Lua API 和新菜单中）；
*   修复一个聊天设置中控制被禁用的老问题；
*   将滑痕导出为 OBJ 兼容 DLSS 及类似扩展；
*   Nice Screenshots：修复分辨率倍率；
*   新 KN5 加载器：修复包围球缓存未干净重置的问题；
*   改进与非线性（gamma）Weather FX 风格的兼容性；
*   IMGUI：可选滚动条不再导致宽高联动的组件（如取色器）闪烁；
*   完整重载不再破坏自定义灯光（例如 Light Maker 应用的灯光）；
*   包围球重算更新，速度稍快且更善于处理异常情况；
*   崩溃报告会包含运行在其他线程上的 Lua 脚本信息；
*   修复加载时调整窗口大小导致的崩溃；
*   修复 Walking Out 助手，现在加载车辆时朝向正确；
*   多显示器的小修复；
*   加载过程更加平滑；

## 配置

*   车辆：
    *   赛车也配备近光灯（此前赛车的 `[BASIC] IS_LOW_BEAM_AVAILABLE` 默认为 0，现在只有方程式赛车为 0）；
    *   车辆配置新增 `[AUDIO_PROPERTIES] WHEEL_BRAKE_TEMPERATURE=1` 参数，用于向车轮音频事件传递 `brake_temperature` 参数；
    *   车载音响新增 `SKIP_FRAMES` 参数（默认为 3）；
    *   车载音响修复：更好的字符查找、跳帧改为基于时间而非帧数、有真实频谱时提升刷新率；
    *   即使 `DIFFUSE_CONCENTRATION` 低于 0.7，车头灯也会投射阴影（反正它对车头灯也没有其他影响）；
    *   `CORNERINGLAMP_…` 车辆输入：新增 `MAX_SPEED_KMH` 参数，默认 40 km/h；
    *   修复维修区内后宇宙悬挂离地间隙检测的问题；
    *   `DISABLE_NEW_FLAMES_ENTIRELY` 选项现在按预期工作；
    *   `general.ini` 新增隐藏选项 `[DEV] EXPORT_RAIN_TYRES=…`，允许导出生成的雨胎纹理；
    *   车辆布料旗帜物理重写（仍需进一步完善）；

*   赛道：
    *   新增 `[GRASS_FX] COLOR_SAMPLE_MIP_LEVEL=…` 参数（默认为 0，调高可让草的颜色更平滑）；
    *   基于 ksanim 的赛道动画新增 `DELAY_BETWEEN_RUNS`；
    *   编辑被包含的赛道配置不再不断触发完整重载；

*   车辆与赛道通用：
    *   `[MESH_ADJUSTMENT_…]` 新增 `RECOMPUTE_TANGENTS = 1/INVERT` 选项；
    *   修复 `make-rgba::` 和 `make-script::` 纹理；
    *   Objects Inspector：点击并拖动一维数值可临时更改；
    *   新增深度模式：`WRITE_ONLY`（用于特殊情况）；

*   会话：
    *   新会话调整（离线与在线均可用）：`[EXTRA_RULES] BACK_TO_PITS_PRESERVES_DAMAGE=1`，传送回维修区时不再重置车辆损伤；
    *   离线比赛新增 `[EXTRA_RULES] CHANGE_TYRES_PER_AXIS=1` 参数，允许通过快速进站菜单仅更换前轴或后轴轮胎（在线比赛方面，下次 CM 更新将提供复选框；若启用且用户选择同时更换两轴轮胎，换胎时间翻倍）；
