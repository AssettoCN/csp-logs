# 更新日志

## 新功能、选项与改进

*   修复了滴答模式下的自定义动画（0.1.53 中损坏）；
*   车漆纹理的自动重载现在也适用于 txDiffuse 以外的纹理；
*   赛道条件新输入：一年中的第几天、星期几、当前节日（更多细节见 wiki）；
*   `[SHADER_REPLACEMENT_...]` 的 `SKINS` 参数现在不区分大小写；
*   使用稳定化矩阵的 Smart Shadows 或许效果更好，但需要更多测试；
*   缺少刹车痕时 AC 不会再崩溃了；
