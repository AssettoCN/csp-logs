# 更新日志

## 新功能、选项与改进

*   黑色斑点已修复；
*   使用 ksTree 和 ksGrass 着色器的车辆现在显示正确；
*   INI 文件又添了一些功能：
    *   include 和变量有了更好更简短的语法；
    *   引号已修复，现在支持 `\`；
    *   变量替换已修复并改进；
    *   模板；
    *   Mixins；
    *   表达式；
    *   函数；
    *   独立的解析器（[https://github.com/ac-custom-shaders-patch/inipp](https://github.com/ac-custom-shaders-patch/inipp)），以及该格式的文档；
*   新的 include 可用作材质库；
    *   使用时请小心：它们比 `dev_` 文件可靠得多，但仍然会变动；
*   新车漆着色器已修复：清漆层现在有单独的厚度参数，色调改为叠加颜色而非相减；
*   车漆着色器新增金属度参数；
*   新的备选车漆着色器，用于变色龙效果、彩虹镀铬以及各向异性彩虹镜面高光；
*   赛道条件新增 `BOUND_TO_SPECTATORS` 属性，将输出乘以观众数量；
*   其他小修复；
