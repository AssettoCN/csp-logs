# 更新日志

## 新功能、选项与改进

*   Nice Screenshots：
    *   新选项：
        *   自定义文件名格式；
        *   使用焦点车辆而非主车辆的名称；
        *   新截图的元数据；
        *   用 AMD FidelityFX CAS 额外锐化（默认 10%）；
    *   正确显示累积进度，不再闪烁（需在 AC 视频设置中启用 FXAA）；
    *   修复了分辨率倍率带来的伪影；
*   那个新的照片模式应用：
    *   构图网格，颜色和形状可自定义；
    *   新的纵横比滑块（竖向比例会在内部旋转相机以充分利用分辨率）；
    *   保存前预览显示时可调整锐化（可在 AC 内的应用设置中开启）；
*   通过配置替换模型：
    *   （可选）多次添加同一模型；
    *   合并模式，合并同名节点的内容；
    *   调整所插入模型的位置、旋转和缩放；
    *   新的 `INSERT_IN` 作为 `INSERT_AFTER` 的替代，用于指定父节点；
    *   新的 `SKINS` 选项，指定替换生效所需的车辆涂装；
    *   现在支持 `ACTIVE` 选项；
    *   `INSERT_IN`、`INSERT_AFTER`、`HIDE` 等可使用网格过滤器；
    *   新的模板配置 `custom_rims.ini`，每个 LOD 四行即可设置自定义轮圈；
*   联机改色已修复；
*   三屏下 Smart Shadows 已修复；
*   小修复；
