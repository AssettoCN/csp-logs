# 更新日志

雨还没有到来，但已接近完成，视觉部分现在基本做好了，只剩几件事。至于这次更新，主要是大量修复，但也有一些新功能：

## 新功能、选项与改进

*   新的屏幕空间环境光遮蔽模式，ASSAO；
*   新的胎沟着色器，观感改进，并为发动机损坏的车辆加入漏油效果（将自动使用）；
*   Weather FX 使用的新的更精确天空着色器；
*   离合器会记录在回放中；
*   累积 DOF；
*   新照片应用：ƒ 值滑块，用于调整 DOF 强度；
*   现代车辆默认改回四种雨刮模式；
*   同时工作的光源最大数量略有提升；
*   累积截图的阴影更好，附带少量基于距离的精确模糊；
*   Tyres FX：反射遮蔽，减轻轮拱下的反光；
*   用油门踏板、右扳机或关联按钮开始比赛的选项（位于 GUI 分区）；
*   几个改进 FPS 限制器行为的选项（位于 General 分区）；

## 修复

*   修复了 SSLR 模糊；
*   修复了截图后折射损坏的问题；
*   修复了部分赛道上某些位置大多数物体变黑的问题；
*   海市蜃楼与大气扭曲不再因车辆驶过而过度消退；
*   车辆 Fake shadows 现在能正确遮挡 SSLR；
*   修复了 Fake Shadows FX：车轮不再有奇怪偏移，阴影不再缺失（但愿如此）；
*   修复了 Weather FX 中反射里天空更亮的问题；
*   修复了 Tyres FX；
*   修复了扩展物理的几个问题，包括 P13c 的问题；
*   减轻了折射引起的闪烁；
*   修复了 VR 下 Graphics Adjustments 的裁剪问题；
*   新雷达应用上不再出现离线车辆；
*   修复了未启用 Extra FX 时烟雾渲染在风挡之上的问题；
*   修复了与着色器替换相关的崩溃与各种小故障；
*   更新了破损玻璃着色器，噪点更少；
*   修复了 `ksMultilayer_fresnel_nm_ps` 的法线贴图问题；
*   新车手名牌在联机中正常工作；
*   修复了其他一些性能与稳定性问题；

## 配置

*   感谢 @Stereo，现已内置着色器 stFlow；
*   轮胎着色器改进，新增选项，可将 txNormal 的 alpha 通道用作粗糙度贴图；
*   现在可以将导航仪、车载音响与模拟里程表合并到单个网格中（车辆动态纹理的许多新扩展即将推出）；
*   自定义自发光新增 `FALLBACK_BASE_COLOR` 与 `FALLBACK_IDLE_COLOR` 选项；
*   `DEPTH_MODE` 新值 `NORMAL_FORCED`，可为半透明网格覆盖 `READ_ONLY` 行为；
*   车辆仪表的 ABS 输入返回实际模式，而不再只是 0 或 1；
*   网格过滤关键字 `alphaBlend:no` 与 `alphaTest:no` 现在可用；
*   新的对象过滤关键字：`driverPiece:yes`，用于车手模型内的部件；
*   PBR 玻璃着色器新增模糊后方景物的选项，非常适合开放式轮式车辆玻璃的边缘；
    *   此外，它还新增了边缘检测选项，可找到朝向特定点的边缘；
*   遮罩 pass（用于有色玻璃的那个）现在可用于风挡着色器；
*   法线平滑现在也可应用于物理网格（反正法线并不影响物理）；
*   导航仪小幅更新，加入新控件与新导航主题 `[Navigator_StyleNavitel]`；
*   着色器 `ksPerPixelAT_NM` 新增光线反弹选项；
*   车窗着色器（带假车内灯光）的反射新增轻微扭曲选项，并修复了从上方观看时的小问题；
*   配置更改时的双重重载现在应会减少；
*   `ksWindscreen` 新增 `bannerMode` 选项，非常适合有色玻璃或 banner 条；
*   `NODE_ADJUSTMENT` 新增 `MOVE_IN_FRONT` 选项；
*   树木与草本着色器的动态光源获得少许背光与增强；
*   新刹车盘着色器的雕刻感更明显；
*   Weather FX 新函数 `ac.setGlareBloomLuminanceGamma()`；
