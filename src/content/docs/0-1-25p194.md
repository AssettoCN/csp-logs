# 更新日志

## 新功能、选项与改进

*   修复了后视镜；
*   Particles FX：
    *   新烟雾的灰尘效果（开发中）；
    *   修复了新烟雾的行为；
    *   可为轨迹（traces）的不同状态设置可选的亮度倍率；
    *   设置轨迹发射位置的选项；
*   `SHADER_REPLACEMENT_…`：
    *   相对原始值修改着色器属性（增加 X 或变为 X 倍）；
    *   蒙皮网格现在也可以修改了；
*   Vertex AO：
    *   支持车辆与坐在车内的车手；
    *   缩放后会作用于反射；
    *   补丁可以包含 `SHADER_REPLACEMENT_…` 节，允许在必要处增大 `ksAmbient`；
    *   gamma 选项；
    *   AO 分离，实现平滑过渡；
    *   备用 AO 集（用于车手阴影）；
    *   为动态物体提供额外的 AO 采样，又快又可靠的环境光遮蔽；
    *   修复了加载缓慢的问题；
*   网格拆分为元素的流程已优化（为勒芒准备远处自发光现在只需 0.02 秒，而不是 5.2 秒）；
*   Weather FX：
    *   访问赛道配置的 API；
    *   改进了云层光线调暗效果；
*   Vertex AO 与 SSAO/HBAO+ 支持 stPerPixelMultiMap_specular 着色器；
*   新的基于 MultiMap 的数字屏幕着色器，支持遮罩；
*   远处自发光的混合效果更好；
*   自由相机的新 Python 函数：`ac.ext_setCameraPosition()` 和 `ac.ext_setCameraDirection()`；
*   修复了仪表；
*   警笛模式支持手柄了；
*   修复了 VR 中阴影被禁用的问题；
*   新的禁用阴影着色器组，漫反射阴影使用 VAO；
*   SSGI 现在作为光源应用，而非后处理效果；
*   Freer Camera：
    *   记录与恢复位置，可选平滑（延迟）；
    *   也可以选择记录并恢复回放位置；
*   更多小修复；
