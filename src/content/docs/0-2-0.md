# 更新日志

## 新功能、选项与改进

*   物理：
    *   Cosmic 悬架更新与修复（参见文档）；
    *   每个轮胎多条检测射线（这次做对了），启用自定义物理时可用；
    *   一批物理核心改进，让碰撞更稳定等；
    *   太阳阴影影响路面温度的选项；
    *   车身形变（需在车辆数据中配置）；
    *   卡丁车可让车手用 VR 头显、红外追踪或额外按键移动重心；
*   控制与 FFB：
    *   所有方向盘轴（不只是刹车）都可配置 gamma；
    *   新的替代软锁实现，适配任何方向盘，应该更平滑、更少弹跳；
    *   用 Lua 创建 FFB 后处理脚本的选项；
    *   可选的 FFB 效果，为脏污轮胎添加振动（默认禁用）；
*   应用：
    *   集成 Mumble 客户端，轻松为联机服务器加入语音聊天，用户无需额外安装任何东西；
    *   新的 App Shelf 应用，包含一批可直接从 Assetto Corsa 安装的额外应用（部分应用已移至那里）：
        *   Car Mirrors：调整 Real Mirrors 设置；
        *   Controller Tweaks：实时配置方向盘、手柄与键盘控制，更改 FFB 与手柄按键；
        *   Flashlight：小工具，为相机加一点光，方便配置；
        *   Paintshop：用鼠标或手写笔直接在车辆与赛道上作画；
        *   Pocket Technician：在离线练习中实时编辑调校；
        *   Radar：从上方查看附近车辆；
        *   Setup Exchange：在调校菜单中分享与下载调校；
        *   Time Shift：在离线练习中按住按键倒回时间；
        *   Unbound：访问你可能忘记绑定到按键的任何功能，例如转向灯、雨刮或制动平衡调整；
        *   Web Browser：浏览网页并将网页固定为新应用；
        *   新的内置 CSP Debug 应用，可微调一些东西，或在练习中拖动车辆；
        *   新的 `View & Settings` 应用，可实时编辑部分画面设置；
*   WeatherFX：
    *   样式可以完全取代 YEBIS 后处理，观感与性能更佳；
    *   默认样式视觉效果更新；
    *   默认样式有了轻量的 YEBIS 替代品，无需再禁用后处理；
*   WindscreenFX：风挡中正确动态反射的选项；
*   ExtraFX：三屏支持；
*   BrakeDiscFX：可用时，发热改用物理温度而非近似值；
*   NeckFX：改用 Lua 脚本替代旧实现，头盔渲染选项大幅重做；
*   Smart Mirrors：降低刷新率并重投影的选项，保持流畅并提速；
*   自动驾驶（Ctrl+C）的一些更新，原始行为可在 General 设置组中恢复；
*   按实时比赛位置重排 AC 排行榜（F9）条目的选项；
*   将 UI 渲染在其他 HUD 元素之上的选项；
*   大量新的后处理色调映射函数，包括创建自定义函数的能力；
*   照片模式：移轴镜头模拟，可用不同方式扭转焦平面，支持 `.CUBE` 色调映射；
*   截图的 Steam 集成；
*   渲染比例选项，改善性能并在高 dpi 屏幕上缩放 UI；
*   改进 DualSense 与 DualShock 支持：LED、陀螺仪转向、触觉反馈等；
*   没有手柄时，可用移动设备的陀螺仪转向；
*   简单 AI 可以使用更基础的路线（默认禁用），或在被挡时表现得不耐烦；
*   面向曲面屏的新后处理滤镜；
*   CM 可用 CSP 生成车辆预览图，用上其全部视觉特性；
*   OBS 集成（需安装 OBS 插件，链接在 Small Tweaks 设置中）；
*   碎片粒子与痕迹重做，外观与行为改进；
*   正式的 emoji 支持（Python 应用需显式启用）；
*   设置重新整理并稍作清理（后续还会清理更多）；
*   VR：空间音频增强选项，不在镜像画面中渲染 HUD 的选项；
*   其他一些更新、优化与一批修复；
