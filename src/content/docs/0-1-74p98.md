# 更新日志

## 新功能、选项与改进

*   双精度物理引擎，改善大型赛道上的物理与 FFB；
*   Graphics Adjustments 中新的 Origin Shift 功能，修复大型赛道上的画面抖动；
*   影响所有车辆与赛道的新通用配置；
*   高级剔除大规模重写，提升其性能；
*   DXGI tweaks 新增几个选项（与 flip model 无关）：
    *   根据 AC 视频设置中所选屏幕使用 GPU；
    *   真正的无边框模式；
    *   三重缓冲与自定义最大帧延迟；
*   赛道的 SIMD 加速可见性剔除选项；
*   选项，AC 最小化或在后台时禁用音频；
*   智能后视镜：选项，覆盖镜子的渲染距离；
*   雷达应用：颜色设置，外观更新；
*   得益于新的内置加载分析器，加载的流畅度与信息量大幅提升；
*   加载现在应该更快，还可通过缓存进一步提速（默认启用）；
*   修复了 VAO 偏暗的问题，gamma 可动态调整；
*   崩溃消息重做，现在带有额外的检查与提示；
*   崩溃报告包含 CSP 设置预设；
*   声速会考虑温度等因素；
*   GUI：可选的油门与刹车踏板重叠警告；
*   联机自定义颜色现在可跨会话保存；
*   自适应近裁剪面选项，改善相机远离车辆与赛道时的观感；
*   自定义 VR 镜像：新模式，仅显示右眼，以及无畸变地显示双眼；
*   传送目的地列表更紧凑，支持分组并可筛选点位；
*   后处理折射改进；
*   破碎玻璃着色器再次重做；
*   AI 线路录制不规范的赛道上与 AI 相关的崩溃应该已修复（它们只会原地不动）；
*   联机：管理员现在可以手动处罚（需要服务器要求 1476 或更新版本的 CSP）；
*   现在使用车辆高度图判断自由相机是否在车内；
*   后方其他车辆照亮你的车辆时，现在会从后视镜产生额外的光；
*   用于车手头部的新着色器（目前仅非蒙皮版本），观感更动态；
*   车门动画与举牌的维修站工作人员会随 AC 一同暂停；
*   通过配置为赛道设置虚假环境阴影，为那些静止车辆下方添加一些暗部；
*   小调整：以防万一，可调整 VR 双眼间距的选项；
*   少量小优化；

## 配置

*   TyresFX：在配置中为特定轮胎类型指定轮胎花纹；
*   车辆扩展物理：
    *   选项，联机时使用真实质量，改善重型车辆的碰撞；
    *   重新定义碰撞参数的选项；
*   赛道扩展物理：
    *   选项，联机时为车辆使用真实质量；
    *   为不同表面重新定义碰撞参数的选项；
    *   选项，在表面与车辆网格碰撞体之间使用刚性碰撞，尽量防止某些极端情况下车辆穿落；
*   用于高级轮胎碰撞检测的扩展光线追踪使用更少的采样数以提速；
*   INIpp：include 现在可以是可选的，文件名支持表达式，新增函数可访问和修改已解析的内容；
*   车辆与赛道配置的 `read()` 新增输入；
*   赛道灯光的新参数 `SHOW_IN_REFLECTIONS`（请谨慎使用，默认只为提速而包含范围超过 10 米的灯光）；
*   新的过滤关键字：节点的 `insideWheel`、`insideSuspension`，材质的 `driverPiece`、`isTextureDefault:<texture name>`；
*   车辆灯光：远光与近光的色调；
*   车辆灯光与自定义自发光：分离的上升/下降延迟、自定义加热颜色及其他参数；
*   设置 `set observeDigital 1` 现在不应再使 AC 崩溃；
*   车辆调试应用现在显示风扇气动力；
*   旗帜可选的更高曲面细分率，阴影同样应用曲面细分；
*   新的半透明阴影模式：NORMALS，考虑表面以在掠射角衰减阳光，非常适合弯曲玻璃；
*   CSP 会较晚渲染车窗网格以确保正确的视觉效果：此类网格的过滤器现在可以更改，以包含自定义饰带之类的内容；
*   Objects Inspector 应用：
    *   选择蒙皮网格；
    *   现在也会显示点击点的表面法线；
    *   额外工具，简化赛道虚假环境阴影的创建（未选中任何内容时点击 `…` 按钮）；
*   光弹性 PBR 玻璃现在也支持多自发光；

## Lua & Python

*   修复了 Python 函数 `ac.ext_loadIniFileAsJson()`，`ac.ext_parseIniFileToJson()` 更名为 `ac.ext_parseIniAsJson()`（旧名称仍可兼容使用）；
*   新的 Python 与 Lua 函数，可获取赛道坐标、时区，以及检查 WeatherFX 是否激活；
*   新的 Lua 函数：`ac.getSoundSpeedMs()` 获取精确声速，`ac.getAudioVolume('key')` 获取音频音量级别；
*   新的 WeatherFX Lua 函数：`ac.setVAOExponent(gamma)`，为顶点 AO 设置 gamma；
*   Lua 音频事件新增音调参数；
*   Lua Debug 应用更新：可复制的存储与调试值，错误信息中的文件可点击（在支持的编辑器中打开文件并定位到正确行）；
*   标准 Lua 库现在以字节码形式附带，以优化加载；
