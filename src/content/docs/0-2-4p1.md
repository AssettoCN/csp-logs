# 更新日志

## 新功能、选项与改进

*   WeatherFX：提高条件限制的选项，允许控制器把温度和风速设到安全范围之外；
*   General/Development（底部）新的实验性选项，在联机中启用即时回放；
*   新的应用切换器，按 Ctrl+Tab 呼出（只要按住任意修饰键，Tab 键就不再显示排行榜）；
*   新任务栏：桌面图标换成预览图（需要的话可在设置中改回图标）；
*   默认 WeatherFX 样式：
    *   新的高层云；
    *   夜晚的流星（不过看到的概率相当小）；
    *   极光观感略有改善；
    *   所有额外效果现在都是可选的；
*   物理实验：
    *   碰撞体提前激活重新默认启用，这次安全得多，改为根据触地车轮数量判断；
    *   调整车辆碰撞体网格的新实验：确保碰撞体提前激活不会再出以前那些问题；
    *   碰撞盒垂直方向扩展的新实验：减少碰撞盒穿入地面的概率，从而减少车辆平摔时整场穿过去的情况；
    *   AC 暂停时转向角平滑过渡到 0° 的新实验（确保这种突变不会弄坏东西）；
*   电台更新（如果你在 AC 里想念音乐的话；感谢 badradio.nz 的点子）：
    *   电台列表与实际播放改由 CSP 处理，Lua 脚本可以接入并进行控制；
    *   默认电台列表更新，加入更多较新的电台；
    *   CSP 使用 radio.co 和 laut.fm 提供的高级 API，收集当前播放音乐的额外信息；
    *   Android Auto：播放移到 CSP 侧，支持专辑封面和曲目信息等新特性（若有提供）；
    *   App Shelf 上新的 Internet Radio 应用：启动时自动恢复播放（可选，默认启用），还有管理电台列表的便捷 UI；
*   照片模式应用：
    *   查看完整截图时可用鼠标滚轮缩放；
    *   带分辨率倍率的截图用 FSR 做降采样（放大查看时除外）；
    *   预览截图热键又能用了，现改为 Alt+F8（显然 Ctrl+F8 是切换鼠标的）；
*   Smart Shadows：
    *   基于距离自动计算级联的选项，调整更简单、级联布局更好；
    *   在相机周围绘制阴影而非只在前方绘制的选项；
    *   阴影稳定性大幅提升；
*   新的 AI Spline Editor 应用：加载 AI 线路，通过拖动调整轨迹和两侧边界；
*   新的 CPU 优化，阻止为其他车辆加载部分音频采样（对 30 辆车以上的服务器可能有点帮助）；
*   Small Tweaks 新选项，提高网页浏览器后端进程的 GPU 优先级（默认启用，应能避免 Windows 11 HAGS 的问题）；
*   GUI：将 AC 应用与 IMGUI UI 一起绘制的选项，互操作性更好，模糊背景也一致；
*   ExtraFX：仅在回放中使用特效的选项；
*   CSP Debug 应用：渲染车辆碰撞体的选项；
*   新暂停菜单：管理员可直接从中重启或跳过会话；
*   Traffic planner：带偏移复制车道，导出线路时可指定垂直偏移；

## 配置

*   远处灯光可通过新的 `[LIGHTS_DISTANT_LAYER_…]` 网格列表与关联网格配对，`DISTANT_LAYER` 灯光选项让它们不再占用灯光总数上限（文档即将推出）；
*   半径或淡出距离很大的灯光现在会进入单独的 4 km 区块（此前只有 800 m 区块，且完全不考虑淡出距离）；
*   淡出或范围超过 4 km 的灯光算作动态灯光，不进区块；
*   新的联机选项：`CUSTOM_MOTION = 1, RESET`，车辆传送时重置插值（测试验证后会为所有服务器默认启用）；
*   赛道：在 `ai` 文件夹添加名为 `ext_alt_fast_lane_?.ai` 的备选线路，CSP 会将其用于随机车辆，实现 NFS5 保时捷那样的备用路线（暂不用于 Track Day 车辆重生成）；
*   在 MultiMap_emissive 着色器上使用 `MATERIAL_FLAG_1 = 1`，让 txEmissive 改用 UV2；
*   在 MultiMap_NMDetail 着色器上使用 `MATERIAL_FLAG_2 = 1`，让 txDetail 的 alpha 也作为反射率倍率；
*   从非三角化网格生成时不再加载 UV2 补丁（CM 侧的过滤更新即将推出）；
*   自发光着色器的 `emSkipDiffuseMap` 现在可取 0 到 1 之间的值，可限制 txDiffuse 的贡献；
*   将 `emSkipDiffuseMap` 设为 -1（或使用 `CustomEmissive_UseDetailInsteadOfDiffuse` 混入），让自发光着色器改用 txDetail 作为 txEmissive 的倍率（替代 txDiffuse）；
*   为赛道配置中灯光等的 `CLUSTER_THRESHOLD` 加上第二个参数 1，切换到 3D 聚类（稍慢）；
*   车辆新选项 `[BASIC] INTERIOR_CLIPPING = …`，指定车内视角是否裁剪草、刹车痕和 Fake Shadows（非开放式车轮车辆默认启用）；
*   着色器替换新的 `FORCE_MINUS_TWO_LOD_BIAS`（不到万不得已请勿使用）；
*   新树木：AO 烘焙现在可以调整；
*   隐藏实验选项 `general.ini/DEV/NANORT_SCENE_RAYCAST`，构建加速结构以加快网格光线检测（可能增加内存占用，并让首次光线检测变慢）；
*   隐藏实验选项 `general.ini/DEV/VIRTUAL_REPLAYS_ALLOCATION`，为回放使用 VirtualAlloc 函数，而非先分配小块内存再随录制帧数增加而扩容；
*   Trees Inspector 现在显示所选树木的更多细节；
*   Volume peak：设备按 `small_tweaks.ini` 中的正则表达式过滤；
