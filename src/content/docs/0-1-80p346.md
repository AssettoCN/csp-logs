# 更新日志

## 新功能、选项与改进

*   新的车辆物理特性：
    *   车身柔性（Body flex）；
    *   车手配重移动（对卡丁车可能有用）；
*   实验性物理选项（目前仅限离线测试）：
    *   轮辋/地面碰撞：当车轮越过其胎面轮廓压入地面时创建物理接触，防止车辆掉出或穿过某些设置不当的赛道表面；
    *   车辆滑动预防：车辆静止时创建物理接触，防止车辆沿倾斜表面滑下；
    *   悬架自动修复：悬架翻转时施加大力把车轮推回正确位置（非常实验性）；
    *   制动抖动预防：限制制动扭矩，确保车轮角速度不会穿过 0 导致来回摆动（也可防止某些车辆静止时刹车引发车辆滚动）；
    *   地面碰撞体修复：对所有物理地面表面强制启用车地碰撞（事实证明部分赛道没有启用，导致车辆直接掉落）；
    *   墙体修复：平滑碰撞解算，帮助那些墙体过薄或过于复杂、导致车辆卡住甚至更糟的赛道；
    *   提升碰撞坚固度：使更深的碰撞更强，更快解算，防止物体互相穿透；
    *   更早激活车辆碰撞体：帮助防止车辆掉出地面；
    *   刚体旋转优化：禁用 ODE 为所有实体启用的有限旋转模式，据我所知 AC 里没有任何东西转得快到需要它；
*   粒子：
    *   火花：与车辆的碰撞改进，远距离着色更好，寿命经过调整且行为已修复；
    *   碎片：大幅重做，粒子数量增加，视觉全新，碰撞逻辑更新，与车辆、雨刮、墙体和地面的交互更好，爆胎碎屑也已加入；
    *   暂时移除了橡胶碎粒（Marbles）；
    *   烟雾（以及刹车痕与碎片）在赛道配置有设置时使用实际地面颜色；
*   新的 App Shelf 应用，用于安装、自动更新与移除新的 Lua 应用：
    *   Car Mirror；
    *   Controller Tweaks（新增把摇杆映射到油门与刹车的选项，以及重新映射扳机）；
    *   Flashlight；
    *   Paintshop（现在可更改画布分辨率，性能也有提升）；
    *   Radar（内置的 CSP Radar 应用已移除）；
    *   Setup Exchange；
    *   Time Shift（在练习赛段中回到过去）；
    *   更多应用即将推出；
*   CSP Debug App 中的新物理辅助工具（仅限离线单车会话，会使圈速无效）：
    *   把车辆重置回赛道（或若已驶出一定距离，则向后退一段再重置）；
    *   保存与恢复车辆状态（数据可跨会话保存），包括速度等；
    *   施加额外的力把车辆下压或上推；
    *   按一个按钮进行跳跃；
    *   按另一个按钮爆胎；
    *   用鼠标拖动车辆；
*   VR：不带后处理渲染 HUD 的选项，以及不在镜像画面中渲染 HUD 的选项；
*   游戏内可用鼠标移动快速进站菜单与损坏指示器；
*   新的 IMGUI 任务栏用绿点标记新安装的应用（可在游戏内任务栏设置中自定义）；
*   WeatherFX 设置中的选项：渲染静态立方体贴图时包含自发光网格，以略微改善此类场景的夜景；
*   重投影车辆 Fake shadows 的选项（若你没在用带 Fake shadows 重投影的 ExtraFX、又在颠簸路面上驾驶，会很有帮助）；
*   实验性选项：让 AI 更谨慎地通过急弯（比如 Trento-Bondone 上的那些）；
*   新的优化选项，进一步降低渲染期间的 CPU 消耗（默认启用）；
*   CM 的系统热键现在由 CSP 直接支持，体验更好也更可靠；
*   Small Tweaks 中的新选项：在离线比赛中禁用传送回维修站或重新开始比赛；
*   TyresFX：现代开放式车轮车辆的新胎在全新状态下更亮（可在车辆配置中设置）；
*   FFB Tweaks：脏轮胎的额外振动（可选，默认禁用）；
*   环绕（F5）相机对维修区内的车辆会根据维修队所在一侧从另一侧开始；
*   在新任务栏中搜索应用时忽略键盘布局（不必切回英文）；
*   按住 Ctrl 并对 F5 相机使用滚轮现在也可以调整 FOV；
*   暂停或降低后台 FPS 的选项从现在起只在 AC 窗口确实被其他窗口遮挡时才生效，避免误触发；
*   Autopilot（默认 Ctrl+C）更新，再按一次停止键会让 AI 停车（不收回控制权），AI 也应更愿意驾驶，完全重启会话才能拿回控制权；
*   服务器可以指定自定义加载背景图；

## 配置

*   火焰的新参数 SCALE 取代了旧的 SIZE，而且这次真的有效；
*   车辆与赛道配置现在可以指定用 IMGUI 绘制的纹理，并可基于现有纹理（有点疯，但有了它 Supra 前灯的折射现在应该能用了）；
*   引用纹理的配置不再因为奇怪的子串巧合而抓错纹理（只取自对应的 KN5）；
*   AC 对数字仪表等文件的监视现在响应更快；
*   赛道调整不再受 0…99 条的限制（加载也更快）；
*   任何带 `_MESHES` 与 `_MATERIALS` 后缀的赛道配置（大多数，较新的那些）现在也会读取 `_MESHES_EXCLUDE_…` 与 `_MATERIALS_EXLCUDE_…`，便于从默认值中直接排除某些网格；
*   材质调整与着色器替换的实时重载更可靠；
*   赛道自定义物理：新选项，用新方式解析物理网格，跳过名称只含数字的网格；
