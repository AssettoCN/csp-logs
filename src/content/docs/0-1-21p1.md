# 更新日志

## 新功能、选项与改进

*   修复了车辆配置的 include 功能；
*   配置会覆盖到 Documents 文件夹中，以保证安全；
*   支持 configs/cars 的子文件夹；
*   文件 `lighting.ini` 更名为 `lighting_fx.ini`，并附注释；
*   可通过相应 INI 文件中的标志，在比赛中启用/禁用动态光源与 tyres FX；
*   为分析性能，可尝试在 `general.ini` 中禁用文件系统监视，说不定正是它拖慢了一切？
    *   更改该标志后需重启 AC；
*   光照新选项：可调整过渡范围与高光倍率；
*   感谢 d3ads1l3nt 提供大量为 F1 赛车关闭灯光的配置！
