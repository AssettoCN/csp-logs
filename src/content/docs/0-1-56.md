# 更新日志

## 新功能、选项与改进

*   VR、三屏与启动菜单的修复；
*   修复了偶尔出问题的 AI；
*   AI Flood 的颜色更改现在应该可以生效了；
*   新的聊天消息应用（可选，位于 GUI 部分）：
    *   选择、复制、粘贴文本等；
    *   提及他人、将他人标记为好友（与 CM 列表同步）或隐藏他们，使用表情符号；
    *   通过聊天分享调校，或更改车身颜色（暂不支持 skin；且仅限特定服务器）；
    *   服务器现在可以禁止玩家发言，聊天仅保留服务器通知；
*   新 UI 应用的文本输入获得焦点时，会屏蔽 AC 的键盘快捷键；
*   区块（chunks）优化默认启用；
*   VR 中的粉色清屏色替换为深灰色；
*   限制可见车辆数量的选项现在可以调整了（暂时没有可视化 UI，只能用文本编辑器）；
*   排气温度输入 `EXHAUST_TEMPERATURE`（GT3 车辆尚未正确使用，即将支持）；
*   各种小修复；
