# 更新日志

## 新功能、选项与改进

*   修复了 Tyres FX 的闪烁；
*   加载画面：改进了 UTF-8 支持，换行正常；
*   灯光调试：显示轮廓、包围盒与包围球（在 blamer 应用或 `lighting_fx.ini` 中设置）；
*   `general.ini` 新增 `TRACK_CONDITIONS_RESTORE` 选项，防止配置更改时灯光被重新启用；
*   灯光类型重新整理：精度提升，聚光灯可以同时拥有 `DIFFUSE_CONCENTRATION` 和非零的 `SPECULAR_MULT`；
*   线光源现在可以拥有 `COLOR_FROM` 和 `COLOR_TO`，可以创建渐变或沿线条调整亮度；
*   线光源同样支持 `SPOT`、`SPOT_SHARPNESS` 和 `DIRECTION`；
*   而且，它现在也可以有镜面高光了，尽管可能比聚光灯的镜面高光更慢；
*   新的 Python 函数：`ac.ext_version()`、`ac.ext_getTyreGrain(car_index, tyre_index)`（另有 `ext_getTyreBlister` 和 `ext_getTyreFlatSpot`）、`ac.ext_pauseFsWatching()`、`ac.ext_resumeFsWatching()`、`ac.ext_debugLights(…)`、`ac.ext_applyTrackConfig(…)`（示例可参见 AccExtHelper 应用）；
*   一些小修复；
