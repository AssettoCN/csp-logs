# 更新日志

## 新功能、选项与改进

*   重做了默认 Weather FX 实现：新的基于高度的雾、新的云朵外观、重做的天空与光照、额外优化；
*   通过新的 CPU 优化选项优化了 RAM 占用（默认启用）；
*   CSP 现在可以直接从 Windows 10 获取当前播放的曲目（需要 Windows 10 版本 2004）；
*   车载音响：模拟音频可视化现在使用音频峰值表，看起来更准确一些；
*   更新了幽灵车外观：折射、更好的 Extra FX 兼容性、额外光晕选项的新着色；
*   支持隐藏在欢迎消息中的新 CSP 服务器配置；
*   联机服务器：设置额外的出生点，并选择允许传送到那里的车辆（需要特殊的服务器与 entry list 配置）；
*   新的小型 FFB 调整，在加载完成前完全停用 FFB（有助于在部分大型赛道上减少噪音）；
*   严重磨损的轮胎会产生火花；
*   键盘离合器现在适用于任何输入方式（不必再设置那些虚拟输入设备了）；

## 修复

*   修复了 Windscreen FX；
*   修复了禁用新火焰时绿灯的问题；
*   Grass FX：修复了草地形变与割草机的问题；
*   修复了相机靠近发光物体时反射过曝的问题；
*   修复了遮罩通道偶尔显示异常的问题；
*   修复了部分半透明物体消失的问题；
*   修复了使用 `default.ini` PP 滤镜加载的问题；
*   修复了时区配置；
*   修复了 FFB Tweaks 偶尔行为异常的问题；
*   修复了联机以管理员身份登录的问题；
*   新 UI 中的光晕效果减弱；
*   修复了新的 `ksMultilayer_objsm_nm4` 着色器，现在支持二维 UV 倍率；
*   各种小修复与优化；

## 配置

*   Weather FX：
    *   各种新函数与修复（可选）；
    *   云现在可以在其他云上投射阴影；
    *   新的隧道检测（以及通用的相机遮挡检测），适用于所有赛道；
*   配置中的节现在可以要求特定 CSP 版本才会激活；
*   车载音响：
    *   新的元素类型：IMGUI 驱动的文本、矩形形状与专辑封面；
    *   可选淡入淡出；
    *   元素的可调 Z 排序；
*   着色器替换现在可以用 ZIP 文件中的纹理替换纹理，与 Tyres FX 类似；
*   新的 Python 函数：
    *   获取任意车辆的 ABS 与 TC 状态及当前是否工作的标志；
    *   获取相机方向；
    *   由任意方向获取罗盘角度；
*   绑定到 CSP 自发光的灯光现在可以正确处理多个自发光来推测其位置；
*   BTTF 车辆的新火焰选项；
*   赛道配置新增 `[ALTER_NORMALS_…]` 选项，允许在加载期间偏移或旋转法线；
