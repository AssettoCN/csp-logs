# 更新日志

## 新功能、选项与改进

*   动态环境光替换为使用模糊立方体贴图的正规 IBL；
*   车内遮罩改进，轮廓更模糊；
*   赛道动画物体：关键帧、沿路径运动、风车、风向标、时钟或基于条件触发；
*   可将赛道网格包裹进节点，以便必要时进一步移动；
*   赛道的烟雾与火花发射器；
*   赛道的烟雾消散器，可选择绑定到某些东西；
*   赛道灯光：
    *   添加体积效果（请谨慎使用，仅在必要时使用）；
    *   从光照贴图中排除；
    *   绑定到移动物体；
*   赛道条件新选项：`MULT`、`OFFSET`、`MOD`、`MIN`、`MAX`；
*   材质调整：
    *   修复了 `ORIGINAL` 用于多个网格时的行为；
    *   支持多通道自发光；
*   将赛道声音绑定到移动物体；
*   新烟雾：
    *   观感更平滑；
    *   随风飘动；
    *   最多支持四个自定义边界；
*   Grass FX：
    *   画质选择器，附带三个预设；
    *   配置重新调整；
    *   能正确应对快速变化的季节；
*   为风的效果加入轻微随机化，减少死板的静态观感；
*   INIpp 解析器在处理表达式时已经稳定；
*   材质可使用点采样纹理的选项（用于那种低分辨率像素风）；
*   新应用：切换 IBL、调试 Lua 脚本、检查赛道条件；
*   新粒子若一段时间未使用会进入休眠状态；
*   新 `ksPerPixel_tilingfix` 着色器：常规 `ksPerPixel`，但无平铺（与那些带特殊选项的 multimap 和 multilayer 着色器相同）；
*   纹理的冬季颜色校正已更改，以减少 `seasonWinter` 偏低且 `seasonAutumn` 偏高时造成的偏粉效果；
*   动态缆索已修复；
*   性能尖峰修复；
*   Extra FX：修复了某些组合下的问题；
*   大量其他修复与优化；
