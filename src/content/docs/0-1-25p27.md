# 更新日志

## 新功能、选项与改进

*   hen.ter 带来的全新 CPU 与 GPU 优化选项（请查看通用设置）；
*   修复了 Porsche 911 GT3 RS 的尾翼；
*   Tyres FX 新增轮胎泥土与草屑：
    *   车辆新增 `DIRT_WIDTH_K`、`DIRT_ACCUMULATION` 和 `DIRT_FADE` 参数；
    *   赛道参数，可为 Tyres FX 指定泥土与草的颜色：[https://github.com/ac-custom-shaders-patch/acc-extension-config/wiki/Dirt-on-tyres](https://github.com/ac-custom-shaders-patch/acc-extension-config/wiki/Dirt-on-tyres)；
*   Tyres FX：平斑会随时间变长，形状现在也更圆了；
*   绑定到网格的灯光不再随车速抖动；
*   不影响地面的车头灯不再产生虚假的反弹光；
*   参数 `EMISSIVE_BRAKELIGHTS_MULT` / `EMISSIVE_PARKINGLIGHTS_MULT` 现在能正确作用于带 `OFF_COLOR` 的刹车灯；
*   车辆灯光新增 `BOUND_EXP` 和 `BOUND_EMISSIVE_MAX` 选项，可调整闪烁或熄灭状态下的发光强度；
*   新的 Logitech G27 LED 扩展：
    *   可禁用 AC 对 G27 LED 的管理；
    *   备选的阈值算法；
    *   新 Python 函数：`ac.ext_isG27Available()` 和 `ac.ext_setG27Thresholds(minRpm, maxRpm)`；
*   观众已修复，现在光照正确；
*   Weather FX 的各种性能改进：
    *   着色器已优化；
    *   渲染顺序改变，天空与云现在最后渲染；
    *   视锥体剔除；
    *   Lua 换成了 LuaJIT；
    *   修复了 `math.clamp` 和 `math.saturate` 函数；
*   空气动力学控制器新增 `CLUTCH` 输入；
*   一些小修复；
