# 更新日志

## 新功能、选项与改进

*   VR：
    *   常规放大器（FSR1、SGSR1、NIS）可与 SPS 一起工作；
    *   渲染目标总会被清空（修复了某些赛道上的若干问题）；
    *   加载画面会显示 VR 初始化失败的原因；
    *   OpenVR：新增在加载期间显示比赛详情的选项；
    *   VR 镜像稳定化会在启动或画面突变时重置，与边角遮罩配合更好；
    *   若干小修复；
*   VR 的 Variable Rate Shading（可变速率着色）：
    *   不再需要 SPS，设置移到了单独的分区（为了让旧预设继续工作，SPS 设置会被重置）；
    *   着色区域自动与视线方向对齐；
    *   若自动对齐失效，也有可用的微调选项，另有可选的调试覆盖层；
    *   VRS 不再作用于 HUD；
*   Rain FX：
    *   雨天物理经过调校，现在应该更可控了；
    *   雨滴与 TAA 的兼容性更好，雨更大时雨滴也更密集；
    *   对于过大的雨强，雨滴命中更多；
    *   调整了光泽表面（如车漆）上的雨水效果，着色有所改进；
    *   雨刮音频更安静了（说真的，我之后该重做那些采样）；
    *   为赛道配置新增 `[RAIN_FX] IDEAL_LINE_RAIN_FACTOR`（设为 0 可让雨天物理不再把理想路线及其对应的轮胎挂胶考虑在内）；
*   默认 Weather FX 样式：
    *   修复了雨声，雨强更大时音量有所提升；
    *   环境阴影稍微没那么暗了；
    *   一些较极端的天气经过调整，不再那么极端；
*   放大器与 Neural Rendering（神经渲染）：
    *   DLSS 更新至 310.9.1；
    *   新的 XeSS 3.0.2 放大器（可在 Intel Arc 之外的 GPU 上工作）；
    *   新的使用 DirectX 12 API 的 FSR3/4 放大器；
*   Neural Rendering：
    *   修复了调整 AC 窗口尺寸时的崩溃；
    *   会话中途启用该效果时，会自动加入调整应用；
    *   `Go beyond` 设置中新增 `loop` 滑块；
    *   修复了 `Allow to load unofficial DLLs`，已知非官方 DLL 列表有所扩充；

## 修复

*   修复了禁用任意烟雾时的崩溃（这次应该是真修好了）；
*   修复了顶部圈数计数器显示圈数比实际少一圈的问题；
*   Python 应用试图创建 0 像素大小的纹理时，不再导致 Assetto Corsa 崩溃；
*   `FREQUENT_TRACK_CHANGES` 功能现在可用于带布局的赛道；
*   TAA：阴影留下的拖影应该少多了；
*   截图的若干小修复，另新增 `Output a frame every accumulation step` 选项以备不时之需（默认禁用）；
*   鼠标转向脚本的设置现在能正确加载；
*   CSP 能处理奇怪的赛道模型了（比如 `vhe_interlagos`，其网格有 489888 个顶点、210 个三角形，浪费了 64 MB 磁盘和内存空间）；
*   Unbound 应用及其他使用 `ac.overrideCarControls()` 的脚本导致的崩溃应该已修复；
*   带 `CULL_MODE = DOUBLESIDED` 的着色器替换现在能正确应用了；
*   `pitcrewtyre.ini` 缺失或损坏时，Assetto Corsa 不再崩溃；
*   修复了与任务栏图标生命周期某些方面相关的崩溃；
*   可燃的赛道几何不应再导致崩溃；
*   Neck FX：修复了原版（非脚本）实现；
*   调整第一人称相机时保存 `car.ini`，现在也兼容 CM 的 `Use extended physics` 调整项；
*   换车时能正确处理次级 LOD 中的方向盘；
*   Revenant 模式不再激活扩展物理；
*   DualSense 触觉反馈：
    *   不再弄乱某些车辆的音频；
    *   会选择与手柄匹配的输出设备（适用于配有多个 DualSense 手柄的环境）；
*   Skidmarks（轮胎痕迹）：
    *   修复了胎面纹理；
    *   `Save as OBJ` 会在会话退出时保存轮胎痕迹，无论 `Save between sessions` 选项如何设置；
*   扩展服务器配置：
    *   新增 `[CUSTOM_PHYSICS] NEW_MOTION_PREDICTION=1` 参数，用略为先进的方案取代远程车辆的外推物理（altonline 会话会自动应用新的运动模式，除非主动退出）；
    *   为数据包速率不均匀的服务器新增 `[CUSTOM_PHYSICS] RAW_TIMESTAMPS=1`；
    *   移除了 `[CUSTOM_PHYSICS] EXTRAPOLATE_STATE`；
*   扩展车辆物理：
    *   `[_EXTENSION] AWD2_INVERTED=1` 现在应该能用了，它会让前轴成为主导轴（请务必为你的车辆指定 4150 或更高的最低 CSP 版本）；
    *   使用 `[_EXTENSION] RIM_SPRING_RATE=0 RIM_DAMPING_RATE=0` 可完全禁用轮辋接触；
*   疑难解答相关：
    *   崩溃报告包含 CSP 日志；
    *   启动时会记录硬件详情；
    *   崩溃报告可上传以供进一步分析；
*   杂项：
    *   GNS 库（用于不经过 Steam 服务器的 P2P 连接）已更新，现在自带正规的 ICE 客户端，不再使用 WebRTC；
    *   P2P 信令的若干改进，就算局域网没有互联网连接，节点之间现在也应该能互相找到；
    *   AI flood：距离调整再次在设置中可见；
    *   改按 Ctrl+Alt+Shift+Win+F10 来生成报告，原先的 F12 已被 Copilot 占用；
    *   调整了 CSP 的换挡及挂空挡绑定，现在按住期间一直生效，而不是只在按下的第一帧生效；
    *   `Extrapolate car state properly` 实验已转正（我终于弄明白远程车辆为什么会抖了）；

## Lua

*   新增 `io.available()` 函数；
*   新的 `dynamic::efx::depth`、`dynamic::efx::…` 纹理现在也可供其他脚本使用（不过没有三倍分辨率）；
*   新增 `physics.exportRacingLineAsync()` 与 `physics.importRacingLineAsync()` 函数，用于联机同步雨天状态；
*   无 I/O 权限的脚本再次可以使用网页浏览器；
*   车辆物理脚本中 `ac.debug()` 的固定图形不再在数据变化时重复出现；
*   文档的若干小修复；
*   Lua Debug 应用：修复了脚本排序。
