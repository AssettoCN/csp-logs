# 更新日志

## 新功能、选项与改进

*   集成 AMD FidelityFX Super Resolution（在 AC 视频设置中同时开启 PP 与 FXAA 时可用，或在 VR 模式下任意配置可用）；
*   Graphics Adjustments 中的 FXAA 替换选项现在也适用于 VR；
*   用快捷键将回放最后 30 秒保存为小视频的选项（服务器还可以为其设置上传 URL，实现更自动化的举报）；
*   Mumble 集成，支持带位置的语音聊天，可在服务器配置中调整比例；
*   为大多数形状与形态的雨刮动画的新方式，无需拆分网格，自动吸附到风挡上等等；
*   新的 Colorized Shadowing 模块，让风挡横幅投下彩色阴影并为附近的环境光染色；
*   车内反射遮罩重做，现在应用于所有附近车辆；
*   封闭座舱车辆的车手模型少许遮蔽，类似 Shadowed Wheels 模块；
*   自由相机下，10 米内最近的车辆现在视为对焦车辆；
*   `Limit audio` 选项更新，带正确的淡出与进一步优化；
*   预计算 CSP 数据（如车辆的新假阴影）的缓存重做，旧条目将自动删除；
*   NeckFX：地平线锁定选项，将相机锁定到赛道表面而非地平线；
*   带三屏模式调整的新模块，可更改画面在三台相机间的分割方式；
*   默认观众法线纹理已正确重绘，着色更新；
*   Ghost（幽灵车）记录器在新纪录产生后立即保存文件，而非等会话结束；
*   后视镜数字显示屏现在为可选，并带更好的 LDR 模拟选项；
*   默认 WeatherFX 实现更新，光照与云已调整，AI 现在也会及时打开大灯；
*   新 UI 的更简单渲染样式选项，为较弱的 GPU 提速；
*   反射立方体贴图的镜面高光已禁用，以减少闪烁；
*   Origin Shift 的调试模式已移除，防止有人不小心激活；

## 修复

*   0.1.74 中加入的赛道假阴影现在可以关联到网格，在缺少网格的布局下消失；
*   修复了部分车辆 LOD 上雨刮乱飞，以及动画应用到 LOD 时失效的类似问题；
*   修复了缓存 AC 数据以加速加载导致车漆损坏的问题；
*   修复了带 VAO 的车辆过暗、要切换几次 VAO 才恢复的问题；
*   修复了几个与 IBL 反射相关的性能问题；
*   VAO gamma 现在也作用于影响车辆亮度的 VAO 采样；
*   修复了 Driver Interview 模式（缺少获胜条件），难度降低，现在也支持 assettocorsamods.net 的赛道；
*   数字屏幕着色器更新，TN 色彩畸变更准确；
*   修复了玻璃侧面边缘折射增强的问题；
*   修复了部分罕见赛道上车辆掉落地面以下的问题（0.1.74 的 bug）；
*   累积模糊截图后，粒子状态将恢复；
*   欢迎消息中的 URL：解析已修复，支持 TeamSpeak 与 Mumble URL，右键菜单可将 URL 复制到剪贴板；
*   Graphics Adjustments 的自定义裁剪平面现在在选择 VR 模式时也生效，除非相机位于车内；
*   AI flood：禁用颜色随机化现在生效了；
*   修复了用于检测相机位置的 CPU 车辆高度图；
*   Origin Shift 在后处理禁用时也能工作；
*   加速反射现在正常工作，不再在部分赛道上出问题；
*   WeatherFX：修复了遮蔽估计，修复了被裁切的云；
*   修复了折射大灯的 TAA；
*   观众的默认法线纹理现在只应用于默认观众纹理；
*   地平线物体检测改进，修复部分赛道上的背景毛刺；
*   修复了 LOD 切换时物体变模糊的问题；
*   修复了特定设置组合下虚拟后视镜破坏 UI 的问题；
*   赛道上带相机的显示屏支持 origin shift，并可显示烟雾、火焰与烟花；
*   修复了视觉油渍卡住的问题；
*   修复了退出时的崩溃；
*   修复了车漆着色器上动态光源的镜面高光；
*   一些小修复与优化；

## 配置

*   人体表面材质现在可以在车辆配置中设置；
*   GrassFX：在赛道配置中调整纹理亮度的选项（针对上色部分）；
    *   为节省空间移除了 Highlands 纹理的变体，为兼容起见 CSP 会改用亮度调整；
*   赛道状态与赛道遮挡物的应用已移除；
*   作为替代，它们作为工具加入了 Objects Inspector，免得应用列表太乱，更多应用很快会迁移和加入；
*   赛道假阴影工具重做，现在可以将阴影关联到网格并一次管理所有阴影；
*   赛道灯光的默认镜面倍率现在改为 1（通过赛道通用配置）；
*   创建数字仪表的新方式，`[SCRIPTABLE_DISPLAY_...]` 显示屏可用 Lua 编写脚本；
*   车辆的新增强件 `[EXTRA_SHAPE_...]`，允许创建新几何体（例如为缺少某些指示灯或正确映射显示屏的 Kunos 车辆）；
*   用 `[EXTRA_SHAPE...]` 轻松创建新显示屏与指示灯的新模板；
*   动态纹理的新 `RESOLUTION_LIMIT` 选项，确保异常设置的缩放不会让它们过大；
*   数字屏幕材质的新模式：VA 矩阵；
*   导航仪现在可以使用车辆纹理作为加载徽标（示例可看 BMW M4 的配置）；
*   所有其他纹理引用（例如在 `[SHADER_REPLACEMENT_...]` 中）也可以使用车辆纹理；
*   使用弯曲着色器的功能的 `ALPHA_MODE` 参数现在正确应用；
*   INIpp：
    *   模板中的宏现在不能覆盖主节中宏设置的值；
    *   生成器所用模板的新 `@GENERATOR_STARTING_INDEX` 参数，用于更改起始索引；
*   `[PARTICLES_FX_EXHAUST_...]`：方向现在为可选，默认朝后；
*   `[MESH_ADJUSTMENT_...]` 与 `[NODE_ADJUSTMENT_...]` 更新：
    *   现在赛道与车辆的用法一致；
    *   将网格移到其他节点时会更新其顶点，使其保持在原位，便于让网格坐标与车辆坐标对齐；
*   `SKINS` 过滤器现在可以使用复杂查询，例如 `SKINS = '{ ( red?, green? ) & !?_matte }'`；
*   为当前活跃的车辆（已加载且未断开）可视化维修区：
    *   开关车库门或为其制作动画；
    *   新的赛道状态输入，检查对应车辆是否存在；
*   将赛道网格元素拆分为独立网格（增加绘制调用次数，请谨慎使用）；
*   着色器 `stPerPixelNM_UVflow`：
    *   UV 倍率与偏移参数（将偏移绑定到动画条件可实现过渡效果）；
    *   改用 txDiffuse 而非 txNormal 的 alpha 通道的参数；
    *   裁掉 0…1 纹理坐标之外所有内容的参数；
*   材质调整中的十六进制颜色现在可用了；
*   后视镜数字显示屏：调整角度的选项；
*   lods.ini 中错误设置的 `OUT` 值现在会自动修正为与下一定义的 `IN` 一致；
*   遮罩通道现在支持延迟渲染（对彩色风挡横幅很有用）；
*   新的车内材质 `[Material_WindscreenBanner]`，包含风挡横幅、边框等所需的一切，便于实现彩色阴影与 RainFX 集成；

## Lua & Python

*   状态结构体扩展，现在包含多得多的数据；
*   Lua API 生成器重写，现在确保类型安全并尽可能添加自动转换；
*   Lua API 的几个修复（现在向量只与向量相等之类）；
*   WeatherFX：
    *   新的 `ac.setCameraOcclusionDepthBoost()` 值，调整基于立方体贴图的遮蔽估计；
    *   新的云材质属性 `.alphaSmoothTransition`，用于调整 alpha 渐变；
    *   云的 `.extraFidelity` 现在可以设为负值，使图案模糊而非添加额外层；
*   新的模式：
    *   绘制 UI 的 API 从 `ac.ui…` 移到了 `ui.…`（很抱歉，我通常尽量不破坏兼容性，但它刚发布，我认为尽早修正更好）；
    *   在 3D 空间中绘制内容的 API；
*   自动生成的定义现在包含类型；
