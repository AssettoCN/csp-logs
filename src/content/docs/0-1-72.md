# 更新日志

## 新功能、选项与改进

*   Smart Shadows：
    *   第四级阴影级联，用于远处阴影与镜中阴影（可选）；
    *   外部相机第一级分段的自适应距离（靠近车辆时距离缩短，可选）；
    *   可调的模糊量；
*   Extra FX：
    *   动态模糊着色器从零重写，以提升性能与质量；
    *   雾气模糊更新；
*   各种优化：
    *   加载期间会计算新的包围球，更小也更精确；
    *   赛道几何体的 AABB 剔除，反射可选 SSE 加速；
    *   新的剔除选项：对部分可见车辆强制剔除、基于朝向的剔除；
    *   基于遮挡体的剔除（遮挡体通过赛道配置定义）；
    *   重做立方体贴图与阴影反射的渲染，更直接也更快；
    *   对反射立方体贴图做重投影的选项，部分更新时过渡更平滑；
    *   FidelityFX：为输出使用 UAV 标志（可选），无需额外拷贝，节省一些时间；
    *   新的性能分析器应用，带图表与详细测量（之后将取代 Render Stats）；
    *   一些没有可见窗口的 Python 应用现在会进入休眠模式，以加快速度；
    *   Python 应用性能分析器已更新，现在能显示更好的平均耗时与最大（取平均后的）耗时；
    *   Extra FX：构建反弹光的光照贴图现在更快；
    *   IMGUI 混合（新 CSP 应用等使用）不再缓慢；
    *   为车内与车外视图禁用第三级联车辆阴影的选项；
    *   WeatherFX：在单独线程中运行垃圾回收或可选维护处理的实验性选项；
    *   一些小优化；
*   外部视图可见车辆数量改为独立参数，默认值略高；
*   反射立方体贴图：预过滤选项，用于消除噪点；
*   镜中可用的立方体贴图反射；
*   MSAA 调整：合成时结合色调映射以提升质量，可选自定义卷积核让画面更平滑；
*   Brake Disc FX：程序化划痕，观感更复杂；
*   新的 CSP 应用现在可以通过标题栏右键菜单固定；
*   不再清空颜色缓冲（可选，对性能和某些赛道的小孔洞稍有帮助）；
*   新选项（通过赛道配置设置），让树木光照与下方表面对齐，有助于改善丘陵赛道观感；
*   导航仪现在会记住之前使用的相机类型；
*   CSP 会尝试修复缺失的风挡着色器，并为仪表盘玻璃应用 `skip G-buffer` 标志；
*   Weather FX 部分新增为联机其他车辆强制开启车头灯的选项；
*   颜色分级：GPU 加速转换，现在能正确支持 16 位和正方形非 HALD 的颜色 LUT；
*   GrassFX 现在默认启用；

## 修复

*   Tyres FX 已修复；
*   背光玻璃着色器已修复；
*   FidelityFX CAS 现在会在 FXAA 3.11 之类之后应用（CMAA2 没问题）；
*   改进了新任务栏的主窗体检测；
*   动态阴影修复：
    *   修复了远处阴影闪烁；
    *   Shuto 之类赛道上不再有遮挡光；
    *   车头灯范围已修复；
    *   低多边形几何体显示正常；
    *   单车多个车头灯现在有正确的动态阴影；
*   修复了 GrassFX 偶尔弄乱动态模糊、看起来一团糟的问题；
*   修复了禁用 CJK 字符的问题；
*   CJK 字符占用 VRAM 更少，比赛开始时也不会再造成卡顿；
*   修复了 Ghost 车用奇怪伪影遮挡视野的问题，其折射也已修复（默认禁用）；
*   修复了封闭式车辆中头盔在镜中不受阳光照射的问题，并在第一人称视角下投射正确的阴影；
*   阴影过滤经过调整以减少伪影，修复了远处几何体的阴影；
*   修复了镜中缺少车辆细节的问题；
*   启动时的时区完整性检查已修复（不会再出现光照错乱）；
*   移除了无阴影与无光照着色器集，以提升加载速度；
*   折射灯光的 TAA 不再有那么多滞后，截图中也更锐利；
*   不再从与非网格车辆碰撞体的碰撞中生成碎片（那些通常用于底盘和滑块）；
*   虚拟后视镜不再干扰 UI；
*   DXGI flip 模式在全屏下不再可用，从一开始就该如此；
*   CSP 雷达应用现在能正常淡出；
*   CSP 车手标签在禁用后处理时正常工作；
*   相机跳变后动态模糊不会再把一切都糊掉；
*   车辆模型变更时，烘焙的虚假阴影或车辆湿度贴图现在会重新构建；
*   现在用实际车辆模型（最低 LOD）计算车辆尺寸，因为事实证明某些 mod 的碰撞体错位严重；
*   修复了静态胎痕着色错误的问题；
*   修复了极端情况下的地面高度估算（比如附近地面有洞时）；
*   修复了 SSLR 在雾中表现异常的问题；
*   Python 函数 `ac.ext_getTyreBlister()` 不再在某些情况下使 AC 崩溃；
*   新火焰与 SSLR 的兼容性更好；
*   移除了雾气模糊效果产生的远处色斑（只靠雾本身就够了）；
*   修复了与 AC PRO 的兼容性；
*   AC 视频设置中的负 mipmap 偏置不再影响 GrassFX 贴图生成之类的性能；
*   修复了远处自发光消失的问题，反射中的观感也得到改善；
*   车辆阴影出现在第三阴影级联中，整体渲染改进；
*   高细节下同时可见的车辆更多；
*   三屏下新主菜单居中显示；
*   车漆现在默认不会再弄坏碳纤维；
*   车漆的极端镜面参数不会再产生刺眼的眩光；
*   着色器 `ksPexPixelAlpha` 在 alpha 参数大于 1 时现在工作正常；
*   修复了 PP 编辑器中颜色分级纹理的实时重载；
*   WeatherFX：视锥体测试新增一个参数，可停止航向角调整；
*   新照片应用：motion 模式不再重置环绕相机；
*   远处自发光支持移动物体（比如摩天轮）；
*   修复了几个小 bug 与崩溃；

## 配置

*   支持 BC7 DDS 压缩（与 DX5 占用相同，观感好得多）；
*   新的赛道遮挡体编排应用：墙体与盒子；
*   新的网格过滤关键字：静态赛道网格的 `static` 标志、投射阴影网格的 `castsShadows` 标志、检查包围球半径的数字 `largerThan`；
*   动态光源阴影的剔除模式现在可调，默认值从双面改为仅正面；
*   现在可以为某些车头灯禁用体积光；
*   车辆输入：默认不再对熄火清零；
*   额外车辆动画：保持最终状态、将多个动画混合、将动画与常规转向动画混合（可用于手刹动画）；
*   原版车辆动画：应用 LUT 和其他后期处理来改变关键帧选取；
*   着色器替换：若纹理替换的文件缺失，整个条目将被忽略；
*   车漆着色器更新（新参数 `ApplyMatteFix`，对 v3 自动应用）；
*   赛道灯光现在可以跳过车辆以加快速度；
*   赛道网格可以不再投射动态阴影；
*   新 Python 函数：`ac.ext_pauseWhenHidden(frames)`、`ac.ext_isAnyAppVisible()`；
*   新赛道配置值：`[WIND] DYNAMIC_FLAGS_TESSELLATION=1`，改为 0 可停用曲面细分；
*   新 G-buffer 标志 `ALPHA_TEST_GBUFFER` 启用 alpha 测试，以 ksAlphaRef 为阈值；
*   新 `INPUT_REFRESH_RATE` 选项，可设置自定义刷新率（Hz），数字仪表默认 5 Hz；
*   车辆与赛道的扩展配置现在可以访问赛道数据；
