# 更新日志

## 新功能、选项与改进

*   修复了 PBR 着色器不加载正确纹理的问题；
*   若有任何纹理缺失，将跳过着色器替换部分；
*   Object Inspector 应用已更新，一些 UI 调整，以及为自定义自发光设置多边形区域的新选项；
*   折射大灯：可镜像第三个灯泡的选项，第四个的镜像现在也是可选的；
*   新的 `ksPerPixelMultiMap_AT_emissive` 着色器：与 `ksPerPixelMultiMap_emissive` 相同，只是用于修复 ksEditor 丢失 alpha 测试标志的问题；
