# 更新日志

## 新功能、选项与改进

*   VR 更新：
    *   Single Pass Stereo，绘制调用数量减半；
    *   面向 NVIDIA 16…、20… 与 30… 系列 GPU 的 Variable Rate Shading（又称注视点渲染）；
    *   可选的单次 YEBIS pass；
    *   支持边角遮罩优化（不再对镜头遮挡的区域着色，以提速）；
    *   支持 Oculus 的 ASW 2.0；
    *   另外，针对 Oculus：CSP 现在会更新 AC 的 manifest，更新资源以显示比赛详情，并在其 VR 组件关闭时关闭 AC；
    *   更好的 OpenComposite（前称 OpenOVR）支持，OpenCompositeACC 与常规 OpenComposite 版本均适用（修复了 `ipdOffset` 导致的崩溃）；
    *   VR 中的崩溃现在会先关闭 AC，再在单独的进程中显示错误，确保 VR 环境切回桌面；
    *   HUD 的 X 光渲染，避免 HUD 前面有几何体时观感怪异；
    *   控制器集成：与 HUD 交互、调整后视镜、使用触摸屏、按压车内按钮等（需车辆有相应设置）；
    *   让车手双手跟随 VR 控制器的实验性选项；
    *   可选的额外抖动，或许能改善 Oculus Air Link 画面过度压缩的问题；
    *   自定义 VR 镜像的 FPS 计数器；

*   自定义 GamepadFX 脚本更新：
    *   实现改进；
    *   独立的漂移与竞速模式，驾驶途中可切换；

*   WeatherFX：
    *   云层的各种改进；
    *   精确的月食（需由 WeatherFX 脚本启用以确保兼容）；
    *   供实现脚本创建自定义效果的新 API；

*   默认 WeatherFX 脚本：
    *   远处雷声效果；
    *   雨雾；
    *   雨声音频；
    *   极光（可在 2022 年 2 月到纬度 60° 以北的赛道试试，例如 Ahvenisto Race Circuit）；
    *   雾的修复，雾会笼罩高层建筑顶部；
    *   修复了行星、太阳与月亮的大小；

*   额外的服务器选项：
    *   实验性选项：远程车辆突然跳变时短暂暂停碰撞；
    *   显式定义时区与坐标，确保自定义赛道未定义这些属性时灯光仍然吻合；
    *   车轮角度同步现在包含主销后倾角；
    *   修复了自定义车辆运动，现在不应再导致远程车辆碰撞时行为略有差异的问题；
    *   自定义车辆运动的额外选项：较慢车辆的平滑运动，改善大型赛道上车辆抖动的问题（可用 `CUSTOM_MOTION = 1, SMOOTH` 激活）；
    *   车辆卡在碰撞中或坠入地面时将其重置的选项，附带可选处罚；
    *   新的核心选项：强制自定义车辆物理、强制自定义赛道物理、隐藏维修站人员以加快加载（CM 支持即将推出）；
    *   显示消息与覆盖封禁消息的命令，可用作新的直接 TCP 命令或兼容的聊天命令；
    *   修复了部分 `EXTRA_RULES` 值允许不进维修站就打开调校菜单的问题（请将最低要求版本设为新的 CSP 版本号）；
    *   新规则：接受维修站处罚前必须先完成当前圈（免得有人倒车穿过维修区蒙混过关）；
    *   可将某些 CSP 模块设为服务器必需；
    *   如果服务器通过该选项要求任何 CSP 模块，或通过旧方法要求 WeatherFX 或 RainFX，设置实时重载将被禁用；
    *   隐藏默认地图应用的选项；

*   面向自定义服务器实现的功能：
    *   自定义封包格式：支持不足一字节的类型（`CUSTOM_UPDATE_V2`）；
    *   批量更新修复已修复（新 ID 为 `BATCH_FIX_V2`）；
    *   频繁更换赛道的服务器可指定 `FREQUENT_TRACK_CHANGES` 功能，CSP 会在连接前将赛道 ID 更新为实际值；

*   Python：
    *   更好的错误处理；
    *   可选缓存以加快加载；
    *   一项兼容性修复：安装旧应用破坏新应用时能帮上忙（强制应用使用最新的 `sim_info` 库）；

*   新的内置应用（用 Lua 编写）：
    *   Controller Tweaks：比赛中调整 FFB、手柄或键盘控制选项，更改实时生效；
    *   Mirrors Configurator：用顺手的滑块调整 Real Mirrors；
    *   Setup Exchange：发布车辆调校，在维修站中加载并应用他人制作的调校（维修站集成默认禁用，可在应用设置中开启）；

*   远程车辆的方向盘角度不再被限制在 127°；
*   现在附带含雨刮音效的 CSP soundbank；
*   水面着色器：几处修复，新的深度感知模式用于平滑混合，焦散（折射与反射皆可）；
*   新的排水沟着色器，用于随降雨渐渐积水的排水沟；
*   车辆新的彩虹贴纸材质；
*   新的 ChromaFlair 车漆；
*   车漆与 `nePerPixelMultiMap_AT_NMDetail_stickers` 着色器支持 UV2，可多出一层放贴纸之类的东西；
*   展厅模式：从 `content/showroom` 加载展厅，并禁用部分 AC 功能以加快加载；
*   一些配置有误的车辆 soundbank 现在会在加载前被修复（感谢 Chr0m3 提供的方案）；
*   ProTyres 与 Camber Extravaganza 应用现在能正确处理虚拟轮胎（例如自动生成的雨胎）；
*   爆胎现在有不同的声音；
*   加载速度的进一步优化；
*   AC 应用现在可以一路拖到屏幕顶端；
*   GUI 控制器集成：必要时可绑定特定按键（例如在没有十字键的情况下）；
*   更新了默认 GrassFX 纹理，其着色有几处小改进；
*   发动机爆炸现在产生更多烟雾；
*   Android Auto 复刻：电台应用现在允许在游戏内添加更多电台；
*   新的 Planetarium 滤镜（另外卡通滤镜已更新）；
*   DDS 纹理现在可以应用 LZ4 压缩以减小文件体积；
*   一项新的实验性功能，用于创建自定义的外部 AI 实现；
*   新的实验性区块优化模式，提升大型赛道上的 FPS；
*   基础区块优化现在使用自适应区块尺寸，提升将小物体归入单独 KN5 的赛道的性能；
*   CSP 版本变更时可选清除系统着色器缓存（默认启用，解决某些硬件上加载卡住的问题）；
*   阻止 AC 为每个已安装赛道创建调校文件夹的选项（还能节省加载时间）；
*   AC 处于后台时暂停渲染的选项；
*   加载纹理与 VAO 补丁时使用内存映射的选项（可能加快加载速度）；
*   联机聊天消息使用 Time-To-Speech 语音的选项；
