# 更新日志

## 新功能、选项与改进

*   新的 FFB Tweaks 扩展，包含 Stereo 编写的更精确的陀螺仪实现；
*   替代原版照片模式应用的新应用：
    *   为截图提供简单的 CPL 模拟；
    *   保存与加载相机位置；
    *   保存前预览截图；
    *   在回放中：
        *   调整快门速度以获得累积运动模糊；
        *   在回放中开关灯光、刹车灯、损坏、污垢或车手；
        *   更改一天中的时间，或旋转整个赛道，让光线落在需要的地方；
*   树木接受阴影现在改为可选，默认禁用；
*   另外，树木接受阴影现在应该更平滑了，还修复了几个 bug；
*   树木 A2C 抖动，减少 MSAA 下的色带；
*   修复了车辆音频的音量调整；
*   动态旗帜现在也改为可选；
*   修复了旗帜 UV 映射破损的问题；
*   IMGUI 应用不会再破坏鼠标与 AC 其余部分的交互；
*   反射立方体贴图中使用更简化的动态光源以加速（跳过车辆灯光或极小的光源）；
*   若车速低于 6 km/h，可降低 AC 遥测中 G 力的选项（为 D-BOX 准备）；
*   Weather FX：
    *   强制机器人开启大灯的选项；
    *   云的新选项，将其渲染为水平方向；
    *   默认天气脚本的几处修复；
*   折射玻璃：基于 txDiffuse alpha 通道的折射遮罩，适用于带部分平整玻璃的大灯；
*   可缓存 AI 线路生成的网格与数据的选项，将加载提速几秒；
*   新的 Python 函数，可获取 AI 线路长度、由世界坐标求线路位置，或反之；
*   AC 位于后台时，环绕相机不再响应鼠标；
*   树木阴影现在也会随风摆动；
*   一些较小的 bug 修复；
