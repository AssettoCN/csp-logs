# 更新日志

## 新功能、选项与改进

*   Smart Shadows：
    *   第四级阴影级联，用于远处的阴影与镜中的阴影（可选）；
    *   外部相机的第一段分割采用自适应距离（靠近车辆时距离缩短，可选）；
    *   可调整的模糊量；
*   Extra FX：
    *   动态模糊着色器从头重写，以提升性能与质量；
    *   雾气模糊已更新；
*   各种优化：
    *   加载期间会计算新的包围球，更小也更精确；
    *   赛道几何体的 AABB 剔除，反射可选启用 SSE 加速；
    *   新的剔除选项：对部分可见的车辆强制剔除其部件、基于朝向的剔除；
    *   基于遮挡体的剔除（遮挡体通过赛道配置定义）；
    *   重做了立方体贴图与阴影反射的渲染，更直接也更快；
    *   可对反射立方体贴图做重投影的选项，让部分更新时的过渡更平滑；
    *   FidelityFX：为输出使用 UAV 标志（可选）后，不再需要额外的拷贝，节省一些时间；
    *   全新的性能分析器应用，带图表与详细测量（之后会取代 Render Stats）；
    *   一些没有可见窗口的 Python 应用现在会进入休眠模式，加快速度；
    *   Python 应用性能分析器已更新，现在能更好地显示平均与最大（取平均后的）耗时；
    *   Extra FX：反弹光的光照贴图构建现在更快了；
    *   IMGUI 混合（新 CSP 应用等在使用）不再缓慢；
    *   可为车内与外部视角禁用第三级联车辆阴影的选项；
    *   WeatherFX：实验性选项，可在单独线程中运行垃圾回收或可选的维护处理；
    *   若干较小的优化；
*   外部视角可见车辆数量的独立参数，默认值略高；
*   反射立方体贴图：预过滤选项，用于消除像素杂点；
*   镜子中可用的立方体贴图反射；
*   MSAA 调整：resolve 时应用色调映射以提升质量，可选自定义核以获得更平滑的图像；
*   Brake Disc FX：程序化划痕，观感更复杂；
*   新的 CSP 应用现在可以通过标题栏的右键菜单固定；
*   不再清除颜色缓冲（可选，对性能和一些赛道上的小洞稍有帮助）；
*   新选项（通过赛道配置设置），让树木光照与下方表面对齐，有助于改善丘陵赛道的外观；
*   导航仪现在会记住之前使用的相机类型；
*   CSP 会尝试修复缺失的风挡着色器，并为仪表盘玻璃应用 `skip G-buffer` 标志；
*   Weather FX 小节中可强制联机中其他车辆开启大灯的选项；
*   调色（color grading）：GPU 加速的转换，现在能正确支持 16 位与正方形的非 HALD 颜色 LUT；
*   GrassFX 现在默认启用；

## 修复

*   修复了 Tyres FX；
*   修复了背光玻璃着色器；
*   FidelityFX CAS 现在会在 FXAA 3.11 之类之后应用（CMAA2 不受影响）；
*   改进了新任务栏下的主窗口检测；
*   修复了动态阴影：
    *   修复了远处阴影闪烁的问题；
    *   在 Shuto 之类的赛道上不再出现遮挡光；
    *   修复了大灯范围；
    *   低多边形几何体观感正常；
    *   单辆车多组大灯现在拥有正确的动态阴影；
*   修复了 GrassFX 偶尔弄坏动态模糊、观感一团糟的问题；
*   修复了禁用 CJK 字符的问题；
*   CJK 字符的显存占用更低，也不再在比赛开始时造成卡死；
*   修复了 Ghost 车辆用奇怪伪影遮挡视野的问题，其折射也已修复（默认禁用）；
*   修复了封闭座舱车辆中头盔在镜中受太阳光照射的问题，并且第一人称视角下投射正确的阴影；
*   调整了阴影过滤以减少伪影，修复了远处几何体的阴影；
*   修复了镜子中缺少车辆细节的问题；
*   修复了启动时的时区完整性检查（不再出现紊乱的光照）；
*   移除了无阴影与无光照着色器集合，以加快加载速度；
*   折射灯光的 TAA 不再有那么多延迟，截图中也更锐利；
*   不再因与非网格车辆碰撞体的碰撞而生成碎片（那些通常用于底盘和滑块）；
*   虚拟后视镜不再干扰 UI；
*   DXGI flip mode 在全屏下不再可用，本来就该如此；
*   CSP 雷达应用现在能正常淡出；
*   CSP 车手名牌在禁用后处理时也能正常工作；
*   相机跳转后，动态模糊不会立刻把一切都糊掉；
*   模型更改时，烘焙的假阴影或车辆湿度贴图现在会重新构建；
*   现在使用实际车辆模型（最低 LOD）来计算车辆尺寸，因为事实证明某些模组的碰撞体错位严重；
*   修复了静态胎痕着色错误的问题；
*   修复了极端情况下地面高度估算的问题（例如附近地面有洞时）；
*   修复了 SSLR 在雾中表现异常的问题；
*   Python 函数 `ac.ext_getTyreBlister()` 在某些情况下不再使 AC 崩溃；
*   新火焰与 SSLR 的兼容性更好；
*   移除了雾气模糊效果的远处模糊（只靠雾就足够了）；
*   修复了与 AC PRO 的兼容性；
*   AC 视频设置中的负 mip bias 不再影响 GrassFX 贴图生成之类的性能；
*   修复了远处自发光消失的问题，反射中的观感也改善了；
*   车辆阴影出现在第三阴影级联中，整体渲染得到改进；
*   同时以高细节可见的车辆更多；
*   新主菜单在三屏下居中显示；
*   车漆默认不会再弄坏碳纤维；
*   车漆的极端高光参数不会再导致疯狂的眩光；
*   着色器 `ksPexPixelAlpha` 在 alpha 参数大于 1 时现在能正常工作；
*   修复了 PP 编辑器中调色纹理的实时重载；
*   WeatherFX：视锥体测试新增一个参数，可停止朝向调整；
*   新照片应用：motion 模式不再重置环绕相机；
*   远处自发光可作用于移动物体（例如摩天轮）；
*   修复了几个较小的 bug 与崩溃；

## 配置

*   支持 BC7 DDS 压缩（开销与 DX5 相同，观感好得多）；
*   全新应用，用于布置赛道遮挡体：墙与盒子；
*   全新网格过滤关键字：标志 `static` 用于静态赛道网格，标志 `castsShadows` 用于投射阴影的网格，数值 `largerThan` 检查包围球半径；
*   动态光源阴影的剔除模式现在可调，默认值从双面改为仅正面；
*   现在可以为某些大灯禁用体积光；
*   车辆输入：熄火时默认不再归零；
*   额外车辆动画：保持最终状态、将多个动画混合、将动画与常规转向动画混合（可用于手刹动画）；
*   原版车辆动画：应用 LUT 与其他后处理来改变关键帧的选择；
*   着色器替换：若纹理替换的文件缺失，将忽略整条替换；
*   车漆着色器已更新（新参数 `ApplyMatteFix`，v3 自动应用）；
*   赛道灯光现在可以跳过车辆以加快速度；
*   赛道网格可以停止投射动态阴影；
*   新的 Python 函数：`ac.ext_pauseWhenHidden(frames)`、`ac.ext_isAnyAppVisible()`；
*   新的赛道配置值：`[WIND] DYNAMIC_FLAGS_TESSELLATION=1`，改为 0 可停用曲面细分；
*   新的 G-buffer 标志 `ALPHA_TEST_GBUFFER`，用于启用 alpha 测试，以 ksAlphaRef 为阈值；
*   新的 `INPUT_REFRESH_RATE` 选项，可设置自定义刷新率（Hz），数字仪表默认 5 Hz；
*   扩展配置（车辆与赛道皆可）现在可以访问赛道数据；
