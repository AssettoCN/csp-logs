# 更新日志

## 新功能、选项与改进

*   首先，我找到了一种非常巧妙的方法，让联机服务器将 CSP 设为必需项。思路大致是修改服务器配置中的赛道 ID，使原版启动器找不到该赛道，而没有 CSP 的人也无法通过重命名赛道来匹配。为了额外一层保护，它还会修改服务器端的 `surfaces.ini`。此外，用类似的技巧我为入场列表添加了额外的标志位，例如可以为特定车辆（或所有车辆）强制开启前大灯；
*   之前视频中见到的雨滴折射现在也能在三屏与两种 VR 模式下工作。而且，现在玻璃着色器也可以使用它；
*   软粒子（雨滴使用的类似技术）现在同样支持三屏与 VR，唯一的要求是保持 YEBIS 启用；
*   为从车上落下的水滴添加了新的粒子效果（碰撞时溅落，或随时间缓慢滴落）；
*   风挡雨滴相比那段视频已经几乎完全重做（这正是花掉大部分时间的地方）；
