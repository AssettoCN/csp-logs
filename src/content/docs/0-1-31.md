# 更新日志

## 新功能、选项与改进

*   折射车灯：
    *   位置自动推测；
    *   自定义灯泡位置的选项；
    *   自发光多通道行为的选项；
    *   相比预览版性能提升；
    *   多重采样选项（开销增至四倍，非确有必要不要使用）；
*   新的多通道自发光着色器：
    *   txEmissive 的新替代模式，纹理的每个通道为一个自发光通道定义遮罩；
    *   可选的程序化模式，有四种定义区域的方式；
    *   两种镜像类型，可将对称网格的通道数从 4 增至 7；
    *   面向仪表盘的新着色器，单个网格与材质即可设置最多 25 个指示灯（仅限程序化模式）；
    *   同时具备 `_emissive` 与数字屏幕功能的新着色器，自发光遮罩也用作数字屏幕遮罩；
    *   带 `_emissive` 功能的新 PBR 玻璃着色器；
    *   车辆自发光可直接指定自发光通道，赛道可使用 `ksEmissive1`（`ksEmissive2` 等）语法；
    *   折射车灯可使用程序化定义的灯泡并关联到不同通道：
        *   [https://gfycat.com/deficientfondhorseshoecrab](https://gfycat.com/deficientfondhorseshoecrab)；（已被删除）；
        *   请使用这种方式而非动态自发光贴图！该功能可能很快就会被移除；
*   程序化草地重做：
    *   现在带几何鳍片；
    *   完全可自定义的级联；
    *   车辆驶过时会拨动草；
    *   目前暂无参数，很快会加回来；
*   新的 Python 函数：
    *   一切都用更不易出错的方式重做，顺带修复了几个 bug；
    *   如果发现 API 有任何不兼容之处，请告诉我，会尽快修复；
    *   切换到严格模式后，参数错误时会报错，而不是像以前那样由补丁静默返回默认值；
    *   Python 性能分析应用现在也会显示日志与错误消息，并更名为 `Python Apps Debug`；
    *   Python 应用的性能分析与错误处理现在在额外回调中也能工作；
*   PBR 着色器更新：
    *   加入镜面环境光（临时方案，等我搞清楚正确做法再换）；
    *   与动态光源正常配合；
    *   修复了过度遮挡的反射；
    *   PBR 格式的 txDetailNormal 新选项，包含法线、遮蔽与镜面反射水平（反转的粗糙度）；
*   灯光推测现在支持四个转向指示灯共用一个网格；
*   动态导航仪；
*   INIpp 格式更新：
    *   破坏性更改：索引现在从 1 开始而非 0，配合表达式使用时不再别扭（由于 Lua 的缘故，表达式早已从 1 开始）；
    *   新功能：
        *   生成器；
        *   可在任何位置引用 mixin，支持内联参数与可选的简短语法；
        *   值的自动编号；
        *   向量支持；
    *   大量 bug 修复；
    *   速度快了一倍；
    *   现在带自动化测试，确保新功能不会破坏任何东西！
    *   更多信息请查看 INIpp 仓库及其 README；
*   带模板的可包含配置：
    *   新的 `custom_emissive.ini`，几行就能设置转向灯之类的东西；
    *   新的 `selflighting.ini`，帮助更快地为车头灯照亮车身添加额外光源；
    *   玻璃：亮度调整选项、使用法线贴图的选项，以及必要时使用法线贴图 alpha 通道的选项；
    *   车漆：平铺修复现在是可选的，使用 `ApplyTilingFix = 0` 可禁用；
    *   车内 PBR 材质：新的 `Material_LeatherDetailed` 模板，带 PBR 细节纹理，另有新选项；
    *   导航仪的大量新内容；
*   Extra FX：车灯玻璃新增 `MASK_GBUFFER` 选项，可获取其背后的局部反射，但更暗；
*   alpha-to-coverage 相关更改暂时回退；
*   尘土粒子使用来自 Tyres FX 的赛道颜色，这次是真的正确了；
*   SSLR 加入少许色调映射，以减少过亮物体反射造成的锯齿；
*   模拟里程表：
    *   背景颜色现在使用正确；
    *   使用 `content/fonts` 中的字体；
    *   字体垂直缩放与垂直偏移的选项；
*   车辆输入：
    *   选项 `INPUT_ADD` 与 `INPUT_MULT`（有 `INPUT_LUT` 时其实用不到，但有时用简单方式设置更省事）；
    *   选项 `INPUT_THRESHOLD_LOWER_INC` 与 `INPUT_THRESHOLD_UPPER_INC`，使用小于等于或大于等于判断；
    *   新的 `SEATBELT` 输入（目前用于隐藏车手的自由相机）；
*   SSLR 与半透明物体配合更好（不像以前那么糟），例如使用新水面着色器的半透明水洼；
*   有物体非常靠近相机时，自适应阴影边界现在应该会拉近；
*   新的数字屏幕着色器，可像叠加层一样作用于现有网格；
*   地形投射阴影的选项：太阳角度低时按双面投射阴影；
*   禁用赛道相机 LOD 距离倍率的选项，默认启用；
*   在 `SHADER_REPLACEMENT_...` 中填充缺失纹理的选项；
*   禁用侧面剔除的选项；
*   水面着色器：使用 txNormal 的 alpha 通道的选项；
*   闪烁自发光的默认频率改为 2.2 Hz（转向灯除外）；
*   新车漆恢复了损坏与污垢效果；
*   车辆网格过滤器：按 LOD 过滤；
*   车灯新选项：
    *   `OFFSET` 与 `OFF_OFFSET`，三个数值，用于微调位置而不必重写推测值；
    *   `ONESIDED`，取值 `LEFT` 或 `RIGHT`：与设置 `MIRROR=0` 和 `POSITION=X, …`（X 为旧的 `MIRROR` 值）等效，但对推测更友好；
    *   `PREFER_FRONT`，用于位置推测（网格被拆成前后两半时）或正确选取自定义自发光；
*   为特定材质或网格的局部反射增加额外锐度的选项；
*   自定义模拟仪表：
    *   修复了 `POS_OFFSET_START` 与 `POS_OFFSET_END`；
    *   使用 `SCALE_START` 与 `SCALE_END` 进行缩放的选项；
    *   新的 `LOWER_BOUND` 选项；
*   大量各类修复与稳定性改进；
