# 更新日志

## 新功能、选项与改进

*   调校菜单与悬架应用中为 Cosmic 悬架新增主销后倾角（Caster）与主销内倾角（KPI）显示；
*   更新了轮胎接触点逻辑；
*   新的物理实验：比赛开始后禁用维修区以外的车辆休眠（暂时默认禁用）；
*   FFB Tweaks：
    *   对跳过的 FFB 采样取平均的选项，让反馈更精确；
    *   降低 FFB 阻尼更新频率的选项（因为它只用于低速 FFB 阻尼，降低更新频率是合理的。对某些方向盘基座可帮助缓解低速时的 99% CPU 警告）；
*   GPU 优化：
    *   对缓存的 CSP 纹理（如 WeatherFX 云或新树木的公告板）使用后台 BC7 压缩的选项；
    *   用后台 BC7 压缩重新编码压缩不当的 AC 纹理的选项，让后续加载更快、运行更好；
*   Graphics Adjustments：
    *   用碰撞体网格为所有车辆生成新的后备 LOD；
    *   限制只有一个 LOD 的车辆的 LOD A 激活数量；
    *   在单屏与三屏模式下于场景之前渲染虚拟后视镜的选项（可能会给折射与 ExtraFX 带来一点小毛刺，但能省一点性能）；
*   按住 Shift 或 Alt 会阻止 AC 系统绑定（如回放的 Ctrl+R），可以把 Ctrl+Shift+R 之类绑定到别的东西上；
*   车辆仪表新增选项，让车头灯稍微晃动；
*   新的音频调整，为更多音频事件添加混响，并稍微增加非混响事件的混响量；
*   新的任务栏更新：
    *   可折叠的分类；
    *   可选的精简模式，直接进入应用列表；
    *   可选的紧凑模式；
    *   滚动速度提升；
    *   支持旧版 CSP 任务栏的 Alt+H 快捷键；
*   全新的内置音频应用，取代原版，带预设与额外滑块；
*   移除了原版太阳轨迹，改用春分轨迹（2023 年 3 月 20 日），但 WeatherFX 样式与 Lua 应用可以更改中性太阳轨迹的时间戳；
*   赛道音量滑块从 Track Adjustments 移到 AC 音频设置，同时也影响赛道 Lua 脚本；
*   将车辆重置与后退一步绑定到控制器按键；
*   CSP Debug 应用：
    *   点击赛道传送到点击位置的选项（单人练习会话中）；
    *   保存与加载车辆状态可绑定到控制器，即使应用关闭也能工作；
*   默认 WeatherFX 样式：
    *   晴天时根据光污染配置添加一点污染雾霾；
    *   雨声与其他降雨相关效果改进；
*   全新的 Traffic 比赛模式（需要带 `traffic-planner-ready` 标签且已配置的赛道）；
*   Walking Out 模块从隐藏模块变为新的 Quick Drive 模式；
*   UI 动画稍快，并支持彻底禁用动画的选项；
*   三屏模式的选项，可为每侧配置边距来稍微移动 UI，避免应用跑到可见区域之外，还能省一点 FPS；
*   OpenVR 的实验性调整，延迟缓冲交换，或许能提升响应速度；
*   部分 CSP 资源被打包进 `dwrite.dll`，工作更可靠、加载也更快；
*   将累积 DOF 形状沿水平或垂直拉伸的选项；
*   网页浏览器引擎更新：来自 OBS CEF 仓库的一些安全修复，直接循环模式下 FPS 不再锁定在 30；
*   窗口化 VR 的选项，可捕获鼠标并强制 AC 窗口置顶，以防万一；
*   CSP 现在支持来自 CM 的所有系统热键，响应更快、修饰键逻辑也更正确；
*   禁用季节时默认也禁用精确太阳轨迹（联机比赛且服务器明确指定日期时除外）；
*   维修区加油时，仪表盘上显示的油量平滑增长；

## 配置

*   新增选项，为载荷敏感度 LUT 使用线性插值（代替默认的三次插值）；
*   会话（离线与联机）可以用 `[EXTRA_RULES] PITS_ORDER=F<TR>` 更改维修区内的动作顺序（`F` 加油、`T` 换胎、`R` 维修，尖括号表示可并行动作，AC 默认行为是 `<FTR>`）；
*   `[RAIN_FX]` 设置应该能从扩展服务器配置正确加载了；
*   Mumble 集成：新参数 `MUTE_DISTANCE`，将比指定距离更远的车辆的声音完全静音；
*   在要求 2690 版本或更新的服务器上，可以重置编辑过的车辆颜色；
*   服务器可以让 CSP 校验自身完整性；
*   车辆再添 4 个额外开关（G、H、I、J）；
*   车辆配置可以指定切换附加项时显示的消息；
*   `ALTERNATIVE_PHYSICS_MESH_DETECTION` 选项现在也适用于没有扩展物理的赛道；
*   线光源可用于车辆大灯、刹车灯等（会禁用边缘或副聚光灯等一些额外功能，但某些特殊场合可能有用）；
*   赛道 .ksanim 动画重载时不应再崩溃；
*   Traffic planner：一些修复，自动加载数据，只需复制模型和带描述的 JSON 文件即可添加新车辆；
*   条件表达式：函数（如赛道条件中的 `INPUT = max(SUN, 45)`）之前不能用，现在应该可以了；
*   NeckFX 头盔参数可按车辆配置；
*   控制器的 `SCRIPT_…` 输入数量从 8 增加到 256；
*   修复了动画雨刮工具在动画未激活时显示 RainFX 痕迹的问题；
*   VAO 车内亮度调整不再应用于 `smCarPaint` 着色器；
*   新的实验性赛道参数 `[VAO] WEIGHT_FACTOR=1`，让额外 VAO 采样更平滑（默认值为 0.05，值越低意味着较暗采样的权重越小）；
*   音响的 multimap 着色器可以自发光；

*   折射玻璃更稳定，并为彩色灯泡和内部法线偏移加了选项，以防万一；
*   以防万一，车辆可以在 `setup.ini` 中用 `[_EXTENSION] QUICK_MENU_WINGS_LABEL=…` 覆盖 `WINGS` 标签；

    *   `ac.setWeatherExactUTC0Timestamp()` 可设置精确的 UTC0 时间戳，同时更新夏令时；

    *   新模式与联机脚本可以更改排行榜顺序；

    *   更改 AI 车手姓名与车队的新物理函数；
