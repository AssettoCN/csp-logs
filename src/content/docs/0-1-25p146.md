# 更新日志

## 新功能、选项与改进

*   @Clout 的新 Chaser Camera（追逐相机）脚本；
*   必要时可在赛道与车辆配置中禁用网格优化；
*   内存占用优化，回放改为动态内存分配；
*   自由相机（Freer camera）：
    *   更平滑移动的选项；
    *   用鼠标第 4、5 键上下移动相机；
    *   回放中按住鼠标右键的同时按左键可进入慢动作；
*   Neck FX：允许用 Track IR 环视与平移的选项，从而可与 RHM 配合使用；
*   改进了对摆动雨刮的推测；
*   模型替换不再将任何车辆网格视为受保护；
*   脉冲转速表支持创建无延迟但带惯性的指针；
*   新的痕迹（traces）粒子，默认禁用，面向特定风格；
*   车内 HBAO+ 改进；
*   自动转向灯的选项；
*   在可用时默认开启近光的选项；
*   车辆局部立方体贴图，用于 Caterham 大灯之类的特殊部件；
*   加载时拆分车辆网格的选项；
*   Reflections FX：车内遮罩的默认参数改进；
*   累积截图不再因调色而使画面变暗；
*   修复了 Stereo 的车漆着色器；
*   修复了静态反射；
*   远处自发光的光晕随距离衰减；
*   Weather FX 现在也会使用 `cubemap_model.kn5`（包括赛道专属的）；
    *   你知道吗，可以创建自己的 `cubemap_model.kn5` 放进赛道文件夹来改变静态反射？这是原版 AC 的功能；
*   配置修复；
*   其他小修复；
