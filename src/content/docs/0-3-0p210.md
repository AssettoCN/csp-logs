# 更新日志

## 新功能、选项与改进

*   重大修复：
    *   修复三屏相关导致 CSP 未读取常规 AC 配置的问题；
    *   重写渲染与物理线程的计时，修复一些偶发的性能问题；
    *   修复折射前车灯弄乱某些网格（尤其是 LOD 网格）的问题；
    *   图形调整：重做车辙修复，不再破坏其他东西；
    *   修复某些配置下 V-sync 工作不正常的问题；

*   CSP 物理：
    *   修复扭矩反作用力的边界情况；
    *   CSP Logger 通道更多，并引入可变精度，避免部分通道触及数据类型上限；
    *   修正 Wings 应用与 CSP 记录器的下压力/阻力数值（鳍片因代码中标志设置错误而被计入，未影响物理）；
    *   新的转向助力最大扭矩设置选项；
    *   修复轮胎保温毯温度和覆盖值；
    *   `tyres.ini` 新增 `GRIP_MULT_Y`；
    *   重写转速限制器，与车桥形变更好地配合；
    *   CSP 控制器输入：为缺失的附加项 G…T 添加输入，新增用于日间行车灯的 `DRL` 输入；
    *   `setup.ini` 新增 `EXT_LOOK = CHECKBOX`，将设置项外观改为复选框（在 `MIN` 和 `MAX` 之间切换）；
    *   使用 `EXT_VISIBLE_WITH` 和 `EXT_ENABLED_WITH`，根据其他设置项的状态隐藏和禁用设置项；
    *   添加 `[EXT_TAB_TWEAKS_0] TAB=ALIGNMENT EXT_VISIBLE_WITH=…` 即可隐藏设置标签页（查询示例：`EXT_VISIBLE_WITH=WING_1` 表示 WING_1 非零时显示，`EXT_VISIBLE_WITH=WING_1:5` 表示等于 5 时显示，`WING_1≠5` 表示不等于 5，`WING_1>5` 表示大于 5，`WING_1≥5` 表示大于等于 5，也支持复杂查询如 `EXT_ENABLED_WITH='{ WING_1:5 & ( ! WING_2<3 | SPRING_RATE_LF>10 ) }'`）；

*   输入：
    *   修复高帧率下部分键盘按键完全失效的问题；
    *   新绑定：切换远光/近光/关闭大灯；
    *   新绑定：切换 DRL；
    *   新绑定：消除烟雾；
    *   Direct Input 设备再次随键盘或手柄输入模式初始化，在后台进行，不影响加载速度；

*   音频：
    *   修复换挡事件的混线问题；
    *   修复 `WAV` 为大写时路面音频不工作的问题；
    *   修复路面音量滑块；
    *   新调整 `Alter wind audio`，用 DSP 效果替代用于尾流的损坏音频采样；
    *   新音频调整：播放附近车辆的风声；
    *   无大气环境时风声音量淡出（用于外太空比赛）；
    *   `Silence audio`：默认值改为新的 `When idling in background`，与 DXGI 调整的后台闲置功能兼容性更好；

*   DXGI 调整：
    *   新调整：AC 在后台时激活 Win11 效率模式，默认启用；
    *   新 `Consider DXGI's occluded state` 调整（此前 0.3 中始终开启，现在可以禁用，用于调试 AC 偶尔停止渲染的问题）；

    *   新实验性后台闲置选项，暂停渲染而非限制帧率（或可解决某些系统上 AC 被 Alt+Tab 切回后偶尔拒绝唤醒的毛刺）；

    *   可根据条件（全屏和/或 VR，或始终）启用将光标限制在 AC 窗口内、强制 AC 置顶和强制聚焦的选项；
    *   无边框窗口选项（即便没有可见边框，仍可拖动和调整大小）；
    *   备用 V-sync 实现，以防 Windows 11 的 `Variable refresh rate` 选项阻止常规 V-sync 生效；

## 配置

*   新增 `[SHADER_REPLACEMENT_…] STICKERS_FIX=1`，让贴纸网格覆盖其下方的任何网格（与 `DEPTH_MODE = LESSEQUAL` 配合效果最佳）；
*   赛道音频：`RELATIVE` 考虑整个变换，而不仅是相对于父节点的局部偏移；
*   Extra FX 自发光体新增 `AVERAGE_NORMAL_MIX` 参数，或有助于某些特别棘手的情况；
*   车辆仪表新增 `INPUT = DRL`，车灯新增 `BIND_TO_DRL`，自定义自发光体新增 `FALLBACK_DRL_COLOR`（默认情况下 `OFF_COLOR` 仅在日间行车灯激活时生效，但若设置了 `FALLBACK_DRL_COLOR`，`OFF_COLOR` 将始终应用），键盘绑定可手动切换 DRL；
*   附加车辆动画（`[ANIMATION_…]`）新标志：设置 `AB_ANIMATION = 1` 后，激活时动画从 0% 走到 50%，停用时从 50% 走到 100%，然后循环回 0%；
*   新增 `[DATA] DI_0_ALPHA = <0.5>, [DIRECT]`，用于调整数字仪表的透明度（目前仅限 v2 文本）；
*   新增 `[BASIC] DISABLE_SHIFTING_ANIMATIONS_WITH_AUTOSHIFTER = 1`，适用于将自动换挡器当作自动变速箱使用的车辆（不推荐，现在也有实现自动变速箱的正确方法）；
*   CSP 动画雨刮按从后到先的顺序加载，修复与旧的、对同一网格多次做动画的损坏 MOD 的兼容性（大约 0.2.8 时期，一个网格实际上会同时被动画化两次引发一些问题，后来修复为已使用的网格会被排除，但这破坏了一些 MOD，现在应该能正常工作且不冲突）；
*   动画雨刮工具：更好地支持 UI 缩放；
*   移除车辆设置 `ALLOW_INTERIOR_SSAO` 和 `ALLOW_INTERIOR_SSGI`（反正它们不影响 HBAO+ 和 ASSAO，而修复它肯定会惹恼很多人）；
*   赛道配置：`[VAO] FORCE_APPLY=1`，将 VAO 调整应用到较新的 VAO 补丁（v4 及以上）；
*   赛道配置新增 `[SPECTATORS] ALLOW_DYNAMIC=0/1` 参数，覆盖赛道调整中的 `Dynamic spectators amount` 选项；
*   场景查询新增 `ownMaterial:y` 和 `inserted:y`（用于 `[MODEL_REPLACEMENT_…]` 中的节点和网格）属性；
*   材质调整现在更改实际材质值，而不仅是镜像到 GPU 的值（解决某些情况下无法正确应用的问题）；
*   赛道的默认光污染色调不再为零（强度仍为 0，这只是让配置稍微简单些）；
*   赛道灯光新增 `DISTANT_LAYER_FADE_AT` 和 `DISTANT_LAYER_FADE_SMOOTH`，在远距层激活时使用；
*   更新赛道远光灯配置不再触发完整重载；
*   赛道 Shader 替换只在开始时加载一次（此前每个 KN5 都会反复加载）；
*   如果某个树木网格没有缓存数据，树木表面对齐将强制重算（而不是像以前那样，缓存中存在已不存在的网格数据时）；
*   Objects Inspector 显示赛道网格的静态状态（静态网格绘制更快）；

## Lua & Python

*   通用 API：
    *   车辆状态新字段：`.isAIUsingRainTyres`（修复此前类型错误的隐藏字段 `.aiRainTyres`）、`.isAIGoingToPits`、`.aiLapsLeft`；
    *   `ac.uniqueMachineKey()` 解除弃用（现在 CSP 在启动时计算该键，无需等待）；
    *   修复游戏开始时部分车辆和模拟状态未被正确填充的问题；
    *   `math.isnan()` 不应再出问题；
    *   `ac.ControlButton:setDisabled()` 应兼容按住模式标志；
    *   所有脚本可用的新全局变量 `__monitored`：若为 `true`，表示 Lua Debug 应用中的脚本标签页已打开；

*   UI API：
    *   新增 `ui.windowTitleWidth()` 函数；
    *   解绑 `ac.ControlButton():control()` 的所有输入会完全移除该节（不影响常规 AC 绑定，仅限自定义绑定）；
    *   `ui.modalPopup()`、`ui.modalPrompt()`：新增自动关闭的正确参数，默认为 `false`，修复近期引入的回归；
    *   附加车辆图标（`ui.drawCarIcon()`）：修复随 UI 缩放的大小和与燃油图标的定位；

*   I/O：
    *   新增 `os.loadDLL()` 函数，以备不时之需；
    *   `io.scanDir()`：修复缺失的文件属性（如 `.isArchive`）；

*   `ui.GIFPlayer()`：
    *   动态 GIF：更好地支持某些循环类型；
    *   `ui.GIFPlayer()` 新增用于倒带、暂停和恢复播放的方法；
    *   WEBP 支持改进；
    *   脚本间状态共享（使用 `:rewind()` 将播放器与其他播放器分离）；
    *   如果播放器通过 Scene API 被指定为纹理，被 GC 回收后仍继续工作；
    *   游戏帧率低时 GIF 不再闪烁；
    *   动态纹理（GIF 和 WEBP）可在 UI API 以及皮肤/Shader 替换中直接使用（对一切都用 `ui.MediaPlayer` 来说可能是更快的替代方案）；

*   Gameplay API：
    *   Gameplay API 新增 `ac.setDriverShiftAnimationPreloadThreshold()`；
    *   `ac.applyContentConfig()`：新增为本地化配置更新设置键的选项，更多赛道特性可被更改；

*   Scene API：
    *   Scene API 新增 `:blendAnimation()`，允许将几个动画混合在一起（此外，AC 动画计算已重写，更平滑、更精简）；
    *   频繁调用的 `sceneRoot:yes` 几何拍摄会阻止附近几何体和车辆被卸载或切换到较低 LOD（现在 OBS 摄像机可以更可靠地渲染远处的东西）；
    *   几何拍摄新增 `:setGrass()`，包含来自 Grass FX 的草地；

*   Physics API：
    *   `physics.addTrackSurface()` 不再使用 Embree，实时赛道表面改由 ODE 处理，以改善编辑性能，代价是轮胎光线检测性能（只要新表面相对低模就足够快，如果不高模，反正也工作不好），稳定性也应更好；
    *   若以 `false` 调用 `physics.setAIPitStopRequest`，会让 AC 在约 100 毫秒内不再指示 AI 进站；
    *   新增 `physics.setAILapsToComplete()`，允许覆盖 AC AI 内部的计数器（该计数器告诉它们何时停止比赛并返回维修区）；

*   车辆脚本：
    *   `ac.setGearLabel()` 新增禁用换挡动画和音频的参数；
    *   `ac.AudioEvent()` 现在可以使用 `cars/:own/engine_int` 之类的语法，无需显式指定车辆 ID 即可创建音频事件（这样 `[AUDIO_REDIRECT]` 就能工作了）；

*   车辆物理脚本：
    *   新增 `ac.extendCarState()`，允许从车辆状态保存和加载额外数据（TimeShift 等应用在使用）；
    *   车辆物理脚本中的 `ac.readDataFile()` 在车辆数据被打包时现在可以用相对路径访问车辆数据（之前的修复只在绝对路径下有效）；
    *   新增 `ac.showNotification()`，允许显示类似降挡警告的警示（更多类型即将推出，有需要请告诉我）；
    *   新增 `ac.setGearsGrinding()`：可添加变速箱损伤的选项；
    *   新增 `ac.replaceClutch()`，允许定义自定义离合器实现；
    *   `ac.setExtraMass()`：新增指定阻尼、刚度和键的参数（允许移动配重位置）；
    *   新增 `ac.CarPhysicsValueID.ForcedAutoclutch`，允许完全禁用自动离合器，即使所选输入方式试图保持启用；
    *   新增 `ac.accessCarPhysics().targetGear`，允许追踪换挡过程；
    *   新增 `ac.CarPhysicsValueID.DrivetrainOpenThreshold`、`ac.CarPhysicsValueID.DrivetrainClutchOverride`、`ac.CarPhysicsValueID.DrivetrainDriveVelocityMult`、`ac.CarPhysicsValueID.DrivetrainEngagedGear`；
    *   来自打包数据的车辆物理脚本的 `__dirname` 现在指向 `/data` 文件夹，与未打包脚本的行为一致（希望没人用它来判断车辆数据是否打包，因为那是个 bug）；

*   库：
    *   新增 `shared/physics/automatic-transmission` 及另外三个库，简化自动和自动手动变速箱的设置；
    *   新增 `shared/ui/replay` 库，简化构建自定义回放 UI；
    *   新增 `shared/sim/di` 库，用于实时更改 `digital_instruments.ini` 的某些属性；
    *   新增 `shared/sim/events` 库，用于罕见事件（目前允许 Weather FX 风格监听光污染配置变化）；
    *   新增 `shared/utils/steamvr` 库，提供一些 Steam VR 附加功能；
    *   新增 `ghost.stripRecordMetadata()`，用于去除 0.3.0+ 的额外幽灵数据；
    *   `shared/ui/components`：新辅助系统编辑器的相关函数；
    *   `shared/` 库从内部存储加载以确保使用它们的脚本的完整性，磁盘上的实际文件现在仅用于文档说明；

*   其他变更与修复：
    *   面向 FFB 脚本的新实验性 `ac.getSteerJointFeedback()`；
    *   预编译 Lua 字节码使用唯一机器键校验，在一台 PC 上生成的缓存文件无法在另一台上使用；
    *   修复一些与 Lua 资源管理相关的崩溃（例如某些用 `ui.GIFPlayer` 播放静态 GIF 的应用在重启时崩溃）；
