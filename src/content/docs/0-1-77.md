# 更新日志

## 新功能、选项与改进

*   新的服务器选项：
    *   计算远程车辆车轮位置的新方法，远程车辆跳变或翻车时应该更好一些（可选）；
    *   同样在新方法下，服务器可以选择让客户端交换束角（toe）与外倾角（camber）数据，使车轮定位更准确；
    *   而且，新方法可能会降低客户端的 CPU 负载；
    *   让已断开的车辆可见；
    *   调整看台上 2D 观众的数量；
    *   限制操控锁定时间；
    *   为所有车辆强制开启大灯，而无需让服务器变成 CSP 专用；
    *   让部分维修通道不计入通过维修区处罚的执行（例如斯帕的副维修通道）；
    *   配置车辆间的碰撞（更软、更硬、更有弹性等；取决于服务器需要什么）；
    *   为穿越维修区的圈数启用圈速无效化；
    *   校验 Assetto Corsa 各类文件的完整性；
    *   强制激活特定 CSP 模块；
    *   扩展此前加入的 `NO_BACK_TO_PITS`：现在可以允许已处于自己停车位的车使用维修区（用于访问调校）；
*   GamepadFX：
    *   新模块，用 Lua 脚本更改手柄输入，实现新的操控方案或单纯充当辅助；
    *   Dmitrii A. 制作的 `Custom` 新脚本，利用作用在方向盘上的力；
*   GUI：
    *   暂停菜单新外观，内置照片模式（目前默认禁用）；
    *   用控制器（如方向盘或手柄）移动鼠标光标并进行选择的选项；
*   加载画面：
    *   不覆盖整个屏幕的动画不再移动，并可用模糊版填充空白区域；
    *   与自定义截图名称的兼容性更好（严格搜索现在默认禁用，名称检查改进）；
    *   严格搜索禁用时递归搜索截图；
    *   可选幻灯片的淡入淡出；
*   键盘输入方式：
    *   平滑切换鼠标转向，确保悬架不会受损；
    *   鼠标转向：可用第 4、第 5 按键或滚轮换挡；窗口失焦时暂停现在也适用于油门与刹车；
*   Graphics Adjustments：
    *   VHS 滤镜被新的可脚本化滤镜系统取代，可用 Lua 创建动态后处理滤镜；
    *   新的隧道效果滤镜，随速度添加少许径向模糊，碰撞时加黑白效果；
    *   新的复古滤镜，试图重现老影像的风格；
*   TyresFX：
    *   随行驶里程显现的额外磨损视觉效果；
    *   爆胎的新外观；
*   WeatherFX：
    *   季节调整（冬天观感）默认禁用，可在 WeatherFX 设置中重新启用；
    *   默认 WeatherFX 脚本更新了天空纹理与星星亮度计算；
    *   默认 WeatherFX 脚本中的阴天与光污染已更新；
    *   天气脚本现在可以单独控制太阳镜面强度，并在使用云穹顶时用遮罩盖住月亮与星星；
*   自定义车辆物理：
    *   用 LUT 将发动机扭矩与故障概率关联到发动机损坏；
    *   添加物理 Lua 脚本，可读写车辆输入等（可用于创建各种自动变速箱、起步控制、不同的控车方式等）；
*   自定义赛道物理：
    *   在 `surfaces.ini` 中定义更快的自定义碰撞体，如胶囊体、圆柱体、长方体、球体与平面；

*   内置脚本重现某种 Android Auto 系统，可轻松加入车辆配置（支持额外的自定义应用）；
*   网格数据压缩现在使用 LZ4 压缩以加快加载；
*   自定义物理：磨损轮胎爆胎的替代选项；
*   尘土粒子随季节调整改变颜色（若在赛道配置中设置）；
*   观众的新渲染方式（带阴影且更快），观众可使用相机闪光灯的选项；

## 配置

*   赛道配置：
    *   更改动态阴影投射属性现在实时生效；
    *   指定可燃材质（干草捆燃烧有额外视觉效果，已默认加入 `materials_track` 的 `Material_Bale`）；
