# 更新日志

- 关键修复：
  - 悬挂损坏已修复；
  - 修复了后部 Cosmic 悬挂损坏未生效、或传送回维修区时损坏未重置的问题；
  - 修复了原版物理在一些带有双面表面的赛道上工作异常的问题；
  - AC 窗口处理略有重构：现在在不同缩放比例的显示器之间能正确识别 DPI，修复了一系列问题。

- FFB：
  - 默认的阻尼帧跳过数从 5 降至 3；
  - FFB 调整中新增 “Adaptive FFB performance”（自适应 FFB 性能）调整项，现在带有实时调整帧跳过的选项，默认禁用；
  - “Custom FFB initialization” 实验已更名为 “Custom FFB handling”，现在包含自定义 FFB 应用（仍默认禁用）；
  - 修复了自适应硬碰撞，现在模拟的是真实的刚性内部结构，而不是神奇地把外表面变刚性，同样适用于轮辋与地面的碰撞；
  - Xbox 手柄的 impulse triggers 扳机震动更新，更安全也更稳定；
  - Gamepad FX 新增将震动频率从 30 Hz 提升到 60 Hz 的选项（默认禁用）。

- 性能相关：
  - 若干修复，应能改善部分 PC 上的性能回退问题；
  - “Hyperthreading fix” 选项已重构，现在为物理工作线程留出更多核心，并默认限制物理工作线程的数量；
  - 前 400 个延迟物理帧会记录一些内部测量数据，以帮助诊断问题；
  - ODE 步进多线程现在仅在求解器耗时较长时才会启用，免得为一点点微不足道的工作白白启动这些线程、浪费时间和资源。

- DLSS：
  - 启用 Neural Rendering 的选项（需要相应的库才能工作，可能得等到正式发布才能获得）；
  - 除非禁用，CSP 会检查自定义 DLSS DLL 的完整性，以保护用户安全。

- 音频：
  - 音频爆音问题应有所改善；
  - 车辆数量上限的设置与原版实现保持一致；
  - 新的车辆音频实现同样会在估算超出范围时禁用远处的音频，与原版一致；
  - 为同时发生的碰撞音频事件添加了数量上限，并更高效地利用事件池；
  - 超出范围的轮胎打滑、路面和碰撞音频事件也不再播放。

- 一些有助于降低内存占用的功能（默认禁用）：
  - 对保存不当的纹理所生成的 MIP 使用 DDS 压缩的选项；
  - 限制纹理分辨率的选项；
  - 按内容追踪内存占用的选项（显示在 Render Stats 中）；
  - 逐步提交回放内存的选项。

- Render Stats 应用：
  - 物理线程的优先级显示在提示信息中；
  - 该应用会追踪提交 FFB 所需的时间（显示在物理提示信息和 “Other threads”（其他线程）部分）；
  - 性能报告包含一些物理计算的细节。

- CSP 预览：
  - 色调映射、环境光和环境照明现在与 Content Manager 中配置的一致；
  - 反射、反射中的阴影、地面切换、DOF 和 HDR 开关均会正常生效；
  - 正确的镜像泛光着色器；
  - 实现已脱离默认的 Weather FX 样式；
  - 转向现在平滑施加，避免某些悬挂爆炸；
  - 修复了某些车辆卡住的问题；
  - 一些小修复；
  - Small Tweaks 中新增一个选项，恢复几个版本前那种旧的破损外观，让为 CSP 调校的旧预设仍能使用。

- P2P 1v1 及其他 altonline 模式：
  - 修复了 P2P 1v1 模式、其他 altonline 模式或初始加载为 “nul” 的车辆中其他车辆声音的问题；
  - P2P 1v1 和 altonline：车辆状态中的标志位现在会被正确应用。

- 杂项：
  - “Repair wheel joints” 实验已重做，改为限制车轮可能的移动（仅适用于 DWB 和支柱式悬挂）；
  - CSP 会在初始化期间为扩展服务器同步服务器特性；
  - 如果禁用了新烟雾，旧烟雾会生成简单的飞溅效果；
  - 新增选项：跟随桌面缩放，或在缩放比例不同的显示器之间保持分辨率不变；
  - “Pace frames better” 选项已改进，应能更可靠地工作；
  - 为联机服务器新增 `[EXTRA_RULES] FORCE_NEW_PARTICLES=1` 参数；
  - 联机连接时的文件校验失败会如实上报，而不再显示为笼统的握手失败；
  - 校验和失败会作为错误显示，并列出可能不匹配的文件；
  - FFmpeg 插件不再在加载一开始就阻塞，而是先让 Assetto Corsa 加载，最后再做阻塞处理；
  - 详细崩溃报告再次默认禁用，以缓解报告生成失败的问题；
  - 更好地处理 DirectX 初始化失败；
  - 新增 “One-sided boxes for car colliders”（车辆碰撞体使用单面盒）实验，默认禁用；
  - 加载期间显示提示和车辆预览的选项，默认禁用；
  - 那些新 ODE 优化的选项现在可见了，以备不时之需；
  - 调整了网络请求的默认设置（HTTP3 和 TCP Fast Open 现在默认禁用）；
  - 部分 IMGUI 内部变量现在即使 UI 隐藏也会更新；
  - 在 “race.ini” 中写入 `[RACE] __START_IMMEDIATELY=1` 后，比赛会立即开始（CM 更新稍后就到）。

- 修复：
  - 动画尾翼在回放中正常工作了；
  - 修复了可选车辆部件的问题，纠正了回放中尾翼等部件缺失的情况；
  - 回放可以在 Wine 中再次打开了（近期引入的回退问题）；
  - 修复了批量射线检测的 ODE 问题；
  - 修复了赛道缺失时的错误消息；
  - 新主菜单：修复了尾流显示（包括离线的滑块和联机时 CSP 调整的显示）；
  - `FREQUENT_TRACK_CHANGES` 功能恢复正常；
  - “Force enable free camera” 现在可用了（此前仅在 VR 中有效）；
  - 观战时雨滴不再绘制在飞溅效果之上；
  - 禁用后期处理但保留 MSAA 时，不再弄乱自定义模式、粒子之类的东西；
  - 修复了车轮与车辆碰撞偶尔导致的崩溃；
  - 修复了从最低 LOD 计算车辆 AABB 的问题，解决了某些车辆在 CSP 预览等方面的异常；
  - 修复了与帧内特定时刻创建和使用的额外光源相关的偶发崩溃；
  - 换入使用 `make-…::` 的车辆不再导致崩溃；
  - 手电筒光源不再残留；
  - 小幅改进了用鼠标旋转自由视角的体验；
  - 崩溃报告的生成应更可靠，对话框不会再在打开几秒后消失；
  - 修复了某些配置下的偶发崩溃；
  - ReflectionsFX Debug 应用不再在非 LCS 天气样式下破坏 IBL。

- Lua：
  - `ac.makeScreenshot()`：新增参数 `iterations` 和 `onCameraStep`；
  - `ui.addSettings()`：将 `vec2()` 作为 `size` 传入，即可得到一个简单的固定尺寸窗口；
  - 为具有 I/O 权限的脚本新增 `require('shared/sim/cspdebug').hideCarInReplay()` 函数；
  - Lua 文档的小修复。
