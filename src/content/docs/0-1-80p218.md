# 更新日志

## 新功能、选项与改进

*   CM 变更；
    *   CSP 安装改进，更稳定，尤其是拖入 CM 的压缩包。另外，支持简短的 CSP 预览版安装 URL；
    *   WeatherFX 控制器选择移至 Quick Drive 的天气选择，集成更无缝，动态 WeatherFX 控制器现在可以定义自己的设置；
    *   Drag 与 Time Attack 模式合并为一个子菜单，CSP 现在也可以在其中添加新模式（而不是显示在模块里）；
    *   Python 应用设置组移至 Assetto Corsa 设置并相应更名；
    *   选项，隐藏车辆与赛道选择对话框的工具提示；
    *   修复了从几何体创建赛道地图；

*   CSP 主要变更；
    *   针对 FFB 方向盘的替代软锁实现：与原版不同，施加平滑，并考虑转向速度，尽量让边界坚实但不突兀，适用于所有方向盘，尽管不同类型的方向盘可能需要一些调整；
    *   现在也可以用 Lua 创建自定义 FFB 后处理脚本（替代软锁最初就是这样实现的，后来为了稍好的性能移入了 C++，但其代码仍可作为示例）。这些脚本可以同时更改 FFB 强度与阻尼；
    *   RainFX 视觉、物理与 AI 行为的各种调整（更多变化很快到来）：
        *   AI 会根据自身水平与攻击性更好地适应雨天条件，并在雨中选择更安全的线路；
        *   修复了轮胎选择。另外，若默认轮胎是半热熔胎，雨天会切换到街胎；
        *   实验性选项，让 AI 绕开水洼；
        *   在某些赛道上 AI 偶尔在急弯前刹车过猛的问题仍存在，正在修复；
        *   改进了默认天气脚本中的雨声音频；
        *   默认雨声音量改为 100%；
    *   其他 AI 调整：
        *   选项，让简单 AI 选择不那么激进的线路（默认禁用）；
        *   选项，让 AI 在被阻挡时表现得不耐烦；
    *   VR：
        *   增强空间音频的选项（位于 VR tweaks，默认禁用）：降低部分音频事件的最小距离，使其方位感更明显；
        *   镜像稳定器（位于 VR tweaks，默认禁用）：平滑主显示器镜像画面中的抖动，改善观赛体验；
        *   自定义 VR 镜像的垂直偏移；
    *   YEBIS 后处理新增色调映射函数（可在内置 PP 滤镜编辑器中使用），PP 滤镜也可以选择定义自己独有的色调映射函数；
    *   DualShock/DualSense：
        *   选项，尝试阻止 Steam 将它们重定义为 Steam 控制器，以免破坏直接集成；
        *   AC 现在可以识别运行中接入的设备，以防你比赛开始前忘记唤醒手柄；
    *   应用列表（AC 右侧）更新：
        *   内置应用的新图标，更多动画图标；
        *   整理：一些清理，应用名称修正，所有开发相关应用移入开发者应用类别，所有设置相关应用移入设置类别。另外，开启整理后原版 render stats 应用会被移除（可在 tweaks 区域的 GUI 设置中禁用）。注：新 render 应用在更紧凑的形态下占用更少的 CPU 与 GPU，同样能显示所有必要信息，稍后详述；
        *   Lua 应用可以将自己的类别指定为开发者或设置；
    *   转向灯：
        *   方向盘回正时自动熄灭现在可选，且仅适用于特定车辆（在车辆配置中设置，默认根据车辆年份与类别猜测）；
        *   重写了自动激活逻辑，工作更可靠；
    *   Nice Screenshots 模块：
        *   Steam 集成：
            *   按下 Steam 截图热键时捕获不含 UI 的正式截图（可选，默认启用）；
            *   将截图作为副本存入 Steam 截图画廊，或直接移动过去（可选，默认禁用）；
        *   改进了 JPG 截图中存储的 Meta Tags，更符合标准；
    *   DXGI tweaks：DPI 感知标志，强制 AC 在高 DPI 显示器上也使用视频设置中设定的分辨率（可用 Graphics Adjustments 模块的 Render Scale 放大 AC）；

    *   车手现在可以选择自己的自定义模型在联机中展示，其他车手则可以选择查看全部、仅模拟向或完全不看其他车手的自定义模型。所有模型都需经过审核，并且先要加入注册表才能生效。另外，借助这套支持实时替换模型的机制，之后应该可以实时更改更多内容；
    *   FSR 设置现在可以实时更改；

    *   使用 CSP 生成车辆预览图：
        *   AC 在后台运行，拍照后关闭；
        *   单次运行最多可为 20 辆车拍照；
        *   自动应用最佳视频与 CSP 设置；
        *   支持所有最新渲染特性与加密车辆；
        *   尽量遵循 CM 预览预设，不过色调映射选项可能仍有偏差（YEBIS 的色调映射与我当年毫无经验时为 CM 展厅做的那套东西差异很大）；
        *   可在最新版 CM 的 `Content Manager/Showroom` 设置中启用（`Use CSP for final previews render`）；
        *   输出格式与 CM 完全兼容，包括带自动选择工具的 `Update Previews`；

        *   调色标签页新增独立的颜色分级滑块。另外，自动白平衡已更新，现在准确得多，也更不容易出岔子；

    *   新 Render Stats 应用更新：
        *   物理 CPU 占用、迟到帧与 FMOD CPU 占用的详情及额外细节；
        *   一张图表，比较不同任务 CPU 与 GPU 消耗的相对占比；
        *   关于 CPU、内存与 VRAM 占用的更多信息；

        *   其他线程现在会显示各自的耗时与占总帧时间的百分比；

        *   切换车手可见性，开关车门；
        *   显示物理调试线，例如轮胎多重光线检测线；
        *   禁用顶点 AO、仅显示顶点 AO 或法线（用于调试）；

## 修复

*   各种物理修复与改进；
*   AI 线路查找网格的新替代实现：1 m 分辨率更精确，生成更快，大约快 30%，内存与磁盘占用大幅减少（Nordschleife 从 20 MB 降至 120 KB，Shuto 从 230 MB 降至 2 MB），并更好地支持在不同高度自相交的 AI 线路；
*   修复了部分模组前大灯的强度；
*   修复了某些方向盘十字键一次按键移动鼠标光标两次的问题；
*   DualSense 触觉反馈配置现在可以正确加载（此前该选项毫无效果）；
*   修复了 VR 下的 Shadowed Wheels 模块；
*   修复了回放中爆胎的音频；
*   又一次修复了基于朝向的剔除（此前会弄坏 Drag 赛道上的信号灯）；
*   文件系统监视重写，开销更低，反应更快，也更不容易丢失变更；
*   无雨时屏幕雨滴不再卡住或消耗 FPS；
*   服务器现在可以禁用雨水物理（此前该选项是坏的）；
*   Smart Mirrors：修复了根据距离调整镜子 FOV 的问题；
*   三屏模式不再因两侧低画质 FSR 区域外出现奇怪光晕而损坏；
*   更好地处理常见的 AC 错误，并提供解决一些常见问题的选项；
*   自定义渲染模式（如 360°）改进，修复了起步相机与近裁剪距离；
*   镜头相机重投影改进，现在更好地处理被反射车辆本身（启用真实后视镜时）；
*   应用图标与用户旗帜被打包进单个 DDS 图集，加载更快，VRAM 占用更优；
*   IMGUI 字体：字体图集中补充了缺失的符号 `−`（减号）与 `≈`；
*   脚本运行异步任务并在任务结束前被释放时，AC 不应再崩溃；
*   触控笔与铅笔集成（例如 Paintshop 应用所用）现在支持自定义渲染比例；
*   赛道音频配置错误时 AC 应该更少崩溃，转而显示信息更丰富的错误消息；
*   修复了自定义物理标签页的顺序，并在 Small Tweaks 模块中新增进一步修正顺序的选项；
*   蒙皮网格现在会更新包围球，以便在 AC 加载后不久即可使用剔除（可在常规设置的 `Optimization` 分区禁用）；
*   人物表面着色器：头部倾斜时眼睛现在会跟随地平线；
*   默认不再自动创建缺失的赛道地图，可在常规设置中更改；
*   修复了太阳严格垂直时阴影损坏的问题；
*   展厅模式：地面扩大到 20×20 km；
*   修复了累积截图的模糊阴影；
*   若车辆在 `car.ini` 中未设置 `SHORT_NAME`，但头部为最新版本，将改用常规名称；
*   KN5 文件缺少纹理时不再刷错误消息，只在加载期间给出一条警告；
*   新的内存映射文件读取器（我在越来越多的场合使用它）不再以独占模式打开文件，从而也能编辑这些文件；
*   DDS 加载改进：现在异步生成 MIP，若 DXT5 编码纹理缺少 MIP 则回退到旧方法（不过还是请考虑始终附带 MIP）。若 BC7 编码纹理缺少 MIP，则完全不会生成；
*   Small Tweaks 脚本现在经过预编译以加快加载（源代码仍在 GitHub 上）；
*   后台线程池现在会按需增长，闲置时自动收缩，保持简洁；
*   修复了折射前大灯偶尔发黑的问题；
*   修复了新 CSP 应用出现在降低分辨率的窗口之外的问题；
*   修复了 AI 的转向平滑；
*   修复了 F5 相机弄乱 LOD 选择的问题；
*   雨刮现在更安静了；
*   修复了监视赛道皮肤目录（默认）的问题，纹理现在又能实时重载了（包括系统装有编解码器时 .DDS 旁边的 .PSD）；
*   修复了 Android Auto 中的 YouTube 应用；

*   用 `ui.getColumnWidth()`、`ui.pushColumnsBackground()` 与 `ui.popColumnsBackground()` 更好地操作列（后两者可用于绘制贯穿所有列的分隔线等）；
*   Lua 应用调用的 UI 函数可以从 DLL 加载图标；
*   所有 UI 函数现在可以使用 `dynamic::screen` 与 `dynamic::hdr` 作为图像源，从屏幕获取图像；
*   绘制裁剪文本的 UI 函数（如 `ui.textAligned()`）新增选项，裁剪文本时使用省略号；
*   新的 `ui.drawTextClipped()` 与 `ui.dwriteDrawTextClipped()`，绘制对齐的裁剪文本（可选省略号）而不推进光标或添加条目，保持极高的速度；

*   函数 `ui.pushStyleVar()` 在类型不匹配时不再崩溃，会自动转换值，枚举注释中也带类型说明；
*   所有带 I/O 权限的脚本都可以使用新函数 `ac.storageSetPath()`，允许两个脚本共享同一存储，并用 `ac.storageChanged()` 在设置变化时收到通知；
*   Lua 应用的函数 `os.runConsoleProcess()` 现在更可靠，需要时可获取进程异步写入 stdout/stderr 时的回调；
*   新的游戏 API 函数（对 Lua 应用与新模式可用）：

*   Scene API：创建网格并实时更改网格顶点，为网格设置混合、剔除与深度模式；
*   一批社交相关函数：访问并编辑其他车手的用户标签（好友或隐藏）、获取其用户名颜色、获取其图标、覆盖其他车手的图标（新旧 UI 均适用，自定义图标在那里替代旗帜）、为车手显示工具提示与上下文菜单；
*   新的 CSP 键盘绑定可从脚本访问，并提供实时绘制编辑控件的选项；
*   有权访问 UI 命名空间的脚本（如 WeatherFX 实现或后处理滤镜脚本）可以实时定义新的设置应用；
*   大多数 Lua 脚本的字节码现在会缓存到 `assettocorsa/cache/lua`，加快后续加载。请尽量在脚本生命周期的最初几秒加载所需模块，否则缓存将被写入并关闭以节省内存；
*   字节码缓存期间会进行一些预处理以提速，并允许使用真正的 `compile-time` 内联常量，甚至通过 `const()` 函数使用常量表达式；
*   在 IMGUI UI 回调中调用渲染函数（例如更新额外画布内容）不再弄坏一切；

*   新函数 `ac.onFileChanged()`；
