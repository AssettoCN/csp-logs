# 更新日志

## 新功能、选项与改进

*   太阳阴影现在可以影响路面温度（离线可在常规设置中启用，联机比赛可在服务器配置中启用）。在大多数赛道上差别不大，但有些赛道，比如 Monza，可能一半完全处于阴影中，另一半被阳光照射，因此差异或许可以察觉；
*   三屏模式现在支持 Extra FX（尽管以有限的方式；例如 TAA 还不太能用；而且性能开销仍然很大，所以需要在 Extra FX 设置中单独启用）；
*   反作弊部分有所改进，现在希望能让入侵 CSP 本身变得更难一些；
*   基于网格的遮罩剔除：赛道现在可以准备一个低多边形网格，用它来隐藏其后的内容，免去用配置布置竖直遮挡墙的种种麻烦；
*   大量各种修复，比如改进新树木的渲染、修复 ExtraFX 自发光、修复高级剔除、一批性能与稳定性改进、为 Linux 用户提供更好的 Wine 支持。啊，对了，Lua GIF 播放器现在也支持动态 WEBP 了（Lua 也随之有其他改进）；
