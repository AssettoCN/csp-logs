# 更新日志

## 新功能、选项与改进

*   面向车辆物理的新线程池实现，应能减少帧延迟；
*   主物理线程重写，同样用于防止帧延迟；
*   新物理实验（默认禁用）：渲染与物理线程的现代计时（应能降低 CPU 消耗、整体改善性能，需要 Windows 10 1803 或更新版本）；
*   物理线程性能计算更新，信息更丰富、更精确；
*   新 KN5 加载器：跨车辆和 LOD 共享材质时会考虑 Shader 名称（修复 Caterham 的问题）；
*   改进并重新调整风对水洼的影响，以及其他一些视觉微调；
*   禁用分块优化器不再弄坏某些赛道；
*   Grass FX：修复三屏模式下的阴影和剔除问题；
*   风声音频调回，现在安静了一些，除非混入外部音频组件（例如车门打开时）；
*   F5 相机不再把最近的车辆当作焦点，而是使用实际选中的车辆（修复风声等音频问题）；
*   自定义 FSR 缩放不应再导致崩溃；
*   修复折射前车灯初始化失败的问题，带动态贴图的条目不再缓存（不过请别用它们）；
*   新的音频驱动火焰与强度大于 1 的狂野火焰配置兼容性更好；
*   禁用导航器的选项回来了，直到我搞清楚怎么让它变快；
*   鼠标悬停在 IMGUI 窗口上时不再隐藏鼠标指针；
*   `CAMBER_GAIN=0` 的轮胎应不那么容易让模拟爆炸；
*   调整对齐车辆定位，更好地应对不同车轮半径的车辆，总体上也更合理；
*   新菜单：修复窗口标题的边距，轮胎板块的附加设置项对不同类型使用完整逻辑；
*   蒙皮与数字 LED 合并的包围球以及其他一些优化已启用并隐藏；
*   CSP 配置缓存默认启用，现在缓存的配置会存储所有被引用文件的列表，任何被引用文件发生变化都会强制重新处理；
*   赛道的 SIMD 加速剔除默认启用；
*   `Alter ambience audio` 选项默认启用；
*   配置纹理的异步加载默认启用（看来之前是用力过猛，黑色纹理现在应该已修复，若仍未修复，请把你的设置、使用的赛道以及是否使用自定义皮肤或配置私信给我）；
*   双面赛道阴影选项被禁用并隐藏（其实没什么必要，还破坏了一些优质赛道）；
*   相机跳转时额外混响会暂停，防止听觉毛刺；
*   Reflections FX：新实验选项，将反射立方贴图定位在地面（实验性且会破坏东西）；
*   新实验性小调整，在线比赛中在车牌上显示车手名称；
*   新小调整，强制启用自由相机（默认启用）；
*   CSP Debug：已保存状态的右键菜单中的 `View in Explorer…`；
*   多线程性能测量不再因同一函数被不同线程并行调用而失控；
*   附加开关新增 `KEEP_ON_RESET` 标志，防止其随车辆传送被重置；
*   `general.ini` 新增隐藏节 `QOS_TWEAKS`，用几种不同方法为 UDP 流量设置 TOS 标志（仅测试用，一切默认禁用）；
*   Lua：修复 `math.nan`，改进 NaN 相关内容的常规处理（包括日志）；
*   修复重载时使用 `asyncUpdate()` 的 Weather FX 风格导致的崩溃；
*   修复 C++→Lua→C++→Lua 调用中的错误处理问题；
*   除非启用该实验调整，PP 滤镜选择器应用不再出现在 VR 中；
*   新增 `physics.Collider.Ray()`；
*   新增 `ui.DWriteFont(…):spacing()`，允许调整字符间距；
*   自定义 DWrite 字体指向不存在的目录时不再崩溃；
*   向 `ui.ExtraCanvas` 传入 `math.huge` 作为 MIP 计数有效；
*   如果 `ui.ExtraCanvas` 被指定给场景随后被释放（或 GC 回收），场景实体保留纹理，不再重置为黑色；
*   新增 `ac.SceneReference:getTextureSlotDetails()`，可获取纹理的更多细节（如尺寸）；
*   新增 `shared/sim/plates`，以 Kunos 风格生成车牌（目前需要 I/O 权限并使用来自 Content Manager 的素材）；
*   向 `physics.setAICarPosition()` 传入 `nil` 作为方向时，车辆沿样条线方向对齐；
*   使用物理 API 传送 AI 会将其发车倒计时参数重置为 0；
*   新增 `physics.setAITimeToStart()`，覆盖 AI 的发车倒计时；
*   `ac.CarControlsInput` 新增 `.combineAxes` 字段，允许覆盖值而非组合；
*   `general.ini` 中针对 UDP 流量的几个隐藏实验性 QOS 调整；
