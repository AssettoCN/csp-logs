# 更新日志

## 新功能、选项与改进

*   修复了三屏模式下的光照；
*   修复了树木摇摆的速度；
*   修复了 Grass FX 弄乱配置的问题；
*   Grass FX 配置可以使用多层着色器的遮罩，或多重贴图着色器 txDiffuse 的 alpha 通道；
*   Grass FX 的颜色遮罩现在会影响粒子；
*   Grass FX 现在能为多层着色器正确同步法线；
*   车辆与赛道配置：可引用 `extension` 文件夹（与 `ext_config.ini` 同级）中 ZIP 文件内的纹理；
*   修复了车辆损坏（移除了破损的`刮擦`外观）；
*   Fake Shadows FX：修复了内饰中的阴影；
*   修复了黑屏截图；
*   修复了 Brake Disc FX，现在联机也能用；
*   修复了 Extra FX 中的雾模糊（不再在没有 SSLR 时破坏渲染）；
*   MATERIAL_ADJUSTMENT 的部分重载现在可用了；
*   一些较小的修复；
