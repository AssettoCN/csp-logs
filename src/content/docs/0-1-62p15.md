# 更新日志

## 新功能、选项与改进

*   风挡雨滴现在默认启用，改用 XAtlas 而非 UVAtlas，以获得更好更稳定的车窗映射（此外应该能解决 Windows 7 上的所有可能问题），FPS 不是 65 时雨刮也能工作，镜中雨滴的着色通过一点遮挡得到了改善、更有立体感，图层已修复（现在，如果风挡上有任何半不透明区域，它们会保持在雨滴下方）；
*   车身外部雨滴重做，增加了较小水滴的次级图层，关联到车辆湿度估计而非主图层使用的雨水遮挡（此前会导致车辆在隧道中瞬间变干）；
*   初步尝试推测外部与内部材质，而非依赖 COCKPIT_HR（虽然整个思路算是失败了，接下来我打算改为添加一次性雨水遮挡烘焙；重新调整了着色器的工作方式，现在可以在不增加 RAM 或 VRAM 占用的情况下向 GPU 的每个顶点传入更多数据）；
*   空中雨滴的观感已调整，现在不那么不透明了。请告诉我你们觉得它们怎么样；
*   修复了几个崩溃；
