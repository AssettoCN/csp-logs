# 更新日志

## 新功能、选项与改进

*   Smart Shadows：
    *   第四级阴影级联，用于远距离阴影与镜中阴影（可选）；
    *   外部相机第一分段的自适应距离（靠近车辆时缩短距离，可选）；
    *   可调整的模糊量；
*   Extra FX：
    *   运动模糊着色器从零重写，提升性能与质量；
    *   雾模糊更新；
*   各项优化：
    *   加载期间会计算新的包围球，更小也更精确；
    *   赛道几何体的 AABB 剔除，反射可选 SSE 加速；
    *   新的剔除选项：对部分可见的车辆碎片强制剔除、基于朝向的剔除；
    *   基于遮挡体的剔除（遮挡体通过赛道配置定义）；
    *   重写了立方体贴图与阴影反射的渲染，更直接也更快；
    *   重投影反射立方体贴图的选项，让部分更新时的过渡更平滑；
    *   FidelityFX：为输出使用 UAV 标志（可选）后，不再需要额外的拷贝，可节省一些时间；
    *   新的性能分析应用，带图表与详细测量（之后将取代 Render Stats）；
    *   一些没有可见窗口的 Python 应用现在会进入休眠模式以提速；
    *   Python 应用性能分析器更新，平均与最大（取平均后）耗时的显示更好看；
    *   Extra FX：构建反弹光的光照贴图更快了；
    *   IMGUI 混合（新 CSP 应用等使用）不再缓慢；
    *   为车内与外部视角禁用第三级联车辆阴影的选项；
    *   WeatherFX：在单独线程中运行垃圾回收或可选维护处理的实验性选项；
    *   若干较小的优化；
*   外部视角可见车辆数量改为单独参数，默认值略高；
*   反射立方体贴图：预过滤选项，可去除杂散像素；
*   镜中可用的立方体贴图反射；
*   MSAA 调整：结合色调映射进行 resolve 以提升质量，可选自定义核以获得更平滑画面；
*   Brake Disc FX：程序化刻痕，观感更复杂；
*   新的 CSP 应用现在可从标题栏右键菜单固定；
*   不再清除颜色缓冲（可选，对性能与部分赛道的小孔洞稍有帮助）；
*   新选项（通过赛道配置设置）：让树木光照与下方表面对齐，有助于改善丘陵赛道的观感；
*   导航仪现在会记住之前使用的相机类型；
*   CSP 会尝试修复缺失的风挡着色器，并为仪表盘玻璃应用 `skip G-buffer` 标志；
*   Weather FX 分区中新增选项，可强制联机其他车辆开启大灯；
*   调色：GPU 加速转换，现在可正确支持 16 位与非 HALD 的方形彩色 LUT；
*   GrassFX 现在默认启用；

## 修复

*   修复了 Tyres FX；
*   修复了背光玻璃着色器；
*   FidelityFX CAS 现在会在 FXAA 3.11 之类之后应用（CMAA2 本来就没问题）；
*   改进了新任务栏的主窗口检测；
*   修复了动态阴影：
    *   修复了远处阴影闪烁；
    *   Shuto 之类的赛道不再遮挡灯光；
    *   修复了大灯照射范围；
    *   低多边形几何体观感正常；
    *   单车多个大灯现在拥有正确的动态阴影；
*   修复了 GrassFX 偶尔弄坏运动模糊、看起来满是 bug 的问题；
*   修复了禁用 CJK 字符的问题；
*   CJK 字符占用 VRAM 更少，比赛开始时也不再卡死；
*   修复了 Ghost 车辆用奇怪伪影遮挡视野的问题，其折射也一并修复（默认禁用）；
*   修复了封闭式座舱中头盔在镜中不受阳光直射的问题，第一人称视角下也能正确投影；
*   调整了阴影过滤以减少伪影，修复了远处几何体的阴影；
*   修复了镜中缺失车辆细节的问题；
*   修复了启动时的时区合理性检查（光照不会再乱掉）；
*   移除了无阴影与无光照着色器集以提升加载速度；
*   折射灯光的 TAA 不再增加那么多延迟，截图中也更锐利；
*   不再从与非网格车辆碰撞体的碰撞中生成碎片（那些通常用于底盘与防滑块）；
*   虚拟后视镜不再干扰 UI；
*   DXGI flip 模式在全屏下不再可用，本来就该如此；
*   CSP 雷达应用现在能正确淡出；
*   CSP 车手标签在禁用后处理时正常工作；
*   相机跳转后运动模糊不会立刻把一切都糊掉；
*   模型更改时，烘焙的 Fake shadows 或车辆湿度贴图现在会重新构建；
*   计算车辆尺寸现在使用实际车辆模型（最低 LOD），因为事实证明某些 mod 的碰撞体错位严重；
*   修复了静态胎痕着色错误的问题；
*   修复了极端情况下的地面高度估算（例如附近地面有洞时）；
*   修复了 SSLR 在雾中表现异常的问题；
*   Python 函数 `ac.ext_getTyreBlister()` 不再在某些情况下使 AC 崩溃；
*   新火焰与 SSLR 的兼容性更好；
*   移除了雾模糊效果的远景模糊（只用基于雾的就够了）；
*   修复了与 AC PRO 的兼容性；
*   AC 视频设置中的负 mip bias 不再影响 GrassFX 贴图生成之类的性能；
*   修复了远处自发光消失的问题，反射中的观感也改进了；
*   车辆阴影出现在第三阴影级联中，整体渲染改进；
*   高细节下同时可见的车辆更多；
*   三屏下新主菜单居中显示；
*   车漆默认不再弄坏碳纤维；
*   车漆的极端高光参数不再产生疯狂的眩光；
*   着色器 `ksPexPixelAlpha` 在 alpha 参数大于 1 时现在工作正常；
*   修复了 PP 编辑器中调色纹理的实时重载；
*   WeatherFX：视锥体测试新增参数，可停止朝向调整；
*   新照片应用：Motion 模式不再重置环绕相机；
*   远处自发光可作用于移动物体（例如摩天轮）；
*   修复了若干小 bug 与崩溃；

## 配置

*   支持 BC7 DDS 压缩（与 DX5 占用相同，观感好得多）；
*   新的赛道遮挡体编排应用：墙体与方块；
*   新的网格过滤关键字：标志 `static` 用于静态赛道网格，标志 `castsShadows` 用于投影的网格，数值 `largerThan` 检查包围球半径；
*   动态光源阴影的剔除模式现在可调，默认从 double 改为 front-facing；
*   现在可以为某些大灯禁用体积光；
*   车辆输入：默认不再对熄火做归零处理；
*   额外车辆动画：保持最终状态、将多个动画混合、将动画与常规转向动画混合（可用于手刹动画）；
*   原版车辆动画：应用 LUT 与其他后处理来改变关键帧选择；
*   着色器替换：若纹理替换的文件缺失，整个替换会被忽略；
*   车漆着色器更新（新参数 `ApplyMatteFix`，v3 自动应用）；
*   赛道灯光现在可以跳过车辆以提速；
*   赛道网格可以不再投射动态阴影；
*   新的 Python 函数：`ac.ext_pauseWhenHidden(frames)`、`ac.ext_isAnyAppVisible()`；
*   新的赛道配置值：`[WIND] DYNAMIC_FLAGS_TESSELLATION=1`，改为 0 可停用曲面细分；
*   新的 G-buffer 标志 `ALPHA_TEST_GBUFFER`，启用 alpha 测试，以 ksAlphaRef 为阈值；
*   新的 `INPUT_REFRESH_RATE` 选项，可设置自定义刷新率（Hz），数字仪表默认 5 Hz；
*   车辆与赛道的扩展配置现在可以访问赛道数据；
