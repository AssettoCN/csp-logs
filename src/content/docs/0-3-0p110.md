# 更新日志

## 新功能、选项与改进

*   设置重新分组，部分移除，部分调整：
    *   Lights FX、Fake Shadows FX、GUI、Reflections FX、Track Adjustments 和 Smart Mirrors 模块不再能被禁用；
    *   彩色阴影不能被禁用，整个设置板块隐藏；
    *   车轮相关的视觉内容合并为单一配置（唯一可能导致用户设置丢失的变更）；
    *   远光灯光晕默认启用；
    *   默认分块优化切换为高级版（带来大量修复和改进）；
    *   强制使用 FXAA 渲染路径的选项已激活并隐藏；
    *   DPI 感知选项已激活并隐藏；
    *   新 KN5 加载器始终激活，物理网格数据剥离默认启用；

*   热圈重做：
    *   所有圈都会保存幽灵（仅保留最好的 5 圈和最后的 5 圈）；
    *   幽灵包含车辆设置、性能表数据、最佳圈速、可比遥测数据、条件详情等；
    *   在主菜单中管理和选择幽灵记录；
    *   从幽灵加载最佳圈速、性能表等，或直接跨重启保留（一切均为可选）；
    *   加载天气及其他条件以匹配幽灵记录；
    *   基于轮胎和车辆筛选幽灵（现在也可以加载其他车辆的幽灵）；
    *   加载的最佳圈速不应出现在共享内存或比赛输出中；
    *   搞砸的圈会停止幽灵录制；
    *   出于安全考虑，存在 RSR 应用时这些功能大部分不可用（类似其他物理实验）；
    *   选项 `Use original materials` 现在也会加载涂装；
    *   幽灵优势可以实时加载；

*   VR：
    *   修复 Oculus manifest 生成（尽管大多数时候仍不会被识别，原因不明）；
    *   CMAA2 兼容 VR；
    *   VR 中的阳光阴影配置更好；
    *   在镜像窗口上显示 HUD 的调整（可选在头显中隐藏或完全隐藏）；
    *   OpenVR：调整帧顺序的参数，或有助于响应速度和性能；
    *   OpenVR：同时提交深度缓冲区的调整（不确定运行时会不会用它，但不妨一试）；
    *   镜像平滑无需 SPS 即可工作；
    *   CSP 对头显移动的感知更好，应能正确处理用户离开车辆的情况（切换音频和渲染；可选，默认启用）；
    *   新 VR 调整（默认禁用）：鼠标未移动或未按下时降低 UI 渲染频率；
    *   VRS 画质：Quest 3 预设提供不同画质选项；
    *   精确后视镜投影暂时从 VR 中移除；
    *   VR 模式下调整 AC 窗口大小不再弄乱 HUD 尺寸；
    *   更好的性能测量支持，加载更平滑；
    *   VR 调整：注入 Revive 以通过 SteamVR 或 OpenXR 运行时以 Oculus 模式运行 VR 的选项；
    *   VR 调整：允许在 VR 中实时切换滤镜的选项，以及从视频配置加载实际滤镜名称的选项（均为实验性，默认禁用）；
    *   车辆移动时，被控制器移动的鼠标不再滞后；
    *   移动控制器时会确保取消隐藏鼠标指针；
    *   修复透视 VR HUD 风格，自定义 VR HUD 风格与 LCS 兼容性更好；
    *   新 VR 调整，确保 AC 窗口在 VR 中不被裁剪（会干扰鼠标，已经坑了我几次）；
    *   VR 窗口模式下将鼠标指针限制在 AC 窗口内默认启用；

*   在线相关：
    *   会话投票条件（新菜单和 API）更贴近原版（现在非比赛会话的最后 30 秒内不能再发起会话投票）；
    *   修复 `Set ballast` 确认按钮；
    *   修复聊天设置中禁用条目的问题；
    *   作弊检测略有改进；
    *   新增 `[EXTRA_RULES] NO_BACK_TO_PITS_SESSIONS=Q, R` 参数，仅在排位赛和比赛会话中禁止传送回维修区（`P` 对应练习赛）；
    *   新增 `[EXTRA_RULES] DISALLOW_DEV_BUILDS=1` 参数，屏蔽 WIP 版本，以防万一；
    *   通过门户跳转时，CSP 会同步服务器特性和背景图片 URL；
    *   即使服务器使用自定义加载图，自定义加载屏脚本也能工作；

*   物理相关：
    *   修复启用雨天物理时罕见的物理崩溃（复现的最佳方式是在颠簸路面上驾驶，确保后轮跟随前轮轨迹）；
    *   新物理实验，计时应答器以 1 毫秒精度工作；
    *   新物理实验，在带热圈起步的练习赛中首次越过起点线时才开始计算第一圈；
    *   `data.acd` 中的 `power.lut` 损坏时 AC 不再崩溃，改用 CSP LUT 加载器（但仅限于原本会崩溃的情况）；
    *   修复出生点的实验移至已完成板块；
    *   取消暂停离线比赛不再导致模拟时间向前跳；

*   控制：
    *   原始鼠标输入重写，真正以鼠标频率运行；
    *   面向 Wooting 键盘模拟输入的新键盘鼠标脚本；
    *   暂停鼠标转向会重置累积角度；
    *   轴重映射从 Gamepad FX 模块移除，请改用 Controller Tweaks 应用，以便正确存入 `controls.ini`；
    *   Gamepad FX 的 `Mobile` 脚本已更新，重新可用（Exo 总在改东西），向导中包含 APK 链接，在 Google 封杀 APK 侧载前应该都能用；

*   渲染改进：
    *   内部遮罩在 LCS 下工作得好得多；
    *   VAO 应用于折射前车灯；
    *   后视镜中的树木可接收逐顶点阴影（无需使用最耗性能的后视镜选项）并对风作出反应；
    *   修复闪烁的反射（有时出现在每帧单面加 LCS 重投影的情况下），反射重投影更平滑，粗糙表面尤其明显；
    *   修复中等距离车辆周围阴影闪烁的问题（例如在 Nordschleife 从最后一位发车时很明显）；
    *   反弹光现在也稍微考虑环境亮度，观感更有生气；
    *   风足够大时水洼会出现波浪；
    *   挡风玻璃 Shader 在像素阶段检测到背向相机的表面时会翻转法线（例如修复 Porsche 911 Carrera S）；
    *   阴影移动更平滑，太阳接近地平线时尤其明显；
    *   轮胎内侧（大约 0.2.6 开始绘制）增加了偏移，这样如果车辆的轮胎网格本来就是双面的（例如 slang_diablo_sv 的 Lamborghini Diablo SV），就不会再显得歪歪扭扭（偏移为 2 厘米）；
    *   草地上的阴影略作调整，更锐利、更合理；
    *   理想线路不再用 Extra FX 照亮一切；
    *   赛道路面的反弹光不应再照进车辆内饰；
    *   CSP 轮胎滑痕不再有高光（不影响冰面、尘土或碎石痕迹）；

*   车辆音频完全重写：
    *   应更快，静音远处车辆的逻辑更好；
    *   车辆音频库不能再重定义不带 `/cars/` 前缀的事件（但可以定义之前没见过的事件）；
    *   车门打开时风声更猛烈；
    *   同时发声的车辆数上限设为 25；
    *   涡轮事件的附加参数 `throttle` 现在使用正确的油门值（考虑切断）；
    *   CSP 排气火焰粒子与回火音频关联，音频已修复；
    *   发动机爆缸时，回火音频用简单的 DSP 处理，声音略有不同；
    *   CSP 车辆音频小幅翻新，去掉了无用的离合器事件；
    *   新调整：车轮的真实刹车强度（受 ABS 影响）；
    *   新调整：无打滑或未接触地面时打滑音频暂停；
    *   F7（自由）相机不再获得赛道相机的 2.5 倍音量乘数，以保持一致性（不是 bug）；
    *   路面音频：音量与车轮载荷挂钩；

*   新的窗口创建与处理：
    *   独占全屏被现代兼容全屏实现取代（保险起见，旧方案仍作为选项提供）；
    *   Alt+Enter 更可靠，AC 会在会话间记住窗口大小；
    *   最大化按钮与 Alt+Enter 行为一致；
    *   Alt+Enter 的绑定可以更改；
    *   如果 AC 窗口覆盖了两个显示器的大部分，按 Alt+Enter 会将其扩展为覆盖那两个（或更多）显示器；
    *   Flip model 处处激活，包括 VR，除非使用兼容选项；
    *   光标裁剪（此前用于 VR）重做，现在也可以在无 VR 的窗口模式下激活；
    *   选项（默认禁用）：调整窗口大小时保持 AC 运行；

*   优化：
    *   新选项（默认启用）使用 WIC（现代 Windows 图像加载方式）加载 PNG 和 JPEG，快得多；
    *   现代 DDS 加载器尽可能在 CPU 上生成 MIP，有助于渲染性能；

    *   赛道的物理设置不再等待纹理加载，加载略快；
    *   大量与 AI 样条线处理相关的函数重写，提高精度和稳定性，也提升性能（某些情况下，极少数超长赛道可能被报告为短了 1%），样条线自相交时 AC 不再崩溃；
    *   CSP 为投射阴影生成轻量替代网格缓冲；
    *   IMGUI 绘制分配器调整，可能稍快；
    *   一批针对加载过程的其他优化；
    *   网格和纹理去重不再拖慢加载或妨碍并行化；
    *   从 C++ 调用 Lua 也稍快；

    *   编译器从 2019 升级到 2022 版（2019 版让我撞上了一个相当大的 bug，所以我觉得是时候了）；
