# 更新日志

## 新功能、选项与改进

*   静态反射现在不再包含赛道，只包含天空（目前始终启用，选项很快会就绪）；
*   修复了静态反射下的 Weather FX；
*   可将任意 AC 按钮绑定到 POV（十字键），或添加键盘修饰键（CM 的支持即将推出）；
*   阻止 AC 在快速进站菜单中使用 POV 的选项；
*   远光与近光切换，默认快捷键为 Alt+L；
*   最多四个自定义灯光，默认快捷键为 Alt+小键盘7、Alt+小键盘8、Alt+小键盘9 和 Alt+加号；
*   大灯延迟推测重做，加入了滞后转时间、时间转滞后的换算公式；
*   新的 Python 函数：
    *   `ac.ext_currentPpFilter()`，返回当前所选 PP•filter 的名称；
    *   `ac.ext_glSetTexture()`，为 `ac.glBegin()` / `ac.glEnd()` 设置纹理；
    *   `ac.ext_glTexCoord2f()`，为 `ac.glVertex2f()` 设置 UV 坐标；
*   新的 Weather FX 函数 `ac.getPpFilter()`；
*   部分车辆的可形变引擎盖与后备箱盖；
*   彻底禁用部分车辆相机；
*   带应用的新任务栏；
*   彻底禁用应用任务栏；
*   仅当鼠标移动超过 20 像素时才显示光标（可选）；
*   已绑定的按键在按下其他修饰键时不再响应，除非那正是预期的修饰键；
*   修复了实时重载导致灯光变黑的问题；
*   修复了车辆阴影被裁切到车轮的 bug；
*   修复了 AI 车辆受损后立即打开双闪的问题；
*   其他修复；

## 扩展物理

*   新增实际温度计算参数（文档在 Trello 上）；
*   修复了悬架弹簧力计算（现在车轮刚度等于运动比乘以机械效益，而非运动比的平方）；
*   修复了简单制动系统（现在能用了…）；
*   自定义物理逻辑重写，现在可以在联机中工作；
*   扩展光线追踪改进；
*   额外灯光也可以绑定为空气动力学输入；
