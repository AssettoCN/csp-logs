# 更新日志

## 新功能、选项与改进

*   修复了奇怪眩光与黑色伪影的问题；
*   VAO 在远处用作太阳阴影（隧道不再过亮）；
*   VAO 不再影响赛道的反射与动态光；
*   近处自发光物体在反射中会被调暗，以消除相机近距离经过灯光时出现的灯光 bug；
*   新烟雾应可在联机、三屏模式、VR 或可见头盔下工作；
*   部分着色器新增远景几何体模式，以消除裁切问题；
*   Weather FX 的云不再出现在几何体前面；
*   与原版 AC 兼容性更好（不再出现 RSS Darche 车辆的怪问题）；
*   修复了车辆的额外动画（`INPUT_AS_PROGRESS` 选项）；
*   修复了模拟行程里程表；
*   Weather FX：访问球谐函数的选项，可改善隧道中的光照；
*   着色器替换：
    *   需要时可重新定义 LOD 进出；
    *   修复了纹理替换；
*   新的 VHS 滤镜，为自定义后处理扩展做准备；
*   其他修复与稳定性改进；
