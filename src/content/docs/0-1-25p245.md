# 更新日志

## 新功能、选项与改进

*   面向新程序化草地的 Grass FX（仍在开发中，还远说不上好）；
*   Particles FX：火花重做，新增碎片与橡胶颗粒的粒子，烟雾和灰尘的几处修复；
*   Smart Shadows：自适应距离，配合 Extra FX 获得更好的远处阴影；
*   Extra FX：
    *   反弹光的新实现，相当快；
    *   屏幕空间光源（目前仅用于火花）；
*   新的基于 IMGUI 的应用（还很初级，以后会有更多）；
*   Python 应用：在应用主文件夹中放入名为 `app.png` 或 `<form name>.png` 的图标即可：
    *   请使用不带圆圈或背景的简单图标，补丁会将其转换为常规样式的图标；
*   树木的顶点阴影（至少算个临时修复）；
*   草地、树木与 ksPerPixelAT 的正确 alpha-to-coverage（不再有条带，而是按其本分用于抗锯齿）；
*   镜面光现在受 Lambert 漫反射倍率影响，以消除错误的镜面高光；
*   新的 ksPerPixel_ppfog 着色器：最简单的 ksPerPixel，但带逐像素雾效，适用于有超大三角形的赛道（不过最好别那么做）；
*   赛道网格新的偏置双面阴影选项；
*   替代 flip model 初始化的选项，性能略有提升；
*   Ctrl+Click 自动对焦改进，现在不进入照片模式也能工作；
    *   使用 Ctrl+End 关闭景深效果；
*   新任务栏：新图标样式的选项；
*   按 Ctrl+F7 垂直对齐自由相机；
*   车辆仪表输入：
    *   为 min/max 模式设置基准值（pivot），可选择与基准值相差最大或最小的值；
    *   新输入：`POSITION`，用于比赛名次；
    *   新的 `INPUT_THRESHOLD_LOWER` / `INPUT_THRESHOLD_UPPER` 选项；
*   弯道灯现在只在大灯开启时工作；
*   若干修复；
