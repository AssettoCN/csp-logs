# 更新日志

## 新功能、选项与改进

*   联机动态天气，可借助服务器插件（文档即将推出）或自定义 acServer 实现；
*   新的 WeatherFX 控制器，使用 OpenWeatherAPI 将天气状况与真实天气动态同步；
*   用于隐藏与显示额外车辆几何体的尾翼状态现在会在联机中同步；
*   FSR：
    *   基于正式发布的 SDK 全面重做：
        *   画质预设与之前不同；
        *   现在使用推荐的锐化级别；
        *   可按推荐值调整 MIP bias 的选项；
        *   旧实现仍然保留，以防你不喜欢新版的效果；
    *   三屏模式下可为左右两侧设置更低画质档位的选项；
    *   可选的调试模式：按住 Space 可快速切换到简单的线性放大以便对比；
*   烟雾全面重做（不含轮胎发热与生成逻辑）：
    *   全新的改进着色；
    *   改进了烟雾与车辆的碰撞；
    *   对开放式车轮车辆支持更好；
    *   极限漂移角度下，轮胎烟雾在车下方生成；
    *   尘土与水花在车辆周围生成，而不再只来自车轮；
    *   尘土从沾满灰尘的车轮上飞出；
    *   部分带木质防滑板的 F1 赛车在防滑板触地时会产生少量尘土（可按碰撞体单独配置，类似火花）；
    *   碰撞时生成尘土云；
    *   接触点会生成更小的泥土碎屑与更小的水花粒子；
    *   持久的烟雾与尘土（可维持数分钟）；
    *   在草地上时，改用更细腻的土壤粒子而非尘土云（颜色在赛道配置中设置）；
    *   排气、过热刹车与损坏发动机的烟雾外观全新；
    *   烟雾不会出现在座舱内部；
    *   彩色烟雾与尘土随扩散失去饱和度，并新增配置参数可调整速率；
    *   烟雾剔除改进，进一步优化并让过渡更平滑；
    *   调整密度与屏幕上大小的新选项，可在观感与性能之间权衡；
    *   在 ExtraFX 下，可让烟雾被车窗裁剪，或改为渲染在车窗后方；
    *   烟雾覆盖整个屏幕的额外效果，用更低的成本获得相机陷入烟雾的效果；
*   碎片粒子更新：
    *   调整了各类碎片的概率、大小与着色；
    *   碰撞检测现在使用车辆高度图而非深度缓冲，结果更准确；
*   修复了火花粒子的大小，火花不再在正面碰撞时生成；
*   TyresFX：
    *   轮胎上的草与泥土重做，纹理与渲染都更新了；

## 配置

*   在 `extension/data_override` 文件夹中创建新文件，即可覆盖 `lods.ini`、`lights.ini` 等与外观相关的车辆数据文件；
*   彩色阴影：整体观感改进，新增参数；

*   自定义车辆物理：
    *   创建与某些 AC 物理控制器关联的隐藏调校项（例如创建随车速自适应车身高度的悬架）；
    *   将离合器损坏与过高的扭矩关联；
    *   为任意悬架创建额外连接，用距离或固定关节连接轮毂，或将轮毂固定到车身；
    *   动态物理控制器的新输入：`DAMAGE_ENGINE`、`DAMAGE_GEARBOX`（0 为原版，1 为完全损坏）；
*   自定义赛道物理：
    *   修复了软墙，新增 `MAX_DEPTH` 选项限制过深碰撞的柔软度（文档即将推出）；
    *   车辆生成时与赛道表面对齐（可选，由赛道物理配置 surfaces.ini 控制，使用自定义赛道物理时默认启用）；
