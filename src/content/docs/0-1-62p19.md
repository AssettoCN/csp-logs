# 更新日志

这个版本还没有雨水，仍在开发中。不过还有一些其他新内容：

## 新功能、选项与改进

*   动态阴影；
*   HDR 支持（需要 DXGI flip model，而且多半还需要调整过的 PP 滤镜）；
    *   现在 PP 滤镜可以有两套色调映射选项，分别用于 LDR 与 HDR 模式；
*   GUI：
    *   对原版 UI 应用 MSAA 的选项（如果有应用画出带锯齿的图形，这应该能帮上忙）；
    *   新的车手标签，可在 VR 与镜子中工作（显示蓝旗与黄旗）；
    *   新的简单雷达应用，注重性能；
*   控制器：
    *   快速切入空挡的新绑定；
    *   键盘输入方式的新离合器绑定；
    *   顺序修复的选项，现在也会考虑实例 GUID（同样，支持该功能的 Content Manager 更新即将推出）；
*   在 Content Manager 中支持仅限 CSP 的服务器（CM 更新即将推出）；
*   常规太阳阴影略有优化：
    *   新的更快渲染遍历；
    *   第三级分割中不再有车辆；
    *   远程车辆使用 LOD D 网格单次绘制调用（没有 LOD D 时回退到碰撞体网格）；
*   Smart Mirror：老旧车辆高速时可选的轻微抖动；
*   平滑粒子在 VR 与三屏下无论是否开启 MSAA 都能工作（但仍需要后处理）；
*   新玻璃着色器的更简单折射，可在单屏、VR 与三屏下工作（需要后处理），适合平坦或过于弯曲的玻璃，设置也容易得多；
*   Fake Shadows FX：会考虑动态光源（配合动态阴影效果很好），另外修复了霓虹灯因假阴影而无法正常工作的问题；
*   Weather FX：
    *   更锐利、更高质量星星的选项（锐化与改变的采样方式）；
    *   提高云层保真度的选项；
    *   极热天气下蜃景般反射的选项；
*   Extra FX：
    *   运动模糊在 TAA 之后应用；
    *   雾模糊在 TAA 之后、运动模糊之前应用；
    *   雾模糊新的热扭曲选项（与 Weather FX 的蜃景反射结合，两者都会考虑快速移动的车辆）；
    *   一些优化；
*   雨刮模式重做：现代车三种模式（间歇、慢速、快速），非常老的车只有一种模式，且可重新定义；
*   雨刮联机同步；
*   Stereo 制作的 FFB 新调整，为麦弗逊式（MacPherson strut）悬挂提供更精确的 FFB 计算（仅应用于少数采用特定不常见配置的稀有车辆，不影响 Kunos 车辆）；
*   照片应用新选项，强制开启火焰；
*   破碎玻璃着色器重做，现在带一点折射与自定义参数；
*   优化的绘制顺序与生成网格及有效载荷的缓存现在默认启用，默认灯光亮度改为 100%；
*   新的小调整，在 VR 第一人称视角下为带 H 挡的车完全隐藏车手模型（但在后视镜中仍会显示）；
*   导航仪支持 Spotify 桌面播放器（还有新的车载音响，参见 Abarth 500）；

## 修复

*   修复了扩展物理有时导致物理线程异常、崩溃到棕粉色屏幕的问题；
*   扩展物理的实时重载导致的各种崩溃或不生效任何更改的问题应该已修复；
*   区块优化现在正常工作（之前一直处于禁用状态）；
*   Tyres FX：自定义纹理现在可以在镜子中工作；
*   Fake Shadows FX：修复了雾逆光的问题；
*   Windscreen FX 的（旧版）雨滴在雨刮状态改变时不应再跳动了；
*   VHS 滤镜可用于截图，另外字体现在随 CSP 一起分发；
*   Nice Screenshots 在竖向长宽比且效果不兼容时不应再使用旋转，另有关闭旋转的选项；
*   联机火花暂时禁用，需要更多测试；
*   灯光处理重做，在有数千盏灯的赛道上提速，并修复了相机远距离跳转后灯光慢慢点亮的问题；
*   现在回放等场合最多可有 12 辆车的车头灯走镜像渲染，而不是以前的 4 辆（那效果太糟了）；
*   修复了赛道上的模拟时钟；
*   新聊天应用：支持 Latin Extended 与 Currency 字符集的符号，登录失败后可以重试，更改颜色可以取消；
*   赛道体积光现在可以更宽，但那样会更短；
*   除非新的照片模式应用处于活动状态，否则环绕（F5）相机不会再失焦；
*   修复了玻璃逆光错乱的问题；
*   修复了较极端设置下的天空伪影；
*   修复了轮胎的地面遮蔽；
*   修复了后视镜中的折射车头灯；
*   Weather FX：默认脚本不再弄乱太阳光束；
*   若干较小的修复与优化；

## 配置

*   车内新毛绒材质（用得太频繁可能开销有点大）；
*   车辆新车载音响，显示当前艺术家、曲目与音源图标，或时间，或简单的动画；
*   新的节点、网格与材质过滤属性（用于制作车辆与赛道配置）；
*   `[SHADER_REPLACEMENT_…]` 新增 `MOVE_MESH_IN_FRONT_OF` 选项；
*   车灯新增 `FADE_FAKE_SHADOW` 选项：霓虹灯之类的可设为 0.8 左右，以降低灯光开启时假阴影的不透明度；
*   新的 `[SMOOTH_NORMALS_…]` 调整，用于平滑某些网格的法线（对部分 Kunos 赛道效果很好）；
*   车辆新增弯曲着色器，可选曲面细分，用于：
    *   雨刮弯曲以贴合风挡曲率、减小缝隙：`[BENDING_WIPER_…]`；
    *   侧网（某些赛车侧窗旁的网）晃动：`[SIDE_NET_…]`；也可用于天线之类；
    *   排气晃动而无需重新排列节点：`[SHAKING_EXHAUST_…]`；
    *   类似 wobbly bits 的摇晃网格，但无需蒙皮：`[WOBBLY_MESH_…]`；
    *   请注意：整套东西相当原始，只是基于与特定区域的接近程度添加一定偏移，不带任何旋转；
*   赛道新的条件动画器，基于条件移动、旋转与缩放；
*   赛道显示屏：使用实际赛道相机的选项、使用 Office 风格占位内容的选项；
*   对象查看器：本地与车内坐标、场景节点树；
*   彩色顶点 AO 不再受支持，加载时会转换为普通版本；
*   为车辆设置自定义雨刮模式：指定速度与每次刮拭间的延迟；
*   新的 Python 函数用于选择模式或查询模式数量（旧函数仍可使用）；
*   雨刮相关的新车辆输入：`WIPERS_MODE` 与 `WIPERS_PROGRESS`（用于动画进度）；
*   不含双闪的转向灯新车辆输入：`TURNSIGNAL_NOHAZARD_LEFT`、`TURNSIGNAL_NOHAZARD_RIGHT`、`TURNSIGNAL_NOHAZARD`；
*   在赛道配置中调整 Extra FX 反弹光强度；
*   赛道灯光新增 `DISABLE_WITH_BOUNCED_LIGHT` 选项：如果将灯光用作假环境光，请使用它；
*   车辆新增 `EXTRA_FX/DELAYED_RENDER_INTERIOR` 选项，用于列出第一人称视角下应在 Extra FX 之后才渲染的网格；
*   现在 `[SHADER_REPLACEMENT_…]` 的 `INCLUDE_IN_CUBEMAP` 选项不会再影响世界细节等级；
*   着色器 `ksMultilayer_fresnel_nm` 的法线贴图现在使用平铺修复与各向异性过滤；
*   PBR 着色器的遮蔽行为已调整，以便更好地配合带反弹光的新 OptiX 烘焙器；
*   Grass FX：自定义纹理中区分彩色与非彩色区域的遮罩更平滑；
*   用 `[HEATING_SURFACES] MESHES = …` 与 `MATERIALS = …` 设置热扭曲与蜃景效果的发热点位列表（否则 CSP 会尝试猜测）；
*   扩展物理新增限速器（固定且静态，为卡车竞速而设）；
