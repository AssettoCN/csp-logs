# 更新日志

## 新功能、选项与改进

*   修复与异步纹理相关的崩溃，该问题有时伴随 Scene API 出现（尤其是在 SRP 服务器上）；
*   修复缺失的排行榜、延迟、发车灯和逆行指示器；
*   修复与部分附加 DLL 插件的兼容性（通常会在离线比赛中引发顶部的 `Integrity-failure` 消息）；
*   Render stats：GPU 详情中的延迟计数器；
*   修复 F6 相机错误检测车内/车外状态的问题；
*   车辆物理线程池及其他线程池的运行速度应稍快；
*   Lua：新增 `shared/utils/openkneeboard` 库，用于向 OpenKneeboard 发送命令；
*   在 VR 中隐藏车手只留手套的选项，现在也可应用于非 VR 模式；
*   新小调整，在 VR 中取消隐藏方向盘和车手；
*   新设置，完全禁用 Microsoft Media Foundation（用于视频，偶尔也用于音频播放器）（主要是为了在特定情况下节省一点帧率）；
*   新设置，完全禁用赛道显示屏（无脚本的那种）（同样为了节省帧率，以防万一）；
*   修复默认 Weather FX 风格下某些情况虚拟后视镜未正确应用后处理的问题；
*   Render stats：其他线程仅在被查看时测量，主窗口折叠但 `Other threads` 窗口打开时继续测量；
*   修复排气火焰（另外加入两种机制，在音频缺失或损坏时解除粒子与音频的关联）；
*   烟雾粒子在生成点使用 VAO；
*   LCS 下烟雾环境阴影不再过暗，用于优化的附近烟雾密度追踪机制得到改进；
*   后视镜中烟雾接收阴影（第四级联）；
*   其他线程测量的名称略微清理，测量按字母排序；
*   新菜单：修复某些类型设置项导致的崩溃；
*   修复后视镜中缺失的假阴影等内容；
*   修复某些特定情况下纹理缺失的问题；
