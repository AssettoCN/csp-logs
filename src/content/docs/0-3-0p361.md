# 更新日志

## 新功能、选项与改进

*   修复玻璃材质出现彩虹色的问题（用于各类效果的内部噪声贴图现在与 0.2.11 中的一致；preview46 中升级到 VS2022 时搞乱了它）；
*   刹车盘：初始磨损配置值再次正确加载；
*   Extra FX：
    *   修复准备过程中的一个笔误，该问题导致一大批效果失常；
    *   一个三屏下光线反弹的老问题也一并修复；
    *   TAA 修复了残影问题，现在可与自定义渲染模式和自定义三屏相机覆盖配合工作，还有几项小改进；
    *   累积截图再次可在三屏下与 Extra FX 和运动模糊一起工作（近期引入的回归）；
    *   运动模糊在自定义渲染模式下不再左右漏色，模糊区域的混合略有改进；
    *   修复部分挡风玻璃遮阳带在 Extra FX TAA 下的外观；
*   放大技术：
    *   新的 XeSS 放大技术（需要 Intel Arc GPU）；
    *   后备机制在画质高于 100% 时不再使用 NVIDIA Image Scaling（它处理不了）；
    *   OptiScaler 更新至 0.9，游戏内菜单现在应该可用，支持 AMD GPU，不再干扰游戏内浏览器；
    *   FSR 2 支持三屏不同侧边缩放；
    *   FSR 3 按需加载；
    *   FSR 2/3：改进反应掩码，车轮周围的画面不那么抖动；
    *   基础放大器：新增 `motion test` 模式，用于调试高级放大技术；
    *   高级放大技术：修复 MIP 偏置，累积截图时始终禁用，改进与曲面显示器滤镜的兼容性；
    *   启用放大后会隐藏后处理抗锯齿板块中的锐化设置；
    *   某些配置下的部分放大技术速度更快，不再执行多余的拷贝步骤；
    *   实时禁用 Extra FX 不再弄乱渲染；
    *   `dynamic::screen` Lua 纹理不再包含闪烁；
*   默认 Weather FX：
    *   体积雾增加了降噪处理，包括时序和常规两种，在 TAA 下更平滑，强度略有增加；
    *   闪电更亮，持续时间稍长；
    *   YEBIS 替代方案的太阳光芒略有改进；
    *   极光已修复，列表已更新；
    *   太阳阴影改变雾的逆光效果经过平滑以防止闪烁，日落期间体积雾更早关闭；
    *   调整外太空着色；
    *   按需加载高分辨率地球纹理；
    *   修复日全食时的光照，星星更亮；
*   自定义渲染模式（分屏、360°、鱼眼）：
    *   鼠标光线（几乎所有鼠标与场景交互的基础）工作正常；
    *   修复放大技术、360°/鱼眼与 AA 设置中锐化的兼容性问题；
    *   `dynamic::screen` Lua 纹理正常工作；
*   为使用 Weather FX 配置条件的在线比赛进行的时间外推已重写，时间不再倒退或振荡，而是可靠且平滑地同步；
*   配置分辨率宽高比与显示器不符时，全屏切换工作更好；
*   Render stats：紧凑形式下细节更多，测量更准确（不包括帧节奏测量）；
*   修复 Tyres FX 的损伤法线和着色；
*   Smart Shadows：自适应首级分割在引擎盖和仪表盘摄像机下生效，F1 车辆的阴影再次清晰（但在其他可驾驶视角下仍禁用，使追逐和保险杠视角的阴影延伸更远）；
*   无后处理的虚拟后视镜观感更合理，尝试模拟 YEBIS 的 HDR→LDR 步骤；
*   Ctrl+F8 隐藏鼠标再次可用；
*   熄火发动机实验：扭矩增加，其他调整，不再破坏自动驾驶；
*   常规设置新选项，阻止车辆和赛道脚本访问网络（web API、加载图片、通过 Media Player 流式传输、通过 URL 加载 GIF）；
*   如果窗口并非真正的前台，CSP UI 会忽略鼠标（影响 UI 和视觉部分；任何物理或音频组件仍使用旧的屏幕覆盖率检查方式以确保安全）；
*   修复由禁用模块的旧 CSP 设置引起的几个小问题；
*   缆线（在已配置的赛道上，如 Laguna Seca）：
    *   抗锯齿改进，缆线现在实际为一个像素宽，淡出效果更好；
    *   修复风动画；
    *   赛道配置可选项，使缆线透明并使用 Alpha 混合替代旧的颜色（默认启用）；
*   几个键盘处理的小修复，或许有助于解决切换摄像头按钮的诡异问题及类似情况；
*   截图闪光（屏幕上的效果，使用累积截图时默认禁用的那个）速度更快；
*   新热键：不带累积的截图（默认为 Alt+F8）；
*   修复太阳接近地平线时的折射（之前只在太空中生效，而不是在除太空外的所有地方生效），日全食期间星星有了一点引力透镜效果；
*   得益于 Artemis 2 任务，地球纹理和着色已更新，Extra FX 也有几处修复，太空中也能看到日食；
*   拍照模式应用：
    *   时间偏移滑块正确显示时间，带小时和分钟；
    *   在拍照应用中为存档点输入名称时按 `Enter` 可快速保存；
*   `Tunnel Effect` 滤镜略作调整；
*   修复 AC Pro 支持（仍需 PDB 文件可用）；
*   默认加载脚本：修复会话名称，其他小修复；
*   若干修复，针对累积被禁用时的截图创建，尤其是在使用放大技术时；
*   重写了 Intel CPU 可能问题的检测以减少误报，不过仍默认禁用；
*   自定义最终拉伸更新，与可能注入 AC 渲染管线的东西兼容性更好；
*   打开任务栏时模态对话框不再关闭；
*   更多关于 AC 窗口定位的日志，以尝试调试某些三屏配置；
*   `ksPerPixelNM_UVMult` Shader 投射的阴影会考虑漫反射 UV 倍率；
*   新的 `ksMultilayer_fresnel_nm5` Shader，带有四个逐通道法线和 `txDetailNM`；
*   如果赛道显示屏的尺寸未配置且纹理大小未知，CSP 将使用 256×256 作为后备分辨率；
*   赛道配置新增 `[WEATHER_FX] CLOUDS_OVER_SCENE=1`，请求 Weather FX 在不透明赛道几何体上方绘制云层；
*   数字显示材质新增 `IDEAL` 类型，保留颜色；
*   刹车盘新增 `CUTS=TANGENT` 选项，添加放射状线条（可通过 `CUTS_TANGENT_FREQUENCY`、`CUTS_TANGENT_THICKNESS`、`CUTS_TANGENT_MODE`、`CUTS_TANGENT_PIVOT_RADIUS_MULT` 配置）；
*   网格新标志，指定其是否应在第四（远距）级联中投射阴影，与主标志分开，以修复远处几何体未按预期投射阴影的问题，可通过 `[SHADER_REPLACEMENT_…] DYNAMIC_SHADOWS=TERRAIN` 更改（如果设置了阴影投射标志，新的 KN5 加载器会默认设置，旧 KN5 加载器不再受支持）；
*   `[SHADER_REPLACEMENT_…]`：新增 `EFX_SKIP_GBUFFER`、`EFX_MASK_GBUFFER`、`EFX_BLEND_GBUFFER` 和 `EFX_DELAYED_RENDER`（替代旧的功能失常的选项）；
*   `[SHADER_REPLACEMENT_…]` 新增 `CUBEMAPLESS_REFLECTION=1`，旨在修复 Nordschleife 围栏的闪烁；
*   `loading.carSkinID()` 已修复；
*   `ac.INIConfig.raceConfig()`、`ac.INIConfig.videoConfig()` 和 `ac.INIConfig.controlsConfig()`：修复了返回配置的类型；
*   新增 `ac.getSim().isTAAActive`；
*   `table.build()` 已修复；
*   `ac.isMeshClicked()` 等不再检查 LOD B 及更远的级别，不再有第一帧的误报；
*   `ac.ControlButton()`：修复默认修饰键（2025 年 4 月 6 日引入的错误）；
*   `ac.makeScreenshot()`：新增设置累积开或关的参数，修复文件名为默认值但格式不同于 JPEG 时的扩展名问题；
*   Weather FX 风格的 `ac.enableRenderCallback()`：新增在所有透明几何体之后、Extra FX 分辨之前调用的回调参数，修复赛道回调偶尔被调用两次的问题；
*   `web.timeouts()`：第五个参数覆盖最大同时请求数；
*   新增 `shared/utils/oswindow` 库，用于创建额外的操作系统窗口；
*   几个 DWrite 文本渲染 API 的修复；
