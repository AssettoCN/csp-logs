# 更新日志

## 新功能、选项与改进

*   默认 Weather FX 实现重做：新的基于高度的雾、新的云朵观感、重做的天空与光照、额外优化；
*   通过新的 CPU 优化选项（默认启用）优化内存占用；
*   CSP 现在可以直接从 Windows 10 获取当前播放的曲目（需要 Windows 10 版本 2004）；
*   车载音响：虚假的音频可视化现在使用音频峰值表，看起来更准确一些；
*   幽灵车观感更新：折射、更好的 Extra FX 兼容性、额外发光选项的新着色；
*   支持隐藏在欢迎消息中的新 CSP 服务器配置；
*   联机服务器：设置额外出生点并选择允许传送到那里的车辆（需要特殊的服务器与入场列表配置）；
*   新的小型 FFB 调整，在加载完成前彻底停用 FFB（有助于在某些较大的赛道上减少噪音）；
*   严重磨损轮胎的火花；
*   键盘离合器现在可用任何输入方式工作（不用再设置那些虚拟输入设备了）；

## 修复

*   Windscreen FX 已修复；
*   修复了禁用新火焰时出现绿光的问题；
*   Grass FX：修复了草的形变和割草机的问题；
*   修复了相机靠近发光物体时反射过曝的问题；
*   修复了遮罩通道偶尔显示错乱的问题；
*   修复了部分半透明物体消失的问题；
*   修复了使用 `default.ini` PP 滤镜加载的问题；
*   时区配置已修复；
*   修复了 FFB tweaks 偶尔异常的问题；
*   联机以管理员身份登录已修复；
*   新 UI 的光晕效果有所减弱；
*   新着色器 `ksMultilayer_objsm_nm4` 已修复，现在有二维 UV 倍率；
*   各种小修复与优化；

## 配置

*   Weather FX：
    *   各种新函数与修复（可选）；
    *   云朵现在可以在其他云朵上投射阴影；
    *   新的隧道检测（以及通用的相机遮挡检测），适用于所有赛道；
*   配置中的节现在可以要求特定 CSP 版本才会激活；
*   车载音响：
    *   新元素类型：imgui 文本、矩形形状和专辑封面；
    *   可选淡入淡出；
    *   元素的可调 Z 排序；
*   着色器替换现在可以用 ZIP 文件中的纹理替换原纹理，与 Tyres FX 类似；
*   新的 Python 函数：
    *   获取任意车辆的 ABS 和 TC 状态及当前是否在工作；
    *   获取相机方向；
    *   从任意方向获取罗盘角度；
*   绑定到 CSP 自发光的灯光现在可以正确处理多个灯光以推测位置；
*   BTTF 车的新火焰选项；
*   赛道配置新的 `[ALTER_NORMALS_…]` 选项，可在加载期间偏移或旋转法线；
