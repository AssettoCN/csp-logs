# 更新日志

## 新功能、选项与改进

*   现在 AC 崩溃时会生成崩溃转储（crash dump）！这让调试轻松多了，所以请一并附上（应生成在 logs 文件夹中）；
*   Weather FX：云朵共用材质、修复了偶发的第二帧崩溃、精确的太阳/月亮/星星/行星运动、新的雾实现（开发中）、云朵渲染优化、阴影可由天气禁用；
*   Neck：手柄的死区和线性度选项、Track IR 支持（因此现在也与 RHM 兼容）、修复了偶发的黑屏；
*   回放保存已修复，AC 不会再损坏其他文件（为此前的问题深表歉意）；
*   新的 Chat Shortcuts 扩展（按 `~` 查看消息；控制绑定选项即将推出）；
*   车牌灯新布局：`TWO_ON_BOTTOM` 和 `ONE_ON_BOTTOM`；
*   动画转向灯新选项：`SMOOTH_IN`（0 或 1，默认值为 1）和 `SMOOTH_OUT`（默认值为 0），用于匹配真实转向灯；
*   油表指针已修复；
*   Trees VAO 可以关闭后再重新开启；
