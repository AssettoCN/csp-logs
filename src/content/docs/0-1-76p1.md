# 更新日志

## 新功能、选项与改进

*   集成 AMD FidelityFX Super Resolution（在 AC 视频设置中启用 PP 和 FXAA 时可用，或在 VR 模式下任意配置均可用）；
*   Graphics Adjustments 中的 FXAA 替换选项现在也适用于 VR；
*   用快捷键将最近 30 秒回放保存为小视频片段的选项（服务器也可以为这些片段设置上传 URL，实现更自动化的举报）；
*   Mumble 集成，支持带位置音频的语音聊天，可在服务器配置中调整缩放比例；
*   为大多数形状与形态的雨刮提供全新动画方式，无需拆分网格，会自动贴合到风挡上等；
*   全新的 Colorized Shadowing 模块，让风挡横幅投下彩色阴影，并为附近的环境光染色；
*   车内反射遮罩重做，现在会应用到附近所有车辆；
*   为封闭式车辆的车手模型添加一点遮挡，类似 Shadowed Wheels 模块；
*   自由相机下，10 米内最近的车辆现在视为对焦车辆；
*   `Limit audio` 选项更新，现在有正确的淡出与进一步优化；
*   预计算 CSP 数据（如车辆的新虚假阴影）的缓存重做，旧条目会被自动删除；
*   NeckFX：地平线锁定选项，可将相机锁定到赛道表面而非地平线；
*   全新的三屏模式调整模块，可改变画面在三台相机之间的分割方式；
*   观众的默认法线纹理重新正确绘制，着色更新；
*   Ghost 车记录器在新纪录诞生后会立即保存文件，不再等待会话结束；
*   镜子的数字显示屏现在为可选，并带有更好的 LDR 模拟选项；
*   默认 WeatherFX 实现已更新，光照与云经过调整，AI 也会及时打开车头灯；
*   新 UI 的简化渲染样式选项，为较弱的 GPU 提速；
*   禁用反射立方体贴图中的镜面高光，以减少闪烁；
*   移除了 Origin Shift 的调试模式，防止人们不小心开启它；

## 修复

*   0.1.74 中添加的赛道虚假阴影现在可以关联到网格，在缺少网格的某些布局上会消失；
*   修复了某些车辆 LOD 上雨刮乱飞，以及动画应用到 LOD 时损坏的类似问题；
*   修复了加速加载的 AC 数据缓存弄坏车漆的问题；
*   修复了带 VAO 的车辆在切换几次 VAO 前显得过暗的问题；
*   修复了几个与 IBL 反射相关的性能问题；
*   VAO gamma 现在也应用于影响车辆亮度的 VAO 采样；
*   Driver Interview 模式已修复（之前缺少获胜条件），难度降低，现在也能用于 assettocorsamods.net 的赛道；
*   数字屏幕着色器更新，TN 色彩失真更准确；
*   修复了玻璃侧面折射增强的问题；
*   修复了某些罕见赛道上车辆掉出地面的问题（0.1.74 中的 bug）；
*   进行累积模糊存储后，粒子状态会被恢复；
*   欢迎消息中的 URL：解析已修复，支持 TeamSpeak 和 Mumble URL，右键菜单可将 URL 复制到剪贴板；
*   Graphics Adjustments 的自定义裁剪平面现在在选择 VR 模式时也会应用，除非相机在车内；
*   AI flood：禁用颜色随机化现在生效；
*   修复了用于检测相机位置的 CPU 车辆高度图；
*   Origin Shift 在禁用后处理时也能工作；
*   加速后的反射现在正常工作，不再在某些赛道上出问题；
*   WeatherFX：修复了遮挡估算，修复了被裁剪的云；
*   修复了折射大灯的 TAA；
*   观众的默认法线纹理只应用于默认观众纹理；
*   地平线物体检测改进，修复了某些赛道上的背景毛刺；
*   修复了 LOD 切换时物体被模糊的问题；
*   修复了特定设置组合下虚拟后视镜破坏 UI 的问题；
*   赛道上带相机的显示屏支持原点偏移（origin shift），并能显示烟雾、火焰和烟花；
*   修复了视觉机油泄漏卡住不动的问题；
*   修复了退出时的崩溃；
*   修复了车漆着色器上动态光源的镜面高光；
*   一些小修复与优化；

## 配置

*   人体表面材质现在可以在车辆配置中设置；
*   GrassFX：在赛道配置中调整纹理亮度的选项（针对彩色部分）；
    *   Highlands 纹理的变体已被移除以节省空间，为保持兼容，CSP 会改为对它们使用亮度调整；
*   赛道条件与赛道遮挡体的应用已被移除；
*   相应地，它们作为工具加入了 Objects Inspector，以免弄乱应用列表，更多应用很快会被迁移和添加；
*   赛道虚假阴影工具重做，现在可以将阴影关联到网格，并一次性管理所有阴影；
*   赛道灯光的默认镜面倍率现在改为 1（配合赛道通用配置）；
*   创建数字仪表的新方式，`[SCRIPTABLE_DISPLAY_...]` 可用 Lua 编写脚本；
*   车辆新增 `[EXTRA_SHAPE_...]`，可创建新几何体（例如为缺少某些指示灯或正确映射显示屏的 Kunos 车辆）；
*   用于配合 `[EXTRA_SHAPE...]` 轻松创建新显示屏与指示灯的新模板；
*   动态纹理新 `RESOLUTION_LIMIT` 选项，确保异常的缩放设置不会让它们变得过大；
*   数字屏幕材质的新模式，VA 矩阵；
*   导航仪现在可以使用车辆纹理作为加载徽标（示例可参考 BMW M4 配置）；
*   其他所有对纹理的引用（例如 `[SHADER_REPLACEMENT_...]` 中）也可以使用车辆纹理；
*   使用弯曲着色器的功能现在能正确应用 `ALPHA_MODE` 参数；
*   INIpp：
    *   模板中的宏现在不能覆盖主段落中由宏设置的值；
    *   模板新增 `@GENERATOR_STARTING_INDEX` 参数，用于生成器中更改起始索引；
*   `[PARTICLES_FX_EXHAUST_...]`：方向现在是可选的，默认朝向后方；
*   `[MESH_ADJUSTMENT_...]` 和 `[NODE_ADJUSTMENT_...]` 更新：
    *   现在对赛道和车辆的工作方式相同；
    *   将网格移动到不同节点会更新其顶点，使它们保持在相同位置，非常适合让网格坐标与车辆坐标对齐；
*   `SKINS` 过滤器现在可以使用复杂查询，例如 `SKINS = '{ ( red?, green? ) & !?_matte }'`；
*   为当前活跃的车辆（已加载且未断开连接）可视化维修站：
    *   切换车库门或为其添加动画；
    *   新的赛道条件输入，用于检查对应车辆是否存在；
*   将赛道网格元素拆分为独立网格（会增加绘制调用次数，请谨慎使用）；
*   着色器 `stPerPixelNM_UVflow`：
    *   UV 倍率与偏移参数（将偏移绑定到动画条件可做过渡效果）；
    *   改用 txDiffuse 而非 txNormal 的 alpha 通道的参数；
    *   将 0…1 纹理坐标之外全部裁掉的参数；
*   材质调整中的十六进制颜色现在可用；
*   镜子数字显示屏：调整角度的选项；
*   lods.ini 中错误设置的 `OUT` 值现在会自动修正为与下一个定义的 `IN` 匹配；
*   遮罩 pass 现在支持延迟渲染（非常适合彩色风挡横幅）；
*   新的车内材质 `[Material_WindscreenBanner]`，风挡横幅、边框等一应俱全，方便实现彩色阴影与 RainFX 集成；

## Lua & Python

*   带状态的 struct 得到扩展，现在包含更多数据；
*   Lua API 生成器重写，现在保证类型安全，并尽可能添加自动转换；
*   Lua API 的几个修复（现在向量只与向量相等等）；
*   WeatherFX：
    *   新的 `ac.setCameraOcclusionDepthBoost()` 值，用于调整基于立方体贴图的遮挡估算；
    *   云材质新属性 `.alphaSmoothTransition`，用于调整 alpha 渐变；
    *   云的 `.extraFidelity` 现在可以设为负数，使图案模糊而非添加额外图层；
*   新模式：
    *   绘制 UI 的 API 从 `ac.ui…` 迁移到 `ui.…`（很抱歉，我通常尽量不破坏兼容性，但它才刚发布，我认为尽早修正更好）；
    *   在 3D 空间中绘制物体的 API；
*   自动生成的定义现在包含类型；
