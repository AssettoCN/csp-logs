# 更新日志

## 新功能、选项与改进

*   双精度物理引擎，改善大型赛道上的物理与 FFB（现在联机也可用）；
*   Graphics Adjustments 新增 Origin Shift 功能，修复大型赛道上的画面抖动；
*   高级剔除大幅重写，以提升性能；
*   DXGI Tweaks 新增一些选项（与 flip model 无关）：
    *   根据 AC 视频设置中选择的屏幕使用 GPU；
    *   真正的无边框模式；
    *   三重缓冲与自定义最大帧延迟；
*   赛道的 SIMD 加速可见性剔除选项；
*   AC 最小化或位于后台时禁用音频的选项；
*   Smart Mirror：覆盖后视镜渲染距离的选项；
*   Radar 应用：颜色设置，外观更新；
*   得益于新的内置加载分析器，加载的流畅度与信息量大幅提升；
*   加载现在应该更快了，还可以通过缓存进一步提速（默认启用）；
*   修复了 VAO 变暗的问题，支持动态调整伽马；
*   重做了崩溃消息，现在带有额外的检查与提示；
*   崩溃报告包含 CSP 设置预设；
*   声速现在会考虑温度等因素；
*   GUI：油门与刹车踏板同时踩下的可选警告；
*   联机自定义颜色现在可跨会话保存；
*   自适应近平面的选项，改善相机远离车辆与赛道时的观感；
*   传送目的地列表更紧凑，支持分组并可过滤点；
*   后处理折射改进；
*   破碎玻璃着色器再次重做；
*   未正确录制 AI 线路的赛道上与 AI 相关的崩溃应该修复了（之前它们只会傻站在那里）；
*   联机：管理员现在可以手动判罚（需要服务器要求 1476 或更新的 CSP 版本）；
*   现在使用车辆高度图判断自由相机是否在车内；
*   后方车辆的灯光照亮你的车时，现在会从后视镜产生额外的光；
*   车手头部的新着色器（目前仅非蒙皮版本），观感更动态；
*   车门动画与举牌的维修站工作人员会随 AC 一起暂停；
*   通过配置为赛道设置假的 Ambient Shadows，为那些静止车辆下方添加一些暗部；
*   新的 VR Tweaks 模块：
    *   VR 镜像（从 Graphics Adjustments 移入）；
    *   新的 VR 镜像模式：仅显示右眼，以及无畸变地显示双眼；
    *   VR 中 HUD 定位的多种选项；
    *   VR 双眼间距调整选项，以防万一；
*   AI Flood（又称 Track Mode）：
    *   生成流程重做，更快也更高效；
    *   支持双向交通地图；
    *   修复了车辆卡住的问题；
    *   增加行为多样性的新选项；
*   针对倾斜表面的 MIP 偏起新选项（对于那些远处的道路，单靠各向异性过滤似乎不够）；
*   新火焰现在会产生一点火花；
*   Walking Out 模块已更新，现在可以切换车辆，但仍需更多工作（现已附带配置，可手动激活）；
*   同时附带 Triple Custom 模块的手动激活配置，可以在三屏模式下完全重新配置相机；
*   新模块 `New Modes`，允许创建由脚本驱动的新驾驶模式（仍在开发中）；
*   会话状态消息不会再在 Track Day 模式中出现；
*   少量小优化；

## 配置

*   TyresFX：在配置中为特定轮胎类型指定轮胎花纹；
*   新的影响所有车辆与赛道的通用配置；
*   车辆扩展物理：
    *   联机使用真实质量的选项，改善重型车辆的碰撞；
    *   重新定义碰撞参数的选项；
*   赛道扩展物理：
    *   联机为车辆使用真实质量的选项；
    *   为不同表面重新定义碰撞参数的选项；
    *   表面与车辆网格碰撞体之间使用刚性碰撞的选项，尽量防止某些极端情况下车辆穿地；
*   用于高级轮胎碰撞检测的扩展光线追踪使用更少的采样以提速；
*   INIpp：include 现在可以为可选，支持文件名表达式，新增访问与修改已解析内容的函数；
*   车辆与赛道配置的 `read()` 新增输入；
*   赛道灯光新参数 `SHOW_IN_REFLECTIONS`（请谨慎使用，默认只包含范围超过 10 米的灯光以提速）；
*   新的过滤关键字：节点的 `insideWheel`、`insideSuspension`，材质的 `driverPiece`、`isTextureDefault:<texture name>`；
*   车辆灯光：近光与远光的色调；
*   车辆灯光与自定义自发光：独立的亮起/熄灭延迟、自定义预热颜色及其他参数；
*   设置 `set observeDigital 1` 现在不应再使 AC 崩溃；
*   Car Debug 应用现在显示空气动力风扇力；
*   旗帜的可选更高细分率，细分同样应用于阴影；
*   新的半透明阴影模式：NORMALS，考虑表面以在掠射角衰减太阳光，非常适合弯曲玻璃；
*   CSP 会晚绘制车窗网格以保证视觉正确：此类网格的过滤器现在可以更改，以包含自定义横幅之类；
*   Objects Inspector 应用：
    *   选择蒙皮网格；
    *   现在也会显示点击点的表面法线；
    *   简化为赛道创建假的 Ambient Shadows 的额外工具（未选中任何内容时点击 `…` 按钮）；
*   闪烁模式：新参数 `BLINKING_OFFSET`（秒），可为循环指定起始偏移；
*   赛道配置参数 `[WIND] IGNORE=…` 现在也影响旗帜，禁用新动画与细分；
*   新的赛道配置参数 `[WEATHER_FX] SKY_BELOW_HORIZON=…`，可指定天空网格延伸到地平线以下多远（1 为完全覆盖）；
*   新的赛道材质 `[Material_Bale]`；
*   光弹性 PBR 玻璃现在也支持多重自发光；

## Lua & Python

*   修复了 Python 函数 `ac.ext_loadIniFileAsJson()`，`ac.ext_parseIniFileToJson()` 更名为 `ac.ext_parseIniAsJson()`（旧名称出于兼容性仍可使用）；
*   新的 Python 与 Lua 函数，可获取赛道坐标、时区，以及检查 WeatherFX 是否激活；
*   新的 Lua 函数：`ac.getSoundSpeedMs()` 获取精确声速，`ac.getAudioVolume('key')` 获取音频音量级别；
*   Lua 函数的新通用特性：能够以几乎零开销访问预先准备好的包含车辆状态等内容的结构（目前由新模式脚本使用）；
*   新的 WeatherFX Lua 函数：`ac.setVAOExponent(gamma)`，用于设置顶点 AO 的伽马；
*   Lua 音频事件新增音高参数；
*   Lua Debug 应用更新：存储值与调试值可复制，错误消息中的文件可点击（在支持的编辑器中打开文件并定位到正确行）；
*   标准 Lua 库现在以字节码形式分发，以优化加载；
