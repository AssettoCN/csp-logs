# 更新日志

## 新功能、选项与改进

*   引入条件（conditions）：可让灯光绑定到仅在一天中的特定时段激活，支持 LUT；
*   条件还可以带有 `LAG` 和 `SIMULATE_HEATING `属性，让灯光平滑地渐亮渐灭，过程中带有一点渐变；
*   修改材质属性！可按材质或按物体进行，既可以是静态的，也可以绑定到条件。示例可参考 Brands Hatch 配置；
*   用于修改 `DIRECTION=NORMAL` 值的新属性：
    *   `DIRECTION_ALTER` 允许在法线基中设置一个向量，例如 `DIRECTION_ALTER=0,0,1` 表示完全不做调整，`DIRECTION_ALTER=1,0,0` 表示向量向左（或向右，现在记不清了）旋转 90°，而 `DIRECTION_ALTER=0,0,-1` 则会将向量反转；
    *   `DIRECTION_OFFSET` 会加到所有向量的常规法线上，例如 `DIRECTION_OFFSET=0,-1,0` 会让所有东西朝下偏；
*   为赛道灯光添加向上的虚假阴影；
*   一些小修复；
