# 更新日志

## 新功能、选项与改进

*   Neoned 制作的全新 Quick Drive 模式 `Drift Challenge`，用于正经漂移；
*   SurfacesFX：
    *   Dmitrii 制作的全新冰面物理，自动应用于某些带冰面的老赛道（可选）；
    *   只要存在冰面，车辆就会获得额外的钉胎胎组；
*   全新的 Quick Drive 模式 `Frozen Drive`，把任何赛道表面变成冰（联机服务器也可以激活此模式）；
*   全新的 KN5 加载器：
    *   使用文件映射，加载更高效；
    *   跳过未使用的纹理（暂时可选，默认禁用）；
    *   在不同车辆之间共享网格数据与材质，节省 RAM 与 VRAM（网格压缩选项也移到了这里）；
    *   彻底跳过被 `[MODEL_REPLACEMENT_…]` 移除的网格；
    *   从仅物理网格中剥离不必要的数据，节省 RAM；
    *   重写后的逻辑附带一堆小优化；
*   默认 WeatherFX 样式：
    *   夜晚、灯光、自发光、车手名牌等的亮度经过重做；
    *   下雪天气或低温降雨时的降雪（目前需要 RainFX 才能运作）；
    *   烟雾天气类型的火山灰（目前也需要 RainFX，因为它们共享同一套底层机制）；
    *   让夜晚稍微更蓝的选项；
    *   龙卷风天气时背景中的基础龙卷风；
*   新的物理实验：
    *   为没有自定义物理脚本重新启用熄火的车辆恢复熄火（若按钮未绑定，油门踏板启动发动机）；
    *   全新的车辆碰撞逻辑（目前基本相同，但估算受损侧的方法略有不同）；
    *   修复网格命名不当的赛道上表面参数分配的问题（它们之前被当成了墙）；
*   TyresFX：
    *   轮胎随角速度在视觉上胀大，与物理状态匹配；
    *   爆胎的视觉与动画略有改进；
*   更好的 Joycon 支持，可选的按键重映射，更适配单只手柄；
*   若所选发动机映射在车辆配置中绑定到了什么，其状态会联机同步并存入回放；
*   车手模型利用之前为车手配重移位添加的那段奇怪代码，随 G 力倾斜与移动；
*   G 力现在也作用于车手头部（在原版逻辑之上的一点额外移动）；
*   加载未激活安全带几何体的选项（可能会弄坏某些在展厅里拿它做装饰的车辆，所以默认禁用）；

## 配置

*   联机：
    *   自定义服务器加载背景图不再使用强制缓存，允许服务器实时更新内容（如果图片是静态的，请记得正确设置缓存头，否则我会很不高兴）；
    *   面向联机服务器的新 `[EXTRA_RULES] AFK_AUTOKICK = <TIME>, [INPUT/SPEED]` 选项（时间以分钟计，`SPEED` 表示静止车辆将被踢出，`INPUT` 则跟踪车辆输入与鼠标位置）；
    *   联机配置的新选项，为特定车辆禁用吸附到地面（以防有人想开飞机之类的）；
    *   用 `[EXTRA_RULES] DISABLE_AUTOBRAKING=1` 禁用自动制动；
