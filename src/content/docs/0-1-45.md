# 更新日志

## 新功能、选项与改进

*   阴影渲染重做：
    *   或许会稍快一些；
    *   txNormal 中带 alpha 的 alpha 测试材质将正常工作；
    *   为某些材质提供半透明阴影的选项；
*   全新更平滑的阴影映射算法；
*   Extra FX：强制网格在 G-buffer 中作为不透明体绘制（针对某些破坏反射的网格）；
*   SSLR 恢复了一点质量过滤，以减少伪影；
*   Fake Shadows FX：新烘焙阴影的缓存又能用了；
*   修复了 Weather FX 的设置条件；
*   默认天气脚本现在也会设置 `wfx_WET`；
*   Particles FX：夜间燃放烟花的选项；
*   `Material_Water` 的新 `UnevenWaterFix` 选项，在网格不那么平坦时能帮上忙；
*   着色器 `ksPerPixelAT_NS` 已修复；
