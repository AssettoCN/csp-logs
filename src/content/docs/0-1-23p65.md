# 更新日志

## 新功能、选项与改进

*   修复了后视镜（偶发卡顿等问题）；
*   修复了与 Sidekick 里程表的同步；
*   修复了部分系统上特定车辆的崩溃；
*   修复了回放中的灯光合并；
*   修复了扩展仪表；
*   回放中车数较少时，灯光的可视距离增加（可选）；
*   用 SMAA 替代 FXAA 的选项，三种不同的质量预设（见 `graphics_adjustments.ini`）；
*   照片模式下烟雾会冻结；
*   回放暂停或照片模式下火焰会冻结；
*   重做了着色器中的所有反射；
*   后视镜中新增天空的反射；
*   Nice Screenshots 扩展：可修改 MIP LOD 偏置的选项，截图时各向异性过滤锁定为 16；
*   里程表新增 `OUTPUT_MULT` 选项；
*   灯光最大数量增加了 25%；
*   Python 新函数 `ac.ext_isVaoPatchLoaded`；
