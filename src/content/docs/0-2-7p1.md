# 更新日志

## 新功能、选项与改进

*   修复了 CSP 音频，例如雨声或雨刮声；
*   修复了手柄上的 FFB；
*   附上了 Mumble 客户端缺失的音频文件（用于新的 PTT 模式），该模式所用失真效果已调整；
*   AI 的路线拉直选项重做，不再标记为实验性；
*   倾斜的车手不再弄坏动态模糊；
*   为防万一，倾斜车手与新的头部晃动为可选，可在 Graphics Adjustments 中禁用；
*   更新了车手与安全带的渲染逻辑，应能修复某些边缘情况下的各种问题；
*   草地风效在禁用 Single Pass Stereo 的 VR 下可用；
*   修复了启用 Single Pass Stereo 时的 TyresFX 观感；
*   修复了 LCS 下 VR 的 HUD 亮度；
*   新的 KN5 加载器不再在联机中弄坏 GT86；
*   修复了交通车辆不可见的问题；
*   Cosmic 悬架更新，包含一些修复；
*   MoTeC 记录器：风向考虑赛道航向角，无效圈不再被跳过，新增通道（外倾/束角符号、涡轮增压、表面抓地力与碰撞体磨损）；
*   Cosmic 悬架：虚拟元件（如绞牙避震）安装到轮毂时现在能正确作用于 FFB；
*   第二追逐相机的替代脚本现在可用了；
*   实时开关 H 挡的新热键；
*   痕迹不再在 AC 启动最初几秒内的大型游戏内日期变更时褪色，橡胶痕迹完全不会随游戏内日期变化褪色；
*   痕迹会记录冬季季节调整，若保存时的值与当前差异过大则不会加载（影响泥土与砂石风格的痕迹）；
*   树木重新在第四级联中投射阴影，这次是半透明阴影；
*   半透明阴影（`SEMITRANSPARENT_SHADOWS=1`）重叠时产生更暗的阴影；
*   材质名含 `groove` 或 `tyre` 且用 alpha 混合渲染的赛道网格不再跳过 G-buffer 导致 SSLR 出错；
*   痕迹也能正确遮蔽 SSLR 反射；
*   修复了 Shuto 上灯罩（以及其他纹理被错配的场合）的问题；
*   赛道灯光序列现在会被缓存，提升 Shuto 加载速度；
*   修复了车辆尘土导致重置失效的小问题；
*   修复了当前播放音乐的读取，尤其是被错配的专辑封面；
*   烟花不再在展厅模式下燃放，烟花烟雾发射器上限提高；
*   不播放音乐时车载音响也会更新时间，专辑封面绘制时保持宽高比；
*   修复了在聊天中按 `Tab` 导致 AC 崩溃的问题；
*   在 `suspensions.ini` 中设置的图形偏移不再视为默认（那是个错误）；
*   音量应用：修复了传动音量联动；
*   联机的 `CUSTOM_MOTION` 选项现在默认应用于要求 CSP 3266 或更新版本的服务器；
*   修复了 `DISABLE_SURFACE_SNAPPING_ONLINE`（`car.ini` 与扩展服务器选项中均是）；
*   VR Variable Rate Shading：视线锁定、隐藏选项与调整视线方向的 API 函数；
*   ReflectionsFX：分辨率超过 512×512 时停止立方体贴图预过滤，运动外推改进；
*   离地过远的车辆不再粘着假阴影；
*   修复了动画悬架下 TyresFX 效果与车轮转动不同步的问题；
*   禁用 WeatherFX 时烟花不再弄坏天空；
*   默认 WeatherFX 样式：蓝色夜晚重做并默认禁用，YEBIS 替代有了正规的 bloom 实现与脏镜头选项（默认禁用），胶片颗粒强度可调，行星已修复，即使有光污染也可见；
*   地球纹理使用双三次插值；
*   土星有光环了；
*   修复了轮胎磨损降低的问题；
*   几个物理实验（替代多线程与物理物体运动）转为完成状态，已启用且处处可用；
*   为一切激活双面阴影的赛道修复，现在对保存不正确的赛道也能生效；
*   若服务器（在其他车辆已连接的情况下）停止发送 UDP 数据包几秒，CSP 会显示警告；
*   WeatherFX：修复了无 SPS 的 VR 中场景渲染回调失效的问题；
*   带动画悬架的车辆的初始车轮转动也会随机化；
*   硬碰撞（发生在异常碰撞深度下，现在的计算方式不同）不再弹跳且配置更好，主车永远不会使用简化的接触计算，确保即使在最奇怪的情况下碰撞也保持稳定；
*   远处大灯眩光重做并回归（在更远处激活，以掩盖许多车灯与自发光没对齐的事实，现在也适用于其他车灯，目前仍默认禁用）；
*   即使没有 `ksTyres` 网格，轮胎防滑钉也会在地面留下痕迹（仍然完全不推荐这么做）；
*   修复了 F5 相机偶尔出毛病变成黑屏的问题；
*   一项安全检查，确保相机不会进入非有限坐标；
*   若玩家车辆被发现处于非有限坐标，则显示警告消息；
*   非常实验性的技巧，可为联机选择特定槽位（针对有多辆不同涂装车辆的服务器），CM 支持即将推出；
*   冰面物理：FFB 已调整；
*   AC 关闭流程更新，提速并改善稳定性；

## 配置

*   赛道灯光的新 `DISTANCE_CLIP`，在特定距离处截断光照，用于额外优化，并模拟一些基本阴影而无需阴影贴图；
*   车辆配置的新 `[EMISSIVE_...] NO_FALLBACK_WHILE_BLINKING=1`，阻止后备值在主输入闪烁的 `off` 阶段激活；
*   `[MESH_ADJUSTMENT]` 与 `[SHADER_REPLACEMENT]` 的 `IS_VISIBLE`；
*   用 `DEBUG_OVERRIDE` 调试侧网偏移，更改最终偏移量（在限度内）；
*   `DistantEmissive` 材质现在支持法线贴图（例如 Shuto 的灯罩所用）；
*   可磨损碰撞体的新 `PROHIBIT_AC_RESET`，彻底阻止 AC 在会话重置时重置碰撞体磨损；
*   `[SHADER_REPLACEMENT]` 的新 `DIM_EMISSIVE_IN_CUBEMAP`；
*   侧网（以及使用同一倾斜机制的宝马 E30 天线等）会取 G 力的高频部分作为一点额外偏移，观感更自然；
*   文件名以 `./` 开头时，赛道配置会在配置旁查找文件（保持兼容）；

## Lua & Python

*   修复了 `ui.imageState()`；
*   为 UI 设置 MIP 偏置的函数现在也可以强制双三次插值；
*   一些 Lua 函数（如 `io.` 与 `os.`）已重写，标准库现在小了 15%，部分功能按需加载；
*   标记车手为好友现在应该可用了；
*   新的 `os.setCurrentFolder()`，影响文件搜索（包括标准 Lua 函数），不影响 AC 本身或其他脚本；
*   修复了 `web.socket()`（之前收到的数据经常乱码）；
*   Lua 预处理器已修复，不再在 `ENUM..somethingElse` 情况下生成无效代码；
*   Lua 着色器：可提示编译器将某些值编译进去（应能解决 YEBIS 替代更改设置导致卡顿的所有问题，现在所有设置都不是编译期的，而是在运行一段时间后按编译期应用）；
*   从不带 `loop` 参数的文件加载的音频事件，播放结束后现在会报告为无效，因为它们确实会失效；
*   `:resetSkin()` 不再影响车辆动态纹理；
*   面向 Lua 应用的新函数 `ac.setHShifterActive()`；
*   Lua Debug 应用：日志消息的时间戳；
*   `ui.drawCarIcon()` 新增提示参数；
*   `physics.resetWearPlanks()` 已弃用（`ac.resetColliderWears()` 的副本）；
*   新字段 `ac.getSim().timeSinceLastUDPPacket`，以备不时之需；
*   传递 C++ API 函数的新方式现在会在期望字符串时把 `nil` 处理为空字符串，与旧方式一致（0.2.5 中会错误地显示为 `'nil'`，`ac.setMessage()` 等函数受影响）；
