# 更新日志

## 新功能、选项与改进

隔了不少时间，这次更新带来了许多与 Lua 脚本相关的东西（Lua 应用、赛道脚本、由联机服务器下发的脚本，用于额外特效甚至新模式），所以我想先确保 API 足够可用。另外，雨还没来，很抱歉，不过现在差不多快完成了。

*   FSR：
    *   整个功能用官方发布的 SDK 重做：新的质量预设、调整过的锐化、根据官方文档建议调整的 MIP 偏置（旧实现仍保留以防万一）；
    *   三屏模式下为屏幕左右三分之一设置更低质量档位的选项；
    *   可选的调试模式：按住 Space 可快速切换到简单的线性放大以便对比；
*   烟雾重做（不含轮胎加热与生成逻辑）：
    *   全新改进的着色；
    *   车辆与烟雾的碰撞改进；
    *   对开放式车轮车辆的支持更好；
    *   漂移角度大时，轮胎烟雾从车底生成；
    *   灰尘与水花从整辆车生成，而不再仅从车轮；
    *   灰尘会从沾满灰尘的车轮上飞出；
    *   带木质滑板的某些 F1 车在滑板触地时会产生少许灰尘（可按碰撞体配置，与火花类似）；
    *   碰撞时会生成尘团；
    *   接触点会生成更小的泥土碎屑颗粒和更小的水花；
    *   长时间的烟雾与灰尘（烟雾可持续数分钟）；
    *   在草地上时改用更细腻的土壤颗粒而非尘团（颜色在赛道配置中设置）；
    *   排气、过热刹车和受损发动机的烟雾全新外观；
    *   座舱内不再显示烟雾；
    *   彩色烟雾与灰尘在扩散时逐渐褪色，新增配置参数可调整速度；
    *   烟雾剔除改进，进一步优化且过渡更平滑；
    *   调整密度和屏幕上尺寸的新选项，在画质与性能之间取得平衡；
    *   启用 ExtraFX 时，新增让烟雾藏在玻璃后面的选项；
    *   烟雾覆盖整个屏幕的额外效果（开销很小，却能营造额外的烟雾感）；
*   碎片粒子更新：
    *   调整了不同类型的概率，以及尺寸和着色；
    *   碰撞检测改用车辆高度图而非深度缓冲，结果更准确；
*   TyresFX：
    *   轮胎上的草与泥土重做，纹理与渲染都更新了；
    *   会考虑土壤颜色；
*   GrassFX：
    *   Active ExtraFX pass 选项现在正确支持车辆 Fake Shadows 重投影；
    *   草的形变更新，现在会考虑草的高度；
    *   如果使用原版 AC 运动模糊，现在也会作用于草；
*   Smart Shadows：
    *   级联之间的平滑过渡重做，且现在可配置；
    *   移除了圆盘阴影过滤；在我研究出正确做法之前，PCF 回归；
    *   烟雾、火焰、半透明物体等的半透明阴影借助 Bayer 抖动得到改进；
*   Nice Screenshots：
    *   旧的 HDR 修正方案换成基于亮度的加权平均；处理起来容易得多，效果也更好；
    *   累积 DOF：自定义散景形状和采样分布的选项；
    *   每隔若干步保存中间结果的选项（万一长时间累积没能撑到最后，也还能留点东西）；

## 配置

*   自定义车辆物理：
    *   将隐藏的调校项链接到动态控制器（例如可以做出离地高度随车速变化的悬架）；
    *   将离合器损坏与过高的扭矩关联；
    *   为任意悬架创建额外链接，将轮毂相互连接，或用固定/距离关节将轮毂连接到车身；
    *   动态物理控制器的新输入：`DAMAGE_ENGINE`、`DAMAGE_GEARBOX`（0 为原版，1 为完全损坏）；
*   自定义赛道物理：
    *   软墙已修复，新增 `MAX_DEPTH` 选项限制过深碰撞的软度（文档即将推出）；
    *   车辆出生时对齐赛道表面（可选，自定义赛道物理下默认启用）；
    *   用 CSP DLL 插件实现自定义赛道轮胎光线检测（例如用高度图而非三角形作为赛道几何）；
    *   各赛道文件的完整性校验（例如可以简单确保重要的 KN5 在联机中未被改动）；
    *   允许 Lua 脚本操纵物理对象的选项（请勿用于竞技赛道，但对自定义内容或许是个不错的补充）；
*   车辆配置：
    *   TyresFX：
        *   新参数 `DIRT_OFFSET_K`，与 `DAMAGE_OFFSET_K` 类似；
        *   为不同轮胎设置自定义网格的选项；
        *   `[MESH_SPLIT_...]`：
            *   直接设置拆分名称或材质，或使用现有材质；
            *   新模式 `COPY_FLIPPED`，修复车内车窗缺失的问题；
            *   新 `INSERT_TO` 选项，为新网格指定新的父节点；
    *   额外车辆开关（即 A/B/C/D 额外功能）：
        *   新增 Extra E 和 Extra F 开关；
        *   开关现在可以在配置中设置名称，加载时显示在车辆描述里；
        *   开关可以选择按住模式（按住按钮期间激活）；
        *   开关可以要求车辆静止才能激活（比如布加迪威龙的速度钥匙），或要求空挡，或踩下刹车；
        *   如果你用翼板动画显示/隐藏附加部件，现在可以配置成让 `hidden` 几何体真正隐藏，省下 draw call：
            *   车辆灯光现在可以绑定到翼板状态，引用翼板 ID 并用 LUT 作亮度倍率；
            *   对于隐藏部件只是缩小或挪远的两状态简单情形，CSP 应能自动推断；
            *   CSP wiki 上有快速生成这类动画及对应配置的工具；
    *   在 `extension/data_override` 文件夹中创建新文件，即可覆盖 `lods.ini`、`lights.ini` 等与视觉相关的车辆数据文件；
    *   彩色阴影：整体观感改进，新增参数；
    *   车辆轮胎现在可以半透明，用 `txNormal` 的 alpha 作透明度，可用于带渐隐贴纸的额外层；
    *   车辆仪表新输入：KERS、`TYRE_VIRTUAL_KM`、`FLAG_TYPE`；
    *   可调翼板现在可以同时作用于多个节点（更容易兼容 LOD）；
    *   配置可以在加载画面上添加关于车辆特性的额外说明；
    *   车漆着色器新参数 `ColoredBlackSpecular`，改善多彩涂装观感，第四版会自动启用；

*   Python 应用：
    *   通过 Python 应用 profiler 实现的 Python 应用实时重载（两种模式：按钮重载，以及任意 `.py` 文件更改时自动重载）；

    *   检查 VR 是否启用的函数；
