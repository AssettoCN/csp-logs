# 更新日志

## 新功能、选项与改进

*   应用已更新，感谢 leBluem、Blamer 和 hen.ter；
*   可禁用按下 F3 或 F5 时顶部显示车手姓名的那条消息的选项；
*   最多可设置 10 个额外里程表；
*   Weather FX：
    *   默认光污染归零；
    *   云的新选项 `isIncludedInCalculate`，默认为 true；
    *   修复了 Chaser Camera；
    *   实现脚本的新函数 `ac.isPpActive()`；
*   可禁用可损坏灯光的选项；
*   新的 Chaser Camera 扩展，可用 Lua 脚本改变追逐相机的运动方式（已附带几个示例脚本）；
    *   目前在与 FPS 绑定的时序与插值上有大问题，不久后会修复；
    *   供 Python 应用调试的新函数 `ac.ext_chaserCameraDebugText()`；
    *   它的另一个用途是录视频；
*   启用 Weather FX 时联机中的时间平滑流动（最初最多需要一分钟才能动起来）；
*   修复了启用 Weather FX 并设置日期后时间错误的问题；
*   修复了启用 Weather FX 时无法关闭车头灯的问题；
*   Graphics adjustments 已修复；
*   修复了偶发的黑屏；
*   修复了树木着色器的 VAO；
*   修复了旗语；
*   更多修复；
