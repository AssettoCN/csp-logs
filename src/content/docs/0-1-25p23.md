# 更新日志

## 新功能、选项与改进

*   修复了 Brake Disc FX；
*   现在与 AC 阴影移除补丁兼容；
*   但与此同时，该功能现在也被整合了进来：换句话说，如果你在 CM 中把阴影设为 Off，就算没有那个阴影移除补丁，阴影现在也会消失；
*   自动识别可视调节的尾翼；
*   车辆新功能：松动物件（wobbly bits）；
*   Neck：
    *   修复了 Track IR；
    *   停用了 G 力快速响应（慎重考虑后，我觉得当初加它就是个坏主意）；
*   修复了动画转向灯；
*   转向灯新选项：`REPEAT_FREQENCY_HAZARDS_HZ`（双闪的独立频率）、`USE_RANGE_FOR_HAZARDS`（设为 0 可在双闪模式下禁用动画）；
*   其他小修复；
