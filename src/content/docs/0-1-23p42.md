# 更新日志

## 新功能、选项与改进

*   Tyres FX：自定义轮胎纹理现在可以在联机中使用，感谢 paul12451 在测试中的大力帮助！
*   Lighting FX：赛道点光源现在支持 `DIFFUSE_CONCENTRATION`；
*   Vertex AO：
    *   修复了多层着色器；
    *   新的 AO 亮度倍率选项，用于修复过暗的赛道；
    *   支持 `.vao-patch` 文件中的 `Config.ini`，无需重新烘焙整条赛道即可调整不透明度与亮度倍率；
    *   支持将单个补丁应用于多个 KN5；
