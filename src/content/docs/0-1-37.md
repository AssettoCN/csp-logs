# 更新日志

## 新功能、选项与改进

*   Weather FX 更新：
    *   第二版云朵着色器，带体积噪声和低分辨率遮罩以加速；
    *   忽略 vertex AO 的次要环境光，用于照亮内部（不应随一天中的时间或天气变化）；
    *   云朵阴影；
    *   基于用户设定系数的云朵排序；
    *   云朵遮挡太阳已修复；
    *   禁用阴影已修复；
    *   每朵云各自的雾倍率；
    *   WeatherFX 实现的新函数：
        *   采样相机 AO；
        *   设置整体亮度；
        *   单独调整天空亮度；
        *   检查 Extra FX 的反弹光是否启用；
        *   现有函数的替代版本，以降低 GC 负担；
*   默认 Weather FX 实现已就绪（不过可能仍需完善）；
*   YEBIS 扩展（Yebisest）：
    *   现在带有设置；
    *   在第一人称视角下禁用变形眩光（anamorphic）或鬼影眩光；
    *   PP 滤镜新参数：
        *   自定义调色强度；
        *   第一人称视角的替代眩光形状；
        *   变形眩光的颜色和形状的若干额外选项；
*   新的 GUI 扩展：
    *   各类 GUI 调整从常规设置移到了这里（带来不便，抱歉）；
    *   PP 滤镜选择器应用的新外观：
        *   带分组的下拉列表；
        *   用于管理的右键菜单；
        *   内置编辑器（在列表中选中滤镜的右键菜单里）；
    *   Objects inspector 高亮效果更好，位置和点击点也能正确显示；
*   Fake Shadows FX：
    *   深度偏移得到改进；
    *   加载期间重新生成阴影，且设置更好；
    *   阴影形状会随光照变化；
    *   仅在启用 Extra FX 时：
        *   使用软粒子同款技术，混合更平滑；
        *   真正感知几何体的阴影映射；
        *   扩展渲染范围，确保受影响区域被正确覆盖；
*   Lighting FX：
    *   动态环境光已彻底禁用；
    *   自由相机经过时，车辆不再使用全范围大灯；
    *   修复了从后方观看车辆时烦人的灯光合并；
    *   额外的限制，进一步提速；
*   Grass FX（彻底重做，这是第三次尝试）：
    *   纹理回来了；
    *   基础配置，外加最多四个可通过本地调整选择的额外配置；
    *   可设置尺寸、宽度、整齐度和草的修剪程度；
    *   基于颜色生成的四个参数（该功能也已重写）；
    *   新的逐网格调整，可选在其中自定义局部区域；
    *   也支持基于纹理的调整；
    *   自定义纹理；
    *   用自定义纹理添加额外贴花精灵（sprites），可自定义概率、尺寸和行为修饰符；
    *   可选的偏移，用于按日期计算的修剪周期；
    *   需要的话，可将条件作为输入；
    *   五种不同的预设；
    *   可选的高级混合（alpha-to-coverage）；
*   Particles FX：
    *   控制烟花的选项；
    *   对草地上尘土的几处调整；
    *   修复了车辆周围气流导致烟雾不对称飘动的问题；
*   Extra FX：
    *   反弹光已修复，现在是正确的 HDR；
    *   SSLR 稍作优化；
    *   运动模糊会忽略旋转的车轮，而不是像以前那样把车轮弄得更糟；
    *   雾现在会被正确考虑；
*   Reflections FX：
    *   内部遮罩已修复（某些车因材质错误导致遮罩不足）；
    *   内部遮罩新选项：按网格名称或按带半径的位置剔除球形区域（默认剔除后视镜）；
*   Nice Screenshots 扩展：
    *   分辨率倍率现在可用于累积运动模糊；
    *   亮度错乱的问题已修复，改用混合 HDR 数据的方案替代旧方案；
*   Python 扩展：
    *   新函数 `ac.ext_markLapAsSpoiled()`；
    *   函数 `ac.ext_debugWiperSoundState()` 和 `ac.ext_mirrorDebug()` 已移除；
*   新车漆（`common/material_carpaint.ini`）：
    *   清漆高光（ aka 太阳高光）不再受自定义高光颜色影响；
    *   可用 txDiffuse 的 alpha 通道对变色龙车漆、彩虹反射等特效做局部化；
    *   基于 txMaps alpha 通道的透明度；
    *   彩虹车漆已更新并修复；
*   赛道配置新增选项，可彻底忽略默认自动加载的配置；
*   新的 `ksMultilayer_fresnel_nm4` 着色器，带四张法线贴图；
*   新的 `ksPerPixel_horizon` 着色器，用于那种像管子一样套在赛道周围的地平线网格，可修复部分现有赛道，并支持复杂的颜色调整；
*   阴影级联之间的平滑过渡；
*   自定义自发光：修复了后续项相减的问题；
*   调整了水面着色器的高光；
*   初步支持来自服务器的聊天命令（可用于联机动态天气之类）；
*   新的 DXGI flip model 又能用了，仅限 Windows 10；
*   纹理映射已优化；
*   常量缓冲区映射已优化；
*   需要时可为车辆使用超过 10 个模型调整；
*   修复了 INI 解析器误处理 `\` 的 bug；
*   低细节层级下不再出现 SSAO 轮廓；
*   修复了通过 Python 应用应用赛道配置的问题；
*   扩展轮胎光线追踪已修复；
*   修复了配置中网格或材质过滤器的正则表达式；
*   修复了视觉风速（烟雾、水面等）；
*   修复了着色器更改时着色器替换的实时重载；
*   小修复与优化；
