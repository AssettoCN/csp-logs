# 更新日志

## 新功能、选项与改进

*   修复了多车的扩展回放；
*   来自天气应用的时间偏移不再存入回放，而是可以在回放过程中更改；
*   修复了自由相机，默认速度值更接近原版；
*   修复了启用 FXAA 时的崩溃；
*   修复了动态物体；
*   回放新增累积模糊（仍在开发中）；
*   将额外动画绑定到额外灯光（示例见 E30 Drift 配置）；
*   将额外动画绑定到喇叭或前大灯；
*   改进了对可执行文件的支持；
*   轮胎着色器现在能获得稍多一些的环境阴影；
*   `loaded` 文件夹中配置的优先级现在更低；
*   修复并改进了车辆配置的查找（尤其是涂装配置的问题；现在会搜索子文件夹中所有名称匹配的文件）；
*   远光灯找回了它们的边缘；
