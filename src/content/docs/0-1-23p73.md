# 更新日志

## 新功能、选项与改进

*   部分重做了字体渲染：现在，应用很多时应该运行更快（请务必测试；感谢 themrdemonized 的想法）；
*   修复了车辆很多时赛道灯光偶尔消失的问题；
*   修复了大灯合并；
*   `Bounced`（反弹光）强度现在取决于光锥角；
*   支持按条件闪烁，包括随机化闪烁；
*   新的赛道灯光条件：`HAZARDS`、`FLAME_FLICKERING`；
*   调整了 `RACING_FLAG` 的延迟；
*   Patch 扩展 Python 应用现在会显示相机位置；
*   为赛道添加了线光源支持（示例可查看 `forliring.ini`）；
*   灯光现在改为 17:30 点亮，以兼容原版服务器与天气，感谢 joshuax_cz；
