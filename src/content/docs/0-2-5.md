# 更新日志

## 新功能、选项与改进

*   Neoned 制作的新 Quick Drive 模式 `Drift Challenge`，供正经漂移用；
*   SurfacesFX：
    *   Dmitrii 制作的新冰面物理，自动应用于部分带冰面的老赛道（可选）；
    *   若存在任何冰面，车辆会获得带钉的额外轮胎组；
*   新 Quick Drive 模式 `Frozen Drive`，把整条赛道表面变成冰（联机服务器也可以激活该模式）；
*   新的 KN5 加载器：
    *   使用文件映射，加载更高效；
    *   跳过未使用的纹理（目前可选，默认禁用）；
    *   在不同车辆之间共享网格数据与材质，节省内存与显存（网格压缩选项也移到了这里）；
    *   彻底跳过被 `[MODEL_REPLACEMENT_…]` 移除的网格；
    *   从仅物理网格剥离不必要的数据，节省内存；
    *   重写逻辑的一批小优化；
*   默认 WeatherFX 样式：
    *   夜晚、灯光、自发光、车手名牌等的亮度已重做；
    *   下雪天气或低温伴随降雨时的降雪（目前需要 RainFX 运行）；
    *   烟雾天气类型的火山灰（目前也需要 RainFX，因为它们共享同一套底层机制）；
    *   选项，把夜景画得更蓝一点；
    *   龙卷风天气背景中的一些基础龙卷风；
*   新的物理实验：
    *   针对没有用自定义物理脚本重新启用熄火的车辆的熄火（若未绑定按钮，油门踏板启动发动机）；
    *   新的车辆碰撞逻辑（目前基本相同，但估计受损侧的方法略有不同）；
    *   修复网格命名不规范的赛道上表面参数分配的问题（它们此前被当成了墙）；
*   TyresFX：
    *   轮胎随角速度视觉增大，与物理状态匹配；
    *   爆胎的视觉效果与动画略有改进；
*   更好的 Joycon 支持，可选的按键重映射以更好适配单只手柄；
*   若所选引擎映射在车辆配置中关联了某些内容，其状态将在联机中交换并存入回放；

*   选项，加载未激活的安全带几何体（可能会弄乱某些在展厅中用它做装饰的车辆，因此默认禁用）；

## 扩展物理

*   修复了部分车辆在雨中静止时轮胎过热的问题；
*   COSMIC 悬架的 bug 修复；
*   COSMIC 支持转向柱柔性（不过在 333Hz 下可能不稳定）；

*   轮胎热模型 V3 开发中，相较旧模型有一些额外功能；
*   新的原生 MoTeC 数据记录器可用（需启用扩展物理），记录频率最高 333 Hz；
*   在 `tyres.ini/[FRONT/REAR]` 中使用 `OVERRIDE_BLANKETS_TEMP`，可按轮胎覆盖保温毯温度；

## 配置

*   联机：
    *   自定义服务器加载背景图不再使用强制缓存，允许服务器实时更新内容（如果你的图片是静态的，请记得设置合适的缓存头，否则我会很不高兴）；
    *   面向联机服务器的新 `[EXTRA_RULES] AFK_AUTOKICK = <TIME>, [INPUT/SPEED]` 选项（时间以分钟计，`SPEED` 表示静止车辆会被踢出，`INPUT` 则追踪车辆输入与鼠标位置）；
    *   联机配置的新选项，禁用特定车辆的地面吸附（万一有人想开飞机之类的）；
    *   用 `[EXTRA_RULES] DISABLE_AUTOBRAKING=1` 禁用自动刹车；
