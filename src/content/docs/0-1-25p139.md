# 更新日志

## 新功能、选项与改进

*   若干重要的渲染与稳定性修复；
*   修复了赛道的运动网格；
*   着色器调整现在也可以修改材质与网格的标志，与 `MATERIAL_ADJUSTMENT` 和 `MESH_ADJUSTMENT` 相同；
*   由于稳定性问题，PP 滤镜的 INIpp 支持目前暂时禁用；
*   新的远景自发光着色器，带自定义光晕以减少闪烁（需通过配置设置）；
*   带内饰照明的新车窗着色器（需通过配置设置）；
*   位移（视差/细分）着色器的正规材质库；
*   改进了材质调整的网格查找；
*   车辆灯光的变更：
    *   近光变暗；
    *   远光的截断减少；
    *   改进了亮度/距离的依赖关系；
    *   远光现在可以正确熄灭；
    *   改进了额外灯光到网格的绑定；
    *   默认不再有车灯照在车身上的镜面反射（SSLR 的效果好得多），可在灯光参数中设置 `NO_SELF_SPECULAR = 0` 开启；
    *   默认刹车灯可视距离从 3 米增加到 5 米；
    *   `MIRROR_DIRECTION` 效果更好，尤其是对短距离灯光，默认启用；
    *   额外灯光新增 `NOT_WITH_HEADLIGHTS` 选项，大灯激活时将其关闭；
*   新增选项，可禁用 AI 返回维修站稍后重新加入比赛的提示消息，默认启用；
*   改进了雨刮的抖动；
*   用自由相机录制并回放相机运动，Ctrl+Delete 和 Alt+Delete；
