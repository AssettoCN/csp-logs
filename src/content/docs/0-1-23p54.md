# 更新日志

## 新功能、选项与改进

*   Real Mirror 修复与改进；
*   修复了闪烁；
*   修复了虚拟后视镜；
*   新的画质调整扩展，可增大运动模糊强度（之后可能还会加入更多功能）；
*   为烘焙了 vertex AO 的赛道提供单独的 `TRACK_AMBIENT_GROUND_MULT_VAO` 参数，并可在赛道配置中重新定义；
*   截图的累积 AA（Accumulation AA）：
    *   使用 Windows Imaging Component 编码，提升 JPEG 质量；
    *   可设置 JPEG 质量的选项；
    *   支持三屏幕；
    *   可禁用 FXAA 以保持截图锐利；
    *   支持运动模糊，另有选项使其更平滑；
    *   DOF 修复（效果一般，但聊胜于无）；
    *   保存耗时缩短；
*   想让截图快一点的话，可将 `nice_screenshots.ini` 中的 `SAVE_ORIGINAL` 设为 0。忘了改这一项，不过设为 1 时可以对比截图，或许有用；
*   为限制 Real Mirror 对帧率的影响，可在 `smart_mirror.ini` 的 `REAL_MIRRORS` 节中设置 `RENDER_PER_FRAME`。`RENDER_PER_FRAME=0` 表示所有后视镜每帧都更新；
