# 更新日志

## 新功能、选项与改进

*   可变刷新率（VRR）默认启用，确保用户不会遇到意外的性能下降；
*   回放的保存与加载应更加稳固（可留意 CSP 日志中的 `Couldn't load the entire replay`）；
*   回放中缺失的车辆会以占位模型加载，显示为粉色方块；
*   挡风玻璃反射在 DLSS 等放大技术下不再生效，除非显式启用（不推荐；也许最终我会找到让它正常工作的好办法，但这类效果本质上与时序放大技术相冲突）；
*   轮胎湿痕透过山丘等物体显示的问题已修复；
*   CSP 预览已修复；
*   加载后的最初几帧里后台 Shader 加载更加密集，使 Shader 更快就绪；
*   偏振滤镜重新兼容 SSLR；
*   Render stats 应用：性能报告更新，信息更丰富、数据更准确，物理测量更清晰；
*   CSP Debug 应用：新增渲染赛道物理网格的选项；
*   Lua Debug 应用：修复某些类型脚本中计时测量偶发异常的问题；
*   新实验：将部分碰撞体升级为凸包，以获得更好的碰撞检测和更高的性能；
*   新物理实验：使用新的 ODE 批量光线检测替代 Embree，节省内存和加载时间；
