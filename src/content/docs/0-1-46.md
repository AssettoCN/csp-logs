# 更新日志

## 新功能、选项与改进

*   修复了 UI 消失的问题；
*   修复了 VR 下出现黑色表面的问题；
*   修复了烟雾阴影缺失或风挡阴影损坏的问题；
*   修复了自定义阴影渲染；
*   Smart Shadows：
    *   自定义阴影矩阵，附带稳定化与更低抖动（可选）；
    *   圆盘阴影，可减轻阴影锯齿（可选，默认禁用）；
    *   阴影锐化（可选，默认 20%）；
    *   更懒散的更新以提升速度（可选）；
    *   在禁用阴影的情况下拥有完整阴影的车内（可选）；
    *   默认距离已调整；
*   轮胎扩展光线检测重写，修复了大量 bug，提升精度并带来新功能；
*   `EXTRA_MASK_PASS_COLOR` 现在可使用负值以聚焦特定色调；
*   修复了任务栏导致 Custom Shaders Patch 重载的问题；
*   车辆后刹车盘使用光源的选项；
*   若你有一些应用没显示在 AC 任务栏中，现在它们也许会出现了，对 AC 的 `ac.newApp()` 做了个小改动；
*   OpenVR：自定义 VR 到显示器镜像的选项；
*   自由相机在 VR 下工作得更好；
*   修复了 SSGI 强度（增强了，也加入了选项），修复了随机斑点；
*   Grass FX：第一与第二遍生成时草更小，以减轻 LOD 爬行效应；
*   调整了模糊反射；
*   最模糊的 SSLR 反射在靠近光源时现在更加模糊；
*   新烟雾：
    *   略微调整了缩放与不透明度；
    *   更平滑的接收阴影；
*   多贴图（multi-map）模式下的自发光着色器：可将几何体区域用作通用遮罩的选项，用于平滑的仪表盘高亮；
*   折射大灯：反射更锐利、对比更强；
*   Chaser Camera 模块：
    *   Bombadil 的新 Drone（无人机）相机；
    *   Levels 相机已更新；
*   一些小修复；
