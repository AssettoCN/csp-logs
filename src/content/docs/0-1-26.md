# 更新日志

## 新功能、选项与改进

*   新的内置应用，可分析 Python 应用性能；
*   新的 Python 函数：
    *   `ac.ext_isAppVisible("app name")`：若应用未启用且无需后台工作，可轻松跳过整个 `acUpdate()`；
    *   `ac.ext_perfBegin("name")` / `ac.ext_perfEnd("name")`：测量两次调用之间的耗时，并直接以毫秒返回（新的性能分析应用也会显示）；
*   自定义烟雾：
    *   修复了高倾角前轮不必要生成烟雾的几个问题；
    *   观感与行为调整；
    *   新的剔除机制以提升性能；
    *   降分辨率渲染烟雾以提升性能的选项（效果不好，且仅在软粒子可用时开放）；
    *   与 TAA 的兼容性更好；
    *   尘土颜色现在与赛道的尘土颜色同步；
    *   修复了与 VR 及三屏的兼容性；
*   碎片粒子：
    *   大小与数量调整；
    *   碰撞检测改进；
    *   在没有 Grass FX 时工作得更好（草屑只会在草地上飞出，颜色也会同步）；
*   光照贴图（Light map）：
    *   也会包含自发光；
*   TAA：
    *   针对移动物体与半透明物体的基于模板（stencil）的抗鬼影；
    *   基于运动的抗鬼影；
    *   使用 Halton 序列采样；
    *   扩散程度可调；
    *   抗鬼影的钳制改为裁剪，以保留颜色；
    *   若干修复；
*   修复了 SSGI；
*   HBAO+ 使用法线贴图，结果更平滑；
*   SSAO/HBAO+ 不再影响反射（之前看着很糟）；
*   SSLR：
    *   模糊改进；
    *   会考虑带颜色的反射；
    *   修复了混合；
*   观众与原版粒子在 TAA 与运动模糊下正常工作；
*   修复了中等画质下的运动模糊；
*   自定义调校项在非英语区域设置下工作得更好；
*   修复了齿比控制；
*   Objects Inspector 应用：
    *   修复了名称缺失；
    *   新增取消选择的按钮；
    *   也会显示材质属性；
*   修复了弯道灯（cornering lamps）；
*   修复了胎压指示灯；
*   修复了 AI 洪流（AI flood）；
*   使用键盘控制时，CSP 可强制禁用 TC；
*   三屏在阴影与裁剪距离等可调项目上使用正确的 FOV；
*   修复了草地与三屏及 VR 的兼容性；
*   修复了三屏与透明物体的罕见问题；
*   调试应用中的 GPU 耗时测量不再拖慢速度；
*   车辆配置中定义的包围盒不再破坏 Particles FX 与 Grass FX 的碰撞体网格；
