# 更新日志

## 新功能、选项与改进

*   在常规设置中用一个复选框即可彻底禁用补丁；
*   Graphics Adjustments 新增选项，可进一步改变车辆 LOD 的挑选方式；
*   Weather FX：
    *   修复了反射；
    *   禁用精确太阳运动时，季节调整也会随之禁用；
    *   禁用季节调整的选项；
    *   联机或旧回放中天气 ID 的关键字识别；
*   修复了树木着色器；
*   其他修复；

## 扩展物理

*   BrakeExtension：
    *   所需语法略有不同（示例参见 Trello 看板）；
    *   新增 `simple` 制动系统（示例在 Trello 上）；
    *   修复了 AI 的一些问题；
*   Suspension DWB Extension：
    *   修复了传动比（motion ratios）的计算位置输入；
    *   各项优化与改进；
