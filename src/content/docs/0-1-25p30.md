# 更新日志

## 新功能、选项与改进

*   修复了 Particles FX；
*   Logitech G27 LED：
    *   可设置自定义延迟的选项；
    *   默认延迟从 50 帧降到 12 帧；
    *   修复了虚拟 LED 模式；
*   踏板应用中显示手刹条的新选项；
*   后处理滤镜的新扩展：
    *   比赛期间自动重载 PP 滤镜；
    *   限制自动曝光测光区域的选项（真正可用）；
    *   按指定顺序添加任意数量的各类色彩校正（尚在开发中）；
    *   更多细节：[https://github.com/ac-custom-shaders-patch/acc-extension-config/wiki/Extra-options-for-post-processing-filters](https://github.com/ac-custom-shaders-patch/acc-extension-config/wiki/Extra-options-for-post-processing-filters)；
*   Track adjustments（赛道调整）：在 track day 或练习模式下隐藏工作人员的选项；
*   Tyres FX 不再在工作人员换胎时让轮胎消失；
