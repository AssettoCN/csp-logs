# 更新日志

## 新功能、选项与改进

*   修复物理线程大量消耗 CPU 的问题；
*   修复物理卡死的问题（不过现在，如果物理工作线程 3 秒内无响应，CSP 将直接崩溃）；
*   若干修复，针对 Rain FX 和水洼生成在某些比赛中或在标记区域之外异常的问题；
*   修复部分车辆在 Smart Mirrors 暂停时后视镜损坏的问题；
*   使用原版物理的车辆现在同样使用 Embree 进行轮胎痕迹接触检测（仍像原版 AC 一样忽略背面）；
*   Render Stats：
    *   用于生成详细性能报告的工具；
    *   一些关于帧节奏的细节；
    *   调整了主性能图表；
    *   物理提示信息会显示碰撞检测所耗时间；
*   底层物理引擎：
    *   回退到 OPCODE，并加入若干优化；
    *   与无厚度墙体及其他奇怪几何体的碰撞应有所改善；
    *   车辆与赛道接触随深度变得更刚性时表现更好，防止车辆在被推挤时穿墙或穿地；
    *   新物理实验：调整动态物体之间的碰撞，避免多车接触时 Assetto Corsa 直接卡死；
    *   新物理实验：更快的碰撞检查（用更自动化的方案替代旧的 Kunos 赛道子空间——反正似乎也没什么 MOD 作者在用）；
    *   多轮胎接触点速度更快；
    *   一批 ODE 内部优化；
    *   新物理实验：加入车轮与车辆之间的碰撞（非常实验性，默认禁用）；
    *   单个赛道物体包含多个碰撞体且启用相互碰撞时应运作更好；
*   部分屏幕空间光照效果（火花、火焰、车辆）在缩放比例不等于 100% 时也能正常工作；
*   AC 暂停时排气火焰的光不再消失；
*   帧率时序实现（Sleep/Timer/…）经过调整更加平滑，渲染的高精度计时器现在会稍微自旋，使各帧更均匀；
*   修复欢迎消息在某些配置下显示为空的问题；
*   CSP 的 INI 解析器不再将 `//` 前有 `http:` 或 `https:` 的内容当作注释；
*   P2P 1v1 模式：修复赛道存在性检查；
*   `physics.RigidBody`：修复一批崩溃、唤醒及其他问题；
*   修复宇宙悬挂未能通过验证的问题；
