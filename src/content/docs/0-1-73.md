# 更新日志

## 新功能、选项与改进

*   车手左右张望现在会存入回放并在联机中同步；
*   改进了新车漆的观感；
*   选项，减少开始回放时的延迟；
*   略微改进了原版反射强度的计算，使过渡更平滑；

## 修复

*   修复了新的高级剔除，目前也默认禁用；
*   修复了被导出为车辆的赛道；
*   修复了可自定义的 TC2 快捷键；
*   修复了 TyresFX（几处轻微的映射问题）；
*   WeatherFX：异步垃圾回收暂时禁用，等我弄清楚再说；
*   修复了用于粒子碰撞测试的车辆高度图；
*   碎片粒子略有调整，更多改进稍后到来；
*   NeckFX：某些赛道上晃动的前瞻移动终于修复；
*   新聊天：修复了管理员遇到的崩溃；
*   修复了 ExtraFX 反弹光的闪烁；
*   修复了 GrassFX 遮挡物行为异常的问题；
*   修复了 G-buffer 标志猜测；
*   修复了风挡在夜间接受负值阴影的问题；
*   云阴影现在能在镜子与反射中工作；
*   修复了其他车辆某些部分消失的问题；
*   修复了卡顿的 CSP 自发光（之前误受默认 `INPUT_REFRESH_RATE=5` 的影响）；
*   负值颜色与 ksEmissive 值不再弄坏新的自定义 MSAA resolve；
*   带清漆的 PBR 着色器在动态光下看起来没那么离谱了；
*   修复了云可能从镜子与反射中消失的问题；
*   命令 `set observeDigital 1` 现在应该更好用了；
*   暂停隐藏的应用不会再把某些时刻可见的应用也一并暂停，这样你仍能正常录制内容；
*   修复了其他几处崩溃与 bug；

## 配置

*   车辆仪表的新输入：`ENGINE_TORQUE`、`ENGINE_POWER`、`TYRE_COMPOUND_INDEX`、`DIFF_PRELOAD`；
*   导航仪的新选项 `USE_SATELLITE_VIEW_BY_DEFAULT` 与 `UI_BACKGROUND_COLOR`；
*   为自定义物理的风扇新增 `MAP_RPM_FORCE`；
*   新的网格过滤关键字：标志 `insideWheel` 与 `insideSuspension`；
*   服务器现在可通过扩展配置关闭逆行警告；
*   强制 SSLR 现在会自动为内饰与车轮启用；
*   WeatherFX 脚本现在可以在夜间增强反射中的自发光；
*   `INPUT_REFRESH_RATE` 的默认值从 5 改为 10；
*   新车漆的次级模糊反射层；
*   PBR 着色器可选的 `txEmissive`（仅作简单乘数）；
*   选项，将 `txNormal` 用作新车漆着色器的常规法线贴图；
*   Light maker 应用现在有了体积光选项；
*   赛道灯光现在默认使用 `[LIGHTS_COMMON]` 中设置的参数；
