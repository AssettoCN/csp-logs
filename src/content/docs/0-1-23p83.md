# 更新日志

## 新功能、选项与改进

*   修复了一个重大 bug（相比 preview82）；
*   Tyres FX：修复了损伤累积；
*   Real mirror：修复了渲染、角色猜测与 HQ 兼容性；
*   修复了 `INCLUDE` 的行为（现在被包含文件中的 `INLUDE` 也能生效，这正是 ACFL F1 赛车表现异常的原因）；
*   加载画面：选项，可退回到某些图形而不是 AC 徽标，目前使用的是那些圆点背景；
*   加载画面：额外的车辆参数；
*   修复了灯光数量限制；
*   赛道灯光：修复了罕见的闪烁 bug；
*   Graphics adjustments：可选的颜色分级，与 Custom Showroom 中的相同（目前在没有 FXAA/SMAA 或在截图中不起作用，非常实验性；支持 DDS 和 PNG 两种格式）；
*   新的 Brake Disc FX：某种轮辋反射，以及动态加热颜色；
*   修复了制动盘灯光；
*   轮拱中车轮的环境阴影；
*   阴天时轮胎更亮；
*   新函数 `ac.ext_getTyreVirtualKM(car, tyre)`；
*   修复了 `ac.ext_version()`；
*   修复了 `log.txt` 中曲线消息刷屏的问题；
*   尝试修复 `PythonInterface.printErr` 错误，目前可能还无法正常工作；
*   修复了网格替换导致 AC 崩溃的罕见 bug（例如，来自这里的修补版 Yellowbird：[https://www.racedepartment.com/downloads/ruf-ctr-yellowbird-visual-update.21343/](https://www.racedepartment.com/downloads/ruf-ctr-yellowbird-visual-update.21343/)）；
*   对于车辆，`LIGHT_SWITCH_DELAY` 现在有了 `LIGHT_SWITCH_LAG` 替代项；
*   改进了灯光平滑切换；
*   调整了 AI Flood 参数；
*   修复了火焰灯光；
*   聚光灯角度可以超过 180°，用于特殊的路灯杆；
*   车辆灯光新增 `AFFECTS_TRACK` 参数；
*   赛道新增 `MESH_ADJUSTMENT` 节，可更改 `IsTransparent` 等参数（说的就是那些丢失车辆环境阴影的湿滑赛道模组）；
*   Caterham 车辆的配置，感谢 benobro；
