# 更新日志

## 新功能、选项与改进

*   全新 `[NODE_ADJUSTMENT_...]` 节，带 `MOVE_TO`，可将节点移动到特定父级；
*   `[MESH_ADJUSTMENT_...]` 的新参数，同样是 `MOVE_TO`；
*   显示器上的自定义镜像现在也支持 Oculus；
*   修复了 Oculus 下的自定义阴影矩阵；
*   修复了高光指数为零时折射出现黑色毛刺的问题；
*   修复了照片模式应用中预览发白的问题；
*   转向灯、双闪和火花现在应该可以在联机中工作了；
*   修复了 G-buffer 遮罩；
*   `[SHADER_REPLACEMENT_...]` 新增 `FIXED_EMISSIVE` 参数，取代旧的 `extFixedEmissive`；
*   修复了回放保存动态 Weather FX 及其他扩展数据的问题；
*   基于 IMGUI 的新应用（包括新聊天应用）现在应该可以在 VR 中工作了；
*   新聊天应用：消息淡出效果，以及几处小修复；
*   Graphic Adjustments 中的原版抗锯齿模式现在不会再搞坏一切了；
*   挡位输入（用于扩展配置）在使用序列式换挡时不再显示空挡；
*   扩展物理新增输入 `GEAR_ALT`，序列式换挡时不会经过空挡；
*   新输入（例如罗盘、单圈时间），以及 `[DI_…]` 的全新格式化模式（已写入文档）；
