# 更新日志

## 新功能、选项与改进

*   Real Mirrors（真实后视镜）：
    *   新增 `Adjust FOV and squeese` 选项，改善掠射角度下后视镜的观感（默认启用）；
    *   新增用于正确后视镜投影的 `Accurate` 选项；
    *   新增一项调整，在禁用高质量后视镜时显示车手头盔护目镜片，默认启用；
*   OpenRGB 集成被新的 `RGB Control` 应用取代，可在 App Shelf 获取，拥有更丰富的自定义能力，以及用于分享预设的专属 Exchange 平台；
*   CSP 会在后续启动时尝试追踪没有任何报告的突发崩溃，并指出 Windows 生成的崩溃报告；
*   新菜单：
    *   Telemetry（遥测）标签页也得到了重做；
    *   Ctrl+Tab 可在标签页之间切换；
*   新增仅隐藏远程玩家维修站工作人员的选项；
*   GUI 新增一项调整，使用系统绑定时改为打开调校菜单而非会话详情；

## 修复

*   修复了 `Fully dynamic`（完全动态）维修站选项导致带车桥（axles）的车辆无法移动的问题；
*   修复了将涡轮、glance 之类绑定到十字键（D-pad）导致的崩溃（0.2.9 中的回退）；
*   修复了 CSP 预览生成；
*   修复了近期 AC 日志重写的问题，不再在输出长字符串时导致 AC 崩溃；
*   "完全隐藏维修站工作人员"选项现在可以在联机中生效；
*   修复了加载过程中偶发的死冻结；
*   若会话重启前车辆在维修站，Autopilot（自动驾驶）不再径直撞墙（总体而言，AI 传送后会再次根据最终位置切换激活的维修通道）；
*   缺少 soundbank 的车辆仍能检测相机是否位于车内（例如有助于风挡上的雨滴）；
*   新的 KN5 加载器又能正确报告缺失的 DLC 了；
*   修复了一堆在 127 辆车以上的服务器上高级联机功能的 bug，原因是 CSP 误将会话 ID 当作有符号数；
*   Extra FX：修复了 TAA 在草地（或其他颜色低于 0 的区域）表现异常的问题；
*   新树木：
    *   重新加载设置时会复用树定义，部分内容的缓存也更激进，修复了使用 Tree Planter 应用时的内存泄漏和性能问题；
    *   太阳阴影平滑了许多，自阴影减少；
    *   宽度超过 100% 的树木，其阴影和 billboard 应该更好看了；
    *   环境阴影小得多、更细微（大规模阴影请使用 VAO）；
*   新菜单：
    *   修复了按住 Alt 拖动镜像滑块（0.2.9 中的回退）；
    *   点击弹窗外部也能关闭欢迎消息；
    *   以 CSV 导出圈速可以正常工作了（之前生成的是空 CSV）；
    *   修复了按索引排序；
    *   投票冷却不再作用于 `kick` 投票，新菜单和 Lua 应用 API 均是如此；
*   Walking Out：
    *   未使用的车辆不再自动切换灯光；
    *   修复了用自由相机切换车辆时大灯范围异常的问题；
*   Smart Mirrors：
    *   MIP 不再不必要地同时生成多次；
    *   镜中镜现在使用立方体贴图来显示内容，而不是一片黑；
    *   若相机相对车辆移动过大，帧跳过会暂停；
*   Rain FX：
    *   雨滴命中效果随距离淡出；
    *   后视镜中的雨雾不再出现在车内（裁剪距离增加）；
    *   风挡 UV 生成复用工作线程，应该能稍稍加快生成速度；
*   按照 Weather FX 大灯建议切换大灯的 AI 又有一定的随机差异了；
*   手柄断开时 AC 不再刷屏 `DInput input lost:`；
*   IMGUI：字形图集中加入了符号 `≤` 和 `≥`；
*   `Skipping LOD A for other cars` 选项不再强制重新烘焙 Rain FX 遮挡；
*   Render Stats 应用：相对子区块（主图下方的那些横条）又有意义了；
*   未启用 LCS 时，镜面着色更贴近主场景；
*   修复了 HTTP2 之类日志消息的刷屏；
*   自定义车手模型不再需要 LOD B；
*   Android Auto：修复了计时器，点击整个状态块（而不只是图标）即可打开应用；
*   风挡反射着色器预加载，应能避免首次切换到车内相机时的卡顿；
*   修复了 CSP 向 CM 报告错误；

## 配置

*   新的车辆输入项：`AUTO_SHIFTING`、`MANUAL_SPEED_LIMITER`；
*   自发光着色器（如 `smGlass_emissive`）兼容 mask pass；
*   `surfaces.ini` 新增 `[_EXTENSION] FORCE_DOUBLESIDED_RAYCASTS=1`，允许赛道为未启用扩展物理的车辆启用双面光线检测（最近的修复搞坏了一些赛道）；
*   Custom AI：
    *   新的 `.v1` 车辆控制结构，可设置额外抓地力、稳定器和自定义 ABS 逻辑；
    *   新增用于启用或禁用输入平滑的字段；
    *   新增 `[DEV] DISABLE_AI_SMOOTH_STEERING`，为调试目的完全禁用 Kunos AI 的平滑；

## Lua & Python

*   通用：
    *   新字段：`ac.getCar().anyFlamesActive`、`ac.getSim().bestLapTimeMs`（全局最佳时间）、`ac.getSim().isMouseSteeringActive`、`ac.getSim().originShift`；
    *   新增 `math.simplex()`：比 `math.perlin()` 更好的替代；
    *   新增 `ac.areShapesColliding()`，可快速检测一对形状（几何体和车辆碰撞体）是否相交；
    *   新增 `ac.getUnreadChatMessages()`，获取未读聊天消息的数量；
    *   新增 `ac.getCarBlindSpot()`，返回盲区中最近车辆的距离；
    *   新的事件监听器 `ac.onLapCompleted()`、`ac.onTrackPhysicsObjectCarCollision()` 和 `ac.onCarColorChanged()`；
    *   `ac.areCarsColliding()` 函数已移入 Common API；
    *   `web.get`、`web.post` 等函数现在允许固定 HTTPS 证书或访问其指纹（与 Firefox 中的 SHA-256 指纹匹配）；
    *   加载远程资产的 `web.load…` 函数可设置请求头并固定 HTTPS 证书；
    *   `math.saturate()` 和 `math.clamp()`（以及 …N 版本）获得重大性能提升，`math.clamp()` 可处理一个限值为向量、另一个为数字的情况（旧 bug）；
    *   `table.same()` 函数在关联表含 `false` 值时不再出问题；
    *   向 `table.clone()` 传入 `'deep'` 作为第二个参数，即可同时复制向量与颜色；
    *   旧函数 `ac.store()` / `ac.load()` 经过重写，效率略有提升；
    *   `ac.setHighBeams()` 在绑定为按住模式时可用；
    *   修复了用 `ac.DriverTags()` 和 `ac.tagAsFriend()` 更新好友状态；
    *   `ac.getSunAngle()` 联机时更新；
    *   联机时配合 WeatherFX 条件或动态天气插件，`ac.getSim().timeMultipler` 不再为零（前提是时间确实在流动）；
*   UI：
    *   `ui.setNextItemIcon()` 可用于 `ui.beginMenu()`；
    *   集成标签栏：将窗口设置按钮纳入考量，下拉按钮样式更新；
    *   新增 `ui.beginPointSampler()` / `ui.endPointSampler()` 函数，将 IMGUI 着色器换成使用点采样的版本；
    *   `ui.keyboardButtonDown()` 支持侧边按键（如左 Ctrl）；
*   Scene API：
    *   光线检测现在将光线长度纳入考量（AABB 光线检测除外）；
    *   使用 NanoRT 加速的光线检测返回正确的局部位置、UV 等，加速结构在后台构建；
    *   移除正被 ExtraFX 自发光使用的节点不应再使 AC 崩溃；
*   Physics API：
    *   新增 `physics.setAIStopCounter()`，可让 AI 停车一段时间；
    *   `physics.RigidBody`：碰撞回调会返回车辆索引（若有）；
*   IO：
    *   `io.load()` 立即释放文件，例如可以在读取后将其删除；
    *   修复了 `io.recycle()`，现在真的会回收了；
    *   新增 `io.findFile()`，返回文件的绝对路径；
    *   后台和物理工作线程现在也支持相对与绝对路径（工作脚本目录仍与父级相同）；
    *   被 Lua Debug 应用保活的工作线程，现在也会立即释放其持有的东西（如事件订阅）；
    *   `os.runConsoleProcess()`：新增 `terminateWithScript = 'disposable'` 选项，可改为返回一个 `ac.Disposable`；此外，将其设为 `false` 并配合此前未记录在案的 `assignJob`，现在可以让进程在 AC 关闭后继续存活；
    *   `io.extractFromZipAsync()`：新增用于关键文件的额外参数，以确保完整解压（该文件会以不同名称最后解压、然后再重命名，因此你的代码只需检查该文件是否存在：只要文件存在，就说明压缩包已完整解压）；
*   `web.loadRemoteAssets()`：可指定关键文件名，类似 `io.extractFromZipAsync()`；拥有完整 I/O 权限的脚本不再受文件类型限制，另有若干修复；
*   Lua 应用：
    *   新增 `ac.restartApp()`；
    *   `ac.exportLapTimesToCSV()` 可用了，并新增可选参数用于指定文件名；
*   New Modes：使用 `[TWEAKS] HIDE_PITCREW` 可完全隐藏维修站工作人员；
*   `shared/sim/cars` 中新增用于获取并修改远程车辆基础车轮位置的函数；
*   `ac.onOpenMainMenu()` 现在可接收其他类型的页面，例如调用 `ac.tryToOpenRaceMenu()` 时；
*   Lua Debug 应用：
    *   查看 Lua 纹理时可使用点采样；
    *   应用现在会在脚本重载之间记住渲染向量时的所选设置；
*   部分函数与字段的文档已更新，sumneko 的 Lua 插件现在能正确理解 CSP `table.` 函数的类型；
*   LuaJIT 与上游同步（包含一些小修复）；
