# 更新日志

## 新功能、选项与改进

*   联机动态天气条件，可通过服务器插件（文档即将推出）或自定义 acServer 实现使用；
*   FSR：
    *   整个功能用官方发布的 SDK 重做：
        *   质量预设现已不同；
        *   现在使用推荐的锐化级别；
        *   可按推荐调整 MIP bias 的选项；
    *   三屏模式下可为左右两侧设置较低质量档位的选项；
*   烟雾彻底重做（轮胎发热与生成逻辑除外）：
    *   全新改进的着色；
    *   改进了烟雾与车辆的碰撞；
    *   更好地支持开放式车轮；
    *   极限漂移角度下，轮胎烟雾会在车底生成；
    *   灰尘与水花在整车周围生成，而不再只从车轮处生成；
    *   灰尘从布满灰尘的车轮上飞出；
    *   一些带木质滑板的 F1 车在滑板触地时会产生少量灰尘（可按碰撞体配置，类似火花）；
    *   碰撞时生成成团的灰尘；
    *   接触点会生成污垢碎屑与小型水花的更小粒子；
    *   长效烟雾与灰尘（可持续数分钟）；
    *   在草地上时，不再用灰尘团，而是使用更细腻的土壤颗粒（颜色在赛道配置中设置）；
    *   排气、过热刹车和受损发动机的烟雾有了新观感；
    *   烟雾不会再出现在座舱内部；
    *   彩色烟雾与灰尘随扩散失去饱和度，新增配置参数可调整速率；
    *   烟雾剔除改进，进一步优化且过渡更平滑；
    *   调整密度与屏幕上大小的新选项，在观感与性能之间取得平衡；
    *   烟雾覆盖整个屏幕的额外效果，以低得多的开销获得相机陷入烟雾的效果；
*   碎片粒子更新：
    *   调整了各类碎片的概率、尺寸与着色；
    *   碰撞检测现在使用车辆高度图而非深度缓冲，结果更准确；
*   修复了火花粒子的尺寸，正面碰撞时不再生成火花；
*   TyresFX：
    *   轮胎上的草与污垢重做，纹理与渲染都变了；
    *   会考虑土壤颜色；
*   GrassFX：
    *   启用 ExtraFX pass 的选项现在能正确支持车辆假阴影的重投影；
    *   草地形变已更新，现在会考虑草的高度；
*   全新渲染模式：360°、鱼眼、分屏（新 Content Manager 支持 AC 视频设置中的自定义模式）；
*   手柄输入模式下可指定手柄索引；
*   支持 VAO patches v5，为动态物体提供空间 AO 采样；
*   全新天空网格，三角形分布更均匀，反射与镜子效果更好；
*   隐藏控制台的选项；
*   为自由漫游服务器创建通往其他服务器传送门的选项；
*   新照片模式应用的场景调整在应用隐藏后于回放中仍然有效；
*   若 VR 初始化失败，加载画面上会出现警告（不小心选错渲染模式时尤其有用）；
*   烟雾、火焰、半透明物体等的半透明阴影借助 Bayer 抖动得到改进；

## 配置

*   在 `extension/data_override` 文件夹中创建新文件，即可覆盖与视觉相关的车辆数据文件，例如 `lods.ini` 或 `lights.ini`；
*   彩色阴影：整体观感改进，新增参数；
*   遮罩通道着色改进，深色纹理下不再那么乱，新增参数；
*   自定义车辆物理：
    *   可创建关联到某些 AC 物理控制器的隐藏调校项（例如创建离地高度随车速自适应的悬架）；
    *   可将离合器损伤与过高的扭矩关联；
*   自定义赛道物理：
    *   修复了软墙，新增 `MAX_DEPTH` 选项，限制过深碰撞的柔软程度（文档即将推出）；
    *   车辆生成时与赛道表面对齐（可选，由赛道物理配置 surfaces.ini 控制，使用自定义赛道物理时默认启用）；
*   面向深度碰撞（配合软碰撞体）的可形变赛道墙，用于轮胎墙等；
*   WeatherFX：
    *   用于创建和操控动态光源的 API，实现更高级的视觉效果；
    *   新增 `ac.setSkyV2SunSaturation(number)`，可调整太阳饱和度；
    *   调整 VAO 与额外 AO 采样参数的函数；
    *   全新的覆盖天空的云，使用全景纹理，作为另一种云的渲染方式；
    *   异步加载纹理的选项，以及卸载纹理的新函数；
    *   云材质新参数 `normalFacingExponent`，用于调整法线计算（默认值为 0.5）；
    *   云的新参数 `normalYExponent`，用于移动整个云的形状，让它看起来更像相机位于下方；
    *   云的新参数 `topFogBoost`，用于增强云顶部的雾；
*   TyresFX：
    *   新参数 `DIRT_OFFSET_K`，与 `DAMAGE_OFFSET_K` 类似；
    *   为不同轮胎设置自定义网格的选项；
*   `[MESH_SPLIT_...]`：
    *   直接设置拆分名称或材质，或使用现有材质；
    *   新模式 `COPY_FLIPPED`，修复缺失的车内车窗；
    *   新选项 `INSERT_TO`，为新网格指定新的父级；
*   参数 `[BOUNCED_LIGHT] AMBIENT_MULT=0.2`，用于减弱环境光对反弹光的影响（毕竟新版赛道 VAO patches 已带光反弹）；
*   面向未正确设置 `COCKPIT_HR` 的车辆的参数 `[REFLECTIONS_FX] INTERIOR_NODES=…` 现在效果更好，影响的 CSP 功能也更多；
*   可脚本化的显示屏现在可以引用脚本文件（`SCRIPT=script.lua`，与 LUT 相同）；
*   Lua 脚本可用的车辆状态新值：KERS 状态、挡位数、涡轮数、用户操控与特定车辆的 H 挡换挡器状态；
*   KERS 的新车辆仪表输入；
*   可调尾翼现在可以同时作用于多个节点（更容易处理 LOD）；
*   车漆着色器新参数 `ColoredBlackSpecular`，改善多彩涂装的观感，第四版自动启用；
*   赛道除污垢与草的颜色外，还可设置土壤颜色；
*   可为不同类型的表面设置土壤、污垢与草的颜色；
*   新的赛道输入：
    *   `CAR_DAMAGE_N` 表示第 N 辆车的损伤量；
    *   `CAR_DAMAGE` 表示所有车辆的最大损伤量（或许可以关联救护车的车顶灯？）；
    *   `ONLINE_RACE` 在联机比赛中切换为 1；
    *   `TIME_SMOOTH`：以秒计的一天时间，不做取整；
*   在条件表达式中，引用其他条件时不再需要写 `condition:` 前缀；
*   此前赛道参数只能取数字或引用条件的地方，现在也完整支持表达式；
*   赛道灯光与材质调整的 `CONDITION` 现在也可以使用表达式（不过暂不支持颜色）；
*   修复了参数 `MOVE_MESH_BEHIND` 与 `MOVE_MESH_IN_FRONT_OF` 无法在同一父级内重排元素的问题；
*   赛道配置现在可以设置火焰发射器；
*   修复了配置中与半透明阴影相关的更改不能实时生效的问题；
*   新的 `common/particles_track.ini`，包含一些粒子预设（篝火、火炉、照明弹）；
*   CSP 配置可以在加载画面上为车辆特性添加额外注释；
*   新的 Python 函数：`ac.ext_getWeatherTimeMult()`、`ac.ext_setWeatherTimeMult(value)`；
