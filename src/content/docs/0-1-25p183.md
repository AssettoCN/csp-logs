# 更新日志

## 新功能、选项与改进

*   Extra FX：
    *   细腻的雾气（以及远景，可选）模糊；
    *   体积感大灯；
    *   可为第一人称视角禁用某些特效或全部特效的选项；
*   远处自发光物体彻底重做，而且现在是可选的；
*   新烟雾：
    *   起步时烟雾更少；
    *   车轮抱死时的表现改进；
    *   在 VR 中可用；
*   全新的仪表输入系统；
*   自定义模拟仪表重做；
*   自定义自发光：
    *   自发光新增 `BLINK` 选项，用于闪烁的指示灯（关闭前会先完成一轮循环）；
    *   TC 介入指示灯现在会按应有的方式闪烁；
*   自由相机：按住右键的同时点击鼠标中键即可截图；
*   支持 setup.ini 中的自定义说明文字；
*   集成 AMD 的 FidelityFX CAS（对比度自适应锐化），适用于 CMAA2、自定义 FXAA 或 FXAA 3.11；
*   网格调整与着色器替换：
    *   新 `LAYER` 选项；
    *   新 `INCLUDE_IN_CUBEMAP` 选项（对 `LAYER` 更友好的包裹方式）；
*   扩展物理新增输入：左右车轮之间或前/后轴之间的转速差；
*   支持逻辑表达式的扩展过滤；
*   Weather FX：一些新函数；
*   各种修复；
