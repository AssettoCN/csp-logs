# 更新日志

## 新功能、选项与改进

*   ExtraFX 更新：
    *   SSLR：大量修复与调整，改进了低分辨率检测，新增质量档位，包括 Hi-Z 检测（开销大，但效果最好）；
    *   SSAO（实现不佳）已移除，等待进一步改进；
    *   SSGI 已彻底移除；
    *   取而代之的是全新的视角无关效果，让车辆把强烈的光反射到周围的地面；
    *   自发光网格可以向周围几何体投射光线（目前需要车辆或赛道配置）；
*   Brake Disc FX：
    *   使用轮辋轮廓，让反射与遮挡更准确；
    *   几处修复，改善与各种车辆的兼容性；
*   全新系统，可为赛道添加数十万棵树木与较矮的灌木：
    *   目前并非程序化生成，需要赛道作者以新格式提供树木模型（文档即将推出）；
    *   树木可以是 3D 的，也可以是 billboard；
    *   大量运用实例化及其他优化技术后，添加成百上千棵树也不成问题；
    *   完整支持 VAO 集成：新树木既能投射阴影，也能接受来自场景和其他树木的环境阴影；
*   原版 AC 热浪更新（可选）：
    *   考虑风速与温度；
    *   火焰与过热刹车时生成更多；
    *   可按车辆配置；
    *   赛道可为篝火等添加类似效果（已包含在 `particles_track.ini` 中）；
*   全新 AI 行为：可选的 rubberbanding（让前车变慢、后车变快）；
*   针对旧着色器的场景光照调整：现在日落时赛道应该更亮一些，观感更接近 PBR（由 WeatherFX 脚本设置）；
*   轮辋中的反射使用带阴影车轮模块做遮挡；
*   默认天气：光照改进，雾气调整；
*   阻止 Escape 键退出回放的选项；
*   提升加载速度的实验性选项；
*   改进了着色器加载（应该能减少微小卡顿）；
*   全新的暂停比赛控制按钮，兼容方向盘与手柄（未选择其他按键时默认使用 Start 按钮）；
*   支持 PS5 DualSense（光条、LED、触摸板，以及 Gamepad FX 的新 API，可访问加速度、陀螺仪并对扳机施加阻力）；
*   Control Tweaks 应用可以实时更改手柄按键（对 DualSense 控制器很有用）；
*   Car Mirrors Configurator 应用现在支持更精细的调整；
*   新的 CSP 应用现在会跨不同桌面保存位置与尺寸；
*   Real Mirrors：`VR lock` 选项现在与 `Alter FOV` 兼容；
*   为后视镜添加 MIP 以减少锯齿的选项（默认启用）；
*   Small Tweaks：随自由相机与环绕相机转动车手头部的选项；
*   一些联机反作弊保护；
*   改进了错误处理；

*   Android Auto：修复了广播应用；

*   Skidmarks FX 禁用时会正确卸载；
*   排气火焰现在的存活时间大多短得多；
*   几处自定义物理的修复，涉及 AI 与整体稳定性；
*   更好地支持自定义联机服务器；
*   AC 动态模糊现在与 FSR 的兼容性更好；
*   修复了网格拆分的崩溃；
*   修复了优化的反射渲染；
*   修复了比赛开始时与 Skidmarks FX 相关的轻微卡顿；
*   联机实时条件现在不会再因服务器给的值而破坏物理；
*   小型修复与改进；

## 配置

*   新的服务器选项：
    *   Mumble 链接，用于可选的自动连接（另外也可选择在退出 AC 时关闭 Mumble）；
    *   尾流效果倍率；
*   车辆配置现在还可以覆盖车辆音频源的位置与朝向；
*   车辆数据可以带有面向 CSP 的替代条目；
*   新 PBR 着色器的更新：UV1 缩放、将未缩放的 UV1 用作 UV2 的选项、micro shadow 与 AO fresnel，multilayer 版本行为与经典着色器一致；
*   WeatherFX：设置远处环境光偏移的选项；
*   车辆配置：晃动节点现在可以用单个节影响多个对象，对 LOD 尤其有用；
*   车辆涂装现在可以包含额外的 UV2 patches；
*   全新无头模式，只运行 AC 的物理部分，外加一些额外调整；
*   用环境变量覆盖文档中的 AC 数据文件夹名或比赛配置文件名（`race.ini`）；
*   Skidmarks FX：将胎痕导出为 OBJ 文件的选项；
*   赛道灯光新参数 `AABB_RANGE`，小幅提升性能；
*   车辆数据：覆盖 AI 的抓地力倍率；
*   用 `[SPLIT_MESHES_...]` 拆分的赛道网格现在可被选中；
*   修复了网格拆分等配置引发的一些崩溃；
*   车辆与赛道灯光若进行了相应配置，在 Extra FX 反弹光正常启用时可以被禁用；
*   CSP 也会在车辆数据中寻找车辆配置（`data/csp_config.ini`）；
*   `CAR_ACTIVE_…` 赛道条件与车库门现在在联机中正常工作；
*   Custom AI：可获取车轮是否在有效赛道表面上的数据，修复了传送方向；

## Lua & Python

*   修复了字符串拆分函数在分隔符长于单个字符时的问题；
*   可通过共享库使用 TTS；
*   全新的共享 UI 库，简化大型虚拟化列表的创建；
*   Lua 模式与联机脚本可以更改音频混响值；
*   Lua 应用：添加通知计数器、检查窗口是否折叠、控制鼠标位置、模拟点击与滚轮、实时更改时区与地理坐标；
*   物理 API（例如联机脚本可用）：限制 DRS 的使用、开关 DRS、禁用车辆碰撞，修复了更改车手名称的问题；
*   自定义物理脚本：更改终传比、更改涡轮或用自定义实现替换、访问动态控制器、创建自定义调校菜单项等；
*   标准库：加载并使用常规 LUT，可选三次插值；
*   扩展车辆状态：可访问挡位比与默认开发者 Wings 应用显示的值；
*   音频：用 FMOD 在 3D 空间播放常规文件（WAV、MP3、FLAC 等）（另外，现在启动音频事件无需等待音频引擎加载完成）；
*   刷新 `sim.isAdmin` 标志的状态；
*   修复了未设置 `LAZY = FULL` 选项时 Lua 应用被卸载的 bug；
*   联机服务器现在可以要求 Lua 脚本必须加载，若因故不可用则关闭 AC；
*   联机服务器可选的周期性实时刷新（客户端每 N 秒重新下载脚本，若脚本有变化则刷新状态）；
*   修复了实时更改车手名称的 API 函数；
*   修复了多个联机脚本同时绘制 HUD 时的崩溃；
*   修复了额外车辆音频源落后于车辆的 bug；
*   修复了 ERS/KERS 数值，另有新的共享库，可更方便地访问轮胎配置值；
*   从 INI 配置加载 LUT 现在也适用于 AC 打包数据；
