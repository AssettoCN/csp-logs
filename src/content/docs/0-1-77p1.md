# 更新日志

## 新功能、选项与改进

好久不见。这次更新引入了许多与 Lua 脚本相关的内容（Lua 应用、赛道脚本、由联机服务器下发以实现额外效果甚至新模式的脚本），所以我想先确保 API 足够完善。另外，雨天还没做出来，很抱歉，不过现在已经接近完成了。

*   FSR：
    *   整体改用官方发布的 SDK 重做：新的质量预设、调整过的锐化、根据文档建议调整的 MIP 偏置（旧实现仍保留，以防万一）；
    *   三屏模式下为屏幕左右两侧设置更低质量档位的选项；
    *   可选的调试模式：按住 Space 可快速切换到简单的线性放大以作对比；
*   烟雾重做（不含轮胎发热与生成逻辑）：
    *   新的改进着色；
    *   改进了车辆与烟雾的碰撞；
    *   更好地支持开放式车轮赛车；
    *   漂移角度大时，轮胎烟雾在车底生成；
    *   灰尘与水花从整车生成，而不再只从车轮；
    *   灰尘会从沾灰的车轮上飞出；
    *   带木质防滑垫的部分 F1 赛车在垫块触地时会出现一点灰尘（可按碰撞体配置，与火花类似）；
    *   碰撞时会生成灰尘团；
    *   接触点会生成更小的泥土碎屑粒子与更小的水花；
    *   长存的烟雾与灰尘（烟雾可持续数分钟）；
    *   在草地上时，改用更细腻的土壤粒子，而非灰尘团（颜色在赛道配置中设置）；
    *   排气、过热刹车与受损发动机的烟雾新外观；
    *   烟雾不会出现在座舱内部；
    *   彩色烟雾与灰尘在扩散时褪色，新增配置参数可调整速率；
    *   烟雾剔除改进，进一步优化并使过渡更平滑；
    *   调整密度与屏幕尺寸的新选项，在视觉质量与性能之间取得平衡；
    *   配合 ExtraFX，新增选项可让烟雾隐藏在玻璃后方；
    *   烟雾覆盖整个屏幕的额外效果（以很低的代价营造额外的烟熏观感）；
*   碎片粒子更新：
    *   调整了不同类型的出现概率，以及尺寸与着色；
    *   碰撞检测现在使用车辆高度图而非深度缓冲，结果更准确；
*   TyresFX：
    *   轮胎上的草与泥土重做，纹理与渲染皆是；
    *   会考虑土壤颜色；
*   GrassFX：
    *   激活的 ExtraFX 通道选项现在正确支持车辆 Fake Shadows 的重投影；
    *   草地形变更新，现在考虑草的高度；
    *   如果你使用原版 AC 运动模糊，它现在也会作用于草；
*   Smart Shadows：
    *   级联之间的平滑过渡重做，且现在可配置；
    *   移除了圆盘阴影过滤；在搞清楚正确做法之前，PCF 回归；
    *   来自烟雾、火焰、半透明物体等的半透明阴影通过 Bayer 抖动改进；
*   Nice Screenshots：
    *   旧的 HDR 修正方式现已替换为基于亮度的加权平均；处理起来容易得多，效果也更好；
    *   累积 DOF：自定义散景形状与采样分布的选项；

## 配置

*   自定义车辆物理：
    *   将隐藏的调校项链接到动态控制器（例如，可以创建离地高度随车速变化的悬架）；
    *   将离合器损伤与过高的扭矩关联；
    *   为任意悬架创建额外连接，将轮毂连在一起，或用固定/距离关节把轮毂装到车身；
    *   动态物理控制器的新输入：`DAMAGE_ENGINE`、`DAMAGE_GEARBOX`（0 为原版，1 为完全损坏）；
*   自定义赛道物理：
    *   修复了软墙，新增 `MAX_DEPTH` 选项限制过深碰撞的柔软度（文档即将推出）；
    *   车辆生成时与赛道表面对齐（可选，启用自定义赛道物理时默认开启）；
    *   用 CSP DLL 插件自定义赛道轮胎光线检测（例如用高度图而非三角形作为赛道几何）；
    *   各赛道文件的完整性检查（例如，可以简单确保重要的 KN5 在联机中未被更改）；
    *   允许 Lua 脚本操控物理对象的选项（不要用于竞技赛道，但对自定义内容或许是个不错的补充）；
*   车辆配置：
    *   TyresFX：
        *   新参数 `DIRT_OFFSET_K`，与 `DAMAGE_OFFSET_K` 类似；
        *   为不同轮胎设置自定义网格的选项；
        *   `[MESH_SPLIT_...]`：
            *   直接设置分割名称或材质，或使用现有材质；
            *   新模式 `COPY_FLIPPED`，修复缺失的内饰车窗；
            *   新 `INSERT_TO` 选项，为新网格指定新的父级；
    *   额外车辆开关（即 extra A/B/C/D 功能）：
        *   新增 extra E 与 extra F 开关；
        *   开关现在可以在配置中设置名称，加载时显示在车辆描述中；
        *   可选地，开关可工作在按住模式（按住按钮期间激活）；
        *   可选地，开关可要求车辆静止才能激活（例如布加迪威航的速度钥匙），或要求空挡，或踩下刹车；
        *   如果你用尾翼动画显示与隐藏附加部件，现在可以配置让 `hidden` 几何体真正隐藏，节省绘制调用：
            *   车辆灯光现在可以绑定到尾翼状态，引用尾翼 ID 并使用 LUT 作为亮度倍率；
            *   对于隐藏部件只是缩小或移远的简单双状态情形，CSP 应能自动识别；
            *   快速生成此类动画及相应配置的工具已发布在 CSP wiki；
    *   通过在 `extension/data_override` 文件夹中创建新文件，覆盖与视觉相关的车辆数据文件，例如 `lods.ini` 或 `lights.ini`；
    *   彩色阴影：整体观感改进，新增参数；
    *   车辆轮胎现在可以是半透明的，使用 `txNormal` 的 alpha 作为透明度，可用于贴纸逐渐褪色的附加层；
    *   新的车辆仪表输入：KERS、`TYRE_VIRTUAL_KM`、`FLAG_TYPE`；
    *   可调尾翼现在可以同时作用于多个节点（更容易适配 LOD）；
    *   配置可以在加载画面的车辆特性处添加额外注释；
