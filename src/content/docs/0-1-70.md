# 更新日志

## 新功能、选项与改进

*   改进的泊松盘阴影过滤现在默认启用，不再是可选项；
*   大幅重写了纹理在纹理槽间的排布方式，性能与稳定性应该略有提升；
*   折射大灯：移除多重采样选项，改为着色器内的时域抗锯齿（支持 VR 与三屏）；
*   赛车现在无论温度如何都会产生少许排气烟雾；
*   全新设置小节，包含音乐收听参数（用于导航仪和立体声音响）；
*   全新 UI：现在支持 CJK 字符（带后备字体）；
*   Extra FX：深度分析被暂时禁用，等我找到改进方法再说；
*   Particles FX：移除了带阴影的粒子选项（它只影响原版烟雾）；
*   联机火花又回来了；
*   开门灯投射阴影；
*   若未设置日期，现在默认使用原版太阳轨迹；
*   鼠标转向：AC 在后台时停用的选项，以及对原版 AC 代码的几处小修复；
*   强制油门（用于键盘操控）：可同时使用鼠标的选项，CM 更新即将推出；
*   Ghost 的折射现在是可选的，默认禁用；

## 修复

*   修复了 0.1.69 引入的两个重大性能问题；
*   修复了自由相机模式下灯光损坏的问题；
*   修复了烟雾在靠近相机时消失的问题；
*   新火焰现在应该可以在联机中工作了，对大多数触发条件有效（antilag 除外）；
*   修复了联机雨刮；
*   修复了所选 PP-filter 缺失时崩溃的问题；
*   修复了低太阳角度下自定义阴影矩阵的问题；
*   新照片应用：强制火焰现在对新火焰有效；
*   修复了车载音响的图标；
*   修复了将车辆 vertex AO 切换为无车手版本的问题；
*   修复了 PBR 反射失常、有时导致车窗不透明的问题；
*   修复了 VR 下的后处理折射；
*   修复了镜子中只有一辆车被正确渲染的问题；
*   其他一些修复与优化；

## 配置

*   车载音响现在可以获取音轨时长和当前进度，也可以显示进度条；
*   车辆网格拆分的新模式 `LOOK_AT`，可以分离朝向内部的网格（专为 Z4 设计）；
*   车辆输入 `ABS` 现在返回 ABS 模式的数值（0 表示禁用，与旧行为兼容）；
*   新输入：`ENGINE_MAP`、`FLAG_TYPE`（与赛道条件的 `FLAG_TYPE` 输入相同）；
*   车载音响与导航仪的格式化字符串现在支持后备值；
*   Object Inspector 应用中的纹理查看器现在可以显示 UV 线框；
*   修复了机油压力估算的默认参数，配置的更改现在可以实时生效了；
