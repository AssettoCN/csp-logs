# 更新日志

## 新功能、选项与改进

*   修复了雨刮的自动识别；
*   修复了 VR 与三屏下的降雨；
*   不会再有身上无雨的车辆（某些特殊情况可能仍需调整配置）；
*   雨滴现在不应该变黑了；
*   修复并更新了水洼生成，新增按赛道调整水洼的参数，以更好地考虑赛道排水的实际情况；
*   修复了基于地势的水洼调整；
*   折射大灯在 AMD GPU 上应该更好用了（不过仍需一些工作）；
*   修复了雨中的车牌；
*   雨刮现在不会再让雨滴穿透过去，能把风挡上的雨滴擦得更干净；
*   新增轮胎反射遮罩，湿胎不再在轮拱中反射天空；
*   反射中天空过亮的老问题终于修复了；
*   修复了自定义 Fake Shadows 的生成；
*   现代车辆的第四档雨刮速度回归；
*   一些底层修复，改善渲染的稳定性与性能；
