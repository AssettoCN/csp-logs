# 更新日志

## 新功能、选项与改进

*   新的 Particles FX 扩展：
    *   软粒子（目前仅在不开启 VR 且启用后处理时有效）；
    *   光照改进；
    *   接收阴影的选项；
    *   对粒子排序的选项，可部分修复绘制顺序问题；
*   Neck 扩展：
    *   锁定到地平线；
    *   鼠标中键平移，滚轮缩放；
    *   可用 Xbox 手柄右侧摇杆环视；
    *   后视镜中的车手模型也会同步；
    *   显示头盔的选项；
    *   重做了对 G 力的快速响应；
    *   参数已调整；
*   hen.ter 的让雨停下的修复；
*   物理扩展：正确的空气密度计算（适用于扩展车辆），作者 JPG_18；
*   感谢 leon_90，为老式赛车实现了精确的脉冲转速表模拟；
    *   用 Alt+R 复位提示灯（telltale），CM 中的绑定即将推出；
*   雨刮按钮支持循环切换；
*   调色（color grading）对截图生效；
*   修复了转向灯；
*   转向灯自动回位；
*   为提升性能而禁用树木光照的选项；
*   可针对每条赛道禁用树木光照的选项（适用于树木远离赛道、平时也照不到光的情况；`[LIGHTING] ENABLE_TREES_LIGHTING=0`）；
*   加载画面在顶部显示状态的选项；
*   加载画面状态水平偏移的选项；
*   修复了灯光轮廓的调试显示；
*   修复了湿滑赛道上的高光；
*   来自 [https://github.com/ac-custom-shaders-patch](https://github.com/ac-custom-shaders-patch) 的大量新配置；
