# 更新日志

## 新功能、选项与改进

*   修复了后视镜归一化；
*   修复了使用抖动 A2C 的树木（在镜子中以及使用圆盘阴影时）；
*   Neck FX 已修复，过弯时比以前更平滑，并带有自适应前视距离；
*   其他依赖 AI 线路的功能（track day、导航仪等）现在应该更快更好用了；
*   Weather FX：
    *   强制开启车头灯的选项现在可用；
    *   更多可见性固定的行星，以及 ISS；
*   Lua 脚本的新函数 `ac.getCameraFOV()`；
*   车手现在对所有 LOD 可见；
*   OpenVR 的自定义镜像新增选项：仅左眼，默认启用；
*   Grass FX：
    *   修复了与镜面高光的同步；
    *   新的局部镜面高光和一点反射，让草地更有光泽；
    *   修复了过陡山坡的过滤（这次真的能用了）；
*   车载相机在非环绕模式下现在也会忽略鼠标事件；
*   玻璃遮罩不再破坏 Ghost；
*   修复了模拟里程表在使用相同纹理的独立网格上不工作的 bug；
*   现在压缩的崩溃转储也会保存日志；
*   一些小修复；
