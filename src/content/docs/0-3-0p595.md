# 更新日志

*   Neural Rendering（神经渲染）：
    *   现在无需放大器也可工作；
    *   兼容 HDR 输出；
    *   设置移到了单独的分区（用游戏内应用可将 NR 移到放大器之前）；
    *   游戏内应用支持调整视觉效果，包括多 pass 与扩展边界；
    *   累积截图改进，现在 NR 改为在最后应用一次（可选，默认启用，可在截图设置中更改）；
*   修复了导致 NoHesi 服务器出问题的 bug，CSP 同步功能列表的能力更强；
*   动态模糊着色器更新，改善观感并解决几个问题；
*   BC7 后台压缩不应再造成卡顿；
*   修复了视频设置配置错误时放大器崩溃的问题（MIP LOD bias 永远没有必要设到低于 -5）；
*   View & Video 设置：眩光滑块最高可到 7（最高画质）；
*   放大器：新增调整 YEBIS 眩光的选项，补偿较低的渲染比例并防止过度闪烁；
*   新的像素密度放大器：Snapdragon GSR1（又好又快，默认启用）；
*   性能报告包含迟到帧的详细信息；
*   修复了纹理加载的小回退，它会导致远处额外锯齿；
*   三屏：时域放大在模块禁用、或"fit resized splits properly"禁用时也能工作；
*   Render Stats：卡顿分析器更新，现在会跟踪正在运行的脚本，保留最慢的 25 帧；
*   从 Lua 异步加载 KN5 更可靠；
*   自定义 TrackIR 实现带来几处小修复，默认启用，并有一个调整缩放以确保正确匹配的变体；
*   Neck FX 与 Track IR 相机运动兼容；
*   新增 `[DATA] DOOR_ANIMATION_CLOSE_SKIP` 参数，关门时可跳过一点车门动画；
*   Snapdragon GSR1 作为像素密度放大器兼容 HDR 输出；
*   LCS 下掠射角度的草地多一点光泽；
*   SSLR 的长高光兼容 LCS；
*   禁用烟雾（全部烟雾）不再导致雨天崩溃；
*   `shared/sim/weather`：新增 `.rainMmPerHourToIntensity()` 与 `.rainIntensityToMmPerHour()`（不过雨强下一步会重做，请不要依赖它）；
*   若从 Oculus 运行时启动 Assetto Corsa，Oculus 模式会自动启用（默认开启）；
*   VR 控制器可以在成绩画面上点击按钮。
