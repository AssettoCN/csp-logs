# 更新日志

## 新功能、选项与改进

*   修复了天气条件（Conditions）的问题；
*   修复了材质调整的问题；
*   新的线光源，用于霓虹灯之类的东西；
*   自定义车辆灯光：转向灯、倒挡、手刹、双闪；
*   车牌灯，支持自动推测；
*   车辆 KN5 扩展，与赛道的类似；
*   灯光会随损坏熄灭；
    *   仅当 lighting_fx.ini 中的 `DISABLE_BINDING_TO_EMISSIVE` 和 `DISABLE_CUSTOM_EMISSIVE_MANAGEMENT` 设为 0 时生效；
*   可更改虚拟后视镜位置；
*   考虑当前车辆与相机的动态虚拟后视镜位置，默认禁用；
*   针对满是灯光的赛道的一些 CPU 优化；
*   一些小修复；
