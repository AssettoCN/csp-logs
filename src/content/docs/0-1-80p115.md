# 更新日志

## 新功能、选项与改进

*   RainFX：修复了远处表面的问题，联机服务器中设置的静态雨强现在会被调整以保持兼容（基本上乘以 0.2），联机服务器可用 `[EXTRA_RULES] DISABLE_RAIN_PHYSICS=1` 禁用雨水物理，后视镜中可以看到雨滴；
*   物理：修复了定风翼的地面高度计算；
*   后视镜重投影的新选项：不再逐帧更新镜子，而是跳过一帧或几帧，并对之前的图像做重投影以保持平滑。应该有助于性能，不过确实会引入一些伪影（对手车辆和赛道可以相当准确地重投影，但烟雾或光照效果之类的会稍有延迟，不过在 60 FPS 下只跳过单帧或许还能接受）；
*   三屏下的 ExtraFX：TAA 现在可以工作，雨刮也不会再弄坏屏幕空间反射。另外为鱼眼和 360° 模式添加了 ExtraFX 支持，但目前有限（某些相机视角下效果不佳）；
*   Mobile Gamepad FX 脚本与应用已更新，改进了 Android 支持与更平滑的转向；
*   过热刹车冒烟现在应该能工作了（此前的发热值实在太低）；
*   其他一些较小的 bug 也已修复，例如未在 GUI 中开启控制器集成选项时十字键无法操作快速进站菜单，或 Lua 应用无法用 draw-text-aligned 函数绘制 TTF 文本。另外新树木现在也会出现在后视镜中；

目前正在验证 RainFX 物理，以确保平均雨水厚度与雨强的关系符合现实，另外我想提供一些关于最新设计变更的细节：
*   湿度与水分参数的逻辑已彻底改变，需要更新控制器，但旧控制器也能正常工作，CSP 会自动为较旧的控制器（使用 `ac.setConditionsSet()` 函数的那些）应用兼容选项。固定雨强的联机服务器此前有问题，现在也应该能用了；
*   更新之前，水洼的分布完全错误，导致滑水现象甚至不会发生（由于分布不均，车辆轮胎很快就能找到干燥得多的地方并停止打滑）。现在水层厚度分布均匀多了，车辆可能更容易失去抓地力并开始滑水，尤其是在没有雨胎或暴雨的情况下；
*   为了准确且可控，雨强现在按线性缩放，也可以高得多，旧的 50% 降雨（中雨）现在用 10% 即可达到，旧的 100%（勉强能开的大雨）现在只是 20%。再往上只留给真正极端的天气；
