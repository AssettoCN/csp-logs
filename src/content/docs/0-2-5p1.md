# 更新日志

## 新功能、选项与改进

*   用于越野物理的新 Surfaces FX 模块现在已在公开版中提供（如何准备车辆或赛道的文档即将推出）；
*   Quick Drive 新增 Rally Stage 模式；
*   App Shelf 上新的 Rally Copilot 应用，适用于拉力模式，或只是学习陌生赛道；
*   App Shelf 上新的 Dynamic Return 应用，用于打磨自选赛道分段的成绩；
*   新选项：
    *   单屏模式下为宽屏居中 UI；
    *   防止回放对车辆传送做插值（默认启用）；
    *   跨会话保存 Assetto Corsa 窗口的大小与位置；
    *   新的物理实验：其他生成点未正确设置时改用维修站位生成；
    *   回放虚拟内存分配的新优化；
    *   最后一圈显示白旗（可选隐藏 `leader on last lap` 消息）；
    *   激活回放时不再切换相机；
    *   新的 Behavior 类调整：阻止 AI 卡住时传送；
    *   在作者忘记翻转的上下坡赛道上自动翻转 AI 线；
    *   强制音频混响始终激活；
    *   隐藏缺失的车手模型而不使用默认模型（以防骨架兼容性问题）；
    *   临时调整：赛道物体过多时回放不再记录其状态，以节省显存；
*   Grass FX：
    *   新的风效实现；
    *   `fuPBR_…` 与 `ksMultilayer_objsp_nm4` 着色器与草地兼容；
    *   修复了相机旋转时屏幕边缘草地缺失的问题；
    *   与 LCS 兼容性更好；
*   Tyres FX：
    *   法线与颜色随磨损淡化；
    *   扩展物理激活时形变使用实际数据；
*   照片应用：
    *   重置曝光的按钮；
    *   缩放使用焦距单位的选项；
    *   删除已存点位现在会保存更改；
*   Triple Tweaks：
    *   处理侧边不齐的新方法，真正与场景吻合；
    *   为不同类型相机重新定义三屏行为的选项；
*   Android Auto：
    *   新的网页浏览器应用（取代车辆信息应用）；
    *   车辆可以添加额外应用（目前需要签名）；
    *   鼠标悬停在虚拟键盘上时可直接用实体键盘输入；
*   手刹联机同步（暂时只用一个比特）；
*   赛道表面类型检测改进，不再被大写字母干扰（改善 Surfaces FX）；
*   任务栏搜索对空格的处理更好（搜 `renderstats` 能找到 `Render Stats` 应用）；
*   CSP Debug 应用：显示最近三辆车的碰撞体，便于调查联机碰撞；
*   Chaser Camera：第一与第二相机可用不同脚本；
*   默认 WeatherFX 样式：眩光多了一点色差；
*   Walking Out：手柄控制、大量修复，主车辆现在可以传送；
*   CSP 会对照 `data_manifest.ini` 校验自身版本号，尝试检测损坏的安装；
*   服务器可发送特定封包，显式更新玩家的管理员状态；
*   缺少 `driver_base_pos.knh` 不再导致崩溃；
*   Rain FX 赛车线受不同类型轮胎的影响不同（目前只是很粗略的估计）；
*   CSP 生成的车辆预览现在更锐利；
*   New Modes 可以禁用黄旗与蓝旗，Track Day 模式下同样禁用；
*   隐藏的配置行，用于指定联机聊天改色影响的纹理列表；

## 配置

*   车辆动画挡泥板；
*   旗帜着色器的新修饰器，可用作帐篷顶（随风晃动、被雨浸湿）；

*   赛道配置新参数 `[PITSTOP_CAMERA] THETA=, PHI=, RADIUS=, FOV=`，更改换胎动画所用相机；
*   赛道配置新参数 `[START_CAMERA] BLOCK_TRAJECTORIES=, POSITION_OFFSET=`，更改起步相机；

*   `ksWindscreen`：新参数 `alphaGamma`，快速调整透明度；

*   赛道正确加载尘土、灰尘与草地颜色（存在分节时通用配置失效），且 `[TYRES_FX]` 节缺失时改从 `[DIRT]` 节加载颜色；
