# 更新日志

## 新功能、选项与改进

*   新火焰（默认禁用，可能还需要更多调整）；
*   新的任务栏外观（可选）；
*   更新的火花：重做了碰撞检测，改进了整体观感与动态光照；
*   慢动作中的音频音调变化（可选）；
*   Freer Camera：慢动作现在可配置；
*   车辆配置现在也能更改音频音调与音频事件参数；
*   通过车辆配置可调整更多音频事件：碰撞、刮擦、车轮与打滑；
*   新照片应用的 Motion 模式，简化长曝光照片的创建；
*   按 Escape 取消累积拍照；
*   选项，为累积拍照禁用闪光；
*   通过数字面板设置的比赛中位置在回放中现在能正确工作；
*   Weather FX：现在可在离线模式下影响物理条件，新函数 `ac.setPpColorGradingIntensity()`；
*   Lua 与 Python 脚本：用于存储和加载数据以交换的函数；
*   新烟雾：VR 下使用降采样的独立选项，默认禁用，最好不要启用；
*   前大灯高质量阴影选项（消除大部分伪影，但开销可能相当大）；
*   修复了调整 FPS 限制器以改善流畅度的选项，现在可正常工作；
*   植被着色暂时回退（局部增强已禁用）；
*   新的 `ksMultilayer_objsp_nm4` 着色器；
*   风挡着色器的新参数 `bannerMode`，现在可取大于 1 的值以模糊饰带后方的内容；
*   各种修复与一些小幅性能改进；
