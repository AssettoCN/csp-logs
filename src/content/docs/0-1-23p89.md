# 更新日志

## 新功能、选项与改进

*   基于网格名称的正规雨刮同步（感谢 hen.ter）；
*   截图已修复（🙏）；
*   带阴影车轮的新选项，适用于 Caterham 及其他类似车辆；
*   修复了动态光源（部分回放相机没有渲染它们）；
*   AC 修复：修复了低 FOV 回放相机的深度冲突；
*   扩展物理新选项：额外的光线检测（不会影响任何现有车辆）；
*   加载画面会在 extension/backgrounds 中查找车辆图片，Spa/Spa 1966 的问题应该已解决；
*   颜色分级：支持 sRGB PNG；
*   在反射中渲染灯光的选项（会毁掉 FPS，至少目前如此）；
*   虚假阴影的不透明度参数现在会被考虑；
*   修复了模拟里程表在 INI 文件更新时偶尔失效的问题；
*   刹车痕着色器回退到原版；
*   禁用年份后缀的选项（在 `general.ini` 中）；
