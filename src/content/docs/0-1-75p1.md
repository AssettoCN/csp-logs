# 更新日志

## 新功能、选项与改进

*   双精度物理引擎，改善大型赛道上的物理与 FFB（现在联机也可用）；
*   Graphics Adjustments 新增 Origin Shift 功能，修复大型赛道上的画面抖动；
*   高级剔除大规模重写以提升性能；
*   DXGI Tweaks 新增几个选项（与 flip model 无关）：
    *   根据 AC 视频设置中选择的屏幕使用对应 GPU；
    *   真正的无边框模式；
    *   三重缓冲与自定义最大帧延迟；
*   赛道 SIMD 加速可见性剔除的选项；
*   AC 最小化或处于后台时禁用音频的选项；
*   Smart Mirror：覆盖镜子渲染距离的选项；
*   雷达应用：颜色设置，外观更新；
*   得益于新的内置加载性能分析器，加载的流畅度与信息量大幅提升；
*   加载现在应该更快，还可通过缓存进一步提速（默认启用）；
*   通过动态可调的伽马修复了 VAO 偏暗的问题；
*   崩溃消息重做，现在带额外的检查与提示；
*   崩溃报告包含 CSP 设置预设；
*   声速会考虑温度等因素；
*   GUI：油门与刹车踏板同时踩下的可选警告；
*   联机自定义颜色现在可跨会话保存；
*   自适应近裁剪面的选项，改善相机远离车辆与赛道时的观感；
*   传送目的地列表更紧凑，支持分组并可过滤点；
*   后处理折射改进；
*   破碎玻璃着色器再次重做；
*   未正确录制 AI 线的赛道上与 AI 相关的崩溃应该已修复（AI 以前只会傻站在那）；
*   联机：管理员现在可以手动执行处罚（需要服务器要求 1476 号或更新版本的 CSP）；
*   现在使用车辆高度图判断自由相机是否在车内；
*   其他车辆从后方照亮你的车时，现在会从后视镜产生额外的光；
*   车手头部的新着色器（目前仅非蒙皮版本），观感更动态；
*   车门动画与举牌维修站人员会随 AC 一起暂停；
*   赛道可通过配置设置假环境阴影，为那些静止车辆下方添加一些暗部；
*   新的 VR Tweaks 模块：
    *   VR 镜像（从 Graphics Adjustments 移来）；
    *   新的 VR 镜像模式：仅显示右眼、显示双眼且不带畸变；
    *   VR 中 HUD 定位的各种选项；
    *   调整 VR 双眼间距的选项，以防万一；
*   AI Flood（又称 Track Mode）：
    *   生成流程重做，更快也更高效；
    *   支持双向交通地图；
    *   修复了车辆卡住的问题；
    *   增加行为多样性的新选项；
*   倾斜表面 mip 偏置的新选项（看来仅靠各向异性过滤还不够照管那些远处的道路）；
*   新火焰现在会产生一点火花；
*   Walking Out 模块已更新，现在允许切换车辆，但仍有待完善（现在附带配置，可手动激活）；
*   同时附带 Triple Custom 模块的手动激活配置，可在三屏模式下完全重新配置相机；
*   新模块 `New Modes`，允许创建由脚本驱动的新驾驶模式（仍在开发中）；
*   Track Day 模式下不再显示会话状态消息；
*   几项小优化；

## 配置

*   TyresFX：在配置中为特定轮胎类型指定轮胎花纹；
*   影响所有车辆与赛道的新通用配置；
*   车辆扩展物理：
    *   联机使用真实质量以改善重型车辆的碰撞；
    *   重新定义碰撞参数的选项；
*   赛道扩展物理：
    *   联机为车辆使用真实质量的选项；
    *   为不同表面重新定义碰撞参数的选项；
    *   在表面与车辆网格碰撞体之间使用刚性碰撞的选项，尽量避免极端情况下车辆穿落地面；
*   用于高级轮胎碰撞检测的扩展光线追踪使用更少的采样以提速；
*   INIpp：include 现在可以是可选的，文件名支持表达式，还有访问与修改已解析内容的新函数；
*   车辆与赛道配置的 `read()` 新输入；
*   赛道灯光新参数 `SHOW_IN_REFLECTIONS`（请谨慎使用，默认只包含范围超过 10 米的灯光以提速）；
*   新过滤关键字：节点的 `insideWheel`、`insideSuspension`，材质的 `driverPiece`、`isTextureDefault:<texture name>`；
*   车灯：远光与近光的色调；
*   车灯与自定义自发光：分别设置点亮与熄灭延迟、自定义加热颜色及其他参数；
*   现在设置 `set observeDigital 1` 不应再使 AC 崩溃；
*   车辆调试应用现在显示风扇气动力；
*   旗帜可选更高曲面细分率，曲面细分也会应用到阴影；
*   新的半透明阴影模式：NORMALS，考虑表面以在掠射角衰减阳光，非常适合弯曲玻璃；
*   CSP 会较晚渲染车窗网格以保证正确观感：此类网格的过滤器现在可以更改，以包含自定义横幅之类的东西；
*   Objects Inspector 应用：
    *   选择蒙皮网格；
    *   现在也会显示点击点处的表面法线；
    *   简化为赛道创建假环境阴影的额外工具（未选中任何东西时点击 `…` 按钮）；
*   闪烁模式：新参数 `BLINKING_OFFSET`（秒），可为循环指定起始偏移；
*   赛道配置参数 `[WIND] IGNORE=…` 现在也影响旗帜，禁用新动画与曲面细分；
*   赛道配置新参数 `[WEATHER_FX] SKY_BELOW_HORIZON=…`，可指定天空网格延伸到地平线以下多远（1 为完全覆盖）；
*   新赛道材质 `[Material_Bale]`；
*   光弹性 PBR 玻璃现在也支持多自发光；

## Lua & Python

*   修复了 Python 函数 `ac.ext_loadIniFileAsJson()`，`ac.ext_parseIniFileToJson()` 更名为 `ac.ext_parseIniAsJson()`（旧名称出于兼容仍可用）；
*   新的 Python 与 Lua 函数：获取赛道坐标、时区，以及检查 WeatherFX 是否处于活动状态；
*   新 Lua 函数：`ac.getSoundSpeedMs()` 获取精确声速，`ac.getAudioVolume('key')` 获取音量等级；
*   Lua 函数的新通用能力：几乎零开销地访问预先准备好的结构，包含车辆状态等（目前供新模式脚本使用）；
*   新 WeatherFX Lua 函数：`ac.setVAOExponent(gamma)`，用于设置顶点 AO 的伽马；
*   Lua 音频事件新增音高参数；
*   Lua Debug 应用更新：存储值与调试值可复制，错误消息中的文件可点击（受支持的编辑器会打开文件并定位到正确行）；
*   标准 Lua 库现在以字节码形式分发，以优化加载；
