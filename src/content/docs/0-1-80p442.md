# 更新日志

## 新功能、选项与改进

*   修复了湿润路面看起来发红发绿的问题（调试视图不知怎么又在重建过程中漏出来了，得让这些东西更牢靠些）；
*   修复了自定义物理轮胎落地时偶尔朝错误方向空转的小问题；
*   新自定义物理调校项的新参数：UNITS 与 DISPLAY_MULTIPLIER；
*   WeatherFX 的联机服务器天气选择器现在可用了（p428 中损坏，好在那个系统只影响画面）；
*   Autopilot 应该更好用了，释放时也能在更大程度上将车辆恢复原状（另外，服务器现在可通过扩展配置中的 `[EXTRA_RULES] ALLOW_AI` 允许新 AI）；
*   修复了 Lua 计时器导致 Controller Tweaks 无法实时应用更改的问题；
*   手柄按键再次可以绑定到额外的 CSP 功能（如离合器）；
*   Chaser Camera：车辆状态中的车辆变换不再滞后一帧；
*   雨天 AI 线路在环形赛道的起步线附近不再出错；
*   Lua：远程图像与网络请求加载应该更快，不再有 p428 引入的队列两秒延迟；
*   NeckFX 头盔暂时在 VR 中禁用，直到找到不烦人的移动方式；
*   Android Auto 中 YouTube 的几处修复；
*   CM 检测到的 AC 关闭时的罕见崩溃应该已修复；
*   一些较小的稳定性改进与针对特定崩溃的修复（比如 Objects Inspector 里的那个）；
*   DualSense、DualShock 与 GamepadFX 整套东西的多处修复，现在连接那些你开赛前忘记碰一下的手柄应该可靠得多，鼠标移动处理也更好，等等；
*   另外，Setup Exchange 后端已修复、优化并迁移到新服务器，速度应该明显更快；
