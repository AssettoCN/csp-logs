# 更新日志

## 新功能、选项与改进

*   VR：
    *   集成 OpenXR，附带可选调整（独立 HUD 层、手部与眼部追踪、透视画面）；
    *   外圈 VRS 半径被完全忽略，因此使用 `Align with eyes` 选项后，外围区域的渲染不再停止；
    *   可自定义 VRS 速率与区域；
    *   新的 VRS 超采样选项；
*   杂项：
    *   LCS 下的烟雾观感更好；
    *   照片应用：新增始终显示网格的选项，并加入黄金比例网格；
    *   新的 DDS 加载器，支持老式纹理（调色板、L8、LA88 等），速度稍快；
    *   默认 Weather FX：调整了大雨时远处的雾；
    *   FSR 3/4 已更新，现在使用 FSR 加载器 DLL 来改善兼容性；
*   不再崩溃：
    *   AC 配置中的畸形向量值（例如 `CHROMATIC_ABERRATION/LATERAL_DISPERSION` 缺少第二个数值）导致的崩溃；
    *   在 Wine 上于 UTF-8 与 UTF-16 之间转换畸形字符串时的崩溃；
    *   缺少 `DRIVER:RIG_Clave_R` 之类条目的车手模型导致的崩溃；
    *   内存不足以渲染折射大灯时（改为直接跳过大灯）；
    *   处理 Python 错误时；
    *   在极低分辨率下使用 Extra FX 时；
    *   车辆物理脚本阻塞一切时，例如为了显示一条消息；
    *   新的媒体追踪功能导致的崩溃；
    *   XeSS 或 FSR DLL 加载失败时；
    *   为没有车轮的车辆创建幽灵时；
    *   脚本与 worker 之间来回传递大量数据导致的崩溃；
    *   `race.ini` 中缺少 `[LIGHTING]` 分区时；
    *   加载分析器与 Python 应用相关的崩溃；
    *   AI 车辆试图使用畸形样条线时；
    *   车辆数据曲线缺失或为空时；
    *   文件读写中途失败时；
    *   保存聊天中分享的调校时；
    *   尝试加载损坏的加密模型时；
    *   三屏侧边宽度为零、Weather FX 样式使用云遮罩、且额外的车载相机被激活时（三者同时发生）；
*   Rain FX：
    *   雨滴与挡风玻璃上的雨滴：数量经过调整；
    *   雨滴视觉的几处小调整；
    *   关闭 Extra FX 时，挡风玻璃横幅在雨中不再显得乱糟糟；

## 修复

*   碰撞产生的尘土粒子数量有所调低，以避免性能问题；
*   修复了 `fuPBR` 材质，新增 `PerceptualRoughness` 选项（如果材质显得昏暗，将其设为 1）；
*   在禁用 TAA 与 Extra FX 的情况下，Neural Rendering 可与旧放大器一起工作；
*   为截图创建缓冲区失败或类似失败，不再让 Neural Rendering 在整个会话中停止工作；
*   修复了远程车辆使用原版外推时抖动的问题；
*   `Compress generated missing MIPs` 选项已改进，现在带缓存，并支持特殊尺寸的纹理；
*   半透明挡风玻璃横幅及其他半透明材质与 Single Pass Stereo 兼容；
*   比赛暂停时，Xbox impulse triggers 扳机震动不再触发；
*   修复了 `Final lap tweak`：白旗不再在整个比赛期间一直挂着；
*   领跑者完成自己的圈数后，或计时赛时间耗尽后，绿旗会收起；
*   猜测后视相机位置的默认规则从 `below the driver's eyes` 改为 `5 cm or more below the driver's eyes`，修复了一些 mod 的问题；
*   回放界面中更改光线方向可与 Weather FX 一起工作；
*   CSP 刹车盘不再错误处理小幅视觉调整；
*   新的 PNG 加载器在加载过程中不应占用过多内存；
*   车身音频的方位感更清晰了一点；
*   禁用赛道相机抖动不再破坏沿样条线移动的相机；
*   修复了几个无法正确加载的纹理；
*   New menu（新菜单）：初始尾流量不为 100% 时，尾流滑块不再出问题；
*   扩展车辆物理：
    *   `TYPE_HINT=WET` 是雨胎的别名（之前预期的值是 `RAIN`）；
    *   修复了 `[SPEED_LIMITER]` 的单位，现在真的是 km/h；
    *   在 `tyres.ini` 中加入 `[_EXTENSION] GENERATE_EXTRA_TYRES=0` 可禁止 CSP 生成任何额外的轮胎；
*   配置：
    *   CSP 配置中赛道相机新增 `MAX_DISTANCE`，让相机在远离玩家时仍能工作（默认 400 m）；
    *   `general.ini` 中隐藏的 `[FMOD]` 分区，供高级折腾使用；

## Lua

*   新增 `ac.overrideTyreIgnitionPoint()`；
*   新增 `os.listAudioDevicesAsync()` 与 `os.openAudioOutput()`；
*   `ui.endTextureShade()` 在调用不匹配时会抛出异常，而不再把 Assetto Corsa 整个带崩；
*   为加载画面脚本新增函数：`loading.hold()`、`loading.ready()`、`loading.proceed()`；
*   修复了 Lua 文档中的错漏。
