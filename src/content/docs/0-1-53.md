# 更新日志

## 新功能、选项与改进

*   FFB Tweaks：新的范围压缩选项；
*   烟花：更多节日，包括地区性节日（基于赛道而非系统设置），脚本已更新；
*   赛道显示屏可显示附近自定义相机的画面；
*   主车辆与赛道的皮肤纹理自动重载（针对 `skins/default` 中的纹理）；
    *   来自 Custom Showroom 的 `.psd` 功能也可用，但需要安装 PSD 编解码器；
*   修复了其他车辆折射大灯看起来发黑的问题；
*   修复了 Real Mirrors 在 Audi R18 或 VRC Formula Lithium 2019 等少数车辆上失效的问题；
*   新的 CPU 优化，针对大型赛道将世界分块，并移除远处块中的网格；
*   Graphic Adjustments 中新增赛道 LOD 缩放；
*   SSLR：修复了光线追踪并调整了画质档位；
*   刹车痕与 Fake shadows 在 SSLR 下工作得更好（若下方表面带反射）；
*   新的 Skidmarks FX 扩展：刹车痕更不规则，边缘更平滑，并会缓慢淡出；
*   面向几何树木的新着色器 `ksTree_ppshadows`（行为与 `ksPerPixelAT` 很像，但支持风与可选的 A2C 抖动）；
*   可选的 A2C 抖动现在也适用于 `ksGrass`；
*   修复了轮胎扩展光线追踪（扩展物理的那个功能）在倾角下表现异常的问题；
*   额外车辆动画：新的 LUT 选项，可添加循环之间的暂停之类的东西；
*   自定义自发光新增几个选项；
*   Weather FX 的更好月亮纹理；
*   摆动雨刮现在默认仅对 Kunos 车辆启用；
*   若干小修复与优化；
