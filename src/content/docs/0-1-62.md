# 更新日志

这个版本还没有雨，仍在开发中。不过，有一些其他新东西：

## 新功能、选项与改进

*   动态阴影；
*   HDR 支持（需要 DXGI flip model，很可能还需要调整过的 PP 滤镜）；
    *   现在 PP 滤镜可以有两套色调映射选项，分别用于 LDR 与 HDR 模式；
*   GUI：
    *   对原版 UI 应用 MSAA 的选项（如果有应用在画带锯齿的图形，这应该有帮助）；
    *   新的车手标签可在 VR 与后视镜中工作（显示蓝旗与黄旗）；
    *   注重性能的新的简易雷达应用；
*   控制器：
    *   快速切换至空挡的新绑定；
    *   键盘输入方式的新离合器绑定；
    *   修正设备顺序的选项，同时考虑实例 GUID（再次说明，支持这些的 Content Manager 更新即将推出）；
*   Content Manager 支持 CSP 专用服务器（其更新即将推出）；
*   常规太阳阴影稍作优化：
    *   新的更快的渲染遍历；
    *   第三级阴影级联中不再有车辆；
    *   远程车辆使用 LOD D 网格单次绘制调用（若无 LOD D 则回退到碰撞体网格）；
*   Smart Mirror：老车在高速下可选的轻微抖动；
*   平滑粒子在 VR 与三屏下无论有无 MSAA 都可工作（但仍需要后处理）；
*   新玻璃着色器的更简单的折射，可在单屏、VR 与三屏下工作（需要后处理），适合平坦或过于不平的玻璃，设置也容易得多；
*   Fake Shadows FX：考虑动态光源（与动态阴影配合良好），另修复了因假阴影导致霓虹灯不能正常工作的问题；
*   Weather FX：
    *   更锐利、更高质量星星的选项（锐化与采样方式调整）；
    *   提高云保真度的选项；
    *   极热天气下海市蜃楼式反射的选项；
*   Extra FX：
    *   动态模糊在 TAA 之后应用；
    *   雾模糊在 TAA 之后、动态模糊之前应用；
    *   雾模糊的新热扭曲选项（与 Weather FX 的海市蜃楼式反射结合，两者都考虑快速移动的车辆）；
    *   一些优化；
*   雨刮模式重做：现代车有三种模式（间歇、慢速与快速），非常老的车只有单一模式，可重新定义；
*   雨刮联机同步；
*   Stereo 制作的新的 FFB 调整，为麦弗逊式悬架更准确地计算 FFB（仅应用于少数具有特定不常见配置的车，不影响 Kunos 车辆）；
*   照片应用的新选项，强制开启火焰；
*   破碎玻璃着色器重做，现在带一点折射与自定义参数；
*   优化的绘制顺序与缓存生成网格及有效载荷现在默认启用，默认灯光亮度改为 100%；
*   新的小调整：在 VR 第一人称视角下为带 H 挡的车彻底隐藏车手模型（但在后视镜中仍会显示）；
*   导航仪支持 Spotify 桌面播放器（还有新的车载音响，去看看 Abarth 500）；

## 修复

*   修复了扩展物理有时导致物理线程异常并崩溃到棕色/粉色屏幕的问题；
*   扩展物理的实时重载导致各种崩溃或不应用任何更改的问题应该已修复；
*   区块优化现在正常工作了（之前始终被禁用）；
*   Tyres FX：自定义纹理现在可以在镜中工作了；
*   Fake Shadows FX：修复了雾背光的问题；
*   Windscreen FX 的雨滴（旧版）在雨刮状态改变时不应再跳动了；
*   VHS 滤镜可用于截图，另外，字体现在随 CSP 一起附带；
*   Nice Screenshots 在纵向比例与不兼容效果同时存在时不应再使用旋转，另可彻底关闭旋转的选项；
*   火花联机暂时禁用，需要更多测试；
*   灯光处理重写，在有数千盏灯的赛道上提速，并修复了相机长距离跳转时灯光缓慢点亮的问题；
*   现在回放等场合最多可有 12 辆车的大灯被镜像，而非之前的 4 辆（那看起来太糟了）；
*   修复了赛道上的模拟时钟；
*   新聊天应用：支持 Latin Extended 与 Currency 字符集的符号，登录失败后可以重试，更改颜色可以取消；
*   赛道体积光现在可以更宽，但那会让它们更短；
*   除非新的照片模式应用处于激活状态，环绕（F5）相机现在不会失焦；
*   修复了玻璃背光错乱的问题；
*   修复了极端设置下的天空伪影；
*   修复了轮胎的地面遮蔽；
*   修复了后视镜中的折射大灯；
*   Weather FX：默认脚本不再弄乱太阳光束；
*   一些小修复与优化；

## 配置

*   用于车内的新的毛绒材质（用得太频繁可能开销有点大）；
*   车辆的新车载音响，显示当前艺术家与曲目及来源图标，或时间，或一些简单动画；
*   新的节点、网格与材质过滤属性（用于制作车辆与赛道配置）；
*   `[SHADER_REPLACEMENT_…]` 的新 `MOVE_MESH_IN_FRONT_OF` 选项；
*   车辆灯光的新 `FADE_FAKE_SHADOW` 选项：为霓虹灯设为 0.8 之类，可降低灯光开启时假阴影的不透明度；
*   新的 `[SMOOTH_NORMALS_…]` 调整，平滑特定网格的法线（对部分 Kunos 赛道很有用）；
*   车辆的新弯曲着色器，带可选细分，用于：
    *   雨刮弯曲以贴合风挡曲率、减少缝隙：`[BENDING_WIPER_…]`；
    *   侧网（部分赛车上侧窗旁的）抖动：`[SIDE_NET_…]`；也可用于天线之类；
    *   无需重排节点的排气抖动：`[SHAKING_EXHAUST_…]`；
    *   类似 wobbly bits 的摇摆网格，但无需蒙皮：`[WOBBLY_MESH_…]`；
    *   请注意：整套东西相当原始，只是基于与特定区域的接近程度添加一定偏移，不含任何旋转；
*   赛道的新条件动画器，基于条件移动、旋转与缩放；
*   赛道显示屏：使用实际赛道相机的选项，使用 Office 式占位内容的选项；
*   对象检查器：局部与车内坐标、场景节点树；
*   彩色 vertex AO 不再受支持，加载时转换为普通版本；
*   为车辆设置自定义雨刮模式：指定速度与运行间隔；
*   选择模式或查询模式数量的新 Python 函数（旧函数仍可使用）；
*   新的雨刮相关车辆输入：`WIPERS_MODE` 与 `WIPERS_PROGRESS`（用于动画进度）；
*   不含双闪的转向灯新车辆输入：`TURNSIGNAL_NOHAZARD_LEFT`、`TURNSIGNAL_NOHAZARD_RIGHT`、`TURNSIGNAL_NOHAZARD`；
*   在赛道配置中调整 Extra FX 反弹光强度；
*   赛道灯光的新 `DISABLE_WITH_BOUNCED_LIGHT` 选项：若将灯光设为类似假环境光，请使用它；
*   车辆的新 `EXTRA_FX/DELAYED_RENDER_INTERIOR` 选项，列出在第一人称视角下应在 Extra FX 之后才渲染的网格；
*   现在 `[SHADER_REPLACEMENT_…]` 的 `INCLUDE_IN_CUBEMAP` 选项不会干扰世界细节等级；
*   着色器 `ksMultilayer_fresnel_nm` 的法线贴图现在使用平铺修复与各向异性过滤；
*   PBR 着色器的遮蔽行为已调整，与带反弹光的新 OptiX 烘焙器更好地配合；
*   Grass FX：自定义纹理更平滑的遮罩，分隔上色与不上色区域；
*   用 `[HEATING_SURFACES] MESHES = …` 和 `MATERIALS = …` 设置热扭曲与海市蜃楼效果的发热区域列表（否则 CSP 会尝试猜测）；
*   扩展物理新增强件：限速器（固定且静态，为卡车竞赛设计）；
