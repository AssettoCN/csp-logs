# 更新日志

## 新功能、选项与改进

*   新增指示灯：刹车、电瓶、轮胎、转向灯（左右灯共用一个指示灯）；
*   急刹车触发双闪（见 Gallardo 的配置中的 `HAZARDS_G_THRESHOLD`）；
*   Ferrari F40 的完整配置；
*   感谢 Just Kauser 提供的额外仪表盘指示灯与里程表；
*   各类 bug 修复；
*   修复了自定义自发光管理；
*   修复了灯光绑定到自发光的问题（例如维修区灯光的情况）；
*   里程表：最大值（`UPPER_BOUND`，模拟表可优雅地回绕到 0，数字表则停在 999…），数字表的格式选项（见 Transit 的配置，`DIGITAL_ITEM_NUMBER_FORMAT`），从 Sidekick 数据库加载数值；
*   Python 函数，可将车辆重置回赛道或后退 300 米（仅限离线单车会话，会使单圈成绩无效）；
*   可隐藏逆行指示器与重置提示的选项（离线，track day 或练习会话中，可选）；
*   Track Day 改进（可选）：AI 洪流功能让赛道更热闹，如有街道胎则强制机器人使用（优先级列表可配置）。与交通 mod 的兼容性暂时还不理想；
