# 更新日志

## 新功能、选项与改进

*   Real Mirrors：
    *   新的 `Adjust FOV and squeese` 选项，改善掠射角度下镜子的观感（默认启用）；
    *   新的 `Accurate` 选项，实现正确的镜子投影；
    *   新的调整，在禁用高质量镜子时显示车手头盔护罩，默认启用；
*   OpenRGB 集成被新的 `RGB Control` 应用取代（可在 App Shelf 获取），自定义空间更大，还有自己的 Exchange 平台用于分享预设；
*   CSP 会在后续启动时尝试追踪无报告的突然崩溃，并指出 Windows 生成的崩溃报告；
*   新菜单：
    *   遥测（Telemetry）标签页也重建了；
    *   Ctrl+Tab 在标签页之间切换；
*   新选项，仅隐藏远程玩家的维修站人员；
*   GUI 新调整，使用那些系统绑定时打开调校菜单而非会话详情；

## 修复

*   修复了 `Fully dynamic` 维修站选项导致带车桥的车辆无法移动的问题；
*   修复了将涡轮、视线等绑定到十字键导致的崩溃（0.2.9 中的回退）；
*   CSP 预览生成已修复；
*   修复了近期 AC 日志重写的问题，输出长字符串时不再让 AC 崩掉；
*   彻底隐藏维修站人员的选项可在联机中工作；
*   修复了加载期间偶发的彻底死锁；
*   会话重启时，若车辆此前在维修站，Autopilot 不再一头撞墙（总体上，AI 传送后也会根据落脚位置重新切换活动维修通道）；
*   缺少 soundbank 的车辆也应能检测相机是否在车内（例如有助于风挡雨滴）；
*   新的 KN5 加载器又能正确报告缺失的 DLC 了；
*   修复了一堆 bug：CSP 误把会话 ID 当作有符号数，导致 127 辆以上车辆的服务器上高级联机功能出问题；
*   Extra FX：修复了 TAA 在草地上（或其他颜色低于 0 的区域）异常的问题；
*   新树木：
    *   重载设置时会复用树木定义，并更积极地缓存部分内容，修复了使用 Tree Planter 应用时的内存泄漏和性能问题；
    *   太阳阴影平滑得多，自阴影减少；
    *   宽度超过 100% 的树木的阴影和公告板应该更好看；
    *   环境阴影小得多、更细腻（大范围阴影请使用 VAO）；
*   新菜单：
    *   修复了按住 Alt 拖动镜像滑块的问题（0.2.9 中的回退）；
    *   在弹窗外点击也能关闭欢迎消息；
    *   圈速导出为 CSV 可以工作了（此前生成的是空 CSV）；
    *   按索引排序已修复；
    *   投票冷却不再作用于 `kick` 投票，新菜单和 Lua 应用 API 均是如此；
*   Walking Out：
    *   闲置车辆不再自动开关灯；
    *   修复了用自由相机切换车辆时大灯范围异常的问题；
*   Smart Mirrors：
    *   MIP 不再被不必要地一次生成多遍；
    *   镜中镜现在用立方体贴图显示内容，而不再是一片黑；
    *   相机相对车辆移动过大时，跳帧会暂停；
*   Rain FX：
    *   雨滴命中随距离淡出；
    *   镜子中的雨雾不再出现在车内（裁剪距离加大）；
    *   风挡 UV 生成改用复用的工作线程，生成应该稍快一点；
*   AI 按 Weather FX 大灯建议开关大灯时，应该又有一些差异了；
*   手柄断开时 AC 不再刷屏 `DInput input lost:`；
*   IMGUI：字形图集加入了 `≤` 和 `≥` 符号；
*   `Skipping LOD A for other cars` 选项不再强制重新烘焙 Rain FX 遮挡；
*   Render Stats 应用：相对子区（主图下方的那些横条）又有意义了；
*   未启用 LCS 时镜中的着色更接近主场景；
*   修复了关于 HTTP2 之类的日志刷屏；
*   自定义车手模型不再需要 LOD B；
*   Android Auto：计时器已修复，点击整个状态块（而不只是图标）都能打开应用；
*   风挡反射着色器预加载，应能避免首次切换到车内相机时的卡顿；
*   修复了向 CM 上报错误的问题；

## 配置

*   新的车辆输入：`AUTO_SHIFTING`、`MANUAL_SPEED_LIMITER`；
*   自发光着色器（如 `smGlass_emissive`）与遮罩通道兼容；
*   `surfaces.ini` 新增 `[_EXTENSION] FORCE_DOUBLESIDED_RAYCASTS=1`，允许赛道为未启用扩展物理的车辆开启双面光线检测（近期的修复弄坏了某些赛道）；
*   Custom AI：
    *   新的 `.v1` 车辆控制结构体，可设置额外抓地力、稳定器和自定义 ABS 逻辑；
    *   激活或禁用输入平滑的新字段；
    *   新的 `[DEV] DISABLE_AI_SMOOTH_STEERING`，为调试目的彻底禁用 Kunos AI 的平滑；

## Lua & Python

*   通用：
    *   新字段：`ac.getCar().anyFlamesActive`、`ac.getSim().bestLapTimeMs`（全局最快圈）、`ac.getSim().isMouseSteeringActive`、`ac.getSim().originShift`；
    *   新的 `math.simplex()`：比 `math.perlin()` 更好的替代；
    *   新的 `ac.areShapesColliding()`，可快速检查一对形状（几何体与车辆碰撞体）是否相交；
    *   新的 `ac.getUnreadChatMessages()`，获取未读聊天消息数；
    *   新的 `ac.getCarBlindSpot()`，返回盲区中最近车辆的距离；
    *   新的事件监听器 `ac.onLapCompleted()`、`ac.onTrackPhysicsObjectCarCollision()` 和 `ac.onCarColorChanged()`；
    *   `ac.areCarsColliding()` 函数移到了 Common API；
    *   `web.get`、`web.post` 等函数现在允许固定 HTTPS 证书或访问其指纹（与 Firefox 中的 SHA-256 指纹一致）；
    *   加载远程资源的 `web.load…` 函数可以设置请求头并固定 HTTPS 证书；
    *   `math.saturate()` 和 `math.clamp()`（以及 …N 版本）性能大幅提升，`math.clamp()` 能处理一个限制是向量、另一个是数字的情况（一个老 bug）；
    *   `table.same()` 不再在关联表中含 `false` 值时出错；
    *   向 `table.clone()` 传第二个参数 `'deep'`，连向量和颜色也会一并复制；
    *   旧函数 `ac.store()` / `ac.load()` 重写，效率略有提升；
    *   `ac.setHighBeams()` 在绑定为按住模式时可用；
    *   修复了用 `ac.DriverTags()` 和 `ac.tagAsFriend()` 更新好友状态的问题；
    *   `ac.getSunAngle()` 联机时更新；
    *   使用 WeatherFX 条件或动态天气插件的联机中，`ac.getSim().timeMultipler` 不再为零（前提是时间确实在流动）；
*   UI：
    *   `ui.setNextItemIcon()` 可与 `ui.beginMenu()` 一起使用；
    *   集成标签栏：考虑窗口设置按钮，下拉按钮样式更新；
    *   新的 `ui.beginPointSampler()` / `ui.endPointSampler()` 函数，将 IMGUI 着色器换成使用点采样的版本；
    *   `ui.keyboardButtonDown()` 支持侧键，如左 Ctrl；
*   Scene API：
    *   光线检测现在考虑光线长度（AABB 光线检测除外）；
    *   NanoRT 加速的光线检测返回正确的局部位置、UV 等，加速结构在后台构建；
    *   移除 ExtraFX 自发光正在使用的节点不应再使 AC 崩溃；
*   Physics API：
    *   新的 `physics.setAIStopCounter()`，让 AI 停车一段时间；
    *   `physics.RigidBody`：碰撞回调会返回车辆索引（若有）；
*   IO：
    *   `io.load()` 立即释放文件，例如读完即可删除；
    *   `io.recycle()` 已修复，现在真的会回收了；
    *   新的 `io.findFile()`，返回文件的绝对路径；
    *   后台与物理 worker 现在也支持相对和绝对路径（脚本工作目录仍与父进程相同）；
    *   被 Lua Debug 应用保活的 worker 仍会立即释放其持有的东西，例如事件订阅；
    *   `os.runConsoleProcess()`：新的 `terminateWithScript = 'disposable'` 选项可改为返回 `ac.Disposable`；另外，将其设为 `false` 并配合此前未写入文档的 `assignJob`，现在可以让进程在 AC 关闭后继续存活；
    *   `io.extractFromZipAsync()`：新增关键文件参数以确保完整解压（该文件会换个名字最后解压，然后再重命名，因此代码只需检查该文件是否存在：只要文件在，就说明压缩包已完整解压）；
*   `web.loadRemoteAssets()`：可指定关键文件名，类似 `io.extractFromZipAsync()`；拥有完整 I/O 权限的脚本不再有文件类型限制，另有大量修复；
*   Lua 应用：
    *   新的 `ac.restartApp()`；
    *   `ac.exportLapTimesToCSV()` 可以工作了，新增可选参数指定文件名；
*   New Modes：使用 `[TWEAKS] HIDE_PITCREW` 可彻底隐藏维修站人员；
*   `shared/sim/cars` 新函数，可获取和更改远程车辆的基础车轮位置；
*   `ac.onOpenMainMenu()` 可以接收其他类型的页面，例如 `ac.tryToOpenRaceMenu()` 被调用时；
*   Lua Debug 应用：
    *   查看 Lua 纹理时使用点采样的选项；
    *   应用现在会跨脚本重载记住渲染矢量的所选设置；
*   部分函数与字段的文档更新，sumneko 的 Lua 插件现在能正确理解 CSP `table.` 函数的类型；
*   LuaJIT 与上游同步（包含一些小修复）；
