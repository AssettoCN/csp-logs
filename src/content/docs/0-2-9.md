# 更新日志

## 新功能、选项与改进

*   新的 FFB 调整：干净 FFB（为使用自定义物理的车辆禁用 ABS 后处理效果，默认启用）；
*   VR 调整：隐藏选项，可平移控制器的位置与旋转，以更好地兼容边角情况（在 `vr_tweaks.ini` 中查找 `[CONTROLLERS_INTEGRATION] SHIFT_…`）；
*   `gameplay.ini` 的 USE_MPH、PIT_INDICATOR/ONLY_IN_PITLINE、GUI/ALLOW_OVERLAPPING_FORMS 支持实时重载；
*   CSP 日志重写，更高效、紧凑且信息更丰富；
*   新的改造版日志实验：
    *   AC 的日志也交由 CSP 处理；
    *   此外，若启用，CSP 与 AC 的日志都会在后台进行，不阻塞；
    *   同时为 AC 日志加上限制，以防万一；
*   新菜单：
    *   会话倒计时与等待时间计时器；
    *   会话信息更新，新增包含 CSP 调整在内的服务器信息窗口；
    *   欢迎消息改用自定义弹窗（除非聊天设置中禁用了弹窗）；
    *   Y 值低于 -2 的调校项会被隐藏；
    *   挡位标签页支持额外条目；
    *   更好地处理左右调校项重叠的情况，标签与提示会相应调整；
    *   踩油门踏板开始比赛可用；
    *   `Setup in pits` 正常工作，与原版行为一致；
    *   制作人员名单改用 `data_credits.txt`；
    *   若干较小的布局修复与改进；

## 修复

*   修复了 ABS 是否激活的判定（0.2.8 中的回退）；
*   带 `TORQUE_MODE_EX=2` 的 `Vanilla` ABS 更平滑了，以防万一；
*   修复了焊接/死差速器车辆的扭矩反作用问题；
*   修复了不带扩展物理的轮胎检测线撞到车辆上方墙体的问题；
*   改进了修饰键处理，修复了与 Steam Deck 的兼容性；
*   修复了 `data_manifest.ini` 导致某些绑定完全不显示的问题；
*   修复了大型赛道加载期间因 ODE 配置错误导致的偶发崩溃；
*   `Delay optional stuff` 选项不再允许 Grass FX 连续跳过两帧（希望能修复草地消失的报告）；
*   Windscreen FX：修复了 `extra reflections for exterior views` 选项；
*   修复了联机中近光与远光闪烁的问题；
*   Rain FX：湿滑刹车痕粒子淡出更快；
*   Rain FX 赛车线：半湿表面上的干燥生效更快，0.2.8 加入的水洼扩散持续性略有缩短；
*   制动扭矩钳制同样作用于影响轮毂的扭矩，避免使用巨大手刹扭矩等的车辆出问题；
*   新菜单、车手工具提示：支持英制单位（若在 AC 设置中设置）；
*   联机比赛开始前 5 秒或更短时间内打开主菜单就把玩家传送回维修站的功能，现在对新菜单或任何菜单替换都有效；
*   湿的旗帜与帐篷更暗；
*   修复了星点纹理采样，解决锯齿、性能与奇怪线条的问题；
*   当 DirectX 报告 HDR 不可用时，CSP 现在会去检查 Windows 中的 HDR 设置作为后备（事实证明 DirectX 在这件事上相当不可靠）；
*   Walking Out 再次与 Gamepad FX 兼容；
*   原版欢迎弹窗会阻挡 IMGUI 鼠标输入；
*   修复了 OpenRGB 集成；

## 配置

*   修复了用 `[REFLECTIONS_FX] MASK_CUBEMAP_SKIP=…` 从车内遮罩中排除网格；
*   Tyres FX：`FLEX_PROFILE_MULT` 的默认值从 1 改为更安全的 0.8（0.2.8 之前是 0.45，但理想值应是 1），修复了某些车辆的小幅穿模问题；
*   修复了带去色 `smGlass` 着色器的遮罩 pass；
*   不区分大小写的过滤（`<?I>` 前缀）可用了（到底坏了多久？）；这也修复了几个 CSP 默认值：不给围栏之类设置风（即使它们用 ksGrass/ksTree）、把含沥青及类似材质的网格用作发热遮罩的默认值（只要着色器是 ksMultilayer_fresnel_nm）、找出气球赛道模型、用显示屏与 LED 遮挡风挡雨滴中的车内折射；
*   过滤节点、网格与材质的新属性 `keyword:`：`keyword:abc+def` 会匹配名称或材质名中含 `abc` 或 `def` 的网格（不区分大小写）；
*   车辆灯光：`RELATIVE_TO` 支持 CSP 过滤器（`{…}` 那套，但仍然只加载单个节点），此外 CSP 现在应能处理 `RELATIVE_TO` 节点在激活 LOD 中缺失的情况；
*   光线检测函数新增背面剔除选项（默认、禁用或反转）；

## Lua & Python

*   修复了 `ac.getSim().isVirtualMirrorActive`；
*   新函数 `physics.preventAIFromRetiring()`，阻止 AI 退赛；
*   新字段 `ac.getSim().windowSize`、`ac.getUI().useImperialUnits`；
*   新函数 `physics.addTrackSurface()`，可实时创建新的赛道物理表面（目前不太好用，因 Embree 重建而严重卡顿；旧的 `__tmp_addPhysicsMesh` 东西已移除）；
*   又新增了几个图标；
*   `physics.RigidBody()` 移入按需加载模块，文档改进；
*   新的 `ac.onOpenMainMenu()`，让自定义主菜单能响应 `Setup in pits` 快捷方式之类；
*   Scene API：网格的新方法 `:getIndices()`；
*   新函数 `ui.itemUnderline()`；
*   新的 `ac.exportLapTimesToCSV()`，供 Lua 应用实现与原版菜单 `print` 按钮相同的功能；
*   修复了 Scene API 移除网格导致重载时动画雨刮崩溃的罕见问题；
