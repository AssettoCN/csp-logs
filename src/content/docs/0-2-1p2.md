# 更新日志

## 新功能、选项与改进

*   物理：修复了路肩上的轮速问题，Cosmic 悬架新增选项（文档已更新）；
*   雨：水洼引起的减速更准确；
*   WindscreenFX：新的可选反射；
*   新的 AgX 色调映射函数；
*   车门音频事件现在可用了（另外，会话开始时车门会立即打开）；
*   显示器后视镜新增亮度设置；
*   常规分区隐藏了一些设置让界面更整洁，Yebis 相关设置移到了 WeatherFX 模块；
*   季节设置移到赛道调整中，现在若设置了日期，默认会应用季节；
*   新的物理实验：在计算 ODE 前更新车辆状态，模拟状态更精确；
*   替代后处理更新：胶片颗粒重做，眩光更新；
*   自定义 FFB 锁新增选项，为转向锁小于控制器转向锁的车辆将锁止区外移；
*   为新树木缩放 LOD 距离的选项（另外，LOD 距离会随变焦增大）；
*   将调校保存为 `ext_default.ini`，即会自动加载；
*   Graphics Adjustments：强制启用 FXAA 的选项，方便配置；
*   New Behaviour 模块的选项，移除 200 km/h 前瞻限制（实验性，默认禁用）；
*   新打开的 IMGUI 窗口会获得焦点并置顶；
*   新的自动驾驶在激活时不再更改涡轮等设置（可选，默认启用）；
*   直线加速赛道上的 AI 若起点离主线太远，会创建新的路线；
*   Small Tweaks：为方向盘上有重要信息的车辆取消隐藏方向盘的选项；
*   可脚本化的 PP 滤镜可根据当前游戏状态停用（例如仅在回放中应用）；
*   展厅模式：发动机默认熄火，图标已修复，环绕相机更好地强制生效，按空格键开关车门，另有启用音频的选项；
*   NeckFX：Lua 脚本的默认设置更新；
*   GamepadFX 的 Gyrosteer 脚本：灵敏度滑块；
*   远光闪烁（按住而非按下）现在在开启远光或关闭大灯时也能工作；
*   音频延迟选项更新，现在影响更多东西，包括碰撞、赛道类型与车辆位置；
*   用赛道隔音墙做音频遮蔽的选项；
*   车辆 LOD 逻辑改变，现在距离带有一点余量，防止过于频繁的切换；
*   默认 WeatherFX 样式的一些更新，改善性能与观感；
*   照片应用新的场景调整：切换远光；

## 修复

*   会话开始时的爆音消失了；
*   VR 下的折射大灯与 SPS 兼容；
*   NeckFX 头盔可在 VR 与三屏模式下工作；
*   修复了慢动作回放中 NeckFX 抖动的问题；
*   湿滑赛道材质不再随车辆驶过而闪烁；
*   动态阴影可以处理累积截图；
*   新树木湿滑时应更合理；
*   草地反光更弱，湿滑时尤其如此；
*   鼠标光标不再卡在窗口缩放形状；
*   引擎盖与保险杠相机在某些 CSP 效果（如 RainFX 观感）中始终视为外部视角；
*   来自车轮以外来源的烟雾不再显得过暗；
*   修复了 TyresFX 反射遮蔽，轮胎不再因 TyresFX 模块被禁用而失去反光；
*   打开的车门会偏移 LOD 距离，迫使主 LOD 保持更久的激活；
*   阴影车轮与车手与 LOD 配合更好；
*   累积 DOF 再次遵循照片应用的滑块；
*   车辆状态外推不再超出物理步长，物理引擎过载时的抖动或可缓解；
*   除非使用了 `ac.onResolutionChange()`，添加额外效果的 WeatherFX 脚本不再应用截图缩放；
*   全屏视频模式下忽略渲染/截图缩放设置；
*   修复了远处车辆座舱缺失的问题；
*   无需雨胎时，AI 不会在降雨开始或结束时进站；
*   AI 不会把涡轮设到 100% 以上；
*   自动驾驶时刹车提示不再重置；
*   自动驾驶不再停止刹车温度估算；
*   风音频事件现在包含风速；
*   过热轮胎着火时不再冒烟；
*   风挡雨滴运动更新，更真实，数量略增；
*   大雨时屏幕上雨滴更多；
*   观众在雨中会躲起来；
*   修复了回放中的气压（该 bug 影响音频延迟之类）；
*   转速过低时，旋转的车辆物体会停止旋转；
*   修复了 WeatherFX 自定义后处理在未启用 FXAA 时不工作的问题；
*   禁用后处理时，默认 WeatherFX 样式稍微变暗；
*   照片模式应用：修复了禁用后处理时的布局；
*   修复了部分车辆上的 LED（以及其他被错误禁用的节点）；
*   AC 与 Python 窗体不能被移出屏幕；
*   Smart mirror：显示器后视镜不再受观看者位置影响，与 WeatherFX 样式着色更兼容；
*   AI 应能从 `ai_default.ini` 加载扩展项；
*   TyresFX：更改阴影偏置与模式以减少漏光；
*   修复了赛道隔音墙：更新更快，配置工具中的点显示正确；
*   热浪不再超过刹车中的车辆；
*   起步相机下不再播放换挡动画（看不见车手时）；
*   字体渲染做了一些调整以提速并让 emoji 正常工作；
*   首次启动时，若检测到旧版 NeckFX 运动的任何设置被调整过，NeckFX 脚本会自行停用（假定用户已按自己的喜好配置好 NeckFX，不需要这样的更改）；
*   AC 暂停时，Xbox One 扳机不应再振动；
*   针对 `rss_gtn_darche_96` 挡位指示的专门修复；
*   1980 年以前的车辆大灯更窄也更暗；
*   修复了重载时的罕见 GPU 崩溃；
*   修复了一批退出时发生的反初始化崩溃；
*   一些小修复与优化；

## 配置

*   车辆轮胎的新参数 `TYPE_HINT=TREADED/VINTAGE_PERFORMANCE/SLICK/SEMISLICK`，帮助自定义物理找到最佳雨天参数；
*   服务器配置的新参数 `[EXTRA_RULES] MAX_METERS_WRONG_WAY`（默认值为 100 m）；
*   RainFX 赛道配置中影响物理的值可从 `surfaces.ini`、赛道配置或 CSP 自带的配置读取，让联机比赛更公平；
*   着色器 `nePerPixelMultiMap_AT_NMDetail_stickers` 新增可选的 `txStickersNormals` 纹理；
*   修复了 `ksMultilayer_fresnel_nm4`，现在也支持着色器 `ksPerPixel_nosdw`；
*   `ksMultilayer_fresnel_nm` 的法线贴图也用上了平铺修复；
*   配置 `proview_nodes.ini` 可以用 data_override 替换，实时重载部分可用；
*   JSON 解析器现在可以处理尾随逗号；
*   新参数 `[EXTRA_TWEAKS] MIN_TIME_BETWEEN_COLLISIONS = 5 ; seconds`，让客户端更早、更频繁地上报碰撞；
*   摇摆效果（如 wobbly bits）现在与车漆着色器兼容；
*   模块 `lighting_fx` 可以加入联机必需模块；
*   Object Inspector 工具新增检查新树木的工具；
*   修复了反弹光的裁剪平面在裁剪点过多时失效的问题；
*   修复了 `[Material_RoomWindows]` 的 `NormalsFactor`；
*   自定义物理调校项：现在支持点击模式参数；
*   车辆配置可为音频调整添加检查（只影响特定 soundbank），并为不同音频事件添加自定义 DSP；
*   树木：修复了 LOD 填充，表面同步不再回退使用 GrassFX 表面，可将模型垂直偏移以便继续使用表面同步；
