# 更新日志

## 新功能、选项与改进

*   用于越野物理的新 Surfaces FX 模块（如何准备车辆或赛道的文档即将推出）；
*   Quick Drive 的新 Rally Stage 模式；
*   App Shelf 上的新 Rally Copilot 应用，用于拉力模式或学习陌生赛道；
*   App Shelf 上的新 Dynamic Return 应用，用于练习自定义赛道分段；
*   新选项：
    *   单屏模式下，宽屏居中 UI；
    *   阻止回放对车辆传送进行插值（默认启用）；
    *   在会话之间保存 Assetto Corsa 窗口的尺寸与位置；

    *   回放激活时停止切换相机；
    *   New Behavior：阻止 AI 卡住时传送的调整；
    *   在上下坡赛道上，若创作者忘记翻转 AI 线路则自动翻转；
    *   强制音频混响始终处于激活状态；
    *   隐藏缺失的车手模型而非使用默认模型（以防骨架兼容性问题）；
    *   临时调整，赛道物体过多时停止回放记录其状态，以节省显存；
*   Grass FX：
    *   新的风实现；
    *   `fuPBR_…` 与 `ksMultilayer_objsp_nm4` 着色器与草地兼容；
    *   修复了相机旋转时屏幕边缘草地缺失的问题；
    *   与 LCS 的兼容性更好；
*   Tyres FX：
    *   法线与颜色随磨损褪去；
    *   扩展物理激活时，形变使用实际数据；
*   照片应用：
    *   重置曝光的按钮；
    *   变焦使用焦距单位的选项；
    *   移除已存点现在会保存更改；
*   三屏调整：
    *   不对称侧边的新方法，真正匹配场景；
    *   为不同类型相机重新定义三屏行为的选项；
*   Android Auto：
    *   新的网页浏览器应用（取代车辆信息应用）；
    *   车辆可以添加额外应用（目前需要签名）；
    *   鼠标悬停在虚拟键盘上时，可用实体键盘输入；
*   手刹联机同步（目前只用一个比特）；
*   赛道表面类型检测改进，不再被大写字母干扰（改善 Surfaces FX）；
*   任务栏搜索更好地处理空格（查询 `renderstats` 能找到 `Render Stats` 应用）；
*   CSP Debug 应用：显示最近三辆车的碰撞体，便于调查联机碰撞；
*   Chaser Camera：第一与第二相机可用不同脚本；
*   默认 WeatherFX 样式：眩光带一点额外色差；
*   Walking Out：手柄控制、大量修复，主车辆现在可以传送；
*   CSP 会对照 `data_manifest.ini` 校验自身版本号，以尝试检测损坏的安装；
*   服务器可以发送特定数据包，显式更新玩家的管理员状态；
*   缺少 `driver_base_pos.knh` 不再导致崩溃；
*   不同类型的轮胎对 Rain FX 赛车线的影响不同（目前只是很粗略的估算）；
*   CSP 生成的车辆预览图现在更锐利；
*   New Modes 可以禁用黄旗与蓝旗，赛道日模式下也会禁用；
*   隐藏的配置行，指定联机聊天中改色影响的纹理列表；

## 配置

*   车辆挡泥板动画；
*   旗帜着色器的新修饰符，可当作帐篷顶（随风摆动，被雨浸湿）；
*   `nePBR…` 与 `nePerPixelMultiMap_bending` 现在支持 UV2 映射的贴纸；
*   车手模型额外阴影的默认设置已调整，观感更好；
*   CSP 数字仪表的新格式类型 `GEAR_RAW`（常规 `GEAR` 现在显示自定义挡位标签（若已设置））；
*   车辆音频缺失时，可指定从哪辆车取音频（另外，车辆音频缺失不再导致崩溃）；
*   车辆配置可用 `[AUDIO_VOLUME_EXT]` 仅为外部视角设置替代音量倍率；
*   赛道配置的新参数 `[PITSTOP_CAMERA] THETA=, PHI=, RADIUS=, FOV=`，更改换胎动画所用相机；
*   赛道配置的新参数 `[START_CAMERA] BLOCK_TRAJECTORIES=, POSITION_OFFSET=`，更改起步相机；
*   `ksPerPixelMultiMap_AT_NMDetail` 应能更好地支持季节变化；
*   新着色器 `ksTree_bush`，行为与 `ksTree` 一样（包括 A2C 支持），但可接收逐像素阴影；
*   `[SHADER_REPLACEMENT_…]` 条目现在将 `SHADER` 值作为列表加载，使用最后一个可用的条目；
*   基于 UV 的网格拆分新参数 UV_REGIONS_USE_SIZE，配置更简单；
*   着色器替换的新值 `BLEND_MODE = PREMULTIPLIED`；
*   `ksWindscreen`：新参数 `alphaGamma`，快速调整透明度；
*   着色器 `ksPerPixelMultiMap`、`ksPerPixelMultiMap_NMDetail` 与 `ksPerPixelMultiMap_damage_dirt` 现在也能接收雨刮痕迹；
*   赛道正确加载尘土、灰尘与草地颜色（若存在相关节，通用配置会失效），且在缺少 `[TYRES_FX]` 节时从 `[DIRT]` 节加载颜色；
