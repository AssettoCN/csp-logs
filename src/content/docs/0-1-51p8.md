# 更新日志

## 新功能、选项与改进

*   新的 FFB tweaks 扩展，带有 Stereo 实现的更精确的陀螺仪；
*   替换原版照片模式应用的新应用：
    *   为截图提供简单的 CPL 模拟；
    *   保存与加载相机位置；
    *   保存前预览照片；
    *   在回放中：
        *   调整快门速度以获得累积运动模糊；
        *   在回放中开关灯光、刹车灯、损伤、污垢或车手；
        *   更改一天中的时间，或旋转整条赛道，让光线落在需要的位置；
*   树木接受阴影现在改为可选，默认禁用；
*   同时，树木接受阴影现在应该更平滑，还修复了几个 bug；
*   树木 A2C 抖动，减少 MSAA 下的色带；
*   修复了车辆音频的音量调节；
*   动态旗帜现在也改为可选；
*   修复了旗帜 UV 映射错误的问题；
*   IMGUI 应用不再破坏与 AC 其余部分的鼠标交互；
*   反射立方体贴图中使用更简单的动态光以提速（跳过车辆灯光或非常小的灯光）；
*   选项，若车速低于 6 km/h，降低 AC 遥测中的 G 力（用于 D-BOX）；
*   Weather FX：
    *   选项，为机器人强制开启前大灯；
    *   云的新选项，将其渲染为水平方向；
    *   默认天气脚本的几处修复；
*   折射玻璃：基于 txDiffuse alpha 通道的折射遮罩，用于带部分平坦玻璃的前大灯；
*   选项，缓存为 AI 线路生成的网格与数据，可将加载提速几秒；
*   新的 Python 函数，可获取 AI 线路长度、由世界坐标求线路位置及反向转换；
*   AC 在后台时，环绕相机不再响应鼠标；
*   树木阴影同样会随风摆动；
*   若干较小的 bug 修复；
