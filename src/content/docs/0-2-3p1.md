# 更新日志

## 新功能、选项与改进

*   序列式换挡的新绑定（应比 CM 的副绑定可靠得多）；
*   基于碰撞体的 LOD 更新：着色和形状都更接近实际模型；
*   新的分屏比赛模式（从 Custom Rendering Modes 模块移来，还带了不少修复）；
*   隐藏远处车手的新选项；
*   Traffic 模式新增最高速度倍率选项，另有大量修复与性能改进；
*   延迟系统绑定在全屏模式下可用；

## 修复

*   Lua 音频已修复；
*   AI 车手不再一窝蜂同时驶出维修站；
*   OpenVR 延迟交换不再影响 FFB；
*   修复了使用 LUT 且设置中最大值非 100% 的车辆 Real Feel Braking 灵敏度问题；
*   基于碰撞体的 LOD 与无 LOD 车辆数量限制兼容；
*   新音频应用：变速箱音量可以与发动机音量联动；
*   修复了自定义变速箱音量设置加载的问题；
*   车辆开关 G/H/I/J 的绑定已加入列表；
*   再次修复了自定义物理车辆的调校标签页顺序；
*   New Modes 与 Custom Rendering Modes 模块始终激活（未启用时不会浪费任何资源）；
*   VAO 补丁能正确应用到车手 LOD B；
*   阴影车轮与车手不再只作用于最近的几辆车；
*   保存车辆状态时应包含滑板磨损；
*   自定义车手模式加载更快，LOD B 的问题已修复；
*   KN5 更改后 AI 载荷缓存会刷新；
*   修复了额外回放流（如带温度的刹车）的罕见崩溃；
*   风挡雨滴摩擦力增大；
*   绑定 POV 时控制冲突消息的问题应该修复了；
*   修复了加载某些严重损坏的 DDS 纹理时的崩溃；
*   少量小修复与稳定性改进；

## 配置

*   Cosmic 悬架加入辅助弹簧，详见文档；
*   完整重载现在能正确重载灯光；
*   为保持稳定，大部分自定义物理不再实时重载；
*   蒙皮与非蒙皮着色器替换之间的套用不再生效；
*   离线比赛中会遵循 `race.ini` 的 `ALLOWED_TYRES_OUT`（值为负时除外）；

## Lua & Python

*   新的 `ac.blockSystemMessages()`，过滤掉部分系统消息；
*   新标志 `ac.StateCar.isDriverSeatbeltOn`；
*   新的 `ac.GeometryShot():setOpaqueAlphaFix()`，在透明背景下正确绘制物体；
*   `ac.applyLiveConfigEdit()` 可用于 `custom_rendering_modes.ini`；
*   面向 Lua 应用的 `ac.loadCarControlsConfiguration()`，用于非常特殊的场合；
*   新的 `physics.setAllowedTyresOut()`（即使其余 Physics API 不可用，新模式中也可用）；
*   面向车辆物理脚本的 `ac.StateCphysCar.fuelConsumption` 和 `ac.setFuelConsumption()`；
*   物理与自定义物理脚本 API 的有限性检查已更改，应更有信息量也更少崩溃；
*   修复了命名 Lua 纹理释放的问题；
*   销毁 Lua 纹理时也会将其清空，以防万一；
*   附加在 AI 驾驶车辆上的脚本不再显示系统消息；
*   修复了 `ac.SceneReference:loadKN5LOD()` 的内存泄漏和性能问题；
*   几个新的 Python 函数；
