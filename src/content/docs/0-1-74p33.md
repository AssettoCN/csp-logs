# 更新日志

## 新功能、选项与改进

*   影响所有车辆与赛道的新的通用配置（目前作用不大）；
*   大幅重写高级剔除以提升性能；
*   DXGI tweaks 新增几个选项（与 flip model 无关）：
    *   根据 AC 视频设置中选择的屏幕使用对应的 GPU；
    *   真正的无边框模式；
    *   三重缓冲和自定义最大帧延迟；
*   赛道 SIMD 加速剔除的选项；
*   AC 最小化或在后台时禁用音频的选项；
*   Smart mirror：覆盖镜子渲染距离的选项；
*   Radar 应用：颜色设置、更新的外观；
*   多亏新的内置加载性能分析器，加载的流畅度和信息量大幅提升；
*   加载现在应该更快了，还有用缓存进一步加速的选项（默认启用）；
*   修复了 VAO 过暗的问题，伽马可动态调整；
*   崩溃消息重做，新增额外检查与提示；
*   崩溃报告包含 CSP 设置预设；
*   声速会考虑温度等因素；
*   GUI：油门与刹车踏板同时踩下的可选警告；
*   联机自定义颜色现在可跨会话保存；
*   自适应近裁剪面的选项，改善相机远离车辆和赛道时的观感；
*   自定义 VR 镜像：新增只显示右眼的新模式；
*   传送目的地列表更紧凑，支持分组和过滤地点；
*   少量小优化；

## 修复

*   修复了某些赛道上的崩溃；
*   更平滑加载的选项现在不会再明显拖长加载时间；
*   `Show on screen` 现在正常工作，包括负坐标或全屏；
*   修复了其他车辆上镜子不反光的问题；
*   修复了反射立方体贴图打乱渲染顺序导致部分网格不可见的问题；
*   已固定的应用不再可调整大小；
*   比赛中更改常规设置不再触发 CSP 完整重载；
*   WeatherFX：修复了云朵阴影与云朵渲染；
*   修复了导航仪偶尔在地图上显示乱码的问题，现在无需启用 GUI 模块也能工作；
*   修复了在某些 GPU 上以奇怪 FPS 限制器形式出现的大型性能问题；
*   修复了禁用车辆仪表模块时的崩溃；
*   修复了未启用反弹光时加热效果无法正常工作的问题；
*   修复了远处车辆网格过早消失的问题；
*   TyresFX 现在在镜子中正常工作；
*   带清漆的 PBR 着色器：动态光源已修复；
*   修复了车外扫视时头部轨迹的问题，避免在某些车里穿出车顶；
*   Accessible color 现在使用 32 bpp 而非 64 bpp，以改善性能；
*   修复了键盘输入模式下的强制油门和空挡按钮；
*   烟花的音频与视觉效果已修复，现在会反射在立方体贴图中；
*   修复了在某些带极短 AI 线的赛道上使用鼠标转向时的崩溃；
*   修复了其他车辆靠近时使用 F6 相机导致镜子损坏、座舱切换到 LR 版本的问题；
*   TyresFX 不再在会话重启后损坏；
*   修复了反射反转的问题（例如夜间导致某些轮胎上出现黑斑）；
*   少量小修复；

## 配置

*   TyresFX：可在配置中为特定轮胎类型指定轮胎花纹；
*   车辆扩展物理：
    *   联机使用真实质量的选项，改善重型车辆的碰撞；
    *   重新定义碰撞参数的选项；
*   赛道扩展物理：
    *   联机为车辆使用真实质量的选项；
    *   为不同表面重新定义碰撞参数的选项；
    *   表面与车辆网格碰撞体之间使用刚性碰撞的选项，尽量防止某些极端情况下车辆穿落地面；
*   INIpp：include 现在可以是可选的，文件名支持表达式，新增访问和修改已解析内容的函数；
*   车辆和赛道配置的 `read()` 新输入；
*   WeatherFX：新函数 `ac.setVAOExponent(gamma)`；
*   Python 函数 `ac.ext_loadIniFileAsJson()` 已修复，`ac.ext_parseIniFileToJson()` 更名为 `ac.ext_parseIniAsJson()`（旧名称出于兼容仍可使用）；
*   赛道灯光新参数 `SHOW_IN_REFLECTIONS`（请谨慎使用，为提速起见默认只包含范围超过 10 米的灯光）；
*   车辆灯光：远光和近光的色调；
*   车辆灯光与自定义自发光：分别设置升起/落下延迟、自定义加热颜色及其他参数；
*   设置 `set observeDigital 1` 现在不应再使 AC 崩溃；
*   新 Lua 函数 `ac.getSoundSpeedMs()`，获取准确的声速；
*   Lua 音频事件新增音高参数；
*   用于高级轮胎碰撞检测的扩展光线追踪使用更少采样以提速；
*   光弹性 PBR 玻璃现在也支持多重自发光；
