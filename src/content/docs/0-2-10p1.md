# 更新日志

## 新功能、选项与改进

*   新的 FFB 调整项：Clean FFB（为自定义物理车辆禁用 ABS 后处理效果，默认启用）；
*   VR 调整：新增用于偏移控制器位置与旋转的隐藏选项，以更好地兼容边缘情况（在 `vr_tweaks.ini` 中查找 `[CONTROLLERS_INTEGRATION] SHIFT_…`）；
*   `gameplay.ini` 的 USE_MPH、PIT_INDICATOR/ONLY_IN_PITLINE、GUI/ALLOW_OVERLAPPING_FORMS 支持热重载；
*   CSP 日志重写，更高效、紧凑、信息更丰富；
*   新的改写日志实验：
    *   AC 的日志也交由 CSP 处理；
    *   此外，若启用，CSP 与 AC 的日志都将在后台完成，不再阻塞；
    *   同时为 AC 日志加上限额，以防万一；
*   新菜单：
    *   会话倒计时与等待时间计时器；
    *   会话信息更新，新增包含 CSP 调整项的服务器信息窗口；
    *   欢迎消息使用自定义弹窗（除非聊天设置中禁用了弹窗）；
    *   Y 值低于 -2 的调校项不再显示；
    *   Gears 标签页支持额外条目；
    *   左右调校项重叠的情形处理得更好，标签与提示会自动调整；
    *   踩油门开始比赛可以正常工作了；
    *   `Setup in pits`（维修站调校）正常工作，还原原始行为；
    *   制作人员名单改用 `data_credits.txt`；
    *   若干更小的布局修复与改进；

## 修复

*   修复了 ABS 激活状态的检测（0.2.8 中的回退）；
*   `TORQUE_MODE_EX=2` 的 `Vanilla` ABS 更加平滑，以防万一；
*   修复了焊接式/锁止差速器（spool）车辆的扭矩反作用问题；
*   修复了未启用扩展物理时轮胎光线检测会打到车辆上方墙壁的问题；
*   改进了修饰键处理，修复与 Steam Deck 的兼容性；
*   修复了 `data_manifest.ini` 导致某些绑定完全不显示的问题；
*   修复了大型赛道加载过程中因 ODE 配置错误导致的偶发崩溃；
*   `Delay optional stuff` 选项不再允许 Grass FX 连续跳过两帧（希望能修复那个"草地消失"的报告）；
*   Windscreen FX：修复了 `extra reflections for exterior views` 选项；
*   修复了联机时近光/远光灯闪烁的问题；
*   Rain FX：湿滑胎痕粒子淡出更快；
*   Rain FX 赛车线：半湿表面上干燥生效更快，0.2.8 新增的水坑扩散更短暂了些；
*   制动扭矩钳制同样作用于影响轮毂的扭矩，避免使用巨大手刹扭矩之类的车辆出问题；
*   新菜单车手提示：支持英制单位（若在 AC 设置中启用）；
*   "联机比赛中、开赛 5 秒内打开主菜单则将玩家传回维修站"的功能，现在在新菜单或任意菜单替换下都能工作；
*   湿状态下的旗帜和帐篷更暗了；
*   修复了星空纹理采样，解决了锯齿、性能和奇怪线条的问题；
*   当 DirectX 报告 HDR 不可用时，CSP 现在会转而检查 Windows 的 HDR 设置作为兜底（事实证明 DirectX 在这方面相当不靠谱）；
*   Walking Out 重新兼容 Gamepad FX；
*   原版欢迎弹窗会阻挡 IMGUI 鼠标输入；
*   修复了 OpenRGB 集成；

## 配置

*   修复了用 `[REFLECTIONS_FX] MASK_CUBEMAP_SKIP=…` 将网格排除出内饰遮罩的功能；
*   Tyres FX：`FLEX_PROFILE_MULT` 默认值从 1 改为更安全的 0.8（0.2.8 之前是 0.45，但理想值本应是 1），修复了部分车辆的小型穿模问题；
*   修复了去饱和 `smGlass` 着色器的 mask pass；
*   大小写无关的过滤（`<?I>` 前缀）可以工作了（坏了多久了？）；这同时修复了若干 CSP 默认值：不给围栏之类设置风力（即便它们用 ksGrass/ksTree）、将含沥青等材质的网格用作加热遮罩的默认值（只要着色器是 ksMultilayer_fresnel_nm）、识别气球赛道模型、用车载屏幕与 LED 遮挡风挡雨滴中的内饰折射；
*   新增用于过滤节点、网格和材质的 `keyword:` 属性：`keyword:abc+def` 会匹配名称或材质名中含 `abc` 或 `def` 的网格（大小写无关）；
*   车辆灯光：`RELATIVE_TO` 支持 CSP 过滤器（`{…}` 那套，不过仍只加载单个节点），且 CSP 现在能处理 `RELATIVE_TO` 节点在当前 LOD 中缺失的情况；
*   光线检测函数新增背面剔除选项（默认、禁用或反转）；

## Lua & Python

*   修复了 `ac.getSim().isVirtualMirrorActive`；
*   新增 `physics.preventAIFromRetiring()` 函数，可阻止 AI 退赛；
*   新字段 `ac.getSim().windowSize`、`ac.getUI().useImperialUnits`；
*   新增 `physics.addTrackSurface()` 函数，可在运行中创建新的赛道物理表面（目前还不太好用，因 Embree 重建会明显卡顿；旧的 `__tmp_addPhysicsMesh` 东西已移除）；
*   又新增了一些图标；
*   `physics.RigidBody()` 移至按需加载模块，文档改进；
*   新增 `ac.onOpenMainMenu()`，让自定义主菜单能响应 `Setup in pits` 快捷方式之类的东西；
*   Scene API：网格新增 `:getIndices()` 方法；
*   新增 `ui.itemUnderline()` 函数；
*   新增 `ac.exportLapTimesToCSV()`，供 Lua 应用实现与原版菜单 `print` 按钮相同的功能；
*   修复了一个罕见的 Scene API 网格移除导致的崩溃——重载时动画雨刮器会崩溃；
