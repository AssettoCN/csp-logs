# 更新日志

## 新功能、选项与改进

*   调校菜单与悬挂应用中为 Cosmic 悬架显示主销后倾角（Caster）与主销内倾角（KPI）；
*   更新了轮胎接触点逻辑；
*   新的物理实验：比赛开始后禁用维修区外的车辆休眠（暂时默认禁用）；
*   FFB Tweaks：
    *   对跳过的 FFB 采样取平均的选项，反馈更精确；
    *   降低阻尼 FFB 更新频率的选项（由于它只用于低速 FFB 阻尼，降低频率合情合理。可解决部分方向盘基座低速时 99% CPU 警告的问题）；
*   GPU 优化：
    *   对 CSP 缓存纹理（如 WeatherFX 云层或新树的公告板）使用后台 BC7 压缩的选项；
    *   用后台 BC7 压缩重新编码压缩不当的 AC 纹理的选项，后续运行时加载更快、表现更好；
*   Graphics Adjustments：
    *   用碰撞体网格为所有车辆生成新的后备 LOD；
    *   限制只有一个 LOD 的车辆激活的 LOD A 数量；
    *   单屏与三屏模式下在场景之前渲染虚拟后视镜的选项（可能在折射与 ExtraFX 上带来轻微小毛病，但能省一点性能）；
*   按住 Shift 或 Alt 会停用 AC 系统绑定（如回放的 Ctrl+R），从而可将额外功能绑定到 Ctrl+Shift+R 之类；
*   车辆仪表中的选项，让车头灯轻微晃动；
*   新的音频调整，为更多音频事件加入混响，并略微增加原本无混响事件的混响量；
*   新任务栏更新：
    *   可折叠的分类；
    *   可选的精简模式，直接进入应用列表；
    *   可选的紧凑模式；
    *   滚动速度加快；
    *   支持旧版 CSP 任务栏的 Alt+H 快捷键；
*   新的内置音频应用取代原版，带预设与额外滑块；
*   移除了原版太阳轨迹，改用春分轨迹（2023 年 3 月 20 日），但 WeatherFX 样式与 Lua 应用可以更改中性太阳轨迹时间戳；
*   赛道音频滑块从 Track Adjustments 移到了 AC 音频设置，且同样作用于赛道 Lua 脚本；
*   将车辆重置与后退一步绑定到控制器按键；
*   CSP Debug 应用：
    *   点击赛道即可传送到所点位置的选项（单人练习会话）；
    *   车辆状态的保存与读取可绑定到控制器，即使应用关闭也有效；
*   默认 WeatherFX 样式：晴天时依据光污染配置加入少许污染雾霾；
*   新的 Traffic 竞速模式（需要带 `traffic-planner-ready` 标签的已配置赛道）；
*   Walking Out 模块从隐藏模块变为新的 Quick Drive 模式；
*   UI 动画稍快，且可完全禁用动画；
*   三屏模式可按边配置边距以微调 UI 位置，防止应用丢到可见区域之外，还能省一点 FPS；
*   针对 OpenVR 的实验性调整，推迟缓冲区交换，可能提升响应速度；
*   部分 CSP 资源被打包进 `dwrite.dll`，工作更可靠、加载稍快；
*   将累积 DOF 形状沿水平或垂直方向拉伸的选项；
*   网页浏览器引擎更新：来自 OBS CEF 仓库的几处安全修复，direct loop 模式下 FPS 不再被锁在 30；
*   窗口化 VR 的选项：捕获鼠标、强制 AC 窗口置顶，以防万一；
*   CSP 现在支持 CM 的全部系统热键，响应更快、修饰键逻辑更正确；
*   禁用季节时默认也禁用精确太阳轨迹（除非是联机比赛且服务器明确指定了日期）；
*   维修站加油时仪表盘显示的油量平滑增加；

## 配置

*   新增选项，为载荷敏感性 LUT 使用线性插值（取代默认的三次插值）；
*   会话（离线与联机皆可）可用 `[EXTRA_RULES] PITS_ORDER=F<TR>` 更改进站操作顺序（`F` 加油、`T` 换胎、`R` 维修，尖括号内的操作可并行，AC 默认行为为 `<FTR>`）；
*   Mumble 集成：新参数 `MUTE_DISTANCE`，与相机距离超过指定值的车辆音频完全静音；
*   在要求 2690 号或更新版本的服务器上，编辑过的车辆颜色可以重置；
*   服务器可要求 CSP 校验自身完整性；
*   车辆再添 4 个额外开关（G、H、I、J）；
*   车辆配置可指定切换附加项时显示的消息；
*   `ALTERNATIVE_PHYSICS_MESH_DETECTION` 选项现在也适用于未启用扩展物理的赛道；
*   线光源可用于车头灯、刹车灯等（会禁用部分附加功能如边缘或辅助聚光，但某些特殊情况可能用得上）；
*   赛道 .ksanim 动画不应再在重载时崩溃；
*   Traffic planner：几处修复、自动数据加载，新增车辆只需复制模型和带描述的 JSON 文件即可；
*   条件表达式：函数（如赛道条件中的 `INPUT = max(SUN, 45)`）之前不工作，现在应该可以了；
*   NeckFX 头盔参数可按车辆配置；
*   控制器的 `SCRIPT_…` 输入数量从 8 增加到 256；
*   修复了动画雨刮工具在动画未激活时显示 RainFX 痕迹的问题；
*   VAO 车内亮度调整也不再应用于 `smCarPaint` 着色器；
*   新的实验性赛道参数 `[VAO] WEIGHT_FACTOR=1`，用于更平滑地采样额外的 VAO 采样（默认值为 0.05，值越低暗部采样权重越小）；
*   Stereo 的 multimap 着色器可以自发光；
*   赛道配置可依据条件更改环境音量（默认已应用于 Kunos 赛道，让夜间更安静）；
*   挂在移动节点上的赛道灯光在移出约 2.5 km 后不再停止工作；
*   `[MESH_ADJUSTMENT_…]` 新增 `REMAP_UV`，加载网格时重做 UV（例如添加 Android Auto 的 MX5 配置就在用）；
*   折射玻璃更稳定，并新增彩色灯泡与内部法线偏置选项以防万一；
*   以防万一，车辆可在 `setup.ini` 中用 `[_EXTENSION] QUICK_MENU_WINGS_LABEL=…` 覆盖 `WINGS` 标签；
*   赛道遮挡墙：
    *   现在最多可同时激活 32 面墙，旧限制为 4 到 8 面；
    *   墙可用于渲染、音频或两者兼有；
    *   遮挡音频的墙可在工具内指定音量、混响增强与柔和度；
    *   用 `[AUDIO_OCCLUDERS] FADE_START=… FADE_END=…` 参数统一配置远离墙面时遮挡效果如何消退；
    *   临近的墙互相扩展，覆盖更高效；
    *   工具可以显示实际生效的墙；
*   用 `[AUDIO_DISTANT_OCCLUSION] DISTANCE=… FADING=…` 略微降低远处声源音量并添加混响，模拟总体遮挡（通用配置中已为 Kunos 赛道默认设置）；
*   即使相机在混响区域之外，也可用 `[AUDIO_DISTANT_OCCLUSION] REVERB_CONTRIBUTION=…` 为混响区域内的音频事件添加混响（同样已为 Kunos 赛道配置）；
*   修复了编辑车灯与自发光时偶发的异常与崩溃；
*   碰撞体现在可用刚度与阻尼而非 CFM/ERP 配置，甚至可用随深度变化的曲线。适用于带弹性底板的车辆（如 LMP2），或只是想更好地控制地面碰撞。文档将添加到 wiki；
*   VAO 环境光调整不再应用于已由配置设置环境光调整的物体；
