# 更新日志

## 新功能、选项与改进

*   Weather FX：附加方向性环境光的选项；
*   默认 Weather FX 脚本：
    *   修复了日落与日出，现在色调更暖；
    *   白天阳光有时饱和度更低；
    *   太阳刚落到地平线下时的额外光照层，带模糊阴影，模拟来自天空的近似方向性光照；
    *   云纹理重做（不过还需要更多工作），种类增加；
    *   整体上，云材质与光照，尤其是月光下的，已重新调整；
    *   天空颜色与亮度重新调整；
    *   现在有了自己的仓库，欢迎用作基础：[https://github.com/ac-custom-shaders-patch/acc-weatherfx-base](https://github.com/ac-custom-shaders-patch/acc-weatherfx-base)；
*   树木与草地上的阴影现在不应再闪烁；
*   Smart Mirror：
    *   不启用它时后视镜也有正确的亮度；
    *   加载时对后视镜映射进行规范化的选项，修复倾斜或拉伸的反射（默认启用）；
    *   用虚拟后视镜禁用 Real Mirrors 的选项；
    *   若 Real Mirrors 的顶部后视镜缺失，虚拟后视镜会在可用时同时显示左右后视镜；
    *   简单倾斜现在默认禁用，设置已重新整理；
*   自定义自发光现在可以控制数字仪表的颜色；
*   动态旗帜改进，包含大量修复、新的运动方式、带背光与可选细分的新着色器；
*   修复了降低雨刮速度的按钮；
*   Wine 下的轮胎音频不再损坏；
*   透明物体现在可以投射阴影；
*   折射玻璃：
    *   光线追踪重做，提升质量与性能；
    *   同一辆车共享贴图（可选）；
    *   颜色遮罩效果更好的新公式（旧设置下禁用）；
    *   无自定义灯泡的多通道模式，内部使用多通道自发光的映射；
    *   通过钳制最大 mip 级别，修复了随距离变平的问题；
    *   其他优化与修复；
*   Extra FX 反弹光：
    *   距离与分辨率提高（可能稍重一些）；
    *   模糊与保真度改进；
    *   修复了竖线毛刺；
    *   车内不再发光；
*   新选项 `[BASIC] IGNORE_OTHER_CONFIGS=0`（默认值为 0），让车辆忽略已加载的配置；
*   新选项 `[BASIC] HAS_CORRECT_COCKPIT_NODE=1`（默认值为 1），为部分 mod 禁用车内效果；
*   新的 Python 函数 `ac.ext_isVirtualMirrorForced()`；
*   使用 `ac.getCarRealTimeLeaderboardPosition()` 导致回放崩溃的 Python 应用不应再崩溃了；
*   从压缩包中移除重复着色器以减小体积；
*   加载画面：幻灯片放映的新选项（目前还没有花哨的过渡效果）；
*   PBR 着色器：修复了动态光源；
*   支持 CM 自动为车辆加载 vertex AO；
*   自定义自发光模板：正确工作的前后雾灯 mixin（需要设置位置）；
*   一些小修复；
