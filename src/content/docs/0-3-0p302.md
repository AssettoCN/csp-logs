# 更新日志

## 新功能、选项与改进

*   新功能：
    *   新 P2P 1v1 比赛模式：通过点对点连接与好友比赛，无需搭建服务器；
    *   实验性支持客户端指定车辆的服务器以及实时更换车辆涂装（部分功能暂不可用，CM 更新即将推出）；

*   物理：
    *   `Extra contact points` 实验回归并默认启用，不再横向移动接触点，因此不会影响 FFB；
    *   新物理实验：为赛道物理物体优化碰撞体；
    *   新物理实验：调校无显式配置的赛道物理物体（重心修正、一点阻尼、一点摩擦）；
    *   新物理实验：统一全 Assetto Corsa 的维修区检测阈值（在线可用 `[PHYSICS_EXPERIMENTS] EQUALIZE_PITS_CHECK=1`）；
    *   常规设置新选项，禁止 AI 或 Physics API 使圈速无效；
    *   自动 Sine→Perlin 升级（仅影响无效路面）现在改为升级到 Simplex；
    *   程序化路面噪声更好地处理多条轮胎光线；
    *   其他若干针对程序化噪声路面表面的改进（更好的车辆放置、更好的地面平面计算）；
    *   修复车辆在某些路面上偶发爆炸的问题；

*   AI：
    *   7 km/h 以下时（物理上的）转向更平滑；
    *   修复轨迹问题（`cautious steering` 调整在捣乱）；
    *   AI 调试应用现在显示实际 AI 输入而非平滑后的；
    *   如果 `Tweak autopilot switching` 选项被禁用，AI 输入平滑及其他一些调整仍会正常工作；
    *   `RACK_TRAVEL_LUT` 在自动驾驶下也停止工作（此前为安全起见对 AI 停用，但自动驾驶不行，导致测试更麻烦）；

*   扩展赛道物理：
    *   赛道物体物理参数新增 `COG_OFFSET=AUTO`，应用重心修正；
    *   移除自定义赛道物体碰撞体参数中的 `COLLIDER_DEBUG`，替换为 CSP Debug 应用中的复选框；
    *   赛道路面新增 `_EXT_PERLIN_NOISE=SIMPLEX`，使用 Simplex 噪声（基本上是 Perlin 但更好一点）；

*   音频：
    *   新音频调整：牵引力控制强度用于其音量（默认启用）；
    *   撞击的碰撞音频不再被切断，而是实时创建新事件；
    *   CSP 不再为纯刮擦碰撞播放撞击音频，或为撞击碰撞播放刮擦音频；
    *   CSP 环境音完全不受多普勒频移影响；
    *   Mumble 语音聊天：禁用说话或聆听时的音量淡出；

*   新主菜单：
    *   更好的设置项标题（如果漏掉什么缩写请告诉我）；
    *   如果任何设置标签页标题含有小写字母，CSP 不再调整大小写；
    *   排行榜使用自定义车手图标（如果设置了）；
    *   改进已禁用设置项的外观和行为；
    *   修复设置标签页的滚动；
    *   `EXT_VISIBLE_WITH` 从一开始就生效，不再等待某些东西变化；
    *   修复隐藏标签页，不再能被选中；
    *   标签页重置支持更多类型的标签页；
    *   在主菜单中按住 Shift 点击车辆预览，可在单人会话中更改颜色；

*   其他 UI 变更：
    *   修复警告图标（左上角那些）和比赛旗帜的位置；
    *   可选禁用警告图标和隐藏比赛旗帜，默认图标随 Ctrl+H 隐藏；
    *   `Center UI` 选项新增变体，同时居中应用栏（和任务切换器）；
    *   新暂停菜单：按钮不再被拍照模式裁剪，菜单被移到屏幕下半部分时按钮会下移；
    *   最近加入的辅助系统编辑器变为可选，可设置关闭；
    *   主菜单打开时发车灯上移；

*   默认 Weather FX 风格：
    *   调整亮度；
    *   白色参考点考虑后处理曝光，确保不同条件下亮度一致（仅限 LCS）；
    *   雾的蓝色调略减；
    *   虚拟后视镜中的眩光减少；

*   粒子：
    *   碎片和火花粒子：与赛道的碰撞改进，火花使用局部高度图，修复火花与车辆碰撞异常的问题；
    *   烟花使用加法混合；
    *   调整烟雾行为，位置方差不再适用于大多数烟雾类型；
    *   修复赛道配置中火焰强度大于 1 时火焰粒子的速度；
    *   调整粒子尺寸：碎片有小概率变大，火焰在高速时更大；

*   Grass FX：
    *   局部随机化不再随原点偏移而跳变；
    *   着色改进；
    *   修复 OpenVR 模式下原点偏移时草地消失一帧的问题；

*   CSP Debug 应用：
    *   修复显示赛道物理物体轮廓的复选框；
    *   拖动改进：力经临界阻尼防止振荡，可同时拖动多辆车，赛道物理物体也可拖动；
    *   点击传送与拖动合并，可调整车辆朝向；
    *   拖动工具还支持推或拉车辆；

*   多幽灵热圈：
    *   使用 AI 完成的圈（通过新选项禁用了 AI 圈速无效化）会被标记；
    *   修复将最佳记录复制到 AC 原本存储幽灵的位置，现在包含布局 ID；

*   杂项：
    *   VR 调整：`Custom VR HUD` 和 `Skip post-processing` 选项默认启用（这样效果要好得多，而且也兼容 LCS）；
    *   AC 不再因空的 `aero.ini` 报错；
    *   其他致命 AC 错误得到正确显示；
    *   启用自定义运动时，远程车辆的爆胎影响车轮定位；
    *   远程车辆：前轮角度有了极小的平滑，改进方向盘角度范围的修复；
    *   如果 Lua 脚本做某事超过一秒，CSP 会显示警告；
    *   如果缺少国家名称，聊天中该国旗的工具提示将被隐藏；
    *   Nice Screenshots：累积 HDR 求和被标记为与可脚本化滤镜不兼容，滤镜激活时会暂停；
    *   `ek_akina_snow` 的雪/冰定义；
    *   修复 `rt_lime_rock_park` 的时区，添加了朝向角；
    *   核心少于四个或多线程被禁用时，AC 计时得到改进；
    *   复古可脚本化滤镜：小更新以减少抖动；
    *   改进 `Show important steering wheels` 调整；
    *   修复并改进了让动态物体气球随风移动的旧调整；
    *   略微改进任务栏关闭行为；
    *   `Disable Steam interface` 选项重命名并重置，以防有人误启用（现在 CSP 不再提供激活它的选项）；
    *   Neck FX 更改 FOV 时会暂时暂停拍照应用的 FOV 滑块，让两者更好地协作并修复一些与其他组件的问题；
    *   切换虚拟后视镜的热键可以更改（允许绑定 F… 键的 CM 更新即将推出）；
    *   Steam 覆盖层激活时停止 IMGUI 的鼠标悬停效果；
    *   启用 CSP 火焰后，原版火焰不再浪费时间寻找纹理；
    *   渲染调试：新选项，在 D3D11 错误时强制生成信息丰富的崩溃；
    *   崩溃报告默认为详细模式，紧凑版没什么用处；

## 配置

*   车辆与赛道配置：
    *   新增 `[TYRES_FX] RADIUS_OFFSET` 参数，允许更改轮胎的视觉半径；
    *   玻璃材质：新 `NormalMapUVMult` 参数；
    *   Brake Disc FX：调整 `CERAMIC` 默认值的计算，降低出现频率；
    *   车辆配置实时重载的几项改进；
    *   修复 `BLIND_SPOT` 车辆输入和 `ac.getCarBlindSpot()`，现在同时返回与前车（Z）和后车（W）的距离；
    *   数字仪表的 `[DATA] DI_…_…` 修饰符可使用 `BASE` 替代索引，作用于全部仪表；
    *   `[DATA] DI_…_ALPHA` 也影响第一版文本节点；
    *   赛道状况工具也显示输入值；
    *   新增 `[BASIC] SEASONS_DEACTIVATION_AWARE=0`，修复那些在禁用季节变化时不期望 `YEAR_PROGRESS` 为 -1 的赛道，除 `dousojin_touge` 和 `dousojin_touge_1990` 外默认启用；
    *   改进了赛道物体碰撞体的包围盒猜测（尝试用盒子替换网格，用于自定义赛道物理）；

*   在线服务器扩展配置：
    *   使用 `[CUSTOM_PHYSICS] EXTRAPOLATE_STATE=1, 1, RAW` 尝试避免抖动的新方案；
    *   使用 `[CUSTOM_PHYSICS] SMOOTHING_FACTOR=100` 让远程车辆的运动更干脆、更少平滑（值越低越平滑，默认值为 250）；
    *   添加 `[EXTRA_DATA] VR=1` 同步使用 VR 的车手状态（需要 AssettoServer）；
    *   使用 `[EXTRA_RULES] ALLOW_PITS_JUMP=1` 允许在维修区内按住 Ctrl 点击车辆预览进行跳跃；
    *   设置 `[PHYSICS_EXPERIMENTS] EQUALIZE_PITS_CHECK=1` 统一 AC 检查车辆是否在维修区的阈值（实验性）；
    *   跳跃限制略有改进，对左右跳动更敏感，默认时间从 5 秒减至 2 秒，只有车辆与其他车相交时才闪烁，通过 Physics API 禁用碰撞后车辆不再闪烁；
