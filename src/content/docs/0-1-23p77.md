# 更新日志

## 新功能、选项与改进

*   Real Mirrors：
    *   新的 `SHOW_HEAD` 与 `VR_LOCK` 选项；
    *   新的 `ac.ext_mirrorParams()` 函数；
    *   若干修复；
*   字体渲染进一步重做，应该能让 AC 跑得快一点（个别情况下可能略有崩溃风险，如遇崩溃请把崩溃日志发给我）；
*   Python 应用现在可以使用额外选项，例如细体或超细字体，参见 `AccExtHelper.py`；
*   新的自定义加载画面扩展，配置在 `splashscreen.ini`（目前对特殊长宽比支持不佳，且在三屏模式下禁用，明天会更新）：
    *   所选赛道的详细信息；
    *   现在 AC 会尽量响应输入事件，加载期间不再那么容易卡死，可以重新获得焦点或用 Alt+F4 关闭；
*   修复了灯光在色彩丰富的条件下偶发消失的问题；
*   修复了材质调整的 Off 值；
*   修复了车辆灯光的推测与绑定；
*   新的 `FLASHING_LUT` 选项，用于更特定或彩色的闪烁；
*   新的 `FLASHING_SMOOTHNESS=LINEAR` 值；
*   新的 `FLASHING_SKIP_DOWNHILL_STATE` 选项；
