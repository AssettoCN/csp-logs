# 更新日志

## 新功能、选项与改进

*   全新的 FFB 后处理脚本，彻底替代 FFB；
*   新的优化（实验性，默认禁用）：
    *   推迟可选功能，防止卡顿；
    *   超线程修复（尝试让物理运算远离负责渲染的核心）；
    *   GPU 优化，加快 GPU→CPU 数据传输；
*   MoTeC 记录器：新增空气速度与 Cosmic 悬架力；
*   Drift Challenge 更新到 1.1；
*   Physics experiments：
    *   针对单帧生命周期碰撞的全新碰撞检测逻辑；
    *   与车辆物理并行计算物理碰撞的新选项；
    *   实验项 `Repair wheel joints` 与 `Fix ground colliders` 从实验升级为定案的常驻调整，现在可在联机中使用；
*   Graphics Adjustments/LOD：
    *   实验性选项，为次要车辆彻底跳过 LOD A，默认禁用；
    *   实验性选项，基于 Tyres FX 的 `VISIBLE_IN_INTERIOR_CAM` 参数为车内视角隐藏车轮（对开放式车轮车辆生效）；
*   Smart Shadows：
    *   为树木阴影使用各向异性过滤的选项；
    *   自动分割时，为第一人称视角禁用锐利车内阴影的选项；
*   新的 Loading screen：
    *   可隐藏某些组件的选项；
    *   可使用 Lua 脚本彻底替换外观的选项，附一个基础脚本作为示例；
*   New Behavior：
    *   修复 AI 升挡阈值的选项现在默认启用（适用于升挡阈值高于 `limiterThreshold - 100` 的车辆）；
    *   更改 AI 降挡阈值的新选项（若升挡阈值已被更改则默认激活），会考虑齿比；
    *   非常实验性的 AI 调整，为 AI 增加一些差异与适应，尽量让它们在可能时快上一点；
*   Nice Screenshots：
    *   累积时使用实际 HDR 或估算 HDR 的选项，以获得真正正确的结果（使用分辨率倍率时实际 HDR 不可用）；
    *   对图像稍作预模糊的选项，以改善累积 DOF 的效果；
    *   变形宽银幕 DOF 的选项（散景看起来像径向模糊）；
    *   DOF 色差的选项（仅限 DOF）；
    *   与 DOF 相关的选项可在照片应用中调整，包括快速启用累积 DOF 的功能；
    *   为截图使用按车辆立方体贴图的选项，反射更准确；
    *   按 `enter` 可停止截图累积，若效果已足够好则保存结果；
    *   无运动模糊的累积 DOF 会将偏移从小到大排序，DOF 随累积增强，但观感始终不错；
    *   累积阴影：单一滑块改为独立滑块，并基于迭代次数实时调整，默认设置与正常的太阳角直径相符；
    *   为反射立方体贴图添加累积 AA 的选项；
*   默认 Weather FX 样式：修复了 LCS 下的太阳光束，流星的出现几率略有提高；
*   GUI：在暂停菜单中启用应用的选项（将使用第五个游戏内桌面，作为专用应用布局）；
*   若车辆没有专用闪光灯，原版 AC 的 `Flash Headlights` 绑定现在会闪烁常规大灯；
*   Grass FX 着色更新，增添了更多深度与强度；
*   通用：为 AC 明确指定所用互联网连接的选项（适用于联机、`web.` API 与 Mumble 客户端）；
*   Render Stats 应用：三个核心分组的测量（相加后与整帧 CPU 和 GPU 时间接近得多），测量层级已修复；
*   加载期间，对主板固件未更新的 Intel Gen13/14 CPU 显示警告（检测是用 ChatGPT 做的，我手头的硬件没法测试，但也许能用）；
*   自定义 VR HUD：跟随头显的实验性选项；
*   Windscreen FX：为外部视角的风挡添加反射的选项（主要是为了开门时玻璃内侧的观感）；
*   CSP 版本变更时清除部分 CSP 缓存的选项（默认启用）；
*   Mumble 客户端：音量滑块上限从 100% 提高到 200%；
*   Android Auto：浏览器现在应该能拦截一些广告了；

## 配置

*   车辆：
    *   `[AUDIO] MIX_EXTERIOR_AUDIO_OUTSIDE=1`，用于需要将外部音频与内部音频混合的车辆（仅当车辆来自 Kunos 且非赛车时默认为 `1`）；
    *   覆盖数字仪表颜色（原文未完成，TODO）；
    *   使用 `[HIDING_NODES] INTERIOR=… EXTERIOR=…` 为车内与外部视角隐藏特定几何体；
    *   车灯新增 `DISTANT_GLARE` 参数（默认为 `1`，设为 `0` 可禁用 0.2.6 中新增的远处眩光）；
    *   车灯新增 `RAW_RANGE` 参数，阻止 CSP 钳制范围（请仅在特殊场合使用，比如直升机探照灯；如果有太多车辆带着过于夸张的大灯配置，我就只能开始忽略它了）；
    *   修复了导航仪的 `USE_SATELLITE_VIEW_BY_DEFAULT` 参数；
    *   修复了轮胎花纹的实时编辑；
*   车辆与赛道：
    *   `[SHADER_REPLACEMENT_…]` 新增 `LINK_KS_VALUES = 1` 标志，将 ksAmbient 与 ksDiffuse 一同同步（对大型赛道表面应该很有帮助）；
*   联机服务器：
    *   新增 `[EXTRA_TWEAKS] RESET_DISCONNECTED_NAMES=1`，强制 CSP 在车手加入时清除已断开车手的名称；
    *   新增 `[EXTRA_TWEAKS] RESET_RECONNECTED_LAPTIMES=1`，若新连接车手的名称不同，强制 CSP 清除其单圈时间；
    *   新增 `[EXTRA_RULES] SLIPSTREAM_SPEED_FACTOR=…` 会话调整，可更改尾流距离（默认值为 0.5）；
    *   若要求的 CSP 版本高于 3303，即可在扩展服务器配置中使用 `[PHYSICS_EXPERIMENTS] ALT_COLLISIONS_HANDLING/ALT_COLLISIONS_PROCESSING`；
*   Objects Inspector：第 N 次 Alt+点击会显示该点与第 (N-1) 次点击之间的距离；
*   定位辅助（那些用来移动物件的箭头和圆圈）现在在鼠标悬停于 UI 上或使用 F5 相机时不活跃；
*   禁用纹理后，也应会禁用动态车辆与赛道纹理以及其他一些视觉效果；
*   烘焙赛道 VAO 时，AC 不再要求 Abarth 500 存在才能导出树木；
